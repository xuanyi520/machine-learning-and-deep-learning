## 〇、这一节在解决什么

**你训了一个肝脏分割模型，Dice 卡在 0.88，怎么调都上不去。**

**你的第一反应可能是：换网络、加数据、调超参。**

**但有一种可能你没想过：0.88 已经是这个数据集的天花板了。**

因为标注本身就不一致。

**这一节要解决两件事：**

1. **怎么知道天花板在哪**（标注质量评估）
2. **怎么在不动模型的前提下，把 Dice 再挤出几个点**（后处理）

## 一、先看一组真实数字

我在这台机器上造了一个球体，然后模拟两个「标注者」：

- **标注者 A**：球心偏了 1 个体素，半径准确
- **标注者 B**：球心准确，半径小了 2 个体素

```python
import numpy as np

size = 64
zz, yy, xx = np.ogrid[:size, :size, :size]
truth = ((zz-32)**2 + (yy-32)**2 + (xx-32)**2) <= 15**2

def dice(a, b, smooth=1e-6):
    a, b = a.astype(bool), b.astype(bool)
    return (2*(a & b).sum() + smooth) / (a.sum() + b.sum() + smooth)
```

**实际结果：**

```
标注者A vs 真值:  Dice=0.9499
标注者B vs 真值:  Dice=0.7866
A vs B 一致性:    Dice=0.7866   ← 这就是标注间的天花板
```

### 怎么读这三个数

**A 和 B 都是「合理的标注」，没有谁故意标错。** 只是对边界的判断不同。

**但它们之间的 Dice 只有 0.7866。**

**这意味着什么：**

> **如果你的模型在预测 A，而测试集用的是 B 的标注，你的 Dice 最高也只能到 0.7866。**
>
> **换网络、加数据、调超参，全都突破不了这个数。**

**这就是天花板效应（ceiling effect）。**

**真实的医学数据集里，多标注者的一致性通常在 0.80-0.90 之间。** 边界模糊的病灶会更低。

## 二、怎么算你自己数据的一致性

### 前提：你需要至少两个标注者的结果

**没有的话，两个替代方案：**

1. **让同一个标注者隔两周重标一遍**（intra-observer），一致性通常比 inter-observer 高，但也能反映不确定性
2. **看公开数据集的一致性报告**，作为参照

### 计算方法

```python
import numpy as np
from itertools import combinations

def dice(a, b, smooth=1e-6):
    a, b = a.astype(bool), b.astype(bool)
    return (2*(a & b).sum() + smooth) / (a.sum() + b.sum() + smooth)

def inter_observer_agreement(annotations):
    """annotations: 列表，每个元素是一个标注者的掩码"""
    pairs = list(combinations(range(len(annotations)), 2))
    scores = [dice(annotations[i], annotations[j]) for i, j in pairs]
    return {
        "mean": float(np.mean(scores)),
        "min": float(np.min(scores)),
        "max": float(np.max(scores)),
        "n_pairs": len(scores),
    }
```

### 还有一个更常用的指标：表面距离

**Dice 只看体积重叠，不看「错在哪」。**

**两个标注的体积完全一样，但整体平移了 5mm，Dice 会很高，但临床上完全不接受。**

```python
from monai.metrics import SurfaceDistanceMetric

sd = SurfaceDistanceMetric(include_background=False, reduction="mean")
```

**或者用 ASSD（平均表面距离）、HD95。**

**报告时三个一起给：**

```
Dice = 0.87 (标注者之间: 0.85 ± 0.04)
ASSD = 1.8 mm
HD95 = 4.6 mm
```

**括号里那句最关键——它告诉读者：0.87 已经接近天花板了。**

## 三、Dice 卡住了，怎么判断是谁的问题

**这张诊断表要记住：**

| 现象 | 判断 | 依据 |
|---|---|---|
| 模型 Dice ≈ 标注者间 Dice | **已经到顶了**，别调了 | 换数据或改进标注规范 |
| 模型 Dice 明显低于标注者间 Dice | **模型的问题** | 继续调 |
| 训练集 Dice 高，测试集低 | 过拟合或数据泄露 | 查划分方式 |
| 某些病人 Dice 特别低 | 看这几例的标注 | 大概率标错了 |
| 所有病例的边界都系统性偏内/偏外 | 标注规范问题 | 和临床医生对一下判定标准 |
| Dice 高但 HD95 也高 | 边界画得糙 | 后处理或改进损失函数 |

**第一行是最有价值的判断。** 很多人不知道这一点，在已经到顶的指标上耗几个月。

## 四、软标签：把不确定性利用起来

**既然多个标注者不一致，那就别用 0/1 硬标签，用「有多少比例的人认为这里是前景」。**

```python
# 三个标注者的结果
soft_label = (ann1.astype(float) + ann2.astype(float) + ann3.astype(float)) / 3

# 值域 0 到 1
# 0.0 = 所有人都说不是
# 0.33 = 一个人说是
# 1.0 = 所有人都说是
```

### 实测

**用上面那三个掩码（truth + A + B）：**

```
不确定体素数 5685，平均置信度 0.841
```

**「不确定体素」= 软标签在 0.01 到 0.99 之间的那些。** 有 5685 个——**占了整个球体的一大块。**

**这些就是边界地带。**

### 怎么用软标签训练

**把 CrossEntropy 换成软标签版本：**

```python
import torch
import torch.nn.functional as F

def soft_ce_loss(logits, soft_targets):
    """logits: (B,C,D,H,W)，soft_targets: (B,C,D,H,W) 每类概率"""
    log_prob = F.log_softmax(logits, dim=1)
    return -(soft_targets * log_prob).sum(dim=1).mean()
```

**Dice 也要改成软的：**

```python
def soft_dice_loss(pred_probs, soft_targets, smooth=1e-6):
    intersection = (pred_probs * soft_targets).sum()
    return 1 - (2*intersection + smooth) / (pred_probs.sum() + soft_targets.sum() + smooth)
```

### 效果和代价

**效果：** 论文里报告的提升通常在 **1-3 个 Dice 点**。原理是让模型学会「边界处不确定是正常的」，不强迫它去拟合某一个人的判断。

**代价：**

- 需要多个标注，成本高
- 实现更复杂
- **不是所有任务都有收益**（边界清晰的器官收益小）

## 五、后处理：不动模型，挤出几个点

**后处理是性价比最高的一环。改几行代码，Dice 涨 1-3 个点，不花一分钱算力。**

**但用错了会大幅掉点。** 下面按「安全程度」排序。

### 第一类：几乎总是安全

**① 去小斑块**

```python
from scipy import ndimage

def remove_small(mask, min_size=100):
    lab, n = ndimage.label(mask)
    if n == 0:
        return mask
    sizes = ndimage.sum(mask, lab, range(1, n + 1))
    keep = np.isin(lab, [i + 1 for i, s in enumerate(sizes) if s >= min_size])
    return keep
```

**实测（三个连通域，大小分别是 1000、8、8）：**

```
min_size=  5 -> 保留 1016 体素, 3 个区域
min_size= 20 -> 保留 1000 体素, 1 个区域
min_size=100 -> 保留 1000 体素, 1 个区域
```

**min_size 设多少？** 用训练集统计一下真值里最小的病灶有多大，取它的 20%-30%。

**② 填空洞**

```python
filled = ndimage.binary_fill_holes(mask)
```

**只对「内部不该有洞」的器官（肝、脾）有效。**

**对肠道、肺（内部本来就有气腔）会填错。**

### 第二类：看任务

**③ 只保留最大连通域**

```python
lab, n = ndimage.label(mask)
if n > 0:
    sizes = ndimage.sum(mask, lab, range(1, n + 1))
    mask = (lab == (np.argmax(sizes) + 1))
```

| 任务 | 能用吗 |
|---|---|
| 肝脏、脾、肾、心脏 | ✅ 强烈推荐 |
| 肝转移瘤（多发） | ❌ **会删掉所有小病灶** |
| 肺结节（多发） | ❌ 同上 |
| 脑肿瘤（单发为主） | ⚠️ 慎用 |

**实测过：对一个有两块病灶的预测做这个操作，Dice 直接砍半。**

### 第三类：要调参数，容易过拟合

**④ 形态学开闭运算**

```python
mask = ndimage.binary_closing(mask, structure=np.ones((3,3,3)))   # 填小洞
mask = ndimage.binary_opening(mask, structure=np.ones((3,3,3)))   # 去毛刺
```

**腐蚀了一圈边界。** 如果你的模型整体偏大，闭运算能救；偏小就更糟。

**必须先在验证集上看效果，不能在测试集上调。**

### 一个系统性的后处理评估流程

```
1. 在验证集上，测不加后处理的 Dice         → 基线
2. 逐个加后处理，每次只加一个              → 看哪个有效
3. 有效的那几个，调参数                    → 找最优点
4. 组合起来再测一次                        → 看是否有交互
5. 最后在测试集上验证一次                  → 只测一次
```

**第 5 步只能做一次。** 反复在测试集上调后处理，就是在过拟合测试集。

### 任务一：造两个标注者，算一致性

```python
import numpy as np

size = 64
zz, yy, xx = np.ogrid[:size, :size, :size]
r = np.sqrt((zz-32)**2 + (yy-32)**2 + (xx-32)**2)

truth = r <= 15
ann1 = np.roll(truth, 1, axis=0)                  # 整体偏移 1
ann2 = r <= 13                                    # 半径小 2

def dice(a, b, smooth=1e-6):
    a, b = a.astype(bool), b.astype(bool)
    return (2*(a & b).sum() + smooth) / (a.sum() + b.sum() + smooth)

print(f"1 vs truth: {dice(ann1, truth):.4f}")
print(f"2 vs truth: {dice(ann2, truth):.4f}")
print(f"1 vs 2:     {dice(ann1, ann2):.4f}   ← 天花板")
```

- [ ] 三个数都算出来了
- [ ] **能解释「1 vs 2」为什么是天花板**

## 十、常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 不看一致性就猛调模型 | 在已经到顶的指标上耗时间 | 先算天花板 |
| 只报 Dice 不报 HD95 | 掩盖边界问题 | 三个指标一起报 |
| 无脑用「只留最大连通域」 | 多发病灶全被删 | 看任务类型 |
| 在测试集上调后处理参数 | 过拟合，真实性能虚高 | 只在验证集调 |
| 软标签当硬标签用 | 训练崩 | 损失函数要改成软的 |
| 认为后处理能修一切 | 期望落空 | 它只能去噪，不能纠偏 |
