## 三、毕业项目：肝肿瘤分割对比研究

**这是整个模块的终点。**

```
数据：LiTS（肝脏肿瘤分割挑战赛数据集）
    │
    ├─ 实验 A：nnU-Net 官方配置跑 baseline
    ├─ 实验 B：SwinUNETR（MONAI 自带）
    ├─ 实验 C：从零写的 3D U-Net（你自己的）
    │
    ├─ 统一评估：Dice、IoU、HD95，按病人分组
    ├─ 失败案例：至少 8 例，逐例归因
    └─ 部署：导出 ONNX，对比推理速度
```

**为什么选肝肿瘤而不是别的：**

1. **和你的科研方向对得上**（肝癌早筛、门脉高压都是你接触过的）
2. 肿瘤分割比器官分割难得多（Dice 从 0.93 掉到 0.65），**「难」才有讨论空间**
3. 三个模型对比，天然形成一篇复现报告

## 五、硬件约束（必须先说清楚）

**你的机器：RTX 5060 Laptop，8 GB 显存，32 GB 内存。**

| 任务 | 8 GB 能做吗 | 建议配置 |
|---|---|---|
| 2D 分割训练 | ✅ 轻松 | batch 32，256×256 |
| 3D patch 训练（96³） | ⚠️ 勉强 | batch 1-2，AMP 必开 |
| 3D patch 训练（128³） | ❌ 会 OOM | 降到 96³ 或 64³ |
| nnU-Net 3D 全配置 | ❌ 会 OOM | **只用 2D 配置，或改 patch 大小** |
| SAM 推理 | ✅ 可以 | 用 ViT-B 版本，不用 ViT-H |
| SwinUNETR 训练 | ⚠️ 小 patch 可以 | 96³，batch 1 |

**这一条决定了你在 18-1 和 18-5 里能做什么。**

**不要硬上 3D 128³。** 会跑一晚上然后 OOM 掉，白烧电。

## 七、学习方式

**这个模块和模块 16 不同：16 是「先跑通再理解」，这个模块是「先理解再跑」，因为跑一次要几小时，理解错了就是几小时的浪费。**

### 三条执行纪律

**① 每个训练脚本，先用 10 张图跑 2 个 epoch 验证能跑通，再上全量。**

```
先验证：数据加载对不对、loss 会不会降、显存够不够
再训练：跑一次几小时的正式实验
```

**这个习惯能省掉你一半的调试时间。**

**② 每次实验必须记录配置**

```python
config = {
    "patch_size": (96, 96, 96),
    "batch_size": 2,
    "lr": 1e-4,
    "epochs": 100,
    "amp": True,
}
```

**不记配置，两周后你看到 results 文件夹里一堆数字，完全不知道自己跑的是什么。**

**③ 所有 Dice 必须带「按病人分组」的说明**

**按切片随机划分 = 数据泄露**（同一个病人的相邻切片会同时出现在训练集和测试集），**Dice 会虚高 5-10 个点。** 模块 5 讲过的病人泄露，在 3D 分割里更致命。
