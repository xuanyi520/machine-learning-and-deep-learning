## 一、导数：变化率

导数回答一个问题：**我稍微动一下输入，输出会变多少？**

```
f(x) = x²
f'(x) = 2x
```

`f'(3) = 6` 的意思是：在 x=3 这个位置，x 每增加一点点，f 大约增加 6 倍的那么一点点。

为什么"大约"？因为导数会变。在 x=3 处导数是 6，在 x=10 处导数是 20。导数本身就是个随 x 变化的函数。

### 三个你只需要记住的导数

| 函数 | 导数 |
|---|---|
| `x²` | `2x` |
| `xⁿ` | `n·xⁿ⁻¹` |
| 常数 `c` | `0` |

再加一条最常用的：**和函数 `f + g` 的导数，就是各自导数相加**。

够用了。

***

## 二、偏导数：多个输入的时候

现实中函数往往有多个输入，比如损失函数依赖 W 和 b 两个参数。

**偏导数 = 只动一个变量，其他当常数。**

```
f(x, y) = x² + 3y

∂f/∂x = 2x        （把 y 当常数，3y 的导数是 0）
∂f/∂y = 3         （把 x 当常数）
```

符号 `∂` 读作"偏"，只是提醒你"这里有多个变量，我只动了一个"。

***

## 三、梯度：把偏导数打包成一个向量

```
∇f = [∂f/∂x, ∂f/∂y]
```

梯度是一个向量，每个位置是对应变量的偏导数。

**梯度的核心意义（背下来）：**

> 梯度指向函数**上升最快**的方向。
> 所以沿**负梯度**方向走，函数下降最快。

这是梯度下降的全部理论基础。

### 一维的时候最容易理解

`f(x) = x²`，导数 `f'(x) = 2x`。

- 在 x = 5 处，导数 = 10，是正数 → 往右走函数会变大 → 所以要往**左**走（负方向）
- 在 x = -5 处，导数 = -10，是负数 → 往右走函数会变小 → 所以要往**右**走（正方向）
- 在 x = 0 处，导数 = 0 → 到底了，不用动

**看：不管在哪，往 `-f'(x)` 的方向走，都是在往谷底走。**

这就是为什么更新公式是 `x = x - 学习率 × 导数`。那个减号不是随便写的。

***

## 四、梯度下降

训练模型就是找一个函数的最小值。函数太复杂，求不出解析解，所以用"一步步往下走"的办法：

```
重复很多次：
    算出当前位置的梯度
    往反方向挪一小步
```

公式：

```
w = w - lr * grad
```

`lr` 是学习率（learning rate），控制每步挪多远。

### 学习率的直观理解

想象你在下山：

- **lr 太小**：步子太小，走一万步还在半山腰。训练慢到无法忍受。
- **lr 太大**：一步跨过山谷，直接冲到对面山上，来回震荡甚至越走越高（loss 爆炸成 nan）。
- **lr 合适**：稳步下降，十几步就到底。

**这就是为什么你以后会看到 loss 曲线不下降、或者变成 nan。** 那不是玄学，是学习率的问题。

***

## 五、链式法则（反向传播的全部秘密）

复合函数的导数：

```
y = f(g(x))
dy/dx = f'(g(x)) · g'(x)
```

翻译成人话：**一层一层往外乘。**

例子：

```
y = (3x + 1)²
```

拆开：令 `u = 3x + 1`，则 `y = u²`。

```
dy/du = 2u
du/dx = 3
dy/dx = 2u · 3 = 6(3x+1)
```

验算 x=1：`y = (4)² = 16`，`dy/dx = 6*4 = 24`。

**这就是反向传播。** 神经网络就是很多层函数套在一起，求梯度时从最后一层往前，把每层的导数一路乘回来。"反向"这个词就是这么来的。

你现在只需要理解这个概念，第 8 周 PyTorch 会帮你自动做这件事。

## 六、跟着做：数值梯度验证

这是个非常重要的技能——**当你不确定自己手算的导数对不对，用程序验一下。**

原理：导数的定义就是"变化率"，那用一个小小的增量 h 去逼近它就行。

```python
import numpy as np

def f(x):
    return x**2 + 3*x + 1

def numerical_grad(f, x, h=1e-5):
    """用数值方法求导： (f(x+h) - f(x-h)) / 2h """
    return (f(x + h) - f(x - h)) / (2 * h)

def analytic_grad(x):
    """手算的导数： f'(x) = 2x + 3 """
    return 2*x + 3

for x in [-2.0, 0.0, 1.5, 3.0]:
    num = numerical_grad(f, x)
    ana = analytic_grad(x)
    print(f"x={x:5.1f}  数值={num:9.5f}  手算={ana:9.5f}  差={abs(num-ana):.2e}")
```

会看到两者几乎完全一样（差在 1e-10 量级）。**这个 `numerical_grad` 以后你写自己的模型时会反复用到**，它是检验你实现对不对的标准工具。

## 七、跟着做：手写梯度下降

找 `f(x) = (x - 3)² + 2` 的最小值。肉眼能看出最小值在 x = 3 处，值是 2。我们要让程序自己找出来。

```python
import numpy as np

def f(x):
    return (x - 3)**2 + 2

def grad(x):
    return 2*(x - 3)

x = -10.0        # 随便找个起点
lr = 0.1         # 学习率

history = []
for i in range(50):
    g = grad(x)
    x = x - lr * g
    history.append(x)
    if i % 5 == 0:
        print(f"第{i:2d}步  x={x:8.4f}  f(x)={f(x):8.4f}")

print(f"\n最终 x = {x:.6f}，应该是 3")
```

跑一遍，你会看到 x 从 -10 一路爬到 3。

**然后自己动手改 `lr`：**

- 改成 0.01 → 变慢，50 步到不了
- 改成 0.5 → 快得有点晃
- 改成 1.0 → 震荡，不收敛
- 改成 1.1 → 直接发散，值越跑越大

**这四种现象你一定要亲眼看到。** 以后调参时你脑子里会有画面。

## 九、自测题

1. 导数是什么？用一句话说清楚。
导数描述“输入变化一点点，输出会变化多少倍”——变化率
2. 梯度和偏导数是什么关系？
梯度是把所有偏导数打包成的向量，每个分量是对应变量的偏导数
3. 为什么更新公式里是**减**梯度，不是加？
因为梯度指向上升最快的方向，要下降就得往反方向走
4. 学习率太大会发生什么？太小呢？
lr太大会震荡或发散；太小会收敛极慢
5. 链式法则用一句话说是什么？
复合函数求导时，各层导数连乘
