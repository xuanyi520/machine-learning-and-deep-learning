## 一、先说为什么

机器学习说到底就一句话：**把数据排成矩阵，乘上另一个矩阵，得到预测**。

举个你熟悉的例子。假设你要预测一个肝癌患者的风险，用了三个指标：年龄、AFP 值、肿瘤直径。一个患者就是一行数据：

```
[58, 400, 3.2]
```

一百个患者就是 100 行、3 列的矩阵 X。模型要给每个指标配一个权重（年龄不重要 0.1、AFP 很重要 0.8、直径 0.5），权重是 3 行 1 列的矩阵 W。

预测值 = X 乘 W，结果是 100 行 1 列，每个患者一个风险分数。

**这就是全部。** 神经网络、深度学习、大模型，做的都是这件事的反复套娃。所以矩阵乘法不是"数学课内容"，是你每天要写的东西。

***

## 二、基本概念

| 名字 | 是什么 | 例子 |
|---|---|---|
| 标量 scalar | 一个数 | `3.14` |
| 向量 vector | 一串数 | `[1, 2, 3]` |
| 矩阵 matrix | 一张数表 | `[[1,2],[3,4]]` |
| 张量 tensor | 更高维的数组 | 一堆图片 |

在 Python 里它们都是 `np.array`，区别只在形状：

```python
import numpy as np

a = np.array(3.14)                          # 形状 ()
b = np.array([1, 2, 3])                     # 形状 (3,)
c = np.array([[1, 2], [3, 4]])              # 形状 (2, 2)
d = np.zeros((2, 3, 4))                     # 形状 (2, 3, 4)，三维

print(a.shape, b.shape, c.shape, d.shape)
```

**形状（shape）是你以后每天盯得最多的东西。** 90% 的报错都是形状不对。

## 三、矩阵乘法

这是本节唯一需要背规则的地方。

### 手算规则

两个矩阵相乘，结果的第 i 行第 j 列 = 左矩阵第 i 行 与 右矩阵第 j 列 逐项相乘再求和。

例子：

```
A = [[1, 2],      B = [[5, 6],
     [3, 4]]           [7, 8]]

A × B = [[1*5 + 2*7,  1*6 + 2*8],     [[19, 22],
         [3*5 + 4*7,  3*6 + 4*8]]  =   [43, 50]]
```

验算第一个元素：A 的第 1 行 `[1,2]`，B 的第 1 列 `[5,7]`，逐项乘再相加：`1*5 + 2*7 = 19`。对上了。

### 形状规则（必须记住）

```
(m, n) × (n, p) = (m, p)
        ↑ ↑
      这两个必须一样
```

中间那个数字必须相等，否则没法乘。结果取外面两个数字。

这就是为什么上一节的例子是 `(100, 3) × (3, 1) = (100, 1)`。

**记法：中间塌陷，两头留下。**

### 一个必须知道的坑

矩阵乘法**不满足交换律**：`A × B` 不等于 `B × A`。

而且形状上往往根本乘不了。`(100,3) × (3,1)` 可以，反过来 `(3,1) × (100,3)` 就不行。

## 四、跟着做

打开 Jupyter，一行行敲，看输出。

```python
import numpy as np

# 1. 手算那道题，用代码验证
A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

print("A @ B =\n", A @ B)      # @ 是矩阵乘法运算符
print("A * B =\n", A * B)      # * 是逐元素相乘，完全不同的东西！

# 2. 形状规则
X = np.random.randn(100, 3)    # 100 个患者，3 个指标
W = np.random.randn(3, 1)      # 3 个权重
y = X @ W
print("X:", X.shape, "W:", W.shape, "y:", y.shape)   # 应该是 (100,1)

# 3. 故意乘错，看它报什么错
try:
    bad = X @ X
except ValueError as e:
    print("报错了，这是故意的:", e)
```

**`@` 和 `*` 的区别，是新手第一个大坑。** `@` 是矩阵乘法，`*` 是逐元素相乘。用错了通常不报错，只是结果悄悄不对——这种错误最难查。

## 五、转置

转置就是把行列互换。`(3, 5)` 的矩阵转置后是 `(5, 3)`。

```python
X = np.random.randn(3, 5)
print(X.shape)          # (3, 5)
print(X.T.shape)        # (5, 3)
```

**转置在 ML 里的主要用途是凑形状。** 你想算 `X @ W` 但形状对不上，转一下就行了。以后你会经常写 `.T`。

## 六、范数（简单认识）

范数是"这个向量有多长"。

L2 范数（最常用）：各元素平方和再开方。

```python
v = np.array([3.0, 4.0])
print(np.linalg.norm(v))     # 5.0，就是勾股定理
```

**为什么 ML 要用它**：训练模型时我们希望权重不要太大，因为在损失函数里加一项权重的范数，就能惩罚过大的权重，这叫正则化。W7 会细讲。现在你只要知道"范数 = 长度"就够了。
