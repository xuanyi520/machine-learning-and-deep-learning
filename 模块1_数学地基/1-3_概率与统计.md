## 一、随机变量与分布

随机变量就是"结果不定的量"。抛硬币的结果、一个患者的年龄、一次检测的值。

**分布**描述"各种结果出现的可能性"。

### 两个你会反复遇到的分布

**伯努利分布**：只有两种结果（成功/失败、患病/健康、阳性/阴性）。

```python
import numpy as np
# 患病概率 p=0.02 的人群，抽 10000 人
p = 0.02
samples = np.random.random(10000) < p
print("患病人数:", samples.sum(), " 比例:", samples.mean())
```

**正态分布（高斯分布）**：钟形曲线，由均值 μ 和标准差 σ 决定。

```python
samples = np.random.normal(loc=170, scale=8, size=10000)   # 身高
print("均值:", samples.mean(), "标准差:", samples.std())
```

**为什么正态分布到处都是**：大量独立因素叠加的结果趋近正态（中心极限定理）。测量误差、身高、血压都是。医学参考区间就是这么定的——常取 μ±2σ。

***

## 二、期望与方差

**期望 E[X]**：平均会是多少。离散情况就是加权平均。

**方差 Var[X]**：波动有多大。标准差 σ 是方差开根号，和原数据同量纲，更好用。

```python
data = np.random.normal(170, 8, 100000)
print("期望:", data.mean())
print("方差:", data.var())
print("标准差:", data.std())
```

医学里的例子：同一个人的血压测三次，如果标准差很大，说明这个测量不可靠——即使平均值看起来正常。

***

## 三、条件概率与贝叶斯（本节重点）

**`P(A|B)`**：已知 B 发生的前提下，A 发生的概率。

**贝叶斯公式：**

```
P(A|B) = P(B|A) × P(A) / P(B)
```

看起来很抽象。我直接给你一个和你的专业相关、且**反直觉**的例子。

## 四、癌症筛查的著名陷阱

> 某癌症在人群中的患病率是 **1%**。
> 有一种检测方法：**患病者中 99% 会测出阳性**（灵敏度 99%），**健康者中 95% 会测出阴性**（特异度 95%）。
> 现在你随机一个人去测，结果是**阳性**。
> 请问：他真正患病的概率是多少？

大部分人第一反应是"99% 吧"。**错，答案是约 16.7%。**

算一遍：

假设 10000 人。

- 真正患病：`10000 × 1% = 100` 人
- 健康：`9900` 人

检测结果：

- 患病的 100 人里，阳性：`100 × 99% = 99` 人（真阳性）
- 健康的 9900 人里，假阳性：`9900 × (1-95%) = 9900 × 5% = 495` 人

所以所有阳性的人是 `99 + 495 = 594` 人。

其中真正患病的只有 99 人。

```
P(患病 | 阳性) = 99 / 594 ≈ 16.7%
```

**一个灵敏度 99% 的检测，阳性结果只有 16.7% 是真的患病。**

这就是**基础患病率（先验）**的威力。当疾病很罕见时，即使检测很准，阳性结果里也大部分是假阳性。

### 这对你意味着什么

1. 这就是为什么"早筛"研究里，**阳性预测值（PPV）** 是一个必须报告的指标——它才是临床真正关心的"查出阳性的人里有多少真患病"
2. 这就是为什么筛查高危人群（先验高）比筛查全人群更划算——提高先验，直接提高 PPV
3. 新闻里"某检测准确率 99%"这种说法，如果没给患病率，**基本没有信息量**

**这是本节最值钱的一段。** W7 讲评估指标时你会再遇到它。

## 五、最大似然估计（概念，不用会推）

一句话：**哪种参数设置，最有可能产生我观察到的这批数据？**

抛硬币 10 次，8 次正面。你认为正面概率是多少？直觉是 0.8。这就是最大似然——`p=0.8` 时，观察到"8 正 2 反"的概率最大。

**为什么 ML 要用它**：训练模型的本质，就是找一组参数让"模型产生当前这批训练数据"的可能性最大。你以后看到的交叉熵损失、均方误差损失，都能从最大似然推出来。

现在只要记住这个思想，第 7 周再回头看。

## 六、跟着做：用模拟验证那个 16.7%

**不要相信我的算术，自己跑出来。**

```python
import numpy as np

np.random.seed(42)      # 固定随机种子，结果可复现

N = 1_000_000           # 一百万人
prevalence = 0.01       # 患病率 1%
sensitivity = 0.99      # 灵敏度：患病者测出阳性的概率
specificity = 0.95      # 特异度：健康者测出阴性的概率

# 1. 生成真实状态：True=患病
is_sick = np.random.random(N) < prevalence

# 2. 根据真实状态决定检测结果
random_vals = np.random.random(N)
test_positive = np.where(
    is_sick,
    random_vals < sensitivity,        # 患病者：以 99% 概率阳性
    random_vals > specificity         # 健康者：以 5% 概率阳性
)

# 3. 统计
n_sick = is_sick.sum()
n_positive = test_positive.sum()
n_true_positive = (is_sick & test_positive).sum()

print(f"总人数: {N:,}")
print(f"真实患病: {n_sick:,}")
print(f"检测阳性: {n_positive:,}")
print(f"其中真患病: {n_true_positive:,}")
print(f"阳性预测值 PPV = {n_true_positive / n_positive:.4f}")
print(f"理论值 0.1667")
```

跑出来应该接近 0.1667。

**跑通后，自己动手改 `prevalence`。**

- 改成 0.20（高危人群，比如有肝硬化的患者做 AFP 筛查）
- 看 PPV 变成多少

你会看到它从 16% 跳到 80% 以上。**这就是"高危人群筛查"在数学上的意义。**
