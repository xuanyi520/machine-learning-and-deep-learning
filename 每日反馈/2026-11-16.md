## 学到的知识点

### 一、先看有没有信号，再决定建不建模

**以前拿到数据的第一反应是「怎么训」；今天的顺序是「这数据里到底有没有东西可学」。**

**`quick_signal_check` 干的事：**

```
① 打印目标变量的分布（看类别平不平衡）
② 对每个数值列算 Spearman 秩相关系数 rho
③ 按 |rho| 从大到小排序
④ 用 p 值判断「这个相关是不是碰巧的」
```

**关键的两个数：**

| 指标 | 含义 |
|---|---|
| **rho** | 同步程度。接近 0 = 几乎不同步；+1 = 一起变大；-1 = 一起变小 |
| **p** | 这个同步是碰巧出现的概率。小于 0.05 才算显著 |

**为什么用 Spearman 而不是 Pearson：**

Pearson 测的是「线性关系」，Spearman 测的是「单调关系」——只要求「你大我也大」，不要求是直线。

医学指标很多是单调但非线性的（比如指标越高风险越大，但不是线性增长），所以 Spearman 更合适。

### 二、HCV 数据集的结论：几乎没有信号

**1385 例，29 列，目标是 `Baselinehistological_staging`（肝纤维化分期 1-4）。**

**类别分布：**

```
1    336
2    332
3    355
4    362
```

**四个类别几乎完全均匀。**

**秩相关结果（前几名）：**

```
BMI                rho=-0.059  p=0.029
Nausea/Vomting     rho=+0.055  p=0.042
Epigastric pain    rho=-0.051  p=0.056
RNA 12             rho=+0.040  p=0.134
ALT after 24 w     rho=+0.039  p=0.150
```

**最高的相关系数只有 0.059。**

**这意味着什么：**

rho 0.059 表示「x 变了，y 跟着变的趋势」和随机波动几乎分不开。

**换句话说：这些特征对分期的预测能力，接近零。**

**函数给出的判断是「几乎没有信号，先别建模，回去查数据来源」——这个判断是对的。**

### 三、Hepatitis 数据集：缺失本身携带信息

**155 例，20 列，167 个缺失值。**

**缺失率排名：**

```
Protime            43.2%
Alk Phosphate      18.7%
Albumin            10.3%
Liver Firm          7.1%
Liver Big           6.5%
Bilirubin           3.9%
...
```

**Protime 缺了将近一半。**

**然后做了一个关键的对比——按「是否缺失」分成两组，比较两组的死亡率：**

```python
g = h.groupby(h[c].isna())['Class'].apply(lambda s: (s == 1).mean())
```

**结果：**

```
Bilirubin      缺失组死亡率 0.33   非缺失组 0.20
Alk Phosphate  缺失组死亡率 0.28   非缺失组 0.19
Sgot           缺失组死亡率 0.50   非缺失组 0.20
Albumin        缺失组死亡率 0.31   非缺失组 0.19
Protime        缺失组死亡率 0.21   非缺失组 0.20
```

**Sgot 那一行是重点：缺失组死亡率 50%，非缺失组 20%。差了 2.5 倍。**

**这说明缺失不是随机的。**

**对照模块 5 讲的三种缺失机制：**

| 类型 | 含义 | 能不能直接插补 |
|---|---|---|
| MCAR | 完全随机缺失 | 能 |
| MAR | 和其他变量有关 | 能（用其他变量预测） |
| **MNAR** | **缺失本身和结局有关** | **不能，会引入偏倚** |

**Sgot 属于典型的 MNAR：医生可能是看到病情重了才去查 Sgot，或者是设备原因没测——无论哪种，「没查」这件事本身就和死亡率相关。**

**如果我直接把 Sgot 的缺失用均值填上，等于告诉模型「这个病人的 Sgot 是平均值」，会把「重症」的错误地当成「正常」。**

**正确做法：加一个「是否缺失」的指示列，让模型自己学这个信号。**

## 心得

### 1. 「找不到信号」本身就是一个有价值的结论

**以前我会觉得「分析没结果 = 白做了」。**

**但 HCV 那个结果告诉我：在建模之前先验证有没有信号，能省掉后面的全部无用功。**

**如果直接上 XGBoost，跑出来的准确率可能在 0.30 左右（四分类的随机水平是 0.25），然后我会花几天去调参、换模型、加特征——全部白费。**

**十分钟的信号筛查，省掉三天。**

### 2. 缺失值不是「数据的瑕疵」，可能是「数据的一部分」

**Hepatitis 那个对比让我真正理解了 MNAR。**

**以前对缺失的处理是「看看缺多少，多了就删，少了就填」。**

**现在知道：先问一句「缺失的人和没缺的人，结局一样吗？」**

**不一样，就不能随便填。**

### 3. 两个数据集的对比很说明问题

**同样是肝病数据：**

| | HCV（1385 例） | Hepatitis（155 例） |
|---|---|---|
| 特征信号 | 几乎没有 | 有（缺失模式里） |
| 样本量 | 大 | 小 |
| 类别分布 | 极均匀（336/332/355/362） | 不平衡 |

**HCV 样本多但没信号，Hepatitis 样本少但有结构。**

**样本量不等于数据质量。**

## 卡住的地方 / 不足

### 不足一：HCV 得出「没信号」之后就停了，没有追问

**「没信号」有三种可能：**

1. **数据本身就是随机的**（可能是合成数据）
2. **Spearman 测不出来**（如果关系是非单调的，比如 U 型）
3. **找错了列**（可能真正的标签在别的列，或者需要组合特征）

**我只确认了第 1 种可能，没有排查第 2、3 种。**

**具体的可疑点：四个类别 336/332/355/362，几乎完全均匀。**

**真实医学数据的四分类很少这么整齐。这个分布本身就值得怀疑。**

**下次应该做的：**

- 画几个 rho 最高的特征的箱线图，肉眼看有没有趋势
- 检查有没有非单调关系（分组看均值，而不是只看相关系数）
- 查一下这个数据集在 UCI 上的说明，看别人用它做什么任务

### 不足二：缺失分析只看了 5 个变量

**20 列里只对 5 个做了缺失-死亡率对比，剩下的 15 个没看。**

**而且只看了缺失率大于 0 的那几个，没有系统地把所有有缺失的列都过一遍。**

**应该写成一个循环，把所有缺失率 > 0 的列都算一遍，按差异大小排序。**

### 不足三：两个数据集的分析没有连起来

**HCV 和 Hepatitis 都是肝病数据，但我是分开做的，没有对比。**

**更好的做法：**

- 用同一个函数同时跑两个数据集
- 对比「有信号」和「没信号」的数据长什么样
- 这样能建立「什么样的数据值得建模」的直觉

### 不足四：没做缺失处理决策

**发现了 MNAR，但没往下走——到底该怎么处理？**

**现在停在「知道不能随便填」，但「那到底怎么填」还没有答案。**

**下一步应该做的：**

- 对比三种做法：删行 / 均值填充 / 加缺失指示列 + 填充
- 看三者的模型表现差多少
- **这就是模块 5 里讲的「缺失率 vs AUC 曲线」实验**
