## 学到的知识点

### 一、没有 DICOM 文件也能开工

讲义里的 `E:\某病人CT\IM0001.dcm` 只是**示意路径**，本机没有这个文件，直接跑必报 `FileNotFoundError`。

**pydicom 自带一张真实的 CT**，任何装了 pydicom 的电脑都能取到：

```python
from pydicom.data import get_testdata_file
ds = pydicom.dcmread(get_testdata_file("CT_small.dcm"))
```

以后拿到自己的片子，只要把这两行换掉：

```python
ds = pydicom.dcmread(r"E:\真实路径\xxx.dcm")
```

**这个办法的价值**：不用等数据集下载、不用求人要片子，装完包就能立刻开始读。卡在"没数据"上是最没必要的。

### 二、第一次读出真实元数据

```
模态: CT
图像尺寸: 128 x 128
像素间距: [0.661468, 0.661468]
层厚: 5.000000
位深: 16
```

四个都要会读：

| 输出 | 含义 |
|---|---|
| `CT` | 设备类型是 CT，不是 MR / US |
| `128 x 128` | 图像分辨率（人体 CT 常规是 512×512，这是缩小的示例） |
| `[0.661468, 0.661468]` | 每个像素 0.66 mm，两个数相等说明横纵一致 |
| `5.000000` | 这一层和下一层隔 5 mm |
| `16` | 用 16 位整数存（0~65535） |

**`getattr(ds, 'SliceThickness', '该文件没有')` 这个写法今天第一次真正派上用场**——DICOM 标签不是每个文件都齐全，直接 `ds.SliceThickness` 遇到缺失文件会崩。

### 三、HU 换算的实测结果

```python
pixels    = ds.pixel_array
slope     = float(getattr(ds, 'RescaleSlope', 1))
intercept = float(getattr(ds, 'RescaleIntercept', 0))
hu        = pixels.astype(np.float32) * slope + intercept
```

**算出来 -896 ~ +1167。**

对照讲义表的判断标准：

| 检查项 | 理论 | 实测 | 结论 |
|---|---|---|---|
| 最小值 | 接近 -1000（空气） | -896 | ✓ 这个视野里没有纯空气，最接近的是肺 |
| 最大值 | 1000 以上（骨） | +1167 | ✓ 骨头 |

**两个数字都对得上，说明换算写对了。** 如果最小值还是 0，就是漏了 intercept。

### 四、一张 CT 开出四张截然不同的图

```python
windows = {
  '肺窗':   (-600, 1500),
  '纵隔窗': (40,   400),
  '肝窗':   (60,   160),
  '骨窗':   (400,  1800),
}
```

`apply_window` 三行干的事：

```python
low  = center - width / 2        # 窗下边界
high = center + width / 2        # 窗上边界
img  = np.clip(img_hu, low, high)          # 窗外压到边界（低于变黑，高于变白）
img  = (img - low) / (high - low) * 255    # 窗内线性拉到 0~255
```

**同一份数据，四个窗看出四种东西**——这是医学影像和普通图片处理最大的区别。

### 五、MedMNIST 加载成功

```
任务: binary-class
类别: {'0': 'normal', '1': 'pneumonia'}
通道数: 1
```

三个信息决定后面网络怎么写：

- `binary-class` → 输出 2 维，用 `CrossEntropyLoss`
- `normal / pneumonia` → 标签是 0 和 1，评估时 `target_names` 用这个
- `1 通道` → 第一层 `nn.Conv2d(1, 32, ...)` 的 `1` 就是从这来的

## 心得

**1. "没有数据"往往不是真障碍**

今天最省时间的一步是发现 pydicom 自带测试文件。之前一直觉得"等有了片子才能练"，其实包一装就能开工。**遇到"缺前置条件"的时候，先想想这个工具本身有没有自带示例。**

**2. 讲义的路径是示意，不是能直接跑的**

`E:\某病人CT\IM0001.dcm` 这种写法在教材里很常见——它想说明"这里要填一个真实路径"，但直接复制粘贴必报错。**以后看任何教程，看到具体路径都要先判断：这是示例还是真实文件。**

**3. 理论数字和实测数字能互相验证**

讲义说"换算后最小值接近 -1000"，实测 -896。差 100 左右不是错，是因为这个视野里根本没拍到纯空气。**"对得上"不是数字完全相同，是趋势和量级一致。**
