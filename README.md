# 从零开始学 AI · 第一阶段：地基

## 先说清楚起点

你**不是编程零基础**。你写过 Python 脚本、做过 MCP server、用 python-pptx 改过 PPT。
你是**机器学习零基础**。

所以这份材料不教 Python 语法，不教 for 循环，直接从"数据怎么变成一个会预测的模型"开始。
你会用到的 Python 知识（函数、类、列表推导、numpy 数组）默认你已经会。

如果你某一节发现自己 Python 卡住了，不要停在这份材料里补 Python——那是另一个问题，单独记下来问我。

## 13 周后你要达到什么

时间：2026 年 10 月 — 2027 年 1 月
投入：每周 10-20 小时

**出口标准（做不到就不算学完，别往下走）：**

1. 能手写梯度下降，不用任何机器学习库，纯 numpy 拟合出一条直线
2. 能解释清楚：损失函数是什么、梯度是什么、为什么沿着负梯度走能降低损失

4. 能用 pydicom 读一张医学影像，并说出它的像素值代表什么
5. 拿到一个陌生的分类任务，知道该看哪些指标，而不是只看准确率

## 每周怎么用这 10-20 小时

**建议配比：4 小时看讲义，10 小时写代码。**

这是硬要求。机器学习是手上功夫，看懂和写出来是两件事。你会遇到大量"我以为我懂了，一写就报错"的时刻——那个时刻才是真正学习发生的地方。

每节课的结构固定：

1. **讲义** —— 概念，配最小可运行的例子
2. **跟着做** —— 我给出完整代码，你敲一遍跑通
3. **练习** —— 只给题目，你要自己写
4. **自测题** —— 检验概念，不看答案先答

***

## 最重要的一条纪律

**每道练习，先自己写，卡住 30 分钟再看答案。**

答案在 `参考答案\` 目录里，按模块分。你可以在卡住时瞄一眼思路，但不要整段抄——抄完你会以为自己会了，两周后原形毕露。

写不出来是正常的。写不出来然后看了答案、再关掉答案重写一遍，才叫学会。
