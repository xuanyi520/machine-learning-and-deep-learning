# 17-7 医疗数据合规与安全

**建议用时：4 小时**

**出口标准：能说出健康医疗数据的五级分类，能判断自己手上的数据属于哪一级、能做什么不能做什么。**

---

## 〇、先说清楚

**这一节不是法律意见。** 具体项目要以所在机构的伦理委员会、法务部门意见为准。

**但你必须知道框架在哪，否则连该问什么都不知道。**

**这一节没有代码，但它决定了你能不能碰数据。**

---

## 一、四个文件，构成基本框架

| 文件 | 施行时间 | 管什么 |
|---|---|---|
| **《网络安全法》** | 2017-06-01 | 网络运营者的基本义务 |
| **《数据安全法》** | 2021-09-01 | 数据分类分级、重要数据保护 |
| **《个人信息保护法》** | 2021-11-01 | **个人信息的处理规则** |
| **GB/T 39725-2020《健康医疗数据安全指南》** | 2021-07-01 | **医疗领域的落地细则** |

**前三部是法律，最后一个是推荐性国家标准。**

**推荐性标准的意思是「不强制」，但实际上：**

> **一旦出了事，监管和法院会拿它当「行业应尽义务」的参照。**

**所以它实质上必须遵守。**

## 二、健康医疗数据的五级分类（核心）

**GB/T 39725 把健康医疗数据分成五级，从低到高：**

| 级别 | 内容 | 谁能访问 |
|---|---|---|
| **第 1 级** | **完全公开**：医院名称、地址、电话 | 任何人 |
| **第 2 级** | **去标识化数据**，较大范围可用 | 医生可申请审批后用于研究 |
| **第 3 级** | **部分去标识化，但可重识别** | 限授权的项目组 |
| **第 4 级** | **可直接识别个人身份** | 限相关医务人员 |
| **第 5 级** | **特殊疾病的详细记录**（HIV、性病等） | 仅主治医生，严格条件下 |

### 你手上的数据在第几级，直接决定能做什么

**第 2 级：可以做研究**

```
✅ 可以做统计分析
✅ 可以训练模型
✅ 可以写论文（不暴露个体）
✅ 可以跨机构共享（在协议范围内）
```

**第 3 级：要非常小心**

**「部分去标识化但可重识别」——意思是加了盐哈希之类的处理，但如果你有映射表，就能还原。**

```
✅ 在授权范围内、在受控环境里用
❌ 拷到自己的笔记本上
❌ 上传到任何在线服务
```

**第 4 级：只能在本机构的临床环境里用**

```
❌ 不能拷出来
❌ 不能用于研究（除非另有授权）
```

**第 5 级：基本不能碰**

```
❌ 除非你本人就是主治医生
```

### 你要做的是：先判断级别

**拿到一批数据，第一句话应该是：**

> **「这批数据是几级？有没有伦理批件？批件上写的使用范围是什么？」**

**答不上来，就不要开始处理。**

## 三、敏感个人信息

**《个人信息保护法》第 28 条把医疗健康信息列为「敏感个人信息」。**

**敏感个人信息的要求比一般个人信息严格得多：**

| 要求 | 一般个人信息 | 敏感个人信息 |
|---|---|---|
| 告知同意 | 一般告知 | **单独同意**（不能和其他条款捆在一起） |
| 处理目的 | 明确、合理 | **特定目的、充分必要** |
| 影响评估 | 视情况 | **必须做个人信息保护影响评估（PIA）** |
| 未成年人 | 监护人同意 | 监护人同意 + **单独规则** |

### 「单独同意」是什么意思

**不能这样：**

```
❌ 注册页面底部一行小字：「勾选即表示同意《用户协议》和《隐私政策》」
   （里面包含了医疗数据用于研究）
```

**要这样：**

```
✅ 单独弹一个框：「是否同意将您的检查影像用于 XX 研究？」
   （不同的研究要分别征得同意）
```

### 去标识化 vs 匿名化

**这两个词经常被混用，但法律后果完全不同。**

| | 去标识化 | 匿名化 |
|---|---|---|
| 定义 | 处理后**无法直接识别**，但借助额外信息**仍可重识别** | 处理后**无法识别且不能复原** |
| 法律地位 | **仍属于个人信息**，受个保法管 | **不再是个人信息**，不受个保法管 |
| 举例 | 假 ID + 保留映射表 | 彻底销毁映射表，且无法反推 |

**关键：**

> **只要你还留着映射表，就算「去标识化」，不算「匿名化」，仍受个保法约束。**

**所以 17-3 讲的那个「映射表要单独保管」，不只是工程建议，是法律要求。**

## 四、伦理审查

**涉及人的研究，必须过伦理委员会（IRB / EC）。**

### 什么时候必须做

| 情况 | 要不要伦理审查 |
|---|---|
| 用人的数据做研究 | **要** |
| 用动物数据 | 要（动物伦理） |
| 只用公开数据集 | 通常不用，但要确认原数据集有伦理批件 |
| 纯算法研究（不用真实数据） | 不用 |
| 课程作业（用公开数据） | 不用 |

### 申请材料通常包括

```
① 研究方案（目的、方法、样本量、数据分析计划）
② 知情同意书（或申请豁免）
③ 研究者资质
④ 数据安全保障措施
⑤ 利益冲突声明
```

**周期：快的两周，慢的两三个月。要提前规划。**

### 伦理批件上的「使用范围」很重要

**批件上写的是「仅用于 XX 研究」，你不能拿去训练一个商业模型。**

**也不能拿去发一篇和课题无关的论文。**

**超出范围使用，和没批件是一样的。**

## 五、知情同意的豁免

**回顾性研究常常拿不到每个病人的同意（病人早出院了）。**

**这种情况下可以申请「免除知情同意」，但条件很严：**

### 通常要同时满足

```
① 研究具有重要社会价值，且无法用其他方式实现
② 使用的数据是经过脱敏的
③ 不会对受试者造成伤害
④ 研究不涉及个人隐私的敏感信息，或者有充分的保护措施
⑤ 经伦理委员会审查批准
```

**第 ⑤ 条是关键：豁免本身也要伦理委员会批准，不能自己决定「反正都脱敏了」。**

## 六、实操：十条必须遵守的规矩

**这些是「不管什么项目都该遵守」的底线。**

### 数据获取

**① 没有书面的授权，不拿数据**

微信群里发来的「这是我们的数据，你用吧」，不算授权。

**② 确认伦理批件覆盖了你的用途**

批件上写「用于诊断模型研究」，你拿去做商业产品，超范围。

**③ 拿到数据先做去标识化**

不要「先用着，以后再脱敏」。

### 数据存储

**④ 不放在个人设备**

除非有明确批准。**移动硬盘、私人网盘、个人笔记本，都不算受控环境。**

**⑤ 映射表和数据分开存**

**映射表本身就是最高级别的敏感信息。**

**⑥ 访问要有日志**

谁、什么时间、拿了什么文件。

### 数据使用

**⑦ 不上传到任何未经批准的在线服务**

```
❌ ChatGPT / 文心一言 / 任何云端大模型
❌ 网盘自动同步
❌ GitHub（哪怕是私有仓库）
```

**这一条现在特别容易踩。** 很多人在调试时会贴一段数据给 AI 看。

**⑧ 不用真实数据做演示**

截图、PPT、论文里的图，都要确认不含 PHI。

### 数据销毁

**⑨ 研究结束后按协议销毁或归还**

很多协议里写着「研究结束后 6 个月内销毁数据」。**要留销毁记录。**

**⑩ 保存期限不是「越久越好」**

**很多机构要求原始数据保存不少于 6 年（可回溯），但也要求到期销毁。** 两头都有义务。

## 七、五个常见误区

### 误区一：「数据是医院的，我是医院的人，随便用」

**错。** 医院的数据使用权归医院，具体到每个研究，要有批件。

### 误区二：「已经去标识化了，就是匿名数据，不受管」

**错。** 只要留了映射表，就是「去标识化」，仍是个人信息。

### 误区三：「我只用一小部分，不会被发现」

**错。** 审计日志会记录一切。而且小样本反而更容易重识别。

**GB/T 39725 里有个「最小计数原则」：统计结果的样本数少于 5 人时不应发布**，因为太小了容易被反推。

### 误区四：「发到网上的公开数据集，我可以随便用」

**看许可协议。** 很多公开数据集要求：

```
✅ 仅研究用途
❌ 不得商用
❌ 不得再分发
✅ 发表时要引用
```

**MedMNIST 是 CC BY 4.0，可以商用但要署名。**
**但有些数据集（比如部分医院的公开数据）是「仅研究」，用了发商业产品就违规。**

### 误区五：「我在自己电脑上跑，没人知道」

**数据一旦离开受控环境，就已经违规了。** 不管你做了什么处理。

## 八、跟着做

### 任务：给你自己项目做一次合规自检

**如果你手上有数据，或者将来要用，填这张表：**

| 项 | 你的情况 |
|---|---|
| 数据来源是什么 | |
| 属于 GB/T 39725 第几级 | |
| 有没有伦理批件 | |
| 批件批准的使用范围 | |
| 你的用途是否在范围内 | |
| 是否已去标识化 | |
| 映射表存在哪 | |
| 存储环境是否受控 | |
| 有没有访问日志 | |
| 结论：能开始吗 | |

**十项里有一项答不上来，就不要开始。**

### 任务二：查一个公开数据集的许可

**挑一个你可能会用的公开数据集（MedMNIST、LiTS、TCIA 上的某个），把它的 license 找出来，回答：**

```
□ 能商用吗
□ 能再分发吗
□ 发表时要怎么引用
□ 有没有额外的注册/申请流程
```

**验收：** 四个问题都有明确答案，并且能指出 licence 在哪一页/哪一段。

## 九、练习

### 练习 17-7-A（必做）：判断级别

**下面五个场景，各属于第几级？**

1. 某三甲医院的官网首页
2. 一份脱敏的、有假 ID 的 500 例肝癌 CT 数据
3. 上面那份数据 + 一张假 ID 到真实病历号的对照表
4. 一份包含病人姓名和住院号的原始病历
5. 一份 HIV 感染者的完整用药记录

**填表，并说明判断理由。**

### 练习 17-7-B（必做）：找出你项目里的三个风险点

**用你现在做的项目，列出三个可能的合规风险。**

**每个写：风险是什么、后果有多严重、怎么改。**

### 练习 17-7-C（必做）：写一份数据使用申请

**假设你要向医院申请一批脱敏数据用于研究，写一份 300 字的申请，说明：**

```
研究目的
数据需求（多少例、什么模态）
使用方式（存在哪、谁用、怎么用）
安全保障（怎么防泄露）
数据处置（研究结束后怎么办）
```

**这个能力在实习时直接能用。**

### 练习 17-7-D（选做）：读一遍 GB/T 39725

**网上能找到全文。至少读第 5 章（数据分类分级）和第 7 章（安全措施）。**

**读的时候，把你项目里对应的部分标出来。**

## 十二、常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 「用一下再说」 | 违规已成事实 | 先确认授权 |
| 以为脱敏就自由 | 法律上仍是个人信息 | 保留映射表=受管 |
| 数据存私人设备 | 违反受控环境要求 | 用机构提供的环境 |
| 贴给在线 AI 调试 | 数据外泄 | 用假数据调试 |
| 超范围使用 | 等同于无批件 | 看批件原文 |
| 不记录访问日志 | 出事无法追溯 | 系统层面记录 |
| 以为公开数据集随便用 | 违反 licence | 查清协议 |
