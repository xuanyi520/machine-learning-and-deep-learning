# 17-6 数据质检与自动化流水线

**建议用时：6 小时**

**出口标准：能写出一套在训练之前自动跑完的质检流水线，并给出一份数据说明书。**

---

## 〇、这一节在解决什么

**脏数据不会在训练时温柔地提醒你。**

**它会这样炸：**

```
训练到第 3 天，loss 突然 nan
    ↓
查了两天，发现是某个病人的 CT 只有 3 层，归一化时除以 0
    ↓
如果有质检，这件事在第 1 分钟就能发现
```

**这一节要做的是：把「训练时才发现」变成「入库时就拦住」。**

---

## 一、四类质量问题

| 类型 | 例子 | 发现时机 |
|---|---|---|
| **完整性** | 文件缺失、标签对不上 | 可以自动查 |
| **一致性** | 同一病人两个 ID、日期格式不统一 | 可以自动查 |
| **合理性** | 日期是 2099 年、层厚 0.001mm | 可以自动查 |
| **质量** | 图像全黑、严重伪影、扫描未完成 | 部分能自动查 |

**前两类是纯逻辑检查，必须做。第三类是物理常识检查。第四类要人工抽查配合。**

## 二、完整性检查

### 检查一：图像和标签是否配对

```python
from pathlib import Path

def check_pairs(img_dir: Path, lbl_dir: Path):
    imgs = {f.stem.replace("_0000", ""): f for f in img_dir.glob("*.nii.gz")}
    lbls = {f.stem: f for f in lbl_dir.glob("*.nii.gz")}

    missing_lbl = set(imgs) - set(lbls)
    missing_img = set(lbls) - set(imgs)

    return {
        "总图像": len(imgs),
        "总标签": len(lbls),
        "有图无标签": sorted(missing_lbl),
        "有标签无图": sorted(missing_img),
    }
```

**这个检查五分钟能写完，但能省下两天调试。**

### 检查二：文件是否能正常读取

**「文件存在」不等于「文件完好」。** 下载中断会产生半截文件。

```python
import nibabel as nib
import pydicom

def check_readable(path: Path) -> tuple[bool, str]:
    try:
        if path.suffix in (".gz",) or path.name.endswith(".nii.gz"):
            img = nib.load(str(path))
            _ = img.shape                          # 触发实际读取
            return True, ""
        elif path.suffix == ".dcm":
            ds = pydicom.dcmread(str(path), stop_before_pixels=True)
            return True, ""
    except Exception as e:
        return False, f"{type(e).__name__}: {e}"
    return True, ""
```

### 检查三：DICOM 序列的层数是否合理

**一个 CT 序列应该有几十到几百层。只有 1-3 层通常说明扫描中断了。**

```python
def check_series_integrity(dicom_dir: Path):
    """按 SeriesInstanceUID 分组，检查每个序列的层数"""
    from collections import defaultdict
    import pydicom
    from pydicom.data import get_testdata_file

    series = defaultdict(list)
    for f in dicom_dir.rglob("*"):
        if not f.is_file():
            continue
        try:
            ds = pydicom.dcmread(str(f), stop_before_pixels=True, force=True)
        except Exception:
            continue
        uid = getattr(ds, "SeriesInstanceUID", None)
        if uid:
            series[str(uid)].append(f)

    issues = []
    for uid, files in series.items():
        if len(files) < 10:
            issues.append({
                "SeriesInstanceUID": uid,
                "层数": len(files),
                "问题": "层数过少，可能扫描未完成",
            })
    return issues
```

**这个检查在真实数据里命中率很高。**

## 三、一致性检查

### 检查一：同一个病人是不是同一个 ID

**数据来自多个来源时，这几乎必然出问题。**

```python
import pandas as pd

df = pd.read_csv("index.csv")

# 同一个名字对应多个 ID（可能是同一个人录入不一致）
name_ids = df.groupby("patient_name")["patient_id"].nunique()
print(name_ids[name_ids > 1])

# 同一个 ID 对应多个名字（可能是 ID 重复分配）
id_names = df.groupby("patient_id")["patient_name"].nunique()
print(id_names[id_names > 1])
```

**两个方向都要查。**

### 检查二：日期格式

```python
import re

def check_date_format(dates, expected="YYYYMMDD"):
    bad = []
    for d in dates:
        s = str(d)
        if not re.fullmatch(r"\d{8}", s):
            bad.append(s)
    return bad
```

**常见的不统一：**

```
20260115 / 2026-01-15 / 2026/1/15 / 15/01/2026 / 20260115 120000
```

**混着来，后面按时间排序就全乱。**

### 检查三：模态和扩展名是否匹配

**CT 存成 `.png`，或者 MR 存成 `.dcm` 但里面是 JPG 压缩——这类问题在转换脚本出错时会出现。**

```python
def check_modality_consistency(df):
    """每个模态的常见尺寸范围，超出就标红"""
    ranges = {
        "CT": {"rows": (128, 1024), "cols": (128, 1024)},
        "MR": {"rows": (64, 1024), "cols": (64, 1024)},
    }
    issues = []
    for _, r in df.iterrows():
        m = r.get("Modality")
        if m in ranges:
            lo, hi = ranges[m]["rows"]
            if r.get("Rows") and not (lo <= r["Rows"] <= hi):
                issues.append((r["path"], f"{m} 行数异常: {r['Rows']}"))
    return issues
```

## 四、合理性检查

**这一类靠「物理常识」。**

### 常见的不合理值

| 字段 | 合理范围 | 不合理的例子 |
|---|---|---|
| `SliceThickness` | 0.5 - 10 mm | 0、0.001、100 |
| `PixelSpacing` | 0.1 - 2 mm | 0 |
| `PatientAge` | 0 - 120 | 999 |
| `StudyDate` | 1980 - 今年 | 2099 |
| `Rows` / `Columns` | 64 - 4096 | 0 |
| 图像像素值 | 有方差 | 全 0、全 255 |

```python
from datetime import datetime

def check_physical_plausibility(ds) -> list[str]:
    issues = []

    st = getattr(ds, "SliceThickness", None)
    if st is not None:
        st = float(st)
        if not (0.1 <= st <= 20):
            issues.append(f"层厚异常: {st}")

    try:
        ps = getattr(ds, "PixelSpacing", None)
        if ps:
            ps = [float(x) for x in ps]
            if any(x <= 0 or x > 5 for x in ps):
                issues.append(f"像素间距异常: {ps}")
    except Exception:
        pass

    date = getattr(ds, "StudyDate", None)
    if date:
        s = str(date)
        if len(s) == 8 and s.isdigit():
            year = int(s[:4])
            if year < 1980 or year > datetime.now().year:
                issues.append(f"检查日期异常: {s}")

    return issues
```

### 图像本身的合理性

```python
import numpy as np

def check_image_quality(arr):
    issues = []
    if arr.size == 0:
        return ["空数组"]
    if arr.std() < 1e-3:
        issues.append(f"图像几乎无变化（std={arr.std():.6f}），可能是全黑或全白")
    if np.isnan(arr).any():
        issues.append("含 NaN")
    if np.isinf(arr).any():
        issues.append("含 Inf")
    return issues
```

**`std` 那一行能抓住「拍糊了」「曝光错误」「全黑」这些情况。**

## 五、流水线：把检查串起来

**一个个跑太麻烦。做成一条流水线。**

```python
from pathlib import Path
from dataclasses import dataclass, field
import json

@dataclass
class CheckResult:
    name: str
    passed: int = 0
    failed: int = 0
    details: list = field(default_factory=list)

    def add(self, ok: bool, msg: str = ""):
        if ok:
            self.passed += 1
        else:
            self.failed += 1
            self.details.append(msg)

class QCPipeline:
    def __init__(self, root: Path):
        self.root = root
        self.results = {}

    def run(self) -> dict:
        self.results["完整性"]  = self.check_completeness()
        self.results["可读性"]  = self.check_readable()
        self.results["一致性"]  = self.check_consistency()
        self.results["合理性"]  = self.check_plausibility()
        self.results["图像质量"] = self.check_quality()
        return self.report()

    def check_completeness(self):
        r = CheckResult("完整性")
        imgs = list((self.root / "imagesTr").glob("*.nii.gz"))
        lbls = {f.name for f in (self.root / "labelsTr").glob("*.nii.gz")}
        for img in imgs:
            key = img.name.replace("_0000.nii.gz", ".nii.gz")
            r.add(key in lbls, f"{img.name} 缺少对应标签")
        return r

    def check_readable(self):
        import nibabel as nib
        r = CheckResult("可读性")
        for f in (self.root / "imagesTr").glob("*.nii.gz"):
            try:
                nib.load(str(f)).shape
                r.add(True)
            except Exception as e:
                r.add(False, f"{f.name}: {type(e).__name__}")
        return r

    def check_consistency(self):
        r = CheckResult("一致性")
        # 见上一节
        return r

    def check_plausibility(self):
        r = CheckResult("合理性")
        # 见上一节
        return r

    def check_quality(self):
        import nibabel as nib
        import numpy as np
        r = CheckResult("图像质量")
        for f in (self.root / "imagesTr").glob("*.nii.gz"):
            try:
                arr = nib.load(str(f)).get_fdata()
                if arr.std() < 1e-3:
                    r.add(False, f"{f.name}: 几乎无变化")
                else:
                    r.add(True)
            except Exception:
                r.add(False, f"{f.name}: 读取失败")
        return r

    def report(self) -> dict:
        out = {}
        for name, r in self.results.items():
            out[name] = {
                "通过": r.passed,
                "失败": r.failed,
                "失败明细": r.details[:20],       # 只留前 20 条
            }
        return out
```

### 用法

```python
p = QCPipeline(Path("data/v2_preprocessed"))
report = p.run()
Path("results/qc_report.json").write_text(
    json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8"
)

# 汇总打印
for name, r in report.items():
    flag = "✓" if r["失败"] == 0 else "✗"
    print(f"{flag} {name}: 通过 {r['通过']}, 失败 {r['失败']}")
```

### 什么时候跑

```
① 数据入库时       → 拦住源头问题
② 预处理之后       → 确认处理没搞坏东西
③ 训练之前         → 最后一道关
④ 提交代码之前     → 做成 pytest，防止回归
```

**第 4 条是把它变成工程规范。** 质检脚本不跑，等于没有。

## 十、常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 只查文件是否存在 | 半截文件混进去 | 实际读取一次 |
| 不检查图像内容 | 全黑的图进了训练 | 查 std |
| 检查写错但没人验证 | 以为数据干净 | 故意造错测试 |
| 质检范围太大 | 跑几小时没人愿意跑 | 抽样 + 增量 |
| 报告只有汇总没有明细 | 出问题不知道哪个文件 | 保留失败清单 |
| 不存档报告 | 无法对比 | 每次带时间戳 |
