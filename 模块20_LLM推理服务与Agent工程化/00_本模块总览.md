## 三、一个必须提前说的事实

**vLLM 在 Windows 上装不了。**

**实测（2026-11-12）：**

```
pip install vllm
  Downloading vllm-0.33.0.tar.gz (47.1 MB)      ← 只有源码包
```

**没有 Windows 的预编译 wheel。** 装它要本地编译 CUDA 扩展，需要：

```
CMake + CUDA Toolkit + MSVC，且三者版本完全匹配
```

**在 Windows 上成功率极低，而且即使装上，vLLM 的许多功能依赖 Linux 的调度特性。**

### 那你用什么

**你机器上已经装好了 Ollama，还有三个现成模型：**

```
qwen3-vl:8b-instruct-q4_K_M          5.8 GB   多模态，能看图
deepseek-coder-v2:16b-Q4_K_M         9.7 GB   代码
qwen2.5:7b-instruct-q4_K_M           4.4 GB   通用
```

**Ollama 在 Windows 上能跑，而且它的底层同样用了连续批处理。**

**所以这一节的策略是：**

```
vLLM 讲原理 + 说清 Windows 的限制
Ollama 做实操 + 用真实数据支撑所有结论
```

**你不需要 vLLM 才能理解 vLLM。**

## 四、硬件现实

**你的机器：RTX 5060 Laptop，8 GB 显存，32 GB 内存。**

**实测（2026-11-12，qwen2.5:7b Q4）：**

| 指标 | 值 |
|---|---|
| **TTFT（首 token 延迟）** | **0.03 秒** |
| 生成速度 | **74.6 tokens/s** |
| 一次对话总耗时 | 0.36 秒（含 24 个生成 token） |
| 首次加载 | 3.9 秒 |

**结论：7B 的 Q4 量化模型，8 GB 显存跑得很轻松。**

| 模型 | 8 GB 能跑吗 |
|---|---|
| 1.5B - 8B（Q4） | ✅ 轻松，70+ tokens/s |
| 14B（Q4） | ⚠️ 勉强，会掉速 |
| 32B（Q4） | ❌ 装不下 |
| 并发 2 个请求 | ⚠️ 显存翻倍，要降模型大小 |

**并发测试在 20-2 会做。**
