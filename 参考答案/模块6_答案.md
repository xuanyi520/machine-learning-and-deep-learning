### 练习 6-A（OR 表）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')
from sklearn.linear_model import LogisticRegression
from sklearn.impute import SimpleImputer
from scipy.stats import norm

h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')
y = (h['Class'] == 1).astype(int).values
cols = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
unit = {'Age': '岁', 'Bilirubin': 'mg/dL', 'Alk_Phosphate': 'U/L',
        'Sgot': 'U/L', 'Albumin': 'g/dL', 'Protime': '单位不明(0-100)'}

imp = SimpleImputer(strategy='median')
X = imp.fit_transform(h[cols])
model = LogisticRegression(C=np.inf, max_iter=5000).fit(X, y)

# Wald 标准误：SE = sqrt(diag((X'WX)^-1))，W = diag(p(1-p))
p_hat = model.predict_proba(X)[:, 1]
Xd = np.column_stack([np.ones(len(X)), X])
W = p_hat * (1 - p_hat)
cov = np.linalg.inv(Xd.T @ (Xd * W[:, None]))
se = np.sqrt(np.diag(cov))
beta = np.r_[model.intercept_, model.coef_[0]]
z975 = norm.ppf(0.975)
sd = X.std(axis=0, ddof=1)

def or_ci(b, s, scale=1.0):
    return np.exp(b * scale), np.exp((b - z975 * s) * scale), np.exp((b + z975 * s) * scale)

rows = []
for i, name in enumerate(cols, start=1):
    o, lo, hi = or_ci(beta[i], se[i])
    osd, losd, hisd = or_ci(beta[i], se[i], sd[i - 1])
    pval = 2 * (1 - norm.cdf(abs(beta[i] / se[i])))
    rows.append({'变量': name, '单位': unit[name], 'beta': round(beta[i], 3),
                 'OR': round(o, 3), '95%CI': f'{lo:.3f}-{hi:.3f}',
                 'p': round(pval, 3), 'OR_per_SD': round(osd, 3),
                 'SD': round(sd[i - 1], 2)})
print(pd.DataFrame(rows).to_string(index=False))

# 单变量 Age，和多变量模型对比
age = SimpleImputer(strategy='median').fit_transform(h[['Age']])
m1 = LogisticRegression(C=np.inf, max_iter=5000).fit(age, y)
p1 = m1.predict_proba(age)[:, 1]
X1 = np.column_stack([np.ones(len(age)), age])
c1 = np.linalg.inv(X1.T @ (X1 * (p1 * (1 - p1))[:, None]))
se1 = np.sqrt(np.diag(c1))
b1 = np.r_[m1.intercept_, m1.coef_[0]][1]
o, lo, hi = or_ci(b1, se1[1])
print(f'\nAge 单变量: OR={o:.4f}  95%CI={lo:.4f}-{hi:.4f}  '
      f'p={2 * (1 - norm.cdf(abs(b1 / se1[1]))):.4f}')
print(f'Age 多变量: OR={np.exp(beta[1]):.4f}  '
      f'95%CI={np.exp(beta[1] - z975 * se[1]):.4f}-'
      f'{np.exp(beta[1] + z975 * se[1]):.4f}  '
      f'p={2 * (1 - norm.cdf(abs(beta[1] / se[1]))):.4f}')
print('事件数 %d，变量数 %d，EPV=%.1f' % (y.sum(), len(cols), y.sum() / len(cols)))
```

**表注（可直接贴进论文）**：Age 单位为岁；Bilirubin 为 mg/dL；Alk_Phosphate、Sgot 为 U/L；Albumin 为 g/dL；Protime 原始取值 0-100，不是常见秒数，**编码存疑**，其 OR 方向与临床相反，解释时要注明。OR 为每 1 个单位；OR_per_SD 为每 1 个标准差。

**读法**：Bilirubin OR=2.009（CI 1.263-3.193），白蛋白 OR=0.220（CI 0.089-0.544），两个都不跨 1。Age 单变量 OR=1.044（CI 1.011-1.078）显著，多变量 OR=1.030（CI 0.991-1.070）不显著，**说明年龄的效应被肝功能指标吸收了一部分**。EPV=32/6=5.3，低于经验阈值 10，这张表的 CI 偏窄，换一批病人系数会动。

**判分要点**

- Bilirubin OR 在 1.9-2.1、CI 不跨 1（1.263-3.193）算对
- Albumin OR 在 0.20-0.24、CI 不跨 1（0.089-0.544）算对
- Age 单变量 1.044 显著、多变量 1.030 不显著，并把两个 CI 都写出来算满分
- SE 来自 `(X'WX)^-1` 的对角线，没有 import statsmodels 算对
- 额外给出 OR_per_SD 一列（1.448 / 2.295 / 0.855 / 0.876 / 0.392 / 0.554）算满分
- 表注写清单位和"每 1 unit / 每 1 SD"算对
- 只给出 OR 不给 CI，算部分分
- 用 `predict` 的 0/1 反推 OR，算错

**常见错误**

- 用 `penalty=None` → sklearn 1.8+ 报 FutureWarning 或参数错误 → 用 `C=np.inf`
- 把 OR 当 RR → 死亡率 20.6% 时 OR=2 大约只等于 RR=1.66 → 讨论部分说明，或改用 log-binomial
- 连续变量只报 per 1 unit → ALP 的 OR=0.997 看起来"没用"，换成 per SD 是 0.855 → 同时报 per SD
- 算 CI 时忘了乘 SD → per SD 的 CI 和 OR 对不上 → `exp((beta ± 1.96*SE) * SD)`
- 把截距也放进论文表 → 截距没有临床意义 → 只报 6 个变量
- 18 个变量全塞进去 → EPV=1.8，系数爆炸 → 预设 3-5 个临床变量，其余做敏感性分析

### 练习 6-B（L1 vs L2）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.metrics import roc_auc_score

h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')
y = (h['Class'] == 1).astype(int).values

num_cols = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
bin_cols = ['Sex', 'Steroid', 'Antivirals', 'Fatigue', 'Malaise', 'Anorexia',
            'Liver_Big', 'Liver_Firm', 'Spleen_Palpable', 'Spiders', 'Ascites', 'Varices']
Xall = pd.DataFrame(index=h.index)
for c in num_cols:
    Xall[c] = h[c]
for c in bin_cols:
    Xall[c] = (h[c] == 1).astype(float).where(h[c].notna())
Xall = Xall.fillna(Xall.median())
print('Xall', Xall.shape)

def make_lr(kind, C):
    if kind == 'l1':
        return LogisticRegression(penalty='l1', solver='liblinear', C=C, max_iter=5000)
    return LogisticRegression(penalty='l2', C=C, max_iter=5000)

def fit_coef(kind, C):
    pipe = Pipeline([('scale', StandardScaler()), ('clf', make_lr(kind, C))])
    return pipe.fit(Xall, y).named_steps['clf'].coef_[0]

print('\nC      L1非零  L2非零')
for C in [0.02, 0.05, 0.1, 0.3, 1.0]:
    n1 = int((np.abs(fit_coef('l1', C)) > 1e-8).sum())
    n2 = int((np.abs(fit_coef('l2', C)) > 1e-8).sum())
    print(f'{C:<6} {n1:^6d} {n2:^6d}')

c1, c2 = fit_coef('l1', 0.1), fit_coef('l2', 0.1)
print('\n' + pd.DataFrame({'变量': Xall.columns,
                           'L1_C0.1': c1.round(3),
                           'L2_C0.1': c2.round(3)}).to_string(index=False))
print('\nL1 保留:', [Xall.columns[i] for i in np.where(np.abs(c1) > 1e-8)[0]])
print('L2 最小|系数|=%.4f (%s)' % (np.abs(c2).min(), Xall.columns[np.argmin(np.abs(c2))]))

cv = StratifiedKFold(5, shuffle=True, random_state=0)
print('\nC      L1_AUC           L2_AUC')
for C in [0.02, 0.05, 0.1, 0.3, 1.0]:
    out = []
    for kind in ['l1', 'l2']:
        p = Pipeline([('scale', StandardScaler()), ('clf', make_lr(kind, C))])
        s = cross_val_score(p, Xall, y, cv=cv, scoring='roc_auc')
        out.append(f'{s.mean():.3f}+-{s.std():.3f}')
    print(f'{C:<6} {out[0]:16s} {out[1]}')

# L1 系数路径
Cs = np.logspace(-2.2, 0.5, 40)
paths = np.array([fit_coef('l1', C) for C in Cs])
fig, ax = plt.subplots(figsize=(8, 5))
for j in range(paths.shape[1]):
    ax.plot(Cs, paths[:, j], lw=1, label=Xall.columns[j])
ax.set_xscale('log')
ax.set_xlabel('C (log scale)')
ax.set_ylabel('standardized coefficient')
ax.axhline(0, color='k', lw=0.5)
ax.set_title('L1 coefficient path')
print('\n路径图: %d 个 C x %d 个系数' % paths.shape)
print('Sgot 与 Bilirubin 相关: %.3f' % Xall['Sgot'].corr(Xall['Bilirubin']))
print('Sgot 单变量 AUC: %.3f' % roc_auc_score(y, Xall['Sgot']))
```

**读法**：C=0.02 时 L1 把 18 个系数全压成 0，模型对所有人输出同一个概率，AUC 正好 0.500。C 增大，系数逐个解冻：0.05 有 4 个，0.1 有 6 个，0.3 以后到 15 个。L2 在任何 C 下都是 18/18，只是整体变小。

C=0.1 时 L1 保留 6 个：**Bilirubin、Albumin、Protime、Malaise、Spiders、Ascites**。前三项对应肝合成/排泄功能，Malaise 是全身症状，后两项是门脉高压体征。

Sgot 被压成 0，不是因为它没信息（单变量 AUC 0.569），而是因为**给定 Bilirubin 之后它的增量信息接近 0**：两者相关 0.236，Bilirubin 的 AUC 是 0.755，模型先用 Bilirubin 解释掉了大部分。L1 在相关特征之间是"随机挑一个"，不是挑"更对的"那个，换一份数据被留下的可能是 Sgot。

L2 最小系数是 Sgot 的 0.0145，**不能解释成"没影响"**。它只是被 L2 按平方惩罚整体压小了；在 6-A 里 Sgot 的每 SD OR 是 0.876，方向仍然是保护，只是 CI 跨 1。

补充：C=0.3 的 L1 非零数在重跑时可能是 14 或 15。最弱的那个系数在 4e-5 附近，liblinear 收敛时会在 0 和 4e-5 之间跳。**"保留几个"本身带数值容差**，报告时要写清阈值（这里用 `|coef| > 1e-8`）。

**判分要点**

- C=0.02 时 L1 为 0、L2 为 18 算对
- C=0.1 时 L1 为 6，且能列出 6 个变量名算满分
- 能说出"Sgot 的 0 是给定 Bilirubin 后的冗余，不是单变量无效"算满分
- L2 最小系数 0.0145，明确说"不能解释成没影响"算对
- 用 CV 选 C（L1 在 0.1 最好，0.02 退化成 0.500）算加分
- 只说"L1 能做特征选择，所以更好"算部分分
- 说"L1 保留的变量更重要"算错

**常见错误**

- 不标准化就直接加惩罚 → ALP（26-295）和 Albumin（2.1-6.4）尺度不同，惩罚不公平 → Pipeline 里先 StandardScaler
- 以为 C 越大正则越强 → 实际 C 约等于 1/lambda，C 越小惩罚越重 → 记住 C=0.02 全压成 0
- L1 用默认 lbfgs → 报 `Solver lbfgs supports only l2` → L1 用 `solver='liblinear'` 或 `saga`
- 把 L1 的 0 当成"这个变量临床上不重要" → 它只是在这组变量里冗余 → 换数据集/换 C 重跑，报告 bootstrap 选择频率
- 用训练集准确率选 C → 永远选正则最弱的 → 用交叉验证 AUC

### 练习 6-C（维度灾难）

**参考代码**

```python
import numpy as np
import warnings
warnings.filterwarnings('ignore')
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import Pipeline
from sklearn.metrics import pairwise_distances

def run(d, n_inf, n_samples=600, seed=42):
    X, y = make_classification(n_samples=n_samples, n_features=d, n_informative=n_inf,
                               n_redundant=0, class_sep=1.0, flip_y=0.03, random_state=seed)
    Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25,
                                          stratify=y, random_state=0)
    pipe = Pipeline([('sc', StandardScaler()),
                     ('knn', KNeighborsClassifier(5))]).fit(Xtr, ytr)
    Z = StandardScaler().fit_transform(Xte)
    D = pairwise_distances(Z)
    np.fill_diagonal(D, np.nan)          # 排除自己到自己的 0
    ratio = (np.nanmin(D, axis=1) / np.nanmax(D, axis=1)).mean()
    return pipe.score(Xte, yte), ratio

print('第一组：固定 2 个有用特征')
for d in [2, 10, 50, 200, 500]:
    a, r = run(d, 2)
    print(f'd={d:<4} acc={a:.3f} 最近/最远={r:.3f}')

print('\n第二组：固定 200 维')
for k in [2, 10, 50, 100]:
    a, r = run(200, k)
    print(f'n_inf={k:<4} acc={a:.3f} 最近/最远={r:.3f}')

print('\n加样本 (d=200, n_inf=2)')
for n in [600, 2000, 6000]:
    a, r = run(200, 2, n_samples=n)
    print(f'n={n:<5} acc={a:.3f} 最近/最远={r:.3f}')

fig, axes = plt.subplots(1, 2, figsize=(11, 4))
d_list = [2, 10, 50, 200, 500]
acc1 = [run(d, 2)[0] for d in d_list]
axes[0].plot(d_list, acc1, 'o-')
axes[0].set_xscale('log')
axes[0].set_xlabel('dimension')
axes[0].set_ylabel('test accuracy')
k_list = [2, 10, 50, 100]
acc2 = [run(200, k)[0] for k in k_list]
axes[1].plot(k_list, acc2, 's-')
axes[1].set_xlabel('n_informative')
axes[1].set_ylabel('test accuracy')
plt.tight_layout()
```

**读法**：第一组准确率从 0.887 降到 0.560，最近/最远比从 0.036 升到 0.862。d=2 时最近的邻居只有最远邻居的 3.6%，"近"很有区分度；d=500 时这个比例到 86.2%，**所有点几乎一样远，"最近邻"失去意义**。

第二组固定 200 维，有用特征从 2 增到 100，准确率从 0.587 恢复到 0.747，但仍低于 2 维的 0.887。原因是另外 100 维噪声还在，距离比只从 0.799 降到 0.777，几何性质没有根本改变。**有用特征变多只能部分恢复，不能回到低维水平。**

加样本救不了：600 到 6000，样本翻 10 倍，准确率 0.587 到 0.587，距离比 0.799 到 0.746。最近邻距离按 `n^(-1/d)` 下降，d=200 时样本翻 10 倍，距离只降约 `10^(-1/200) ≈ 1.1%`。**指数级的维度需要指数级的样本。**

几何原因：d 维球的体积正比于 `r^d`，体积集中在表面薄壳；任意两个随机点的距离趋近 `sqrt(2d)`，相对波动按 `1/sqrt(d)` 缩小。于是 `(最远距离 - 最近距离) / 最近距离 → 0`。这不是"数据不够"，是空间本身的性质。

**判分要点**

- 第一组准确率 0.887 → 0.560、距离比 0.036 → 0.862，数量级对算对
- 第二组 200 维、100 个有用特征时准确率 0.747，仍低于 2 维的 0.887 算对
- 答出"距离集中"的几何原因，而不是"样本不够"算满分
- 加样本实验（600 → 6000 准确率基本不动）算加分
- 只说"维度高所以不好"算部分分
- 说"多加点样本就能解决"算错

**常见错误**

- 用 `pdist` 的全局最小/最大算比值 → d=2 会得到 0.002 而不是 0.036，因为全局最远点对不是每个点各自的最远邻 → 按每个测试点算 `最近/最远`，再取平均
- `np.fill_diagonal(D, np.inf)` 后又用 `D.max(axis=1)` → 最大值变成 inf，比值全 0 → 用 `np.nan` 填对角线，再用 `nanmin/nanmax`
- 不标准化就算距离 → ALP 式的量纲主导，维度效应被掩盖 → Pipeline 里先 StandardScaler
- 在训练集上算距离比 → 训练集点更多、更密，比值偏小 → 在测试集上算
- 用 `n_informative` 等于总维度 → 那是"全有用"，当然不掉 → 噪声维度才是灾难的来源

### 练习 6-D（手算 Gini 和信息增益）

**参考代码**

```python
import numpy as np
import pandas as pd
from sklearn.tree import DecisionTreeClassifier, export_text

df = pd.DataFrame({
    'A': [1, 1, 0, 0, 1, 0, 0, 0],
    'B': [1, 0, 1, 0, 0, 0, 0, 0],
    'y': [1, 1, 1, 1, 0, 0, 0, 0],
})

def H(s):
    p = s.mean()
    if p in (0, 1):
        return 0.0
    return -(p * np.log2(p) + (1 - p) * np.log2(1 - p))

def G(s):
    p = s.mean()
    return 1 - (p ** 2 + (1 - p) ** 2)

def split_info(s):
    p = s.value_counts(normalize=True).values
    return -(p * np.log2(p)).sum()

print('根节点 n=%d 死亡=%d H=%.4f Gini=%.4f' %
      (len(df), df.y.sum(), H(df.y), G(df.y)))
for f in ['A', 'B']:
    ig, gg, si = H(df.y), G(df.y), split_info(df[f])
    for v, g in df.groupby(f):
        w = len(g) / len(df)
        print(f'  {f}={v}: n={len(g)} 死={g.y.sum()} '
              f'H={H(g.y):.4f} Gini={G(g.y):.4f}')
        ig -= w * H(g.y)
        gg -= w * G(g.y)
    print(f'  IG({f})={ig:.4f}  Gini gain({f})={gg:.4f}  '
          f'splitinfo={si:.4f}  gain_ratio={ig / si:.4f}\n')

for crit in ['entropy', 'gini']:
    t = DecisionTreeClassifier(criterion=crit, max_depth=1, random_state=0)
    t.fit(df[['A', 'B']], df['y'])
    print(f'{crit:8s} 选中: {["A", "B"][t.tree_.feature[0]]}  '
          f'根不纯度={t.tree_.impurity[0]:.4f}')
    print(export_text(t, feature_names=['A', 'B']))
```

**手算过程**

根节点：8 人，4 死 4 活。

```
H(root)    = -0.5*log2(0.5) - 0.5*log2(0.5) = 1.0000
Gini(root) = 1 - (0.5^2 + 0.5^2) = 0.5000
```

按 A 分：A=1 有 3 人（病人 1、2、5），2 死 1 活；A=0 有 5 人（3、4、6、7、8），2 死 3 活。

```
A=1: H = -(2/3)*log2(2/3) - (1/3)*log2(1/3) = 0.9183
     Gini = 1 - ((2/3)^2 + (1/3)^2) = 1 - 5/9 = 0.4444
A=0: H = -(2/5)*log2(2/5) - (3/5)*log2(3/5) = 0.9710
     Gini = 1 - ((2/5)^2 + (3/5)^2) = 1 - 13/25 = 0.4800

IG(A)        = 1.0000 - (3/8)*0.9183 - (5/8)*0.9710
             = 1.0000 - 0.3444 - 0.6069 = 0.0488
Gini gain(A) = 0.5000 - (3/8)*0.4444 - (5/8)*0.4800
             = 0.5000 - 0.1667 - 0.3000 = 0.0333
```

按 B 分：B=1 有 2 人（1、3），2 死；B=0 有 6 人，2 死 4 活。

```
B=1: H = 0.0000   Gini = 0.0000
B=0: H = -(2/6)*log2(2/6) - (4/6)*log2(4/6) = 0.9183
     Gini = 1 - ((1/3)^2 + (2/3)^2) = 1 - 5/9 = 0.4444

IG(B)        = 1.0000 - (2/8)*0 - (6/8)*0.9183 = 0.3113
Gini gain(B) = 0.5000 - (2/8)*0 - (6/8)*0.4444 = 0.1667
```

增益率：

```
splitinfo(A) = -(3/8)*log2(3/8) - (5/8)*log2(5/8)
             = 0.375*1.4150 + 0.625*0.6781 = 0.9544
gain_ratio(A) = 0.0488 / 0.9544 = 0.0511

splitinfo(B) = -(2/8)*log2(2/8) - (6/8)*log2(6/8)
             = 0.25*2.0000 + 0.75*0.4150 = 0.8113
gain_ratio(B) = 0.3113 / 0.8113 = 0.3837
```

三种准则都选 B：信息增益 0.3113 > 0.0488，Gini gain 0.1667 > 0.0333，增益率 0.3837 > 0.0511。

**实测输出**

```
根节点 n=8 死亡=4 H=1.0000 Gini=0.5000
  A=0: n=5 死=2 H=0.9710 Gini=0.4800
  A=1: n=3 死=2 H=0.9183 Gini=0.4444
  IG(A)=0.0488  Gini gain(A)=0.0333  splitinfo=0.9544  gain_ratio=0.0511

  B=0: n=6 死=2 H=0.9183 Gini=0.4444
  B=1: n=2 死=2 H=0.0000 Gini=0.0000
  IG(B)=0.3113  Gini gain(B)=0.1667  splitinfo=0.8113  gain_ratio=0.3837

entropy  选中: B  根不纯度=1.0000
|--- B <= 0.50
|   |--- class: 0
|--- B >  0.50
|   |--- class: 1

gini     选中: B  根不纯度=0.5000
|--- B <= 0.50
|   |--- class: 0
|--- B >  0.50
|   |--- class: 1
```

**读法**：A 把数据切成 3/5，两边都不纯，IG 只有 0.0488；B 切出一个纯节点（2 个都死），虽然只有 2 个人，但 IG 到 0.3113。**这正是信息增益偏爱"能切出纯子集"的变量的原因，也是它偏爱高基数变量的原因**——如果按病人 ID 分，每个叶子一个样本，IG 最大但毫无意义。增益率用 splitinfo 惩罚了 B 的 2/8 不平衡（0.8113 < A 的 0.9544），但 B 仍然赢，说明这里的纯度提升是真实的。

sklearn 的 `max_depth=1` 两种 criterion 都选 B，和手算一致。

**判分要点**

- 根节点 H=1.0000、Gini=0.5000 算对
- IG(A)=0.0488、Gini gain(A)=0.0333 算对
- IG(B)=0.3113、Gini gain(B)=0.1667 算对
- 增益率 A=0.0511、B=0.3837 算对
- sklearn 两种 criterion 都选 B，并指出与手算一致算满分
- 中间步骤（各子节点的 H 和 Gini）写出来算满分
- 只报最终数字、没有过程，算部分分
- 用自然对数算 IG（数值变成 0.0338 / 0.2158）算错，题目要求 log2

**常见错误**

- 忘记按子节点样本数加权 → IG 直接减两个子节点熵 → 数值对不上
- 把 Gini gain 和 Gini 本身混了 → 根节点 Gini 0.5 是"不纯度"，0.0333 是"下降量"
- 增益率写成 `IG * splitinfo` → 应该是除法 `IG / splitinfo`
- 除以 `log2(类别数)` 而不是 splitinfo → 公式记错
- `H` 在 p=0 或 p=1 时算 `log2(0)` → 报 `-inf` 或 warning → 加边界判断
- 以为 B 只有 2 个人所以"不可靠" → 这道题问的是划分准则，不是样本量；可靠性是 6-E 的问题

### 练习 6-E（读树，找不可靠规则）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeClassifier, export_text, plot_tree

h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')
y = (h['Class'] == 1).astype(int).values

num_cols = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
bin_cols = ['Sex', 'Steroid', 'Antivirals', 'Fatigue', 'Malaise', 'Anorexia',
            'Liver_Big', 'Liver_Firm', 'Spleen_Palpable', 'Spiders', 'Ascites', 'Varices']
Xall = pd.DataFrame(index=h.index)
for c in num_cols:
    Xall[c] = h[c]
for c in bin_cols:
    Xall[c] = (h[c] == 1).astype(float).where(h[c].notna())
Xall = Xall.fillna(Xall.median())

tree = DecisionTreeClassifier(max_depth=3, min_samples_leaf=8, random_state=0)
tree.fit(Xall, y)
print(export_text(tree, feature_names=list(Xall.columns),
                  decimals=2, show_weights=True))

leaf = tree.apply(Xall)
rows = []
for lf in sorted(set(leaf)):
    m = leaf == lf
    n = int(m.sum())
    d = int(y[m].sum())
    rows.append((lf, n, d, d / n))
print('\n每个叶子:')
print(pd.DataFrame(rows, columns=['leaf_id', 'n', '死亡', '死亡率']).to_string(index=False))

imp = pd.Series(tree.feature_importances_, index=Xall.columns).sort_values(ascending=False)
print('\n特征重要性前 8:')
print(imp.head(8).round(3).to_string())
print('Bilirubin 重要性:', imp['Bilirubin'],
      ' 是否被分裂:', bool((tree.tree_.feature == list(Xall.columns).index('Bilirubin')).any()))
print('训练准确率:', round(tree.score(Xall, y), 3),
      ' 叶子数:', tree.get_n_leaves(), ' 深度:', tree.get_depth())

fig = plt.figure(figsize=(13, 6))
plot_tree(tree, feature_names=list(Xall.columns), class_names=['alive', 'dead'],
          filled=True, rounded=True, proportion=True, fontsize=9)
plt.tight_layout()
print('Albumin 与 Bilirubin 相关:', round(Xall['Albumin'].corr(Xall['Bilirubin']), 3))
```

**读法**：`weights: [存活数, 死亡数]`，class 0=存活、1=死亡。5 个叶子：

| 叶子规则 | n | 死亡 | 死亡率 | 预测 |
|---|---|---|---|---|
| Albumin <= 2.85 | 13 | 11 | 84.6% | 死亡 |
| Albumin > 2.85，Protime <= 44.5，ALP <= 113.5 | 8 | 6 | 75.0% | 死亡 |
| Albumin > 2.85，Protime <= 44.5，ALP > 113.5 | 8 | 3 | 37.5% | 存活 |
| Albumin > 2.85，Protime > 44.5，无蜘蛛痣 | 93 | 2 | 2.2% | 存活 |
| Albumin > 2.85，Protime > 44.5，有蜘蛛痣 | 33 | 10 | 30.3% | 存活 |

**不可靠规则 1**：`Albumin > 2.85 且 Protime <= 44.5 且 ALP <= 113.5 → 预测死亡`，只有 **8 个人**（6 死 2 活）。

不可靠的理由：

- 8 个样本撑一条三条件规则，换一个病人规则就可能翻（6 死 2 活，加 1 个存活就变成 6/9）
- Protime 44.5 在这份数据里是偏短的一侧（中位数 61），凝血时间短通常意味着凝血功能好，方向与临床相反
- ALP 113.5 接近正常上限（常用上限约 120 U/L），用一个"正常"的碱性磷酸酶预测死亡，没有病理机制
- 这是典型的"小样本把噪声学成规则"

**不可靠规则 2**：`Protime > 44.5 且有蜘蛛痣 → 预测存活`，n=33，10 死，死亡率 30.3%，**高于全队列 20.6% 却预测存活**。而且这个节点的两个孩子（有/无蜘蛛痣）都预测存活，这次分裂没有改变任何人的预测类别，只是把 Gini 降了一点。树的贪心准则允许这种"无效分裂"。

**Bilirubin 一次都没被用到**：重要性 0.000，`是否被分裂: False`。但在 6-A 的多变量逻辑回归里，Bilirubin 的 OR=2.009、p=0.003，是最强的独立因子。原因有两条：

- **贪心**：每一步只选"当前能把 Gini 降最多"的特征。Albumin 先被选了（重要性 0.509），后面不再回头检查"换一个变量组合是否更好"。
- **相关**：Albumin 与 Bilirubin 相关 -0.371。Albumin 已经解释了一部分胆红素的信息，Bilirubin 的增量 Gini 增益被压到很小，再也没有机会进来。

**结论：树的特征重要性不是因果重要性，也不是"这个变量没用"。** 要给 OR 和 CI 用逻辑回归；要给医生规则用树，但必须标注每条规则的样本量。

**判分要点**

- 用 `export_text` 打出 5 个叶子，并给每个叶子标 n、死亡数、死亡率算对
- 至少找出一条 n<10 的规则（这里是 8 人），说明"样本太少、换一个病人就翻"算满分
- 指出 `Protime <= 44.5 + ALP <= 113.5 → 死亡` 只有 8 人支撑算满分
- 说出 Bilirubin 重要性 0，但多变量 LR 里 p=0.003 算对
- 能解释"贪心 + 特征相关（-0.371）导致强变量被漏掉"算满分
- 只说"树选了 Albumin，所以 Albumin 最重要"算部分分
- 说"Bilirubin 对死亡没影响"算错

**常见错误**

- 把 `weights` 当成 `[死亡数, 存活数]` → 方向全反 → sklearn 按类别 0/1 排序，是 `[存活, 死亡]`
- 只看叶子的预测类别，不看死亡率 → 漏掉"30.3% 死亡率却预测存活"这条矛盾 → 每个叶子都算死亡率
- 把"树的特征重要性=0"解释成"变量无效" → 这是条件重要性，不是边际效应 → 用 LR 的 OR 或 permutation importance 交叉验证
- 不限制 `min_samples_leaf` → 树长到 19 个叶子、训练准确率 1.0，规则全是噪声 → 用 CV 选剪枝参数
- 把树规则当因果结论 → "Albumin 低导致死亡" → 只能说"该节点里死亡率高"

### 练习 6-F（换一份数据做完整对比）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import make_scorer, confusion_matrix

hd = pd.read_csv(r'E:\AI学习\练习代码\data\uci\HeartDisease.csv')
y = (hd['num'] > 0).astype(int).values

cat_cols = ['cp', 'restecg', 'slope', 'thal', 'ca']       # 分类编码，不能当连续值
num_cols = ['age', 'trestbps', 'chol', 'thalach', 'oldpeak']
bin_cols = ['sex', 'fbs', 'exang']

pre = ColumnTransformer([
    ('num', Pipeline([('imp', SimpleImputer(strategy='median')),
                      ('sc', StandardScaler())]), num_cols),
    ('cat', Pipeline([('imp', SimpleImputer(strategy='most_frequent')),
                      ('oh', OneHotEncoder(handle_unknown='ignore',
                                           drop='first'))]), cat_cols),
    ('bin', SimpleImputer(strategy='most_frequent'), bin_cols),
])
X = hd[num_cols + cat_cols + bin_cols]

def specificity(y_true, y_pred):
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred, labels=[0, 1]).ravel()
    return tn / (tn + fp)

spec = make_scorer(specificity)
cv = StratifiedKFold(5, shuffle=True, random_state=0)

models = {
    'LR': LogisticRegression(max_iter=5000),
    'KNN k=15': KNeighborsClassifier(15),
    'SVM rbf': SVC(kernel='rbf', C=1.0, gamma='scale'),
    'DT depth=3': DecisionTreeClassifier(max_depth=3, random_state=0),
}
print(f'{"模型":12s} {"AUC":>16s} {"accuracy":>16s} {"recall":>16s} {"specificity":>16s}')
for name, clf in models.items():
    pipe = Pipeline([('pre', pre), ('clf', clf)])
    out = []
    for sc in ['roc_auc', 'accuracy', 'recall', spec]:
        s = cross_val_score(pipe, X, y, cv=cv, scoring=sc)
        out.append(f'{s.mean():.3f}+-{s.std():.3f}')
    print(f'{name:12s} ' + ' '.join(f'{v:>16s}' for v in out))

print('\n阳性 %d / 阴性 %d，阳性率 %.3f' % (y.sum(), (1 - y).sum(), y.mean()))
print('转换后特征数:', pre.fit(X, y).transform(X).shape[1])
```

**实测输出**

```
模型                        AUC         accuracy           recall      specificity
LR               0.916+-0.005     0.848+-0.013     0.806+-0.030     0.884+-0.011
KNN k=15         0.882+-0.021     0.796+-0.039     0.706+-0.081     0.872+-0.048
SVM rbf          0.894+-0.014     0.815+-0.021     0.785+-0.070     0.842+-0.029
DT depth=3       0.822+-0.025     0.756+-0.043     0.683+-0.028     0.818+-0.078

阳性 139 / 阴性 164，阳性率 0.459
转换后特征数: 20
```

**选型理由（三句话）**：

1. LR 的 AUC 0.916 最高，且 std 只有 0.005，是四个里最稳的。
2. 这份数据要写进临床报告，需要每个变量的方向和 OR，树和 RBF SVM 给不了，LR 直接给。
3. DT 的 AUC 0.822 明显低一档，只能作为给医生看的规则补充，不作为主模型。

**读法**：LR 0.916 > SVM 0.894 > KNN 0.882 > DT 0.822。LR 和 SVM 差 0.022，std 分别是 0.005 和 0.014，这个差距已经超过两个模型各自的标准差，可以说 LR 更稳；但 SVM 的 recall 和 LR 接近，如果只关心排序、不需要系数，SVM 也能用。DT 低 0.09，是单棵树的方差问题，不是数据问题——换成随机森林通常能追到 0.90 以上。

`ca`（0-3）和 `thal`（3/6/7）虽然存成数字，但它们是**分类编码**，不是连续测量。当成数值喂给 LR，等于假设"ca=3 和 ca=0 的距离是 ca=1 的 3 倍"，没有临床依据。所以 one-hot 后特征从 13 个变成 20 个。

**判分要点**

- LR 的 AUC 在 0.88-0.93（实测 0.916）算对
- DT 的 AUC 明显低于其他三个（实测 0.822）算对
- 四个模型都报告 AUC、accuracy、recall、specificity 的 `mean ± std` 算满分
- `ca`、`thal` 按分类变量 one-hot，`num>0` 作为目标算对
- 预处理（插补、标准化、one-hot）全部放在 Pipeline/ColumnTransformer 里算对
- 选型理由绑定"是否需要解释"，而不是"谁 AUC 高选谁"算满分
- 只报 AUC 一个指标，算部分分
- 把 `ca`、`thal` 当连续数值直接喂进去，算部分分（AUC 可能接近，但编码逻辑错）

**常见错误**

- 在 `cross_val_score` 之前做 `fit_transform` → 插补和标准化用了验证折，指标虚高 → 全部放进 Pipeline
- `OneHotEncoder` 不设 `handle_unknown='ignore'` → 某一折出现训练时没见过的类别会报错 → 加上这个参数
- 用 accuracy 选模型 → 阳性率 45.9%，accuracy 0.85 和 0.80 的差别可能只是阈值位置 → 看 AUC + recall + specificity
- 只报一个数字不报 std → 0.916 和 0.916±0.005 是两种信息 → 必须报 mean ± std
- 把 `num` 当连续目标做回归 → 题目要的是二分类"有/无心脏病" → 先 `num > 0`
- 选型写"因为 LR 的 AUC 最高" → 这只说了一半 → 补上"需要 OR/可解释性/校准概率"

---

**一句话总结这六题**：6-A 是"能不能把系数翻译成医生的话"，6-B 是"正则化到底把系数怎么了"，6-C 是"距离在高维为什么会失效"，6-D 是"分裂准则的手感"，6-E 是"树给的规则哪些不能信"，6-F 是"换一份数据，整套流程能不能复用"。
