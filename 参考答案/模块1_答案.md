# 1-1 向量与矩阵

## 练习 1-1-A

`A` 有 2 行 3 列，形状是 `(2, 3)`。

```python
A = np.array([[2,0,1],[1,3,2]])
print(A.shape)    # (2, 3)
```

## 练习 1-1-B

**A @ B：**

```
A = [[2,0],      B = [[1,4],
     [1,3]]           [2,5]]

A@B = [[2*1+0*2, 2*4+0*5],   [[2,  8],
       [1*1+3*2, 1*4+3*5]] =  [7, 19]]
```

**B @ A：**

```
B@A = [[1*2+4*1, 1*0+4*3],   [[6, 12],
       [2*2+5*1, 2*0+5*3]] =  [9, 15]]
```

**`[[2,8],[7,19]]` 和 `[[6,12],[9,15]]` 完全不同。** 这就是交换律不成立的实证。

```python
A = np.array([[2,0],[1,3]])
B = np.array([[1,4],[2,5]])
print("A@B =", (A@B).tolist())    # [[2, 8], [7, 19]]
print("B@A =", (B@A).tolist())    # [[6, 12], [9, 15]]
```

## 练习 1-1-C

**报错原因**：`X` 是 `(32, 784)`，`W` 是 `(32, 10)`。矩阵乘法要求左边列数 = 右边行数，即 `784 == 32`。**不成立。**

报错信息类似：`ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0`

**两种修法：**

```python
# 修法1：把 W 改成 (784, 10)
W = np.random.randn(784, 10)
y = X @ W          # OK -> (32, 10)

# 修法2：转置 X（前提是语义上说得通）
y = X.T @ W        # (784,32) @ (32,10) -> (784, 10)
```

**哪种对？取决于你想算什么。** 修法 1 是把 784 维输入映射到 10 维输出（正确）；修法 2 是转置后算别的（这里没有意义）。**不要为了让它跑起来就随便转置。**

## 练习 1-1-D

**1.** 64 张 28×28 的图，每张拉平是 784 维，所以整体是 `(64, 784)`。

**2.** 全连接层 `784 → 10`：
- 权重 `W` 形状 `(784, 10)`
- 偏置 `b` 形状 `(10,)`

**3.**

```python
X = np.random.randn(64, 784)          # 一批输入
W = np.random.randn(784, 10)          # 权重
b = np.random.randn(10)               # 偏置

y = X @ W + b                         # (64,10) + (10,) = (64,10)
print(y.shape)                        # (64, 10)
```

**注意 `+b` 为什么能work**：`(64,10)` 加 `(10,)` 时，numpy 自动把 b 广播到每一行。这叫**广播（broadcasting）**。这是你以后天天要用的特性。

## 自测题答案

1. `(5, 3) × (3, 7) = (5, 7)`。中间塌陷，两头留下。
2. 会报错。`3 != 5`，中间对不上。
3. `@` 是矩阵乘法（行列配对求和），`*` 是逐元素相乘。**用错通常不报错，只是结果悄悄不对。**
4. `(1000, 32, 32, 3)`。顺序是 `(批次, 高, 宽, 通道)`。

> **注意**：PyTorch 用的是 `(批次, 通道, 高, 宽)`，也就是 `(1000, 3, 32, 32)`。**numpy/OpenCV 习惯和 PyTorch 不同**，这是迁移时必踩的坑。第 3-4 节你会遇到。

# 1-2 微积分与梯度

## 练习 1-2-A

**1.** `f(x) = 5x³ - 2x + 7`
```
f'(x) = 15x² - 2
```
（5x³ 的导数是 5·3x² = 15x²；-2x 的导数是 -2；常数 7 的导数是 0）

**2.** `f(x) = (2x+1)²`
```
令 u = 2x+1，f = u²
df/du = 2u
du/dx = 2
f'(x) = 2u · 2 = 4(2x+1) = 8x + 4
```

**3.** `f(x,y) = x²y + 3xy²`
```
∂f/∂x = 2xy + 3y²        （把 y 当常数：x²y → 2xy；3xy² → 3y²）
∂f/∂y = x² + 6xy         （把 x 当常数：x²y → x²；3xy² → 6xy）
```

## 练习 1-2-B

```python
import numpy as np

def f(x):
    return 5*x**3 - 2*x + 7

def analytic(x):
    return 15*x**2 - 2

def numerical(f, x, h=1e-5):
    return (f(x+h) - f(x-h)) / (2*h)

x = 2.0
a, n = analytic(x), numerical(f, x)
print(f"手算={a:.6f}  数值={n:.6f}  差={abs(a-n):.2e}")
# 手算=58.000000  数值=58.000000  差≈1e-10
```

差在 `1e-10` 量级，远小于要求的 `1e-6`。

**为什么不是完全相等**：数值梯度是近似（用割线代替切线），h 越小越准，但太小会被浮点误差淹没。`1e-5` 是个好折中。

## 练习 1-2-C

```python
import numpy as np

def f(x):
    return (x + 4)**2

def grad(x):
    return 2*(x + 4)      # 链式法则：外层 2(x+4)，内层导数 1

x = 10.0
lr = 0.1
xs = [x]

for i in range(30):
    x = x - lr * grad(x)
    xs.append(x)
    print(f"第{i+1:2d}步  x={x:9.5f}  f(x)={f(x):10.6f}")

print(f"\n最终 x = {x:.6f}")
```

**最终 x 应该接近 -4**（函数最小值在 x = -4 处，值为 0）。

**中间过程**：x 从 10 每次乘以 `(1 - 2*0.1) = 0.8`。所以是 10 → 6.2 → 3.96 → ... 指数逼近 -4。

## 练习 1-2-D

```python
import matplotlib.pyplot as plt
import numpy as np

matplotlib.rcParams['font.sans-serif'] = ['SimHei']
matplotlib.rcParams['axes.unicode_minus'] = False

def f(x): return (x + 4)**2
def grad(x): return 2*(x + 4)

x, lr = 10.0, 0.1
xs, fs = [x], [f(x)]

for _ in range(30):
    x = x - lr * grad(x)
    xs.append(x)
    fs.append(f(x))

fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].plot(fs, 'o-')
axes[0].set_xlabel('迭代步数'); axes[0].set_ylabel('f(x)')
axes[0].set_title('损失曲线'); axes[0].grid(alpha=0.3)

axes[1].plot(range(len(xs)), xs, 'o-')
axes[1].axhline(-4, color='r', linestyle='--', label='最优 x=-4')
axes[1].set_xlabel('迭代步数'); axes[1].set_ylabel('x')
axes[1].set_title('x 的移动轨迹'); axes[1].legend(); axes[1].grid(alpha=0.3)

plt.tight_layout(); plt.show()
```

**损失曲线**：快速下降然后趋平（趋近 0），这是"收敛"的样子。
**轨迹**：x 从 10 平滑滑向 -4，越接近越慢。

## 练习 1-2-E

lr = 1.1 时，每次更新是：
```
x_new = x - 1.1 * 2(x+4) = x - 2.2(x+4)
```

令 `d = x + 4`（离最优点的距离），则 `d_new = d - 2.2d = -1.2d`。

**每步距离乘以 -1.2**：绝对值在**变大**（1.2 > 1），符号在翻转。

结果：x 在 -4 两侧剧烈来回跳，且越跳越远，**发散**。

**结论**：学习率必须满足 `|1 - lr * 2| < 1`，即 `0 < lr < 1`。lr ≥ 1 就发散。

## 自测题答案

1. 导数描述"输入变化一点点，输出会变化多少倍"——变化率。
2. 梯度是把所有偏导数打包成的向量，每个分量是对应变量的偏导数。
3. 因为梯度指向**上升最快**的方向，要下降就得往反方向走。
4. lr 太大 → 震荡或发散（loss 变大甚至 nan）；太小 → 收敛极慢。
5. 复合函数求导时，各层导数连乘。

# 1-3 概率与统计

## 练习 1-3-A

假设 10000 人。

- 患病：`10000 × 2% = 200` 人
- 健康：`9800` 人

检测结果：

- 患病的 200 人中阳性：`200 × 90% = 180`（TP）
- 健康的 9800 人中阳性（假阳性）：`9800 × (1 - 98%) = 9800 × 2% = 196`（FP）

阳性总人数：`180 + 196 = 376`

```
P(患病|阳性) = 180 / 376 ≈ 0.4787 ≈ 47.9%
```

**一个灵敏度 90%、特异度 98% 的好检测，阳性预测值不到一半。**

## 练习 1-3-B

```python
import numpy as np

np.random.seed(42)
N = 1_000_000
prev, sens, spec = 0.02, 0.90, 0.98

is_sick = np.random.random(N) < prev
rv = np.random.random(N)
test_pos = np.where(is_sick, rv < sens, rv > spec)

tp = (is_sick & test_pos).sum()
fp = (~is_sick & test_pos).sum()
print(f"模拟 PPV = {tp/(tp+fp):.4f}")
print(f"手算 PPV = 0.4787")
```

模拟值应该在 0.478 附近波动（百万样本，误差在千分位）。

## 练习 1-3-C

阴性的人：

- 患病的 200 人中阴性：`200 × 10% = 20`（FN）
- 健康的 9800 人中阴性：`9800 × 98% = 9604`（TN）

阴性总数：`20 + 9604 = 9624`

```
P(健康|阴性) = 9604 / 9624 ≈ 0.9979 ≈ 99.8%
```

**为什么阴性更可信**：因为健康人多（先验高 98%），阴性结果里绝大多数是健康的。**先验高的一方，负面结论更可靠；先验低的一方，正面结论更不可靠。**

这是贝叶斯的核心直觉，也是为什么临床上**确诊靠活检，筛查靠初筛**。

## 练习 1-3-D

```python
import numpy as np
import matplotlib.pyplot as plt

matplotlib.rcParams['font.sans-serif'] = ['SimHei']
matplotlib.rcParams['axes.unicode_minus'] = False

np.random.seed(42)
data = np.random.normal(60, 5, 50000)

print(f"均值: {data.mean():.3f}   标准差: {data.std():.3f}")

mu, sigma = data.mean(), data.std()
out = np.mean((data < mu - 2*sigma) | (data > mu + 2*sigma))
print(f"μ±2σ 之外的比例: {out:.4f}")     # 应该在 0.045 左右

plt.hist(data, bins=100, density=True, alpha=0.7)
plt.axvline(mu, color='r', label=f'μ={mu:.2f}')
plt.axvline(mu - 2*sigma, color='g', linestyle='--', label='μ±2σ')
plt.axvline(mu + 2*sigma, color='g', linestyle='--')
plt.title('正态分布直方图'); plt.legend(); plt.show()
```

理论值是 4.55%（不是 5%，因为正态分布 μ±2σ 内的概率是 95.45%）。模拟值接近即可。

**这个 95% 就是医学参考区间的来源**——常取 μ±2σ 作为正常范围，意味着约 5% 的正常人会被判为"异常"。

## 练习 1-3-E

至少问三个：

1. **患病率（先验）是多少？** 在什么人群里测的？全人群还是高危人群？——这直接决定 PPV。W4 的 16.7% 就是先验低导致的。
2. **准确率的定义是什么？** 是灵敏度还是 PPV？如果它说的是"准确率"但没给混淆矩阵，基本没法用。
3. **测试集怎么划分的？有多少样本？有没有外部验证？** 内部测试和外部验证的差距往往很大，尤其医学图像（不同医院设备不同）。

**第四个可以问**：97% 是在什么终点上？检测病灶存在，还是预测预后？这两个难度完全不同。

## 自测题答案

1. 灵敏度 = P(阳性|患病)；特异度 = P(阴性|健康)。**都是"已知真实状态，预测检测结果"的方向。** 而 PPV/NPV 是反过来。
2. 因为患病率（先验）低时，大量健康人产生的假阳性会淹没真阳性。即使灵敏度和特异度都高，PPV 也会很低。
3. 期望描述"平均在哪"，方差描述"波动多大"。
4. 例：两种血糖仪的读数均值都是 6.0 mmol/L，但 A 的标准差 0.2、B 的标准差 1.5。**A 可以用于诊断决策，B 只能看趋势。** 均值完全相同，临床价值天差地别。
