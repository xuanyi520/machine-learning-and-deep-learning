## 练习 2-1-C

```python
import numpy as np
from sklearn.model_selection import train_test_split

N = 1000
X = np.random.randn(N, 5)
y = np.random.randint(0, 2, N)

# 第一次：分出 15% 测试集
X_temp, X_test, y_temp, y_test = train_test_split(
    X, y, test_size=0.15, random_state=42)

# 第二次：从剩下的 85% 里再分验证集
# 15/85 ≈ 0.176 才能让验证集占原始的 15%
X_train, X_val, y_train, y_val = train_test_split(
    X_temp, y_temp, test_size=0.176, random_state=42)

print(f"训练 {len(X_train)}  验证 {len(X_val)}  测试 {len(X_test)}")
# 大约 700 / 150 / 150
```

**关键点**：
- `random_state` 保证可复现
- 第二次的 `test_size` 要算一下，因为是在剩下的 85% 里切
- **医学数据分类任务要加 `stratify=y`**，保证各集合的类别比例一致（尤其类别不平衡时）

## 练习 2-1-D

三个（或更多）必问的问题：

1. **数据怎么划分的？** 有没有独立的测试集？是不是在同一批数据上训练又测试？——如果是后者，99% 可能是过拟合。
2. **样本量多少？** 100 个样本的 99% 和 10 万个样本的 99%，可信度完全不同。而且医学数据常有"同一患者多张图像"的情况，如果划分时没按患者分（同一患者的图分散在训练和测试集），会严重高估性能。**这叫数据泄漏，是医学 AI 最常见的错误之一。**
3. **正负样本比例？** 如果正类只占 1%，99% 准确率等于什么都没做（回顾 W7 的"全预测负类"）。

**还可能问**：外部验证做了吗？不同中心/不同设备的数据上表现如何？——这是医学 AI 论文的审稿重点。

## 自测题答案

1. 传统编程是人写规则，机器学习是人给例子让程序自己找规则。
2. 因为模型可能只是"背下来"了训练数据，不代表学到了规律。就像考前背答案，考原题满分，考变式完蛋。
3. 验证集用来调超参数和选模型（可以用很多次）；测试集只在最后用一次，报告最终性能。**如果根据测试集结果反复调参，测试集就污染了。**
4. 衡量预测和真实答案的差距，是训练时要最小化的目标。
5. 看训练集和验证集的性能差距。差距大 = 过拟合。

# 2-2 线性回归与梯度下降

## 练习 2-2-A

```
loss = (1/N) Σ (w·xᵢ + b - yᵢ)²
```

令 `eᵢ = w·xᵢ + b - yᵢ`。

**对 w：**
```
∂loss/∂w = (1/N) Σ ∂(eᵢ²)/∂w
         = (1/N) Σ 2eᵢ · ∂eᵢ/∂w          ← 链式法则
         = (1/N) Σ 2eᵢ · xᵢ               ← ∂eᵢ/∂w = xᵢ
         = (2/N) Σ eᵢxᵢ
```

**对 b：**
```
∂loss/∂b = (1/N) Σ 2eᵢ · ∂eᵢ/∂b
         = (1/N) Σ 2eᵢ · 1                ← ∂eᵢ/∂b = 1
         = (2/N) Σ eᵢ
```

## 练习 2-2-B

```python
true_w, true_b = -1.8, 5.0
y = true_w * x + true_b + np.random.randn(N) * 1.5
# 其余不变
```

跑完 `w` 应该接近 -1.8，`b` 接近 5.0。

**注意**：w 为负时梯度下降一样work，因为 `- lr * dw` 会自动朝正确方向走。梯度里的符号信息已经包含了方向。

## 练习 2-2-C

```python
import numpy as np

np.random.seed(42)
N = 500
X = np.random.randn(N, 3)
true_w = np.array([2.0, -3.0, 0.5])
true_b = 4.0
y = X @ true_w + true_b + np.random.randn(N) * 0.5

# 拼成 (N, 4)：三列特征 + 一列全1（吸收偏置）
X_aug = np.column_stack([X, np.ones(N)])
w = np.zeros(4)
lr = 0.05

for epoch in range(2000):
    pred = X_aug @ w
    error = pred - y
    loss = np.mean(error**2)
    grad = (2/N) * (X_aug.T @ error)
    w = w - lr * grad

print("学到的:", np.round(w, 4))
print("真实的: [ 2.  -3.   0.5  4. ]")
```

应该学出 `[2, -3, 0.5, 4]` 附近的值。

**关键理解**：把 `b` 也当成一个权重，它对应的"特征"是 1。这样就统一了，不用单独处理偏置。

## 练习 2-2-D

典型观察结果：

| lr | 现象 |
|---|---|
| 0.001 | loss 下降极慢，1000 步后还在较大值 |
| 0.01 | 正常收敛，loss 平滑下降到接近噪声水平 |
| 0.1 | 收敛更快，前期可能略有波动 |
| 0.5 | 明显震荡，loss 上下跳 |
| 0.6 | 发散，loss 越来越大 |

**临界值**：对标准化不好的数据，MSE 的 Hessian 特征值可能很大，lr 上限是 `2/λ_max`。实践中靠试。

**经验法则**：从 0.01 或 0.001 开始试。用 Adam 的话可以到 0.001~0.01。

## 练习 2-2-E

```python
import numpy as np

np.random.seed(42)
N = 100
X = np.random.randn(N, 3)
y = X @ np.array([1.5, -2.0, 0.8]) + 3.0 + np.random.randn(N)*0.1
X_aug = np.column_stack([X, np.ones(N)])     # (N,4)

w = np.random.randn(4)

def compute_loss(w):
    return np.mean((X_aug @ w - y) ** 2)

# 解析梯度
pred = X_aug @ w
error = pred - y
analytic = (2/N) * (X_aug.T @ error)

# 数值梯度：对每个参数加小扰动
h = 1e-6
numerical = np.zeros_like(w)
for i in range(len(w)):
    w_plus = w.copy();  w_plus[i] += h
    w_minus = w.copy(); w_minus[i] -= h
    numerical[i] = (compute_loss(w_plus) - compute_loss(w_minus)) / (2*h)

print("解析梯度:", np.round(analytic, 6))
print("数值梯度:", np.round(numerical, 6))
print("最大差异:", np.abs(analytic - numerical).max())
```

最大差异应该在 `1e-6` 以下。

**为什么这题重要**：梯度公式写错时，程序**不会报错**，只是学不会。数值验证是唯一的排查手段。以后你自己实现新网络层时，这是标准操作。

## 自测题答案

1. MSE：`(1/N) Σ (预测 - 真实)²`
2. 因为梯度指向上升最快的方向，要降低 loss 就得往反方向走。
3. `X` 是 `(N, d)`，`X.T` 是 `(d, N)`，`error` 是 `(N,)`，所以 `X.T @ error` 是 `(d,)`——正好是 d 个参数的梯度。
4. 可能震荡不收敛，甚至发散（loss 变大或变 nan）。
5. 因为 `b` 相当于对应"特征恒为 1"的权重，拼进权重向量后可以统一写成矩阵乘法，代码更简洁。

# 2-3 分类与评估指标

## 练习 2-3-A

给定：100 个样本，80 健康 / 20 患病。

- 找到 16 个患者，其中 14 个是真的 → **TP = 14**，剩下 2 个患者没找到 → **FN = 20 - 14 = 6**
- 在健康人里报了 10 个阳性 → **FP = 10**
- 剩下的健康人：**TN = 80 - 10 = 70**

验证：`TP + FP + FN + TN = 14 + 10 + 6 + 70 = 100` ✓

**指标：**

```
准确率   = (TP+TN)/100 = (14+70)/100 = 0.84
精确率   = TP/(TP+FP)  = 14/24 ≈ 0.5833
召回率   = TP/(TP+FN)  = 14/20 = 0.70
特异度   = TN/(TN+FP)  = 70/80 = 0.875
F1       = 2×0.5833×0.70/(0.5833+0.70) ≈ 0.6364
```

**解读**：准确率 84% 看起来还行，但召回率只有 70%——**20 个患者漏了 6 个**。在医疗场景这是个严重问题。

## 练习 2-3-B

```python
import numpy as np
from sklearn.metrics import *

y_true = np.array([1]*20 + [0]*80)                    # 20患病 + 80健康
# 构造预测：14个TP + 6个FN + 10个FP + 70个TN
y_pred = np.array([1]*14 + [0]*6 + [1]*10 + [0]*70)

print(f"准确率  : {accuracy_score(y_true, y_pred):.4f}")     # 0.8400
print(f"精确率  : {precision_score(y_true, y_pred):.4f}")    # 0.5833
print(f"召回率  : {recall_score(y_true, y_pred):.4f}")       # 0.7000
print(f"F1      : {f1_score(y_true, y_pred):.4f}")           # 0.6364
print("\n混淆矩阵:")
print(confusion_matrix(y_true, y_pred))
# [[70 10]
#  [ 6 14]]
```

和手算对上。

## 练习 2-3-C

改成 `weights=[0.99, 0.01]` 后：

1. 逻辑回归的准确率大约 **0.97~0.99**（看起来很高）
2. 无脑全预测负类的准确率大约 **0.99**
3. **结论**：在这个情况下准确率**几乎没有意义**。你的模型和无脑猜测打平甚至更差。

**这就是为什么医学 AI 论文必须报告 AUC、灵敏度、特异度。** 只报准确率的论文，审稿人第一反应是"数据是不是不平衡"。

## 练习 2-3-D

**1. 社区医院早筛** → **选低阈值**

理由：社区是初筛环节，目标是**不漏人**。

- 漏诊一个肝癌患者 = 错过治疗窗口 = 可能致命
- 误报一个健康人 = 多做一次检查 = 花钱、受辐射、焦虑

代价严重不对等。所以宁可把阈值压到 0.2 甚至更低，把召回率做到 95%+，接受精确率下降。

**2. 三甲医院辅助确诊** → **选高阈值**

理由：这时候是"辅助决策"，医生会做最终判断。

- 如果模型天天误报，医生会失去信任，直接弃用
- 医生有更强的判断力，可以容忍一定漏报（他们自己会复核）

**这就是为什么"同一个模型"在不同临床场景要用不同的阈值。** 这不是技术问题，是临床场景问题。

**面试时能答出这一层，就能区分你和只会调参的人。**

## 练习 2-3-E

- 曲线上的每一点对应一个阈值

## 自测题答案

1. 类别不平衡时。比如正类只占 1%，全预测负类也能有 99% 准确率。
2. 精确率问"判为阳性的里面有多少是真的"；召回率问"真阳性里面有多少被找到了"。
3. 因为漏诊（FN）的代价远大于误诊（FP）。漏掉一个癌症患者可能致命，多做一个检查只是花钱。
4. 模型的排序能力和随机猜测一样，**没有任何区分能力**。
5. 提高阈值 → 判为正类的门槛变高 → 精确率通常上升，召回率下降。
