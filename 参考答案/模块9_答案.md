### 练习 9-B（病人泄露复现）

**参考代码**

```python
# 文件：ans_9bc.py（9-B 部分）
import numpy as np
import pandas as pd
from sklearn.model_selection import KFold, GroupKFold, cross_val_score
from sklearn.ensemble import RandomForestClassifier

# 1. 造数据：80 个病人 × 6 次随访 = 480 行
rng = np.random.default_rng(7)
n_pat, n_visit = 80, 6
u = rng.normal(0, 1.0, n_pat)      # 病人层面的真实风险
b = rng.normal(0, 1.5, n_pat)      # 病人"签名"，与结局无关
rows = []
for i in range(n_pat):
    for v in range(n_visit):
        rows.append([i,
                     b[i] + rng.normal(0, 0.02),   # x1 签名：随访间几乎不变
                     u[i] + rng.normal(0, 1.2),    # x2 很弱的真实信号
                     rng.normal(0, 1.0)])          # x3 纯噪声
sim = pd.DataFrame(rows, columns=['pid', 'x1', 'x2', 'x3'])

# 2. 结局是病人层面的
y_pat = (1.0 * u + rng.normal(0, 0.8, n_pat) > 0).astype(int)
sim['y'] = y_pat[sim['pid'].values]

Xs, ys, groups = sim[['x1', 'x2', 'x3']], sim['y'].values, sim['pid'].values
rf = RandomForestClassifier(n_estimators=400, min_samples_leaf=2,
                            random_state=0, n_jobs=-1)

# 3. 两种切法
kf = KFold(5, shuffle=True, random_state=0)
gkf = GroupKFold(5)
a1 = cross_val_score(rf, Xs, ys, cv=kf, scoring='roc_auc')
a2 = cross_val_score(rf, Xs, ys, cv=gkf, groups=groups, scoring='roc_auc')
print('按行 KFold      :', np.round(a1, 3), f'{a1.mean():.4f}')
print('按病人 GroupKFold:', np.round(a2, 3), f'{a2.mean():.4f}')
print(f'虚高 {a1.mean()-a2.mean():+.4f}')

# 4. 每折统计：测试病人有多大比例在训练集里出现过
for name, cv in [('KFold', kf), ('GroupKFold', gkf)]:
    print(f'\n每折病人重叠比例（{name}）')
    for k, (tr, te) in enumerate(cv.split(Xs, ys, groups=groups), 1):
        tr_pid, te_pid = set(groups[tr]), set(groups[te])
        ratio = len(te_pid & tr_pid) / len(te_pid)
        print(f'  折{k}: 测试病人 {len(te_pid)} 个，'
              f'出现在训练集 {len(te_pid & tr_pid)} 个，比例 {ratio:.1f}')
        if name == 'GroupKFold':
            # 这个 assert 必须有：一旦 groups 写错第一时间报错
            assert len(tr_pid & te_pid) == 0, 'GroupKFold 出现病人跨折'

# 5. 只用签名特征 x1：证明模型学的是"病人身份证"
a1_x1 = cross_val_score(rf, sim[['x1']], ys, cv=kf, scoring='roc_auc')
a2_x1 = cross_val_score(rf, sim[['x1']], ys, cv=gkf, groups=groups,
                        scoring='roc_auc')
print(f'\n只用 x1（与结局无关）: KFold {a1_x1.mean():.3f} '
      f'vs GroupKFold {a2_x1.mean():.3f}')
```

**判分要点**

- 核心数字：按行 KFold 0.8097，按病人 GroupKFold 0.7001，**虚高 0.1096**，达到"至少 0.08"的验收线。达到这条线靠的是三件事：签名特征几乎不随随访变化（病人间方差占比约 1.0）、真实信号 x2 很弱、结局只落在病人层面。
- 每折重叠比例必须打印出来：KFold 五折全是 **1.0**（每个测试病人都能在训练集里找到），GroupKFold 五折全是 **0.0**。这是比 AUC 差更硬的证据。
- 代码里必须有断言。推荐写法是 `assert len(set(groups[tr]) & set(groups[te])) == 0`，写错 `groups=` 时会在第一折就崩，而不是等审稿人问。
- 最有说服力的一段是最后一行：**x1 与结局完全无关，按行切能拿到 0.903，按病人切只有 0.474（低于 0.5，说明连方向都是反的）**。这句话直接证明"模型学的是病人身份证，不是病"。
- 解释要落到机制：同一病人的 6 行共享同一个 x1，按行随机切时，训练集里已经有这个病人的 5 行，模型只要记住"x1 约等于 b_i"就能把这一折的标签背出来；换一个没见过的病人，这套映射完全失效。
- 允许 AUC 的具体数值有差异（换随机种子会动 0.02 到 0.05），但方向必须是 KFold > GroupKFold，且重叠比例必须是 1.0 对 0.0。若 KFold 只高 0.02，说明签名特征造得不够"稳定"或真实信号太强，应加大签名特征的信噪比、削弱 x2。

**常见错误**

- 用了 `GroupKFold` 但忘记传 `groups=`，sklearn 会直接报错或（在旧写法里）退化成按行切，数字看着正常，其实还是泄露。
- 只造"病人多次随访"却不给病人 ID，导致根本无法分组。纵向数据的第一列必须是 `pid`。
- 把 `groups` 设成行号或折号，而不是病人 ID。`groups` 的语义是"哪些行属于同一个集群"，医学里就是病人、中心、切片。
- 用 `StratifiedGroupKFold` 时只看了 AUC，没检查每折阳性病人数。80 个病人里只有 32 个阳性，5 折后每折 6 到 7 个，AUC 抖动会很大，必须同时报每折结果。
- 把重复测量直接删成"一人一行"来避免泄露却不说明规则（取第一次？取最差？），这本身会引入选择偏倚，审稿人会追问。
- 认为"GroupKFold 的 AUC 更低说明模型变差了"。低的那一个才是**对新病人的真实估计**，高的那个是幻觉。
- 只报均值不报每折。9-B 的 GroupKFold 各折从 0.585 到 0.851，跨度 0.27，只报 0.700 会掩盖不稳定性。

### 练习 9-C（学习曲线判读）

**参考代码**

```python
# 文件：ans_9bc.py（9-C 部分）
import numpy as np
import pandas as pd
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
plt.rcParams['axes.unicode_minus'] = False

from sklearn.model_selection import StratifiedKFold, learning_curve
from sklearn.ensemble import RandomForestClassifier
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = [c.strip().replace(' ', '_') for c in df.columns]
y = (df['Class'] == 1).astype(int).values
X = df.drop(columns=['Class'])

def make_rf():
    return Pipeline([
        ('imp', SimpleImputer(strategy='median', add_indicator=True)),
        ('clf', RandomForestClassifier(n_estimators=300, random_state=0,
                                       n_jobs=-1)),
    ])

cv = StratifiedKFold(5, shuffle=True, random_state=42)
sizes, tr_s, va_s = learning_curve(
    make_rf(), X, y, cv=cv, scoring='roc_auc',
    train_sizes=np.linspace(0.15, 1.0, 8),   # 8 个点
    shuffle=True, random_state=1, n_jobs=-1)

for n, a, b in zip(sizes, tr_s.mean(1), va_s.mean(1)):
    print(f'n={n:3.0f} train={a:.3f} val={b:.3f} gap={a-b:.3f}')

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(sizes, tr_s.mean(1), 'o-', label='训练集 AUC')
ax.fill_between(sizes, tr_s.mean(1) - tr_s.std(1),
                tr_s.mean(1) + tr_s.std(1), alpha=0.15)
ax.plot(sizes, va_s.mean(1), 's-', label='验证集 AUC')
ax.fill_between(sizes, va_s.mean(1) - va_s.std(1),
                va_s.mean(1) + va_s.std(1), alpha=0.15)
ax.set_xlabel('训练样本量（例）')
ax.set_ylabel('AUC（5 折交叉验证）')
ax.set_title('Hepatitis 随机森林学习曲线')
ax.legend(loc='lower right')
ax.grid(alpha=0.3)
plt.tight_layout()
plt.savefig(r'E:\AI学习\模块9_模型评估与可解释性\fig_ans_learning_curve.png', dpi=150)
```

**判分要点**

- 参考诊断（约 150 字，可直接改写）：训练集从第一个点起就是 1.000，模型把 155 例中的训练部分完全记住了。验证集在 48 例时为 0.875，到 124 例反而降到 0.872，**76 例新增样本没有带来任何提升（-0.004）**，曲线在 0.87 附近已经平台。因此这不是"缺数据"：再加 100 例，按这个斜率预计变化在 0.01 以内，会被 5 折标准差（约 0.05）完全淹没。瓶颈是现有特征的信息量用完了，不是样本量，也不是树太深。
- 必须引用具体数字，至少要有"48 例 0.875、124 例 0.872、差 -0.004"这一组。"验证集已经平台"是结论，"从 48 到 124 只涨/降 0.004"是证据，两者都要有。
- 下一步动作要写清优先级和预期收益：第一位是**加新特征**（例如 MELD 评分、影像组学、随访期间的实验室变化），因为验证集平台说明现有 19 列已经把信号榨干；第二位是**换模型做对照**（逻辑回归约 0.83、更稳但更低，说明差距不是模型族能补的）；第三位才是**外部验证**，检验 0.87 这个天花板是不是这批 155 人的样本特异性。加数据排在最后，预期收益小于噪声。
- 必须明确写"加数据没有用"，不能含糊成"可以再收集一些"。审稿人最反感的是"样本量不足"当万能挡箭牌，而学习曲线正好是反驳它的工具。
- 允许"训练集 1.000"存在，但结论里必须解释成"容量过剩/方差大"，**不能**写成"模型性能好"。训练集 AUC 在这份数据上没有信息量。
- 曲线平台但 gap 不闭合（0.128）这件事要解释：不是典型的"高方差"形状（高方差会随样本增加而靠拢），而是"信号到顶 + 训练集可完美记忆"的组合。所以降复杂度（限制树深）只能压 gap，不会抬验证集，这点在讲义的验证曲线里有实测（depth 1 到 10，验证集都在 0.86）。

**常见错误**

- 横轴用"训练集比例"而不是绝对样本量（18、33、48……），导致不同数据集之间无法比较，也无法回答"再加 100 例值不值"。
- 只画均值不画波动带。8 个点的验证集标准差约 0.04 到 0.06，不画带子会把 0.875 到 0.872 的下降读成"变差了"。
- 样本量只跑到 50% 或 60% 就下结论。曲线没平之前说"数据不够"或"够了"都不可靠，至少要跑到全量的 80%。
- 把"训练集 1.000"当成过拟合的铁证然后直接去调正则化。这份数据的验证曲线显示调深度不涨，真正的动作是换特征。
- 用 `train_sizes` 的相对比例（0.15 到 1.0）却在文字里写成"18 到 124 例"时没核对。`learning_curve` 返回的 `sizes` 已经是绝对数，直接用即可。
- 在已经看过测试集之后再画学习曲线并据此改模型，等于把测试集信息带进决策；学习曲线只能用于训练/验证阶段的诊断。

### 练习 9-D（同预算搜索对比）

**参考代码**

```python
# 文件：ans_9de.py（9-D 部分）
import numpy as np
import pandas as pd
from sklearn.model_selection import (StratifiedKFold, GridSearchCV,
                                     RandomizedSearchCV)
from sklearn.ensemble import RandomForestClassifier
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from scipy.stats import randint, uniform

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = [c.strip().replace(' ', '_') for c in df.columns]
y = (df['Class'] == 1).astype(int).values
X = df.drop(columns=['Class'])

def make_rf():
    # 为省时间用 60 棵树；换成 300 结论方向不变，数字会略变
    return Pipeline([
        ('imp', SimpleImputer(strategy='median', add_indicator=True)),
        ('clf', RandomForestClassifier(n_estimators=60, random_state=0,
                                       n_jobs=-1)),
    ])

# 网格：3 × 2 × 2 × 2 = 24 组
grid = {
    'clf__max_depth': [2, 4, 6],
    'clf__min_samples_leaf': [1, 3],
    'clf__max_features': ['sqrt', 0.5],
    'clf__criterion': ['gini', 'entropy'],
}
# 随机：从更宽的空间抽 24 组
dist = {
    'clf__max_depth': randint(1, 13),
    'clf__min_samples_leaf': randint(1, 11),
    'clf__max_features': uniform(0.15, 0.85),
    'clf__criterion': ['gini', 'entropy'],
    'clf__min_samples_split': randint(2, 21),
}

g_scores, r_scores = [], []
for rep in range(8):
    cv = StratifiedKFold(5, shuffle=True, random_state=rep)  # 每次换划分
    gs = GridSearchCV(make_rf(), grid, cv=cv, scoring='roc_auc',
                      n_jobs=-1).fit(X, y)
    rs = RandomizedSearchCV(make_rf(), dist, n_iter=24, cv=cv,
                            scoring='roc_auc', random_state=rep,
                            n_jobs=-1).fit(X, y)
    g_scores.append(gs.best_score_)
    r_scores.append(rs.best_score_)
    print(f'rep{rep+1}: 网格 {gs.best_score_:.4f}  随机 {rs.best_score_:.4f}  '
          f'{"网格胜" if gs.best_score_ > rs.best_score_ else "随机胜"}')

g_scores, r_scores = np.array(g_scores), np.array(r_scores)
print(f'\n网格 24 组: {g_scores.mean():.4f} +- {g_scores.std(ddof=1):.4f}')
print(f'随机 24 组: {r_scores.mean():.4f} +- {r_scores.std(ddof=1):.4f}')
print(f'差值 {g_scores.mean()-r_scores.mean():+.4f}，'
      f'网格胜 {(g_scores > r_scores).sum()}/8')
```

**实测输出**

```text
rep1: 网格 0.8994  随机 0.8947  网格胜
rep2: 网格 0.8838  随机 0.8836  网格胜
rep3: 网格 0.8987  随机 0.8718  网格胜
rep4: 网格 0.8965  随机 0.8974  随机胜
rep5: 网格 0.8852  随机 0.8866  随机胜
rep6: 网格 0.9027  随机 0.8934  网格胜
rep7: 网格 0.9010  随机 0.8856  网格胜
rep8: 网格 0.8912  随机 0.8860  网格胜

网格 24 组: 0.8948 +- 0.0072
随机 24 组: 0.8874 +- 0.0080
差值 +0.0074，网格胜 6/8

**判分要点**

- 预算必须严格相同：网格 3×2×2×2 = 24 组，随机 `n_iter=24`，两边都是 24 组 × 5 折 = 120 次拟合。验收时可以直接数配置数量。
- 必须重复 8 次且每次换 CV 划分（`random_state=rep`），不能只跑一次。本次结果：网格 0.8948 ± 0.0072，随机 0.8874 ± 0.0080，**网格平均高 0.0074，胜 6/8**。
- 结论与 Bergstra 相反，必须解释，且解释要落到"搜索空间设计"上，不能只说"随机搜索运气差"：
  1. 网格的 24 个点全部落在合理区域（树深 2/4/6、叶子 1/3），这是按经验事先排除了明显欠拟合的区域；
  2. 随机从 1 到 12 层、1 到 10 个叶子、特征比例 0.15 到 1.0 的宽空间抽样，24 次里有相当一部分落在树深 1、叶子 10 这类欠拟合角落；
  3. 随机森林对超参很不敏感（验证曲线 0.86 到 0.87 是平的），粗网格已经够用，随机搜索"覆盖更多取值"的优势体现不出来。
- 本次随机在 rep4、rep5 两次胜出，恰好说明**单个最佳实践不能当定理**。要写"网格在这个任务上不劣于随机"，而不是"随机搜索是错的"。Bergstra 的结论有条件：超参多、有效维度低、单次训练贵，随机才明显占优。
- 数字允许与讲义不同（讲义是 0.8971 对 0.8864、8/8），因为讲义用的随机种子序列、树数量可能与本次不同。**只要预算相同、重复 8 次、结论方向一致（网格不劣于随机）、解释落到空间设计，就给满分。**
- 标准差要报。网格 0.0072、随机 0.0080，两者重叠，说明 0.0074 的差距本身也在噪声边缘；这正是"不能只看一次"的理由。

**常见错误**

- 网格 24 组、随机却跑了 60 次，预算不等，结论无效。这是本题最容易犯的错。
- 随机搜索的分布范围和网格完全一样，只是"随机打乱网格的 24 个点"，那当然比不出差别。随机搜索的意义在于**更宽的空间**，必须写清两边空间不同。
- 只跑一次就下结论。单次的折间波动约 0.01，比两策略的真实差（0.007）还大。
- 为了迎合 Bergstra 改数字或改空间。改了空间就要重新跑 8 次，并在答案里说明改了什么。
- 用 `best_score_` 当最终性能。这里的 0.89 是"24 个候选里的最大值"，含选择偏差，真实性能应看嵌套 CV（讲义 1.6 节，RF 平均虚高约 0.03）。
- 忘记固定 `random_state`，两次运行的"随机搜索"其实是两次不同的搜索，无法配对比较。
- 用准确率而不是 AUC 做评分。155 例里 123 例存活，全猜存活准确率 79%，accuracy 曲线会被基线淹没。

        if m.sum():
            e += m.sum() / len(p) * abs(y_true[m].mean() - p[m].mean())
    return e

**判分要点**

- 三种方法的 Brier 和 ECE 都要报，且要带 15 次的均值和标准差。本次未校准 ECE **0.1613**，满足"至少一个模型 ECE > 0.10"的验收条件；Platt 降到 0.0989，Brier 从 0.1536 降到 0.1380。

- "AUC 基本不变"必须解释成：Platt 是 `1/(1+exp(A·f+B))`，Isotonic 是单调分段常数，**两者都是单调变换，不改变任意两个病人预测值的先后顺序**，所以 AUC 理论上不变。本机 0.7964 → 0.8058 → 0.8104 的小幅上升来自 `CalibratedClassifierCV(cv=5)` 内部重新分折训练，不是校准本身提高了排序能力。
- 校准器只能接触训练集。`CalibratedClassifierCV(...).fit(Xtr, ytr)` 就是正确写法，内部 `cv=5` 会把 `Xtr` 再切分；如果把 `Xte` 传进去，测试集就泄露了。
- Isotonic 的 LogLoss 标准差 **0.3775**，是本次最重要的细节：Brier 最低（0.1365）但 LogLoss 标准差是 Platt 的 14 倍。155 例里只有 32 个死亡，等渗回归的分段常数在某些折里会给出接近 0 或 1 的极端概率，一旦预测错，LogLoss 爆炸。写法上应推荐"小样本先 Platt，样本过千再考虑 Isotonic"。
- 校准后要重新检查 AUC。如果 AUC 大幅变化（比如 0.80 变 0.90），不是校准的功劳，而是流程里泄露了。

**常见错误**

- 在测试集上 `fit` 校准器（`CalibratedClassifierCV(...).fit(Xte, yte)`），Brier 和 ECE 会好得不真实，这是最常见的作弊。
- 期待校准提高 AUC，发现没提高就写"校准失败"。校准改的是数值，不是排序。
- 分 20 个箱画可靠性图。155×0.3 ≈ 47 个测试样本，分 20 箱后每箱 2 到 3 人，曲线会剧烈锯齿，什么都读不出来。8 到 10 箱是合理范围。
- 只报 Brier 不报 AUC。全部预测为 0.206 的常数模型 Brier 也能到 0.16 左右，看起来不比模型差。
- 把 `class_weight='balanced'` 之后的概率直接当人群概率用。权重会把概率整体推高，必须重新校准（讲义 4.4 节实测 ECE 从 0.097 升到 0.122）。
- 用同一批数据既选阈值又评校准，阈值和校准器都过拟合。
- 报告 ECE 时不给分箱数。ECE 依赖分箱，8 箱和 10 箱能差 0.02。
- 只跑一次 70/30。本次 15 次的 Brier 标准差 0.03，单次结果可能让你误判"校准没用"。

# 文件：ans_9fg.py（9-F 部分）
import numpy as np
import pandas as pd
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import StratifiedKFold, cross_val_predict

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = [c.strip().replace(' ', '_') for c in df.columns]
y = (df['Class'] == 1).astype(int).values
X = df.drop(columns=['Class'])

def make_rf():
    return Pipeline([('imp', SimpleImputer(strategy='median', add_indicator=True)),
                     ('clf', RandomForestClassifier(n_estimators=300,
                                                    random_state=0, n_jobs=-1))])

# 1. 用 OOF 预测挑"真实死亡且预测 > 0.8"的病人
cv = StratifiedKFold(5, shuffle=True, random_state=42)
p_oof = cross_val_predict(make_rf(), X, y, cv=cv, method='predict_proba')[:, 1]
cand = np.where((y == 1) & (p_oof > 0.8))[0]
i = int(cand[0])
print(f'病人 #{i}，y={y[i]}，OOF p={p_oof[i]:.3f}')

# 2. 手写 permutation SHAP（本机未装 shap 库）
model = make_rf().fit(X, y)
Xmat = X.fillna(X.median()).values.astype(float)
rng = np.random.default_rng(0)
background = Xmat[rng.choice(len(Xmat), 80, replace=False)]

def shap_values(model, Xmat, background, n_perm=120, seed=0):
    rng = np.random.default_rng(seed)
    n, d = Xmat.shape
    base = model.predict_proba(background)[:, 1].mean()
    out = np.zeros((n, d))
    for i in range(n):
        phi = np.zeros(d)
        C = np.empty((n_perm, d + 1, d))
        orders = np.empty((n_perm, d), dtype=int)
        for p in range(n_perm):
            b = background[rng.integers(0, len(background))].copy()
            order = rng.permutation(d)
            orders[p] = order
            cur = b.copy()
            C[p, 0] = cur
            for s, j in enumerate(order, start=1):
                cur[j] = Xmat[i, j]
                C[p, s] = cur
        P = model.predict_proba(C.reshape(-1, d))[:, 1].reshape(n_perm, d + 1)
        for p in range(n_perm):
            for s, j in enumerate(orders[p]):
                phi[j] += P[p, s + 1] - P[p, s]
        out[i] = phi / n_perm
    return out, base

PHI, base = shap_values(model, Xmat[[i]], background, n_perm=120, seed=0)
pred = model.predict_proba(Xmat[[i]])[:, 1][0]

# 3. 加性检验：base + sum(SHAP) 必须接近预测值
err = float(abs(base + PHI.sum() - pred))
print(f'base={base:.4f}  预测={pred:.4f}  加性误差={err:.4f}')

s = pd.Series(PHI[0], index=X.columns).sort_values(key=np.abs, ascending=False)
print(s.head(8))

**判分要点**

- 加性检验必须通过：base 0.2062 + SHAP 合计 0.7305 = 0.9367，与模型输出 0.9367 的误差 **0.0013**，远小于 0.05 的验收线。误差来源是背景样本只取了 80 例、排列只做了 120 次，属于蒙特卡洛误差，加大到 500 次会继续下降。
- 前 5 个贡献必须列全并给出方向和取值。本题：凝血酶原时间 +0.142、胆红素 +0.123、白蛋白 +0.113、腹水 +0.096、静脉曲张 +0.073。注意"白蛋白低"是**取值低、贡献为正**，方向和取值相反，这是最容易写错的地方。
- 医生版解释（约 200 字，可直接用）：

  > 这位 48 岁的病人，模型给出的死亡风险是 94%，属于很高危。
  >
  > 把风险推上去的主要是五项。凝血酶原时间 31 秒，凝血功能明显延长，单独推高约 14 个百分点；胆红素 4.8，明显升高，推高约 12 个百分点；白蛋白只有 2.7，合成功能差，推高约 11 个百分点；已经出现腹水，推高约 10 个百分点；还有食管静脉曲张，推高约 7 个百分点。这五项合起来是同一个临床图像：肝功能失代偿加门脉高压。
  >
  > 需要说明，这是模型在这批既往病例里学到的关联，不等于"这些指标导致了死亡"，也不能保证这位病人一定会死亡。它说明的是：在这套数据里，他的指标组合和结局最差的那些病人最像。

- 文中不能出现"SHAP"三个字，也不能出现"+0.1417"这种原始小数。要用"百分点"或"约 14 个百分点"。
- 顺序必须从大到小，先给结论（风险 94%、很高危），再逐条列原因，最后归成一个临床图像。这个"结论—原因—综合—限定"的四段结构是给医生写解释的标准骨架。
- 最后一句"关联不是因果"必须有，而且要说人话（"不等于这些指标导致了死亡"），不能写成"SHAP 不提供因果推断"。

**常见错误**

- 用训练集上的预测挑病人，再在同一个模型上算 SHAP。预测和解释都过拟合，应该用 OOF 预测挑人（本题 OOF 0.847 与全量模型 0.937 的差距就是过拟合的体现）。
- 挑不到 p > 0.8 的死亡病人就放宽标准却不说明。本次用 seed=42 的 OOF 只筛出 1 个（#100），如果换种子筛出 0 个，应改用"死亡病人里预测最高的一位"并注明。
- 加性检验算的是 `base + sum(SHAP) - p_oof`，把 OOF 预测和全量模型的 SHAP 混在一起比。必须用**同一个模型**的预测值。
- 把 SHAP 的正负号读反。白蛋白的 SHAP 为正不代表"白蛋白高"，而是"这一项的取值把风险往上推"，本例是白蛋白低（2.7）。
- 只给全局重要性不给个体。医生关心的是"我这个病人"，全局条形图回答不了。
- 解释里写"凝血酶原时间贡献 +0.1417，在模型中权重很高"。医生听不懂 SHAP 单位，也不关心模型内部。
- 把 SHAP 说成因果："低白蛋白导致了他的高死亡风险"。只能说"模型认为这一项最像既往死亡病例"。
- 忽略了相关特征。凝血酶原时间、胆红素、白蛋白三者相关，贡献会被分摊；如果论文要写"独立危险因素"，必须另做多因素模型，不能用 SHAP 代替。
- 排列次数太少（比如 20 次），加性误差会超过 0.05，此时应先怀疑次数不够，而不是怀疑实现。

# ---------- 4. DeLong 完整实现 ----------
def _midrank(x):
    """并列取平均秩，DeLong 的标准做法。"""
    J = np.argsort(x)
    Z = x[J]
    N = len(x)
    T = np.zeros(N)
    i = 0
    while i < N:
        j = i
        while j < N and Z[j] == Z[i]:
            j += 1
        T[i:j] = 0.5 * (i + j - 1) + 1
        i = j
    out = np.empty(N)
    out[J] = T
    return out

def delong_test(y_true, p1, p2):
    """比较同一批病人上两个模型的 AUC。返回 (auc1, auc2, z, p)。"""
    order = np.argsort(-y_true)
    yt = y_true[order]
    preds = np.vstack((p1[order], p2[order]))
    m = int(yt.sum())          # 阳性数
    n = len(yt) - m            # 阴性数
    pos, neg = preds[:, :m], preds[:, m:]
    tx = np.array([_midrank(pos[r]) for r in range(2)])
    ty = np.array([_midrank(neg[r]) for r in range(2)])
    tz = np.array([_midrank(preds[r]) for r in range(2)])
    aucs = tz[:, :m].sum(axis=1) / (m * n) - (m + 1) / (2 * n)
    # V01/V10：结构分量，用于估计 AUC 的方差与协方差
    v01 = (tz[:, :m] - tx) / n
    v10 = 1.0 - (tz[:, m:] - ty) / m
    S = np.cov(v01) / m + np.cov(v10) / n
    var = S[0, 0] + S[1, 1] - 2 * S[0, 1]
    if var <= 0:
        return aucs[0], aucs[1], 0.0, 1.0
    z = (aucs[0] - aucs[1]) / np.sqrt(var)
    return aucs[0], aucs[1], z, 2 * norm.sf(abs(z))

print(delong_test(y, p_rf, p_lr))
print(delong_test(y, p_rf, p_rf))      # 自检：应得 z=0, p=1
```

**判分要点**

- 四个数字缺一不可：
  1. 10 个种子的均值：LR **0.8264 ± 0.0184**，RF **0.8805 ± 0.0106**；
  2. Bootstrap 95% CI（OOF 预测，seed=42）：LR 0.8450（0.7503-0.9159），RF 0.8768（0.8081-0.9319）；
  3. 配对 t：**t=1.413，p=0.2304**；
  4. DeLong：**z=1.432，p=0.1522**。
- 四种口径的 AUC 不完全相同（0.8805 是 10 个种子平均，0.8768 是 seed=42 的单次 OOF），这是正常的，报告时必须写清是哪一个。混着报会被审稿人抓住。
- 配对 t 与 DeLong 的区别要能讲清：配对 t 的比较单位是"折"，只有 5 个点，而且 5 折的训练集互相重叠、不独立，p 值只能当参考；DeLong 的比较单位是"病人"，直接用同一批病人的预测值估计 AUC 的方差和两个 AUC 的协方差，是 AUC 比较的标准方法。本题两者结论一致（都不显著），但不是必然。
- DeLong 实现要能自检：`delong_test(y, p_rf, p_rf)` 必须返回 `(0.8768, 0.8768, 0.0, 1.0)`；算出的 AUC 必须与 `roc_auc_score` 一致到小数点后 10 位（本机 0.876778455285 完全相同）。这两条是判断实现对不对的最快方法。
- 6 个模型两两比较共 **C(6,2) = 15 对**。Bonferroni 阈值 = 0.05/15 = **0.0033**。本次原始 p<0.05 有 7 对，BH q<0.05 有 6 对，Bonferroni 只剩 3 对（RF vs DT3、RF vs GB、DT3 vs KNN）。三个数字不同，正好说明"校正方法决定结论"。
- 结论句要写成："RF 的 AUC 为 0.877（95% CI 0.808-0.932），高于 LR 的 0.845（95% CI 0.750-0.916），但差异未达统计学显著（DeLong z=1.43，p=0.152；配对 t p=0.230）。"**不能写"RF 优于 LR"**。
- 要指出 0.054 的均值差为什么仍不显著：155 例里只有 32 个死亡，AUC 的标准误约 0.04，两个相关 AUC 之差的标准误约 0.022，0.032 的差（OOF 口径）只对应 1.4 个标准误。
- 多重比较部分必须提"预设定比较优于事后校正"：如果主要终点事先只定 RF vs LR 一对，就不需要除以 15；从 15 对里挑 p 最小的再声称显著，是 p-hacking。

**常见错误**

- 比较两个模型时各自跑各自的 CV，然后用两个 AUC 直接相减或做独立样本 t 检验。折不同、病人不同，配对结构丢失，方差被高估。
- 用 DeLong 时传入的不是同一批病人的预测（比如一个用 OOF、一个用测试集），或者样本顺序不一致。`delong_test` 里对 `y_true` 排序时必须把 p1、p2 一起排。
- 把 `np.cov` 换成 `np.var`，丢掉两个模型之间的协方差项。两个模型在同一批病人上高度相关，协方差很大，漏掉会让方差虚高、p 值虚大。
- 只算 z 不算双侧 p，或者用单侧。默认双侧，`2 * norm.sf(abs(z))`。
- 把 Bonferroni 用在高度相关的 15 对上还宣称"更严格所以更好"。Bonferroni 控制 FWER 但很保守，相关指标会过度惩罚；探索性分析更适合 BH。
- 报告 "p = 0.000"。应写 p < 0.001。
- 用 10 个种子的标准差（0.0184）当置信区间。标准差描述种子间波动，95% CI 是 1.96×SE 或 bootstrap 分位数，两者不是一回事。
- 认为"p > 0.05 就证明两个模型一样好"。只能说没有足够证据证明不同；0.032 的差值在临床上可能仍有意义，要结合 CI 讨论。
- 同一病人多次测量时直接用 DeLong。独立假设不成立，方差被低估，应改用按病人聚类的 bootstrap。
