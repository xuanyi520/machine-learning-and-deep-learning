### 练习 5-A（缺失策略对比）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')

from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer, KNNImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')
y = (h['Class'] == 1).astype(int).values
cols = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
X = h[cols]
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)

def make_lr():
    return LogisticRegression(max_iter=2000, class_weight='balanced')

pipes = {
    '中位数': Pipeline([
        ('imp', SimpleImputer(strategy='median')),
        ('sc', StandardScaler()),
        ('clf', make_lr())]),
    '中位数+缺失指示': Pipeline([
        ('imp', SimpleImputer(strategy='median', add_indicator=True)),
        ('sc', StandardScaler()),
        ('clf', make_lr())]),
    'KNNImputer': Pipeline([
        ('sc', StandardScaler()),               # 先缩放，KNN 的距离才有意义
        ('imp', KNNImputer(n_neighbors=5)),
        ('clf', make_lr())]),
}

for name, p in pipes.items():
    s = cross_val_score(p, X, y, cv=cv, scoring='roc_auc')
    print(f'{name:12s} AUC={s.mean():.4f} +- {s.std():.4f}   每折 ' +
          ' '.join(f'{v:.3f}' for v in s))

imp = SimpleImputer(strategy='median', add_indicator=True).fit(X)
print('add_indicator 后列数:', imp.transform(X).shape[1])
print('缺失列:', [cols[i] for i in imp.indicator_.features_])
```

**实测输出**

```
中位数          AUC=0.8312 +- 0.0358   每折 0.807 0.847 0.860 0.774 0.869
中位数+缺失指示     AUC=0.8152 +- 0.0581   每折 0.833 0.873 0.780 0.720 0.869
KNNImputer   AUC=0.8292 +- 0.0370   每折 0.800 0.867 0.807 0.792 0.881
add_indicator 后列数: 11
缺失列: ['Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
```

**读法**：三种策略的 AUC 是 0.831、0.815、0.829，最大差 0.016，而每折标准差在 0.036 到 0.058 之间。**差值小于标准差，不能说谁更好。** 结论是"三种在这个数据上打平"。

第 2 种**没有**优于第 1 种，反而低了 0.016。原因是 155 个样本里只有 6 个原始特征，加上 5 个指示列后特征变成 11 个，EPV 进一步下降；指示列带来的信息（Sgot 缺失组死亡率 50% vs 20%）被多出来的方差抵消了。这正是讲义 7.2 对照实验的结论：**缺失指示列是原则，加不加必须用交叉验证决定。**

KNNImputer 要先标准化再做，因为它的距离是欧氏距离，不缩放的话 Alk_Phosphate（26-295）会主导邻居选择。

**判分要点**

- 三种策略都跑出 5 折 `mean ± std`，数值落在 0.81-0.84 附近算对
- 明确指出**三者差异在噪声范围内**（差值小于 std）算对
- 答出"第 2 种在这份小样本上并没有更好，因为特征数翻倍、方差变大"算满分
- 只说"中位数插补最简单所以最好"，不比较 std 算部分分
- 说"加缺失指示列一定更好，因为医学上缺失带信息"算错，这是把原则当成了结论

**常见错误**

- 先 `fillna` 再 `train_test_split` → 中位数用了测试集，指标虚高 → 全部放进 Pipeline，折内 fit
- KNNImputer 不做缩放 → Alk_Phosphate 主导距离，插补值接近该列的中位数 → 先 StandardScaler 再 KNNImputer
- 用 accuracy 比较 → "全猜存活"就有 79.4%，三种策略看不出差别 → 用 AUC
- 认为中位数插补"保留了分布" → 它把缺失值全堆在同一个点，方差被压缩 → 要报告插补前后分布，或用多重插补
- `SimpleImputer(add_indicator=True)` 以为一定加 6 列 → 只给"训练折里有缺失"的列加，全量 fit 时是 5 列 → 别写死列数

### 练习 5-B（识别废数据）

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')
from scipy.stats import spearmanr
from sklearn.model_selection import StratifiedKFold, cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

def quick_signal_check(df, target, exclude=()):
    print(f'目标: {target}')
    print(df[target].value_counts().sort_index().to_string())
    print('\n=== 与目标的秩相关 ===')
    rows = []
    for c in df.select_dtypes('number').columns:
        if c == target or c in exclude:
            continue
        sub = df[[c, target]].dropna()
        if len(sub) < 30:
            continue
        rho, p = spearmanr(sub[c], sub[target])
        rows.append((c, rho, p))
    rows.sort(key=lambda x: -abs(x[1]))
    for c, rho, p in rows[:10]:
        flag = '  <-- 有信号' if abs(rho) > 0.15 and p < 0.05 else ''
        print(f'  {c:28s} rho={rho:+.3f}  p={p:.3f}{flag}')
    strong = [r for r in rows if abs(r[1]) > 0.15 and r[2] < 0.05]
    print(f'\n结论: {len(strong)} 个特征有显著相关')
    if len(strong) == 0:
        print('  警告: 几乎没有信号，先别建模，回去查数据来源')
    return strong

hc = pd.read_csv(r'E:\AI学习\练习代码\data\uci\HCV_Egyptian.csv')
hc.columns = hc.columns.str.strip()
strong_hc = quick_signal_check(hc, 'Baselinehistological staging',
                               exclude=('Baseline histological Grading',))
print('有信号特征:', [r[0] for r in strong_hc])

h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')
strong_h = quick_signal_check(h, 'Class', exclude=('Histology',))
print('有信号特征:', [r[0] for r in strong_h])

y_hc = hc['Baselinehistological staging'].astype(int).values
feat = [c for c in hc.select_dtypes('number').columns
        if c not in ('Baselinehistological staging', 'Baseline histological Grading')]
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)
pipe = Pipeline([('imp', SimpleImputer(strategy='median')),
                 ('sc', StandardScaler()),
                 ('clf', LogisticRegression(max_iter=5000))])
s = cross_val_score(pipe, hc[feat], y_hc, cv=cv, scoring='roc_auc_ovr')
print(f'\nHCV 四分类 OVR AUC = {s.mean():.4f} +- {s.std():.4f}')
print('每折:', ' '.join(f'{v:.3f}' for v in s))
print('多数类基线准确率:', round(np.bincount(y_hc)[1:].max()/len(y_hc), 4))
```

- HCV 直接建模的 AUC 落在 0.49-0.53 算对
- 答出"不是模型没调好，是数据里没有信号，应回查数据来源"算满分
- 提到"1385 行、零缺失不等于能用"算加分
- 只跑了函数、没做建模验证，算部分分
- 说"HCV 样本大，调调参就能到 0.8"算错

**常见错误**

- 忘了 exclude 另一个结局列（Histology / Grading）→ 泄露，Hepatitis 会多出一个 rho 接近 1 的"特征" → 先分清哪些列是特征、哪些是结局
- 用 `Class`（1/2）解读方向 → 把 Bilirubin 说成保护因素 → 先转成 0/1 再解释符号
- 只看 p 值不看 |rho| → 1385 个样本下 rho=0.055 也能 p<0.05，但效应量可以忽略 → 两个条件都要卡
- 把 HCV 的 AUC 0.505 归因于"逻辑回归太弱" → 换随机森林、XGBoost 仍然是 0.5 → 先查信号，再换模型

### 练习 5-C（病人泄露）

**参考代码**

```python
import numpy as np
import pandas as pd
import warnings
warnings.filterwarnings('ignore')
from sklearn.model_selection import train_test_split, GroupShuffleSplit
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.metrics import roc_auc_score

# ---------- 造数据：200 个病人，每人 3 次随访 ----------
rng = np.random.default_rng(2026)
n_pat, n_visit = 200, 3
pid = np.repeat(np.arange(n_pat), n_visit)

base = rng.normal(size=(n_pat, 5))                  # 病人层面的“体质”
X = base[pid] + rng.normal(scale=0.05, size=(n_pat * n_visit, 5))  # 随访噪声很小

logit = 1.2 * base[:, 0] - 0.6 * base[:, 1]         # 结局只由病人体质决定
y_pat = rng.binomial(1, 1 / (1 + np.exp(-logit)), n_pat)
y = y_pat[pid]                                      # 同一病人 3 条记录标签相同

feat = [f'x{i+1}' for i in range(5)]
df = pd.DataFrame(X, columns=feat)
df['病人ID'] = pid
df['y'] = y

print('记录数 %d  病人数 %d  死亡率 %.3f' % (len(df), df['病人ID'].nunique(), y.mean()))
print('病人 0 的 3 条记录 x1:', df.loc[df['病人ID'] == 0, 'x1'].round(3).tolist())
print('病人间 x1 标准差 %.3f  病人内 x1 标准差 %.3f' %
      (base[:, 0].std(), df.groupby('病人ID')['x1'].std().mean()))

# ---------- 两种划分 ----------
tr, te = train_test_split(df.index, test_size=0.25, stratify=df['y'], random_state=0)

gss = GroupShuffleSplit(n_splits=1, test_size=0.25, random_state=0)
tr_b, te_b = next(gss.split(df, df['y'], groups=df['病人ID']))

models = {
    'RandomForest': RandomForestClassifier(n_estimators=300, random_state=0),
    'LogisticRegression': Pipeline([('sc', StandardScaler()),
                                    ('m', LogisticRegression(max_iter=2000))]),
}
print(f'{"模型":18s} {"按记录划分":>10s} {"按病人划分":>10s} {"差值":>8s}')
for name, m in models.items():
    m.fit(df.loc[tr, feat], df.loc[tr, 'y'])
    a = roc_auc_score(df.loc[te, 'y'], m.predict_proba(df.loc[te, feat])[:, 1])
    m.fit(df.loc[tr_b, feat], df.loc[tr_b, 'y'])
    b = roc_auc_score(df.loc[te_b, 'y'], m.predict_proba(df.loc[te_b, feat])[:, 1])
    print(f'{name:18s} {a:>10.4f} {b:>10.4f} {a-b:>+8.4f}')

print('按记录划分：测试集里“该病人也出现在训练集”的比例 %.1f%%' %
      (df.loc[te, '病人ID'].isin(df.loc[tr, '病人ID']).mean() * 100))
print('按病人划分：同一比例 %.1f%%' %
      (df.loc[te_b, '病人ID'].isin(df.loc[tr_b, '病人ID']).mean() * 100))
```

**实测输出**

```
记录数 600  病人数 200  死亡率 0.505
病人 0 的 3 条记录 x1: [-0.773, -0.771, -0.826]
病人间 x1 标准差 1.075  病人内 x1 标准差 0.045
模型                      按记录划分      按病人划分       差值
RandomForest           0.9905     0.6960  +0.2945
LogisticRegression     0.7881     0.7639  +0.0242
按记录划分：测试集里“该病人也出现在训练集”的比例 98.0%
按病人划分：同一比例 0.0%
```

**读法**：病人内标准差 0.045，病人间标准差 1.075，同一个人 3 条记录几乎是同一个点。按记录随机划分时，**98% 的测试记录对应的病人也在训练集里**，模型见过了这个人的另外两次随访。随机森林能记住这种"病人指纹"，AUC 从 0.696 虚高到 0.9905，差 0.2945。

逻辑回归只涨 0.0242，因为线性模型没有能力记住 200 个病人的个体模式。**这说明泄露的严重程度取决于模型容量**：论文里用 CNN、随机森林、XGBoost 时，内部 AUC 0.95、外部 0.70 的落差，就是这么来的。

造数据的关键三点：结局是**病人层面**的（3 条记录同一个标签）；特征是病人体质 + 很小噪声（病人内高度相似）；信号本身是弱的（病人层面 AUC 只有 0.70 左右）。如果信号很强，两种划分都高，看不出泄露。

**判分要点**

- 造出 200 病人 × 3 次 = 600 条，同一病人记录高度相似算对
- 按记录划分 AUC 明显高于按病人划分（随机森林差 0.25 以上）算对
- 答出"测试集病人也在训练集里，模型记住的是病人不是规律"算满分
- 报告了"测试集中病人在训练集出现过的比例"（98% vs 0%）算加分
- 只跑出两个数字、没解释机制，算部分分
- 用线性模型跑出很小的差距就下结论"泄露不严重"算错，要说明模型容量的影响

**常见错误**

- 三次随访直接复制同一条记录 → 病人内方差为 0，两种划分差距被夸大得不真实 → 加小噪声（本代码 0.05）
- 标签按记录随机生成 → 同一病人 3 条记录标签不同，病人在训练集里也学不到东西 → 标签必须是病人层面
- `GroupShuffleSplit` 忘了传 `groups=` → 报错或退化成普通划分
- 用 `train_test_split(..., groups=...)` → 这个函数没有 groups 参数，会报错 → 用 `GroupShuffleSplit` 或 `GroupKFold`
- 只看 AUC 不看重叠比例 → 说不清泄露从哪来 → 把"测试病人是否见过"量化出来

### 练习 5-D（SMOTE 误用）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings('ignore')
from sklearn.model_selection import StratifiedKFold, cross_val_score, train_test_split
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
from sklearn.neighbors import NearestNeighbors
from imblearn.pipeline import Pipeline as ImbPipeline
from imblearn.over_sampling import SMOTE

h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')
y = (h['Class'] == 1).astype(int).values
cols = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
X = h[cols]
cv = StratifiedKFold(5, shuffle=True, random_state=0)
clf = LogisticRegression(max_iter=2000, class_weight='balanced')

# 基线
base_pipe = Pipeline([('imp', SimpleImputer(strategy='median')),
                      ('sc', StandardScaler()), ('clf', clf)])
s0 = cross_val_score(base_pipe, X, y, cv=cv, scoring='roc_auc')
print(f'基线（无 SMOTE） AUC={s0.mean():.4f} +- {s0.std():.4f}')

# 做法 1：SMOTE 只发生在训练折内
pipe_smote = ImbPipeline([('imp', SimpleImputer(strategy='median')),
                          ('sc', StandardScaler()),
                          ('smote', SMOTE(random_state=0)),
                          ('clf', clf)])
s1 = cross_val_score(pipe_smote, X, y, cv=cv, scoring='roc_auc')
print(f'只在训练折 SMOTE      AUC={s1.mean():.4f} +- {s1.std():.4f}')
print('每折:', ' '.join(f'{v:.3f}' for v in s1))

# 做法 2：全量 SMOTE 再划分（错误示范）
prep = Pipeline([('imp', SimpleImputer(strategy='median')),
                 ('sc', StandardScaler())])
X_all = prep.fit_transform(X)                 # 预处理也用了全部数据
X_res, y_res = SMOTE(random_state=0).fit_resample(X_all, y)
print('全量 SMOTE 后:', np.bincount(y_res))

Xtr, Xte, ytr, yte = train_test_split(X_res, y_res, test_size=0.25,
                                      stratify=y_res, random_state=0)
m = LogisticRegression(max_iter=2000, class_weight='balanced').fit(Xtr, ytr)
auc2 = roc_auc_score(yte, m.predict_proba(Xte)[:, 1])
print(f'全量 SMOTE 再划分     AUC={auc2:.4f}')

# 量化“测试集里有多少训练集的近亲”
nn = NearestNeighbors(n_neighbors=1).fit(Xtr)
d, idx = nn.kneighbors(Xte)
print('测试样本到最近训练样本的距离: 中位数 %.4f, 10%%分位 %.4f' %
      (np.median(d), np.percentile(d, 10)))
print('最近训练样本与测试样本标签相同的比例: %.3f' % (ytr[idx[:, 0]] == yte).mean())
```

**实测输出**

```
基线（无 SMOTE） AUC=0.8312 +- 0.0358
只在训练折 SMOTE      AUC=0.8291 +- 0.0341
每折: 0.807 0.853 0.867 0.774 0.845
全量 SMOTE 后: [123 123]
全量 SMOTE 再划分     AUC=0.8418
测试样本到最近训练样本的距离: 中位数 0.6109, 10%分位 0.0830
最近训练样本与测试样本标签相同的比例: 0.806
```

**读法**：正确做法（训练折内 SMOTE）AUC 0.8291，和基线 0.8312 持平——**SMOTE 没有带来提升**。错误做法（全量 SMOTE 再划分）AUC 0.8418，只高了 0.011。

这个结果和"全量 SMOTE 会让 AUC 接近 1.0"的常见说法不一致，原因是这份数据只有 6 维、少数类只有 32 个：SMOTE 在 6 维空间里插值，合成点分散得比较开，测试集里的合成点不一定能在训练集里找到近邻。但泄露确实存在：10% 的测试样本到训练集最近点的距离只有 0.083（中位数 0.611 的 1/7），最近邻标签一致率 80.6%，而平衡后随机猜的期望只有 50%。**维度越高、少数类越少、样本越多，这种"近亲复制"越严重，AUC 就越接近 1.0。** 在影像组学那种几百维特征上做全量 SMOTE，才会看到 0.99。

**判分要点**

- 两种做法都跑出数字（0.829 vs 0.842 附近）算对
- 答出"做法 2 在划分前造样本，测试集里混入了训练样本的插值版本"算满分
- 答出"正确做法没有提升，说明 SMOTE 在这份数据上没用"算加分
- 能解释"为什么这里只涨 0.011，而高维数据会接近 1.0"算满分
- 只说"SMOTE 平衡了类别所以 AUC 高"算部分分（方向对，机制没说清）
- 说"SMOTE 提升了模型效果"算错，正确做法根本没提升

**常见错误**

- 在 `train_test_split` 之前做 `fit_resample` → 测试集被污染 → 只在训练折内做，用 `imblearn.pipeline.Pipeline`
- 用 sklearn 的 `Pipeline` 装 SMOTE → SMOTE 会在 `fit` 时对验证折也重采样，行为不对 → 用 `imblearn.pipeline.Pipeline`
- 先 SMOTE 再插补 → SMOTE 不能处理 NaN，直接报错 → 先 `SimpleImputer`，再 `SMOTE`
- 对测试集做 SMOTE 只为"平衡测试集" → 指标完全失真 → 测试集保持原始分布
- 只看 AUC 提升就认为有效 → 0.011 小于 std 0.034，是噪声 → 报告 mean ± std

### 练习 5-E（异常值决策）

**参考代码**

```python
import pandas as pd
import numpy as np

h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')

x = h['Bilirubin']
q1, q3 = x.quantile([0.25, 0.75])
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
out = (x < low) | (x > high)

print(f'n={len(h)}, 缺失={x.isna().sum()}')
print(f'Q1={q1:.2f} Q3={q3:.2f} IQR={iqr:.2f} 下界={low:.2f} 上界={high:.2f}')
print(f'异常值个数={out.sum()} ({out.mean():.1%})')
print('异常值:', sorted(x[out].tolist()))

print(f'异常组死亡率={h.loc[out, "Class"].eq(1).mean():.3f} '
      f'(n={out.sum()}, 死亡={h.loc[out, "Class"].eq(1).sum()})')
print(f'正常组死亡率={h.loc[~out, "Class"].eq(1).mean():.3f} '
      f'(n={(~out).sum()}, 死亡={h.loc[~out, "Class"].eq(1).sum()})')

print(f'全体死亡率={h["Class"].eq(1).mean():.3f}')
print(f'删掉异常值后死亡率={h.loc[~out, "Class"].eq(1).mean():.3f}')

# 对照：3 sigma 法
m, s = x.mean(), x.std()
out3 = (x - m).abs() > 3 * s
print(f'3sigma 判异常 {out3.sum()} 个, 死亡率 {h.loc[out3, "Class"].eq(1).mean():.3f}')
```

**实测输出**

```
n=155, 缺失=6
Q1=0.70 Q3=1.50 IQR=0.80 下界=-0.50 上界=2.70
异常值个数=17 (11.0%)
异常值: [2.8, 2.8, 2.9, 3.0, 3.2, 3.2, 3.5, 3.9, 4.1, 4.2, 4.6, 4.6, 4.6, 4.6, 4.8, 7.6, 8.0]
异常组死亡率=0.647 (n=17, 死亡=11)
正常组死亡率=0.152 (n=138, 死亡=21)
全体死亡率=0.206
删掉异常值后死亡率=0.152
3sigma 判异常 2 个, 死亡率 1.000
```

**读法**：IQR 上界 2.70 mg/dL，17 人被判异常，占 11%。这 17 人死亡率 64.7%，其余 138 人只有 15.2%，**差 4.3 倍**。如果按 IQR 删掉他们，队列死亡率会从 20.6% 降到 15.2%，等于系统性地把最重的病人删掉，模型学到一个"病人都不重"的假世界。

**不删。** 胆红素 7.6、8.0 mg/dL 在临床上完全可能（重型肝炎、肝衰竭），是真实极端值，不是录入错误。正确处理：树模型不用管；逻辑回归/SVM 用 `RobustScaler` 或 `log1p` 变换，把长尾压一压，而不是删样本。

顺带看 3σ：只找到 2 个人，死亡率 100%。3σ 在右偏数据上要么漏掉大量高值，要么被极端值撑大标准差，不能作为删人的依据。

**判分要点**

- 报出异常组 0.647、正常组 0.152（或 0.65 vs 0.15）算对
- 明确回答"不删"，并说明这些是危重病人、删了会丢信号算满分
- 提到"改用 RobustScaler / log 变换 / 树模型"算加分
- 只算数字、不给决策，算部分分
- 回答"删掉，因为 IQR 判定为异常"算错

**常见错误**

- `df.dropna()` 或 `drop(index=out)` 一删了之 → 17 个死者被删，AUC 掉、结论偏 → 先判断医学可能性，再决定处理方式
- 把胆红素缺失的 6 个人当 0 参与 IQR → 下界和分位数都错 → `quantile` 默认跳过 NaN，但后续分组要单独处理缺失
- 用 3σ 而不是 IQR → 只找到 2 个，漏掉 2.8-4.8 这一段真实高风险值 → 偏态数据用 IQR
- 认为"异常值一定干扰模型" → 树模型只看排序，不受极端值影响 → 按模型类型决定是否变换
- 删完不报告死亡率变化 → 审稿人一问就露馅 → 报告删除前后的样本量和事件率
