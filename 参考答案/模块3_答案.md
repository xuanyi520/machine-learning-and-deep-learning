# 3-1 Tensor 与自动求导

## 练习 3-1-A

**手算**：`f'(x) = 3x² - 4x`，代入 x=2 得 `3×4 - 4×2 = 12 - 8 = 4`

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = x**3 - 2*x**2 + 5
y.backward()
print(x.grad)      # tensor(4.)
```

对上。

## 练习 3-1-B

**手推**：
```
z = x²y + y³
∂z/∂x = 2xy
∂z/∂y = x² + 3y²
```

代入 x=1, y=2：`∂z/∂x = 4`，`∂z/∂y = 1 + 12 = 13`

```python
x = torch.tensor(1.0, requires_grad=True)
y = torch.tensor(2.0, requires_grad=True)
z = x**2 * y + y**3
z.backward()

print(x.grad)      # tensor(4.)
print(y.grad)      # tensor(13.)
```

## 练习 3-1-C

**问题**：**忘了清零梯度。**

```python
for epoch in range(100):
    loss = (w * 2 - 4) ** 2
    loss.backward()
    with torch.no_grad():
        w -= 0.1 * w.grad
    # ← 这里少了 w.grad.zero_()
```

**后果**：`w.grad` 每步累加，梯度越来越大，更新步子越来越猛，**w 会迅速发散到 inf/nan**。

**修复**：

```python
for epoch in range(100):
    loss = (w * 2 - 4) ** 2
    loss.backward()
    with torch.no_grad():
        w -= 0.1 * w.grad
    w.grad.zero_()          # ← 加上这行
```

**验证**：跑一下两版，观察 w 的最终值。修好的版本 w 应该收敛到 2（因为 `2w - 4 = 0`）。

## 练习 3-1-D

```python
import torch

torch.manual_seed(42)
N = 200
x = torch.rand(N) * 10
y = 2.5 * x + 1.0 + torch.randn(N) * 1.5

w = torch.zeros(1, requires_grad=True)
b = torch.zeros(1, requires_grad=True)
lr = 0.01

for epoch in range(1000):
    y_pred = w * x + b
    loss = ((y_pred - y) ** 2).mean()
    loss.backward()
    with torch.no_grad():
        w -= lr * w.grad
        b -= lr * b.grad
    w.grad.zero_()
    b.grad.zero_()
```

结构对比：

| numpy 版 | PyTorch 版 |
|---|---|
| `error = w*x+b - y` | 同上（`y_pred - y`） |
| `loss = np.mean(error**2)` | `((y_pred-y)**2).mean()` |
| `dw = (2/N)*np.sum(error*x)` | —— 被 `loss.backward()` 替代 |
| `w = w - lr*dw` | `w -= lr*w.grad` |
| —— | `w.grad.zero_()` |

**唯一多出来的东西就是 `zero_grad`。** 这是 PyTorch 的设计取舍（梯度累加支持一些高级用法），代价是用户必须手动清零。

## 练习 3-1-E

**手算**：`f'(x) = eˣ(cos x + sin x)`，x=1 得 `e¹(cos1 + sin1) = 2.71828 × (0.5403 + 0.8415) = 2.71828 × 1.3818 ≈ 3.7563`

```python
import torch
x = torch.tensor(1.0, requires_grad=True)
y = torch.sin(x) * torch.exp(x)
y.backward()
print(x.grad)      # tensor(3.7563)
```

对上。

## 自测题答案

1. Tensor 能放到 GPU、能自动求导；numpy 数组不能。
2. 标记这个变量需要计算梯度，PyTorch 会在反向传播时填充 `.grad`。
3. 因为梯度默认**累加**而不是覆盖。不清零会导致梯度越加越大，训练发散。
4. **autograd 就是自动执行链式法则。** 你在 W3 手推的每步求导+相乘，它都做了，只是自动化的。
5. 节省显存、加快速度。因为推理不需要计算图，PyTorch 可以省掉记录中间结果的开销。

# 3-2 搭建神经网络

## 练习 3-2-A

```python
import torch
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        self.relu = nn.ReLU()

    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        return self.fc3(x)

model = MLP()

```

## 练习 3-2-B

```python
import torch
import torch.nn as nn
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=1000, noise=0.1, random_state=42)
X = torch.tensor(X, dtype=torch.float32)
y = torch.tensor(y, dtype=torch.float32).unsqueeze(1)


class WithReLU(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 32), nn.ReLU(),
            nn.Linear(32, 32), nn.ReLU(),
            nn.Linear(32, 1), nn.Sigmoid())

    def forward(self, x): return self.net(x)


class NoReLU(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 32),
            nn.Linear(32, 32),
            nn.Linear(32, 1), nn.Sigmoid())

    def forward(self, x): return self.net(x)


for name, cls in [('有ReLU', WithReLU), ('无ReLU', NoReLU)]:
    model = cls()
    opt = torch.optim.Adam(model.parameters(), lr=0.01)
    crit = nn.BCELoss()
    for _ in range(300):
        opt.zero_grad()
        loss = crit(model(X), y)
        loss.backward()
        opt.step()
    acc = ((model(X) > 0.5).float() == y).float().mean()
    print(f"{name}: 准确率 = {acc.item():.4f}")
```

**结果**：有 ReLU 的能到 95%+，无 ReLU 的大约停在 85%（因为它只能画一条直线，而 moons 数据是弯的）。

**结论**：没有激活函数，多层网络退化成一个线性分类器，无法拟合非线性边界。

## 练习 3-2-D

在 3-2-A 的网络里，`fc2` 后加 `nn.Dropout(0.3)`。

**观察**：训练集准确率下降（因为 Dropout 让训练更难），但**训练集和测试集的差距缩小**。

**原因**：Dropout 随机关掉一部分神经元，网络不能依赖某几个特定神经元完成判断，被迫学出更鲁棒的特征。这减轻了过拟合。

**评估时记得 `model.eval()`**——否则 Dropout 还在随机丢弃，结果不稳定。

## 自测题答案

1. 因为 `W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)`，还是线性形式。堆多少层都一样。
2. 引入非线性，让网络能拟合复杂函数。
3. `__init__` 定义有哪些层（参数在这里注册）；`forward` 定义数据怎么流。
4. 因为 `model(x)` 会触发 `__call__`，里面处理了 hook、模式切换等。直接调 `forward` 会跳过这些。
5. `zero_grad()` → `backward()` → `step()`。写反会用到旧梯度更新参数，模型学不动。

# 3-4 卷积网络 CNN

## 练习 3-4-A

**参数量**：

```
features:
  conv1: 1×32×3×3 + 32 = 288 + 32 = 320
  conv2: 32×64×3×3 + 64 = 18432 + 64 = 18496
classifier:
  linear1: 3136×128 + 128 = 401536
  linear2: 128×10 + 10 = 1290
总计: 421642
```

**准确率**：3 轮后约 99.0%。

**反直觉的结论**：CNN 的参数量（约 42 万）**比** 3-3 的全连接网络（约 10.9 万）**多得多**，但性能更好。

准确地说：
- **卷积层本身参数极少**（conv1 才 320 个，conv2 是 18496 个）
- **参数大头在最后的全连接层**（401536，占 95%）
- CNN 的优势来自**结构先验**（局部性、平移不变性），不是参数少

**这也是现代 CNN 设计的一个重要方向**：用全局平均池化替代全连接层来减少参数。

## 练习 3-4-B

1. `Conv2d(3, 16, 3, padding=1)`：`(N, 16, 32, 32)`

   padding=1、kernel=3 保持尺寸不变。
2. `MaxPool2d(2)`：`(N, 16, 16, 16)`
3. `Conv2d(16, 32, 3, padding=1)`：`(N, 32, 16, 16)`
4. `MaxPool2d(2)`：`(N, 32, 8, 8)`
5. 展平：`32 × 8 × 8 = 2048`

## 练习 3-4-D

```python
train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.RandomCrop(32, padding=4),
    transforms.ToTensor(),

```

**典型提升**：准确率提升 5-10 个百分点。

**原理**：数据增强让模型每次看到同一张图的不同版本，等于扩大了训练集。模型被迫学习"翻转/平移后仍然是同一个物体"这种不变性，从而泛化更好、更不容易过拟合。

**医学影像的注意事项（重要）**：

- **水平翻转对胸片不合理**：左肺和右肺有解剖差异（心脏偏左、肝右叶）、病变分布可能不对称。翻转会造出解剖学上不存在的图像。
- **垂直翻转对几乎所有医学影像都不合理**：人体有明确的上-下方向。
- **旋转要小心**：小角度（±10°）通常可以，大角度会破坏解剖结构。
- **可用的增强**：轻微平移、缩放、亮度/对比度微调、弹性形变（对超声、病理切片常用）、加噪声。

**这是医学 AI 和自然图像 AI 的重大区别。** 用 ImageNet 那套增强（翻转、大幅裁剪）直接套到医学图像上，是很常见的错误。

## 练习 3-4-E

```python
from torchvision import models
import torch.nn as nn

model = models.resnet18(pretrained=True)

# 冻结所有预训练参数
for p in model.parameters():
    p.requires_grad = False

# 替换最后的全连接层（这一层是新的，要训练）
model.fc = nn.Linear(512, 10)

# 优化器只传需要梯度的参数
optimizer = torch.optim.Adam(
    filter(lambda p: p.requires_grad, model.parameters()), lr=1e-3)
```

**关键点**：

1. `pretrained=True` 加载 ImageNet 上学到的权重
2. `requires_grad = False` 冻结前面的层，训练时不更新
3. `model.fc = nn.Linear(512, 10)` 换成适合你任务的分类头
4. 优化器只传需要训练的参数量

**为什么有效**：ImageNet 上学到的底层特征（边缘、纹理、形状）是通用的，换成医学图像也有用。这样在小数据集上也能拿到好结果。

**医学影像的迁移学习注意**：
- ImageNet 是自然图像，和医学图像域差异大，但底层特征仍然可迁移
- 更好的选择是用**医学图像预训练的模型**（如 RadImageNet、Med3D），但资源少
- MNIST 用 ResNet18 有点杀鸡用牛刀，且要把 1 通道复制成 3 通道：`x.repeat(1,3,1,1)`

## 自测题答案

1. 参数太多、丢失空间信息、对平移不敏感。
2. 参数量极少；同一特征在任何位置都能被检测到（平移不变性）。
3. `(输入 - 卷积核 + 2×padding) / stride + 1`
4. 减小尺寸、减少计算量、增大感受野、提供一定平移鲁棒性。
5. 因为卷积有**结构先验**（局部性、权值共享），这些先验符合图像的性质，所以用更少的参数就能表达出更合适的函数。
