### 练习 8-A（K-means 的 k 选择）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings("ignore")
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

from sklearn.impute import SimpleImputer

h = pd.read_csv(r"E:\AI学习\练习代码\data\uci\Hepatitis.csv", na_values=["?"])

X = SimpleImputer(strategy="median").fit_transform(h[feats])
Xs = StandardScaler().fit_transform(X)

ks = list(range(2, 9))
sse, sil = [], []
for k in ks:
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(Xs)
    sse.append(km.inertia_)
    sil.append(silhouette_score(Xs, km.labels_))
    print(f"k={k} SSE={km.inertia_:7.1f} sil={sil[-1]:.4f} "
          f"sizes={np.bincount(km.labels_).tolist()}")

print("drop%:", [round((sse[i-1] - sse[i]) / sse[i-1] * 100, 1)
                 for i in range(1, len(sse))])

# 同维度随机基线
rng = np.random.default_rng(0)
base = []
for k in ks:
    ss = []
    for i in range(10):
        U = rng.random((155, 6))
        lb = KMeans(k, n_init=10, random_state=i).fit_predict(U)
        ss.append(silhouette_score(U, lb))
    base.append(np.mean(ss))
    print(f"null d=6 k={k}: {np.mean(ss):.3f} p95={np.percentile(ss, 95):.3f}")

fig, ax = plt.subplots(1, 2, figsize=(11, 4))
ax[0].plot(ks, sse, "o-")
ax[0].set_xlabel("k"); ax[0].set_ylabel("SSE"); ax[0].set_title("肘部法：没有明显拐点")
ax[1].plot(ks, sil, "o-", color="tab:red", label="Hepatitis 轮廓系数")
ax[1].plot(ks, base, "s--", color="gray", label="6 维随机基线（10 次均值）")
ax[1].set_xlabel("k"); ax[1].set_ylabel("轮廓系数")
ax[1].set_title("轮廓系数 vs 随机基线"); ax[1].legend(fontsize=8)
fig.tight_layout()
fig.savefig(r"E:\AI学习\参考答案\figs\8a_elbow_silhouette.png", dpi=130)

# k=3 的临床检验
lab = KMeans(3, n_init=10, random_state=42).fit_predict(Xs)
death = (h["Class"] == 1).astype(int).values
print(pd.crosstab(lab, death).to_string())
print("chi2 p:", chi2_contingency(pd.crosstab(lab, death))[1])
```

**回答**

**1. 肘部法支持哪个 k？为什么说不清楚？**

不支持任何一个。SSE 的逐档下降率是 12.2% → 11.7% → 11.6% → 10.4% → 9.5% → 7.4%，**平滑下滑，没有一处突然变缓**。任何递减凸曲线都有"最陡的一段"，在图上硬指 k=3 或 k=4 是人的决定，不是数据的决定。k=2 只解释总方差 23.2%，k=3 解释 32.5%，信息本来就没有集中在前几个方向。

**2. 轮廓系数支持哪个 k？**

k=2（0.2733）。但它只比 6 维随机基线 0.146 高 0.127，而且 k=3 掉到 0.1950（仍高于基线 95 分位 0.152，但只高 0.043）。**轮廓系数不是单调曲线，不要把它当成"找峰"工具。**

**3. 最终选 k=3，三条理由：**

- **统计**：k=3 的轮廓 0.1950 高于同维度随机基线的 95 分位 0.152，且三簇死亡率 2/76=2.6%、16/56=28.6%、14/23=60.9%，卡方 p=2.15e-09，严重程度单调。
- **临床**：三个簇是"轻 / 中 / 重"的 severity 轴。年轻、胆红素 0.85、白蛋白 4.15 的簇几乎不死；胆红素 2.8、SGOT 118、白蛋白 3.3 的簇死亡率 60.9%。中间档决定"是否收 ICU"，k=2 会把中间型和重症合并，临床价值下降。
- **稳健性**：Protime 缺 67 人（43.2%），主分析用中位数插补；用完成病例（83 人）重跑 k=3，轮廓 0.2684，与插补版分组的 **ARI = 0.729**，死亡率为排序后的 4.0% / 30.4% / 60.0%，方向和主分析一致。

**代价必须写出来**：从 k=2 到 k=3，轮廓系数从 0.2733 掉到 0.1950（-0.078），SSE 只降 12.2%。**这是用"统计上更差"换"临床上更有用"。** 医学论文里可以这样交易，但方法部分必须承认"轮廓系数不支持 k=3，k 由临床可解释性决定"，不能假装轮廓系数支持它。

**判分要点**

- 7 行表齐全，SSE 与轮廓系数都自己跑出来；k=1 的 930.0 要报，否则算不出 23.2% / 32.5%。
- 图上两条线：真实数据的轮廓系数 + 同维度随机基线，基线不能省。
- 结论里"轮廓系数"和"临床意义"必须同时出现，并明确说二者冲突时以临床为裁决、统计为参考。
- 必须报 Protime 缺 67 人（43.2%），并给出完成病例的敏感性分析（ARI 0.729）。
- 不能说"k=3 因为轮廓系数最高"——最高的是 k=2。
- 不能只看 p 值。p=2.15e-09 只说明"这三组不是同一分布"，不说明"三组有临床意义"；意义来自死亡率单调且能被一句话解释。

**常见错误**

- 不标准化直接聚类：Sgot 占总方差 74.6%，结果基本只按 Sgot 切，死亡率 p=0.78，一无所获。
- 用肘部图硬指一个拐点，不给下降率。
- 报轮廓系数 0.195 就说"结构明显"，不查 6 维随机基线是 0.146。
- 用参与聚类的六个指标做组间检验，p 必然显著，属循环论证。
- 只报一种缺失值处理，审稿人换一种就翻车。
- 忘记 `n_init=10`，换一次运行结果就变。

### 练习 8-B（随机数据实验）

**参考代码**

```python
import numpy as np
import pandas as pd
import warnings
warnings.filterwarnings("ignore")
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer

# ---------- 1. 300 个 2 维随机点，k=4 ----------
rng = np.random.default_rng(7)
R = rng.random((300, 2))
km = KMeans(n_clusters=4, n_init=10, random_state=0).fit(R)
print("簇大小:", np.bincount(km.labels_).tolist())
print("轮廓系数:", round(silhouette_score(R, km.labels_), 4))
print("四个中心:", np.round(km.cluster_centers_, 3).tolist())

# ---------- 2. k=2..6，每个 20 个种子 ----------
for k in range(2, 7):
    ss = []
    for s in range(20):
        U = np.random.default_rng(1000 * s + k).random((300, 2))
        lb = KMeans(k, n_init=10, random_state=s).fit_predict(U)
        ss.append(silhouette_score(U, lb))
    print(f"k={k}: mean={np.mean(ss):.4f} sd={np.std(ss):.4f} "
          f"p95={np.percentile(ss, 95):.4f} min={min(ss):.4f} max={max(ss):.4f}")

# ---------- 3. 真有四团的数据作对照 ----------
ss = []
for s in range(20):
    U, _ = make_blobs(n_samples=300, centers=4, cluster_std=1.0, random_state=s)
    lb = KMeans(4, n_init=10, random_state=s).fit_predict(U)
    ss.append(silhouette_score(U, lb))
print(f"真实 4 团 k=4: mean={np.mean(ss):.4f} sd={np.std(ss):.4f}")

# ---------- 4. Hepatitis 在 6 维零分布中的分位 ----------
h = pd.read_csv(r"E:\AI学习\练习代码\data\uci\Hepatitis.csv", na_values=["?"])
feats = ["Age", "Bilirubin", "Alk Phosphate", "Sgot", "Albumin", "Protime"]
Xs = StandardScaler().fit_transform(
    SimpleImputer(strategy="median").fit_transform(h[feats]))
hep = silhouette_score(Xs, KMeans(3, n_init=10, random_state=42).fit_predict(Xs))

rng = np.random.default_rng(1)
null = []
for s in range(200):
    U = rng.random((155, 6))
    lb = KMeans(3, n_init=10, random_state=s).fit_predict(U)
    null.append(silhouette_score(U, lb))
null = np.array(null)
print("d=6 k=3 null: mean=%.4f sd=%.4f p95=%.4f"
      % (null.mean(), null.std(), np.percentile(null, 95)))
print("Hepatitis %.4f 的经验分位: %.1f%%" % (hep, (null < hep).mean() * 100))

fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(null, bins=30, color="lightgray", edgecolor="k")
ax.axvline(hep, color="tab:red", lw=2, label="Hepatitis k=3: 0.195")
ax.axvline(np.percentile(null, 95), color="k", ls="--", label="随机 95 分位")
ax.set_xlabel("轮廓系数"); ax.set_ylabel("频数")
ax.set_title("155 例 6 维随机数据的轮廓系数分布（200 次）")
ax.legend(fontsize=8)
fig.tight_layout()
fig.savefig(r"E:\AI学习\参考答案\figs\8b_null_dist.png", dpi=130)
```

**回答**

**1. 随机数据在 k=4 时的平均轮廓系数是多少？**

**0.4142**（20 个种子，sd 0.0162，95 分位 0.4391）。单次点估计可以到 0.4481。也就是说，**2 维纯随机数据拿 0.40-0.45 是常态**。

四簇大小 78 / 71 / 74 / 77，中心几乎落在正方形的四个象限中心：(0.72, 0.24)、(0.22, 0.31)、(0.27, 0.78)、(0.77, 0.72)。图上边界是两条直线，看起来"数据本来就是这样"。这就是 K-means 的本质：**它不发现簇，它把空间切成 k 块。**

**2. Hepatitis 的结果相当于第几百分位？**

必须同维度比。Hepatitis k=3 的 0.1950，在 155 例 × 6 维随机数据的 200 次模拟中，**高于全部 200 次（经验分位 100%，即 >99.5 分位）**。零分布 mean 0.1423、sd 0.0070、95 分位 0.1549，0.1950 已经在分布的右尾之外。

但如果错误地拿它和 2 维随机基线（0.4142）比，会得出"0.195 远低于随机"的相反结论。**同一个分数，换错维度，结论反转。** 这正是本题的核心：绝对值没有意义，参照系决定一切。

**3. 如果审稿人问"0.4 的轮廓系数算好吗"，怎么答？**

> "不能孤立地看 0.4。轮廓系数强烈依赖维度和 k。本机实测：300 个 2 维均匀随机点在 k=4 时平均就有 0.4142（95 分位 0.4391），所以 2 维数据的 0.40 等于随机水平。若是 6 维数据，随机基线约 0.14；若是 30 维，基线约 0.035。判断标准只有一个：**你的值比同维度、同样本量、同 k 的随机基线高多少，以及是否超过其 95 分位。**"

补充：真有四团的数据（make_blobs，cluster_std=1.0）轮廓系数是 0.6695 ± 0.0837，比随机基线高 0.26。**"有结构"和"没结构"在这个尺度上才分得开。**

**判分要点**

- 20 个种子，报 mean、sd、95 分位，不能只报一个数。k=2..6 五行齐全。
- 必须指出随机数据的簇大小 78/71/74/77"看起来很均衡"，但均衡是 K-means 的固有倾向，不是结构证据。
- 第 2 问必须用**同维度**零分布（6 维），并明确说"用 2 维基线比会得出相反结论"。
- 第 3 问的答案要落到"和基线比"，不能只说"0.4 一般算中等"。
- 加分项：解释为什么 2 维基线比 6 维高——维度越高，随机点之间的欧氏距离越趋于相等（距离集中现象），簇的边界越模糊，轮廓系数越低。实测 2 维 0.414、6 维 0.142。

**常见错误**

- 只跑一个种子，0.4042 恰好落在 0.39-0.45 的波动区间里，误以为是稳定值。
- 拿 2 维随机基线去评价 6 维数据（或反过来）。
- 看到 78/71/74/77 就说"四簇很均衡，说明分得好"。
- 把"随机数据也能出图"当成"K-means 不能用"。正确的结论是"K-means 的输出必须用零假设基线证伪"，不是"别用 K-means"。
- 用 `make_blobs` 的轮廓系数 0.67 和随机数据的 0.41 直接比，不说 cluster_std 和维度。两者都是 2 维，这个比较成立；换维度就不成立。

### 练习 8-C（linkage 对比）

**参考代码**

```python
import pandas as pd
import numpy as np
import warnings
warnings.filterwarnings("ignore")
from scipy.cluster.hierarchy import linkage, fcluster, cophenet
from scipy.spatial.distance import pdist
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score, adjusted_rand_score

h = pd.read_csv(r"E:\AI学习\练习代码\data\uci\Hepatitis.csv", na_values=["?"])
feats = ["Age", "Bilirubin", "Alk Phosphate", "Sgot", "Albumin", "Protime"]

sub = h.dropna(subset=feats)              # 保留原索引
print("完成病例:", len(sub))
X = StandardScaler().fit_transform(sub[feats])

for link in ["single", "complete", "average", "ward"]:
    Z = linkage(X, method=link)
    c, _ = cophenet(Z, pdist(X))
    for k in [2, 3]:
        lab = fcluster(Z, k, criterion="maxclust")
        sizes = sorted(np.bincount(lab)[1:].tolist(), reverse=True)
        print(f"{link:8s} k={k}: sizes={sizes} "
              f"sil={silhouette_score(X, lab):.4f} "
              f"ARI_hist={adjusted_rand_score(sub['Histology'], lab):.3f} "
              f"cophen={c:.3f}")
```

**回答**

**1. 哪种 linkage 的轮廓系数最高？它的簇大小是多少？**

single / complete / average 的 k=2 并列最高，都是 **0.5085**，簇大小都是 **82 + 1**。k=3 时 average 最高（0.3854），仍然是 74 + 8 + 1。

**2. 哪种 linkage 和 Histology 的 ARI 最高？**

**Ward**：k=2 时 ARI = 0.211，k=3 时 0.200。其他三种在 0.009-0.076 之间，几乎等于随机。

**3. 为什么最高轮廓系数对应的分组没有临床意义？**

因为"82 + 1"不是两个亚型，是**"82 个正常人 + 1 个离群点"**。单个离群点的 s(i) 接近 1.0（它离所有人远，b 远大于 a），82 人簇内部的平均轮廓也有 0.5 左右，两者一平均就是 0.5085。**轮廓系数被一个点收买了。**

但它的 ARI vs 组织学只有 0.009——这个划分和组织学分期毫无关系。反过来，Ward 的轮廓最低（0.2719），ARI 最高（0.211），簇大小 48/35 才是两个可解释的组。

**这说明：轮廓系数衡量"几何上紧不紧"，不衡量"临床上有没有用"。** 一个离群点就能把分数抬到 0.5，而真正的分组信息可能在一个分数更低的划分里。

**判分要点**

- 8 行表齐全（4 linkage × 2 k），簇大小、轮廓、ARI、共表相关四列都要有。
- 必须明确指出"82+1"是退化分组，不是两个簇。
- 必须解释轮廓系数被单个离群点抬高的机制（a、b、s 的定义）。
- 必须指出 Ward 的 cophenetic 最低（0.579）是正常的：它优化 SSE，不优化距离保真度；**共表相关衡量"树画得准不准"，不是"分得好不好"**，不能拿它选聚类方案。
- 结论：病人分型优先 Ward；single 适合找连通形状（moons、轨迹），不适合找紧凑的团。

**常见错误**

- 看到 0.5085 就宣布"single 最好"，不看簇大小。
- 用共表相关选 linkage：average 0.848 最高，但它的 ARI 只有 0.032。

**回答**

**1. 哪几组能得到 ARI = 1.0？**

6 组：**eps=0.15 和 eps=0.20 的全部 min_samples（3、5、10）**。这两档都完整分出两只月亮、0 噪声。

**2. eps=0.05 时发生什么？eps=0.3 时呢？**

- eps=0.05：邻域太小，每个点只认识最近的几个。min_samples=3 时碎成 36 块、26.5% 判噪声；min_samples=5 时 28 块、54.5% 噪声；min_samples=10 时**一个核心点都没有，400 个点全判噪声**（簇数 0，ARI 无法计算）。

- eps=0.1 是中间地带，对 min_samples 极敏感：ARI 从 0.901（ms=3）掉到 0.117（ms=10）。

**同一个算法，eps 从 0.05 到 0.3，答案从"36 个簇、一半噪声"到"1 个簇"，中间只有 0.15-0.20 这一小段是对的。**

**3. k-distance 图验证 eps：**

第 5 近邻距离的分位数：50% = 0.064，90% = 0.105，95% = 0.118，99% = 0.149。曲线在 0.10-0.15 处开始陡升，拐点对应 eps≈0.15，正好落在实测最优区间 0.15-0.20 内。**用 99 分位 0.149 作为 eps，是有依据的选择，不是试出来的。**

**判分要点**

- 15 行表齐全，簇数、噪声比例、ARI 三列都要有；簇数 0 时 ARI 写"不可计算"，不能写 0。
- 必须指出最优不是单点而是一个区间（eps 0.15-0.20 × ms 3-10 共 6 组），这比"eps=0.15 最好"更准确。
- k-distance 图必须画，并标出所选 eps；报 50/90/95/99 分位。
- 结论要写"DBSCAN 对 eps 极度敏感，eps 从 0.05 到 0.3 答案从 36 簇变 1 簇；它不是不用调参，是把调 k 换成了调 eps"。
- 说明 `min_samples` 的经验起点：维度 + 1，医学数据取 5-10。
- 补充：这里的 ARI 能算，是因为 moons 有真实标签；真实数据没有标签，只能靠稳定性和外部效度，不能靠 ARI。

**常见错误**

- `len(set(lab))` 不减掉 -1，把噪声当成一个簇（本例会多报 1 个簇）。
- 不标准化就跑 DBSCAN（本例 moons 两个维度量纲相同，影响小；真实数据必须先标准化）。
- 用默认 `eps=0.5`，moons 上直接全并成一簇。
- 把 -1 当成"特殊亚型"分析，噪声不是亚型。
- 只用一组参数就下结论，不画敏感性表。
- 认为 DBSCAN"不用给 k 所以不用调参"。

- 在 t-SNE 图上跑 K-means 报告 k。
- 比较图上两群的距离或大小。
- 不报 perplexity 就展示图，读者无法复现。

### 练习 8-G（给一篇聚类论文挑错）

**参考代码**

下面是一个可以直接套在任意聚类论文上的"三条防线复核脚本"。输入特征矩阵、论文给出的分组标签、以及一个**没参与聚类**的结局变量，输出三项裁决。

```python
import numpy as np
import pandas as pd
import warnings
warnings.filterwarnings("ignore")
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score
from scipy.stats import chi2_contingency

def audit(X, lab, name, outcome=None, n_null=20, n_boot=50, seed=0):
    """X: 聚类输入（已标准化）; lab: 论文的分组; outcome: 外部结局（0/1）"""
    k = len(set(lab))
    n, dd = X.shape
    s = silhouette_score(X, lab)

    # 防线一：同维度零假设基线
    rng = np.random.default_rng(seed)
    null = []
    for i in range(n_null):
        U = rng.random((n, dd))
        lb = KMeans(k, n_init=10, random_state=i).fit_predict(U)
        null.append(silhouette_score(U, lb))
    null = np.array(null)

    # 防线二：bootstrap 稳定性
    rng = np.random.default_rng(seed + 1)
    aris = []
    for b in range(n_boot):
        idx = rng.integers(0, n, n)
        lb = KMeans(k, n_init=10, random_state=b).fit_predict(X[idx])
        aris.append(adjusted_rand_score(lab[idx], lb))

    print(f"\n[{name}] n={n} d={dd} k={k}")
    print(f"  防线1 轮廓={s:.3f} | 随机均值={null.mean():.3f} "
          f"95分位={np.percentile(null, 95):.3f} | 分位={(null < s).mean()*100:.0f}%")
    print(f"  防线2 稳定性 ARI={np.mean(aris):.3f}±{np.std(aris):.3f} "
          f"（同维度随机数据约 0.39）")

    if outcome is not None:
        ct = pd.crosstab(lab, outcome)
        p = chi2_contingency(ct)[1]
        rates = [outcome[lab == c].mean() for c in range(k)]
        print(f"  防线3 外部结局 p={p:.2e} 各簇发生率={np.round(rates, 3).tolist()}")
```

**回答：该查哪三件事**

拿到任何一篇"聚类发现疾病亚型"的论文，先查这三件事，任何一件过不了，亚型结论就不成立。

**第一件：有没有同维度零假设基线？**

轮廓系数 0.3、0.4 本身什么都不能说明。必须问："同维度、同样本量、同 k 的均匀随机数据，用同一个算法能拿到多少？"

- 本机基线：2 维 k=4 是 0.414，6 维 k=3 是 0.142，30 维约 0.035。
- 判据：真实值必须显著高于基线的 95 分位。
- HCV 0.0875 vs 基线 0.088（95 分位 0.091）→ **低于基线，等于噪声**。论文若只写"轮廓系数 0.0875，结构较弱但存在"，是错的。

**第二件：换一批病人，分组还稳不稳？**

做法：bootstrap 重采样 50 次，算 ARI。**不要拿 0 当基准**——重采样同一批点，K-means 天然会给相似切分，随机数据的稳定性也有约 0.39。

- 判据：ARI 要明显高于同维度随机数据的稳定性基线（约 0.39-0.45），且 bootstrap 的标准差不能太大。
- Hepatitis 0.541 ± 0.169：高于 0.39，但只高 0.15，只能叫"弱可重复"。
- HCV 0.182 ± 0.158：**低于随机基线**，重采样后分组比随机还乱。

**第三件：外部验证变量是否独立于聚类输入？**

必须用**没参与聚类**的变量：死亡、生存时间、并发症、治疗反应、病理分期。

- 用参与聚类的指标做组间检验是循环论证——K-means 的目标函数保证它们有差异。
- 必须**预先指定** 1-2 个主要结局，其余标探索性，并做多重比较校正。聚类后拿 20 个变量逐个检验，α=0.05 时期望 1 个假阳性。
- Hepatitis：用死亡（未参与聚类），三簇 2.6% / 28.6% / 60.9%，p=2.15e-09，单调 → 通过。
- HCV：用组织学分期（未参与聚类），p=0.0899，ARI=0.0028（随机分组 95% 区间 [-0.0013, 0.0020]）→ **等同于随机贴标签**。

**论文核查表（至少 5 行）**

| 检查项 | 典型论文怎么做的 | 是否合格 | 应该怎么补 |
|---|---|---|---|
| 有没有报告 k 的选择依据 | 只报 k=3 的轮廓系数，不报 k=2..8 的曲线，也不说为什么不是 2 或 4 | 不合格 | 补肘部图 + 轮廓系数随 k 的曲线 + 临床可解释性；明确写出"轮廓支持 k、临床支持 k 时如何取舍" |
| 有没有和随机基线比 | 只写"轮廓系数 0.31，说明存在三个亚型" | 不合格 | 生成同维度、同样本量、同 k 的均匀随机数据 20-100 次，报均值与 95 分位，把自己的值放进去定位 |
| 有没有稳定性分析 | 完全没有；换一个软件/种子结果就变 | 不合格 | bootstrap 50 次，报 ARI mean±sd，并与随机数据的稳定性基线（约 0.39）比较 |
| 外部验证变量是否独立于聚类输入 | 用聚类用过的化验指标做组间比较，p 全部 <0.001 | 不合格 | 换成死亡、生存、分期、治疗反应等未参与聚类的变量；预先指定主要终点 |
| 多重比较有没有校正 | 对 20 个临床变量逐个做 t 检验，挑 p<0.05 的写进讨论 | 不合格 | 预设 1-2 个主要结局；其余标探索性；用 Bonferroni 或 FDR 校正，报告校正后 p |
| 缺失值处理是否做了敏感性分析 | 只报中位数插补版，不提缺失比例 | 不合格 | 报缺失比例；用完成病例重跑，报两次分组的 ARI 和结论方向是否一致 |

**100 字结论（模板）**

> 这篇论文的亚型结论不可信。它的轮廓系数 0.0875 低于同维度随机基线 0.088，稳定性 ARI 0.182 低于随机数据的 0.39，与组织学分期 ARI 仅 0.0028、p=0.09，三条防线全部未过。三个"亚型"是 K-means 把 1385 人切成三块的产物，不是数据里的结构。除非作者补做零假设基线、稳定性和独立外部验证并能过线，否则不应作为临床分型依据。

**判分要点**

- 必须交一张至少 5 行的表，每行有"论文怎么做的 / 是否合格 / 具体补法"三列；"补法"不能写"建议改进"，要写可执行的步骤（多少次重采样、和什么基线比、用什么变量）。
- "该查哪三件事"必须落到三条防线：零假设基线、稳定性、外部效度；每条都要给出判据和本机的实测参照值。
- 必须指出"用参与聚类的变量做检验"是循环论证，这是医学聚类论文最常见的硬伤。
- 必须提多重比较：20 个变量 × 4 个组，α=0.05 时期望假阳性约 1.8 个。
- 最后 100 字结论要明确回答"可信 / 不可信"，不能和稀泥。
- 加分项：指出"轮廓系数高"可能是离群点造成的（见 8-C 的 82+1），要同时看簇大小。

**常见错误**

- 只挑"轮廓系数低"一条就否定论文，不查稳定性和外部效度。
- 把 p<0.05 当成"亚型有临床意义"。样本量大时，任何微小差异都会显著；要看效应量和单调性。
- 用论文自己报告的数字互相印证（轮廓 + p 值），不去核对参照系。
- 建议写成"增加样本量""多做验证"这种空话，没有具体操作。
- 忽略缺失值处理：换一种插补，分组就变（Hepatitis 完成病例 vs 插补 ARI 0.729，仍有 27% 的人换组）。
- 把聚类标签的顺序当严重程度，直接说"簇 1 比簇 2 重"，不先按结局排序。
