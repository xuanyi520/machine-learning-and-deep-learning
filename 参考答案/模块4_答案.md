```python
import matplotlib.pyplot as plt
matplotlib.rcParams['font.sans-serif'] = ['SimHei']
matplotlib.rcParams['axes.unicode_minus'] = False

def apply_window(img, center, width):
    low, high = center - width/2, center + width/2
    img = np.clip(img, low, high)
    return ((img - low) / (high - low) * 255).astype(np.uint8)

windows = {
    '原始（无窗）': None,
    '肺窗 (-600, 1500)': (-600, 1500),
    '纵隔窗 (40, 400)': (40, 400),
    '骨窗 (400, 1800)': (400, 1800),
}

fig, axes = plt.subplots(1, 4, figsize=(20, 5))
for ax, (name, w) in zip(axes, windows.items()):
    if w is None:
        ax.imshow(hu, cmap='gray')
    else:
        ax.imshow(apply_window(hu, *w), cmap='gray')
    ax.set_title(name); ax.axis('off')
plt.tight_layout(); plt.show()
```

**你该看到的差异**：

- **原始（无窗）**：因为 HU 范围 -1000 到 +1000 都被线性映射，软组织（40-60 HU）全挤在很窄的灰阶里，几乎全黑或全灰，看不出结构
- **肺窗**：肺的细节清晰（含气结构），但软组织全糊了
- **纵隔窗**：能看清心脏、血管、肌肉，但肺全是黑的
- **骨窗**：骨头清晰，其他全是黑的

**结论**：**显示参数的选择决定了你能看到什么。** 做肝脏 AI 必须用肝窗（或腹部窗）预处理。

**重要认知**：**医学图像准确率普遍低于自然图像任务**，原因：
- 数据量小（几百到几万，而 ImageNet 有千万级）
- 类间差异细微（不同血细胞形态相似）
- 标注主观性（不同医生可能标得不一样）
- 类别不平衡常见

**所以看到医学论文里一个模型 AUC 0.85，不要觉得"才 85%"，这在临床上可能已经很有价值了。** 判断标准是"比现有方法好多少"，不是绝对的数值大小。

## 练习 4-1-E

**1.** 像素间距 0.7mm/像素，100×100 像素：

```
实际尺寸 = 100 × 0.7 = 70 mm
面积 = 70 × 70 = 4900 mm² = 49 cm²
```

**2. 层厚 5mm 意味着：**

- 每层图像代表 5mm 厚的组织（但显示时是平的）
- **体素不是立方体**：`0.7 × 0.7 × 5.0` mm，是个扁盒子
- **小病灶可能被"部分容积效应"淹没**：一个 3mm 的结节落在 5mm 层厚里，它和周围的正常组织被平均了，对比度大幅降低，可能看不出来
- **三维重建会失真**：直接堆叠会得到"矮胖"的体积，需要用 `PixelSpacing` 和 `SliceThickness` 做各向异性校正
- **对分割任务的影响**：训练时如果 z 方向不重采样，网络学到的"1 层"在图上是 0.7mm 但在 z 方向是 5mm，尺度不一致

**临床对比**：薄层 CT（1mm 层厚）能发现更小的病灶，但数据量大 5 倍、辐射剂量更高。这是临床上的权衡。

**这就是为什么医学 AI 预处理里"重采样到各向同性"（比如统一到 1×1×1 mm）是标准步骤。**

## 自测题答案

1. DICOM 是"图像 + 元数据"，带患者信息、扫描参数、物理尺寸等；普通图片只有像素。
2. HU 是 X 射线衰减的量化单位，水的 HU 是 0（空气 -1000，骨 +400 以上）。
3. 把宽范围的 HU 值映射到人眼能分辨的 0-255 灰阶，只显示感兴趣的区间。
4. 因为不同组织的 HU 差异很大（从 -1000 到 +1000），一幅图线性显示时所有软组织挤在一起。开窗只保留一个窄区间，才能看清该区间的结构。
5. PixelSpacing 告诉你每个像素代表的实际物理尺寸。没有它，你无法知道病灶真实大小，也无法做尺度的标准化。

| 指标 | 值 | 算式 |

| 准确率 Accuracy | 0.8718 | (159+385)/624 |

### 三个必须看懂的细节

**① 第 9、10 轮已经在过拟合**

训练 loss 继续降（0.0852 → 0.0738），验证 loss 反而升（0.0870 → 0.0908）。
按早停规则，应该在**第 8 轮**（val loss 最低 0.0828）就停，并回滚到那一轮的权重。

**② 准确率 87.2% 掩盖了特异度 68.0%**

234 个健康人里 **75 个被判成肺炎**（32%）。每 3 个来体检的健康人就有 1 个被要求复查。
准确率把"漏诊 5 个"和"误诊 75 个"混在一起算，看不出这个代价。

**③ FN 和 FP 的临床含义不对等**

- FN=5 → 漏诊 5 个肺炎病人，可能延误治疗
- FP=75 → 误诊 75 个健康人，增加复查成本、制造恐慌

这个模型偏保守（宁可误报不肯漏诊）。早筛场景方向没错，但特异度偏低要在报告里写清楚。

**④ 为什么必须开确定性模式**

关掉确定性设置时，同一个脚本跑两遍，结果不同：

| 指标 | 第 1 次 | 第 2 次 |
|---|---|---|
| 准确率 | 0.8750 | 0.8686 |
| 特异度 | 0.6923 | 0.6752 |
| AUC | 0.9471 | 0.9437 |

**原因**：`torch.manual_seed()` 只固定 CPU 的随机数。GPU 上的卷积算法选择和 Dropout 掩码走 CUDA 自己的随机发生器，没被固定。

**下面代码里加了三行确定性设置**，可以让结果完全可复现：

```python
torch.backends.cudnn.deterministic = True
torch.backends.cudnn.benchmark = False
torch.cuda.manual_seed_all(42)
```

**实测验证**：加上这三行后连跑两遍，七项指标（含混淆矩阵四个数）完全一致。

代价是训练变慢。**写论文报结果时加，日常调试可以不加。**

### 完整代码

```python
# ============================================================
# 练习 4-2-A：pneumoniamnist 完整跑通，10 轮后记录测试集全部指标
# ============================================================
import numpy as np
import matplotlib.pyplot as plt
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import transforms
import medmnist
from medmnist import INFO
from pathlib import Path
from sklearn.metrics import (accuracy_score, precision_score, recall_score,
                             f1_score, confusion_matrix, roc_auc_score, roc_curve)

plt.rcParams['font.sans-serif'] = ['SimHei']    # 中文标题不变方块
plt.rcParams['axes.unicode_minus'] = False      # 负号正常显示

torch.manual_seed(42)                           # 固定 CPU 随机种子
# 下面三行固定 GPU 的随机性，保证重复运行结果完全一致（代价是训练稍慢）
torch.backends.cudnn.deterministic = True       # 卷积算法选确定的那个，不选最快的
torch.backends.cudnn.benchmark = False          # 关掉自动算法搜索
device = "cuda" if torch.cuda.is_available() else "cpu"
if device == "cuda":
    torch.cuda.manual_seed_all(42)              # 固定所有 GPU 的随机种子
print("使用设备:", device)

# ---------- 1. 数据 ----------
ROOT = Path(r'E:\AI学习\练习代码\data\medmnist')
ROOT.mkdir(parents=True, exist_ok=True)         # 目录不存在就建，已存在不报错

data_flag = 'pneumoniamnist'
info = INFO[data_flag]                          # 数据集档案：类别、通道、样本数
DataClass = getattr(medmnist, info['python_class'])
n_classes = len(info['label'])                  # 2
label_names = info['label']

# ToTensor：PIL → Tensor，(28,28) → (1,28,28)，0~255 → 0~1
# Normalize(0.5,0.5)：(x-0.5)/0.5，把 0~1 压到 -1~1，数据中心化后梯度下降更稳
train_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.5], std=[0.5]),
])
# 验证/测试必须用和训练完全一样的变换，否则输入分布不一致，指标不可信
eval_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.5], std=[0.5]),
])

train_set = DataClass(split='train', transform=train_transform, download=True, root=str(ROOT))
val_set   = DataClass(split='val',   transform=eval_transform,  download=True, root=str(ROOT))
test_set  = DataClass(split='test',  transform=eval_transform,  download=True, root=str(ROOT))

print(f"训练 {len(train_set)} / 验证 {len(val_set)} / 测试 {len(test_set)}")
print("标签:", label_names)

# 训练集打乱（每轮顺序不同，防止记住顺序）；验证/测试不打乱（结果稳定可复现）
train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
val_loader   = DataLoader(val_set,   batch_size=64, shuffle=False)
test_loader  = DataLoader(test_set,  batch_size=64, shuffle=False)


# ---------- 2. 模型 ----------
class MedCNN(nn.Module):
    def __init__(self, in_ch, n_cls):
        super().__init__()
        # 特征提取：通道 1→32→64，尺寸 28→14→7
        self.features = nn.Sequential(
            nn.Conv2d(in_ch, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1),    nn.ReLU(), nn.MaxPool2d(2),
        )
        # 分类：64 通道 × 7 × 7 = 3136
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 7 * 7, 64), nn.ReLU(),
            nn.Dropout(0.3),                     # 训练时随机丢 30% 神经元，防过拟合
            nn.Linear(64, n_cls),
        )

    def forward(self, x):
        return self.classifier(self.features(x))


model = MedCNN(info['n_channels'], n_classes).to(device)
print("参数量:", sum(p.numel() for p in model.parameters()))   # 219714

criterion = nn.CrossEntropyLoss()                # 多分类交叉熵，内部自带 softmax
optimizer = optim.Adam(model.parameters(), lr=1e-3)


# ---------- 3. 一个 epoch 的通用流程 ----------
def run_epoch(model, loader, train=True):
    # train 模式打开 Dropout；eval 模式关闭 Dropout 并切换 BatchNorm 行为
    model.train() if train else model.eval()
    total_loss, correct, total = 0.0, 0, 0

    # 训练要算梯度，评估不需要（关掉能省显存、也避免误改参数）
    ctx = torch.enable_grad() if train else torch.no_grad()
    with ctx:
        for xb, yb in loader:
            xb = xb.to(device)
            yb = yb.squeeze().long().to(device)   # 标签 (64,1) → (64,)，CrossEntropyLoss 只认一维

            if train:
                optimizer.zero_grad()             # 梯度会累加，每步必须清零

            out = model(xb)
            loss = criterion(out, yb)

            if train:
                loss.backward()                   # 反向传播，算出每个参数的梯度
                optimizer.step()                  # 按 Adam 规则更新参数

            # 每个 batch 的 loss 是平均值，乘回 batch 大小才是总损失
            # （最后一个 batch 只有 36 张，直接平均会引入偏差）
            total_loss += loss.item() * xb.size(0)
            correct += (out.argmax(1) == yb).sum().item()
            total += xb.size(0)

    return total_loss / total, correct / total


# ---------- 4. 训练 10 轮 ----------
history = {'train_loss': [], 'val_loss': [], 'train_acc': [], 'val_acc': []}

for epoch in range(10):
    tr_loss, tr_acc = run_epoch(model, train_loader, train=True)
    va_loss, va_acc = run_epoch(model, val_loader,   train=False)

    history['train_loss'].append(tr_loss)
    history['val_loss'].append(va_loss)
    history['train_acc'].append(tr_acc)
    history['val_acc'].append(va_acc)

    print(f"Epoch {epoch+1:2d}  "
          f"train loss={tr_loss:.4f} acc={tr_acc:.4f} | "
          f"val loss={va_loss:.4f} acc={va_acc:.4f}")


# ---------- 5. 测试集：只跑这一次 ----------
# 测试集是"高考"，跑两次以上，报告的指标就虚高了
model.eval()
y_true, y_pred, y_prob = [], [], []

with torch.no_grad():
    for xb, yb in test_loader:
        xb = xb.to(device)
        logits = model(xb)
        prob = torch.softmax(logits, dim=1)[:, 1]   # 取"肺炎"那一列概率，AUC 要用
        y_prob.extend(prob.cpu().numpy())
        y_pred.extend(logits.argmax(1).cpu().numpy())
        y_true.extend(yb.squeeze().long().numpy())

y_true = np.array(y_true)
y_pred = np.array(y_pred)
y_prob = np.array(y_prob)

cm = confusion_matrix(y_true, y_pred)
tn, fp, fn, tp = cm.ravel()                     # 顺序固定：TN, FP, FN, TP

acc  = accuracy_score(y_true, y_pred)           # (TP+TN)/总数
rec  = recall_score(y_true, y_pred)             # TP/(TP+FN) 病人里抓到几个
prec = precision_score(y_true, y_pred)          # TP/(TP+FP) 判成肺炎的里有几个真病
spec = tn / (tn + fp)                           # TN/(TN+FP) 健康人里判对几个
f1   = f1_score(y_true, y_pred)                 # 2PR/(P+R)
aucc = roc_auc_score(y_true, y_prob)            # ROC 曲线下面积，与阈值无关

print("\n===== 测试集（10 轮，阈值 0.5）=====")
print(f"混淆矩阵:\n{cm}")
print(f"  TN={tn}  FP={fp}")
print(f"  FN={fn}  TP={tp}")
print(f"准确率 Accuracy     : {acc:.4f}")
print(f"召回率 Recall       : {rec:.4f}")
print(f"精确率 Precision    : {prec:.4f}")
print(f"特异度 Specificity  : {spec:.4f}")
print(f"F1                  : {f1:.4f}")
print(f"AUC                 : {aucc:.4f}")

# 手算校验：每个数都能自己对上，才算真懂
print("\n===== 手算校验 =====")
print(f"准确率 = (TN+TP)/总数 = ({tn}+{tp})/{len(y_true)} = {(tn+tp)/len(y_true):.4f}")
print(f"召回率 = TP/(TP+FN)   = {tp}/({tp}+{fn}) = {tp/(tp+fn):.4f}")
print(f"精确率 = TP/(TP+FP)   = {tp}/({tp}+{fp}) = {tp/(tp+fp):.4f}")
print(f"特异度 = TN/(TN+FP)   = {tn}/({tn}+{fp}) = {tn/(tn+fp):.4f}")

# ---------- 6. 图 ----------
fig, axes = plt.subplots(1, 3, figsize=(16, 4))

axes[0].plot(history['train_loss'], label='训练', marker='o', ms=4)
axes[0].plot(history['val_loss'],   label='验证', marker='s', ms=4)
axes[0].set_xlabel('Epoch'); axes[0].set_ylabel('Loss')
axes[0].set_title('损失曲线'); axes[0].legend(); axes[0].grid(alpha=0.3)

axes[1].plot(history['train_acc'], label='训练', marker='o', ms=4)
axes[1].plot(history['val_acc'],   label='验证', marker='s', ms=4)
axes[1].set_xlabel('Epoch'); axes[1].set_ylabel('准确率')
axes[1].set_title('准确率曲线'); axes[1].legend(); axes[1].grid(alpha=0.3)

fpr, tpr, _ = roc_curve(y_true, y_prob)
axes[2].plot(fpr, tpr, linewidth=2, label=f'AUC = {aucc:.4f}')
axes[2].plot([0, 1], [0, 1], 'k--', label='随机猜测')
axes[2].set_xlabel('假阳性率 FPR'); axes[2].set_ylabel('真阳性率 TPR')
axes[2].set_title('ROC 曲线'); axes[2].legend(); axes[2].grid(alpha=0.3)

plt.tight_layout()
plt.show()

# 混淆矩阵热图
fig, ax = plt.subplots(figsize=(4, 4))
ax.imshow(cm, cmap='Blues')
for i in range(2):
    for j in range(2):
        ax.text(j, i, cm[i, j], ha='center', va='center',
                color='white' if cm[i, j] > cm.max() / 2 else 'black', fontsize=14)
ax.set_xticks([0, 1]); ax.set_xticklabels(['预测 normal', '预测 pneumonia'])
ax.set_yticks([0, 1]); ax.set_yticklabels(['真实 normal', '真实 pneumonia'])
ax.set_title('混淆矩阵')
plt.tight_layout()
plt.show()
```


**注意**：`n_classes` 必须跟着 `info` 走，硬编码 2 或 10 会报错。

**多分类下怎么读 recall**：`classification_report` 会输出每个类别的 recall。**要看的是"最差的那个类"**——如果某个器官的 recall 只有 0.5，说明模型基本学不会它，需要针对性地看数据。

## 练习 4-2-C

**消融实验表格**（示例，你的数字会不同）：

| 配置 | 验证准确率 | 训练准确率 | 差距（过拟合程度） |
|---|---|---|---|
| 基线 | 0.8814 | 0.9437 | 0.0623 |
| +Dropout(0.3) | 0.8902 | 0.9211 | 0.0309 |
| +数据增强 | 0.9067 | 0.9145 | 0.0078 |
| +两者都有 | 0.9103 | 0.9182 | 0.0079 |

**解读**：
- Dropout 和增强都让训练准确率下降、验证准确率上升
- **"训练准确率下降"是好现象**——说明不再死记硬背了
- 差距（过拟合程度）明显缩小

**这就是消融实验的价值**：不只是报个数字，而是**证明每个组件的贡献**。

## 练习 4-2-D

```python
threshold = 0.3      # 原来是 0.5
preds = (all_probs[:, 1] >= threshold).astype(int)
```

**典型变化**（以肺炎为正类）：

| 阈值 | 召回率 | 精确率 |
|---|---|---|
| 0.5 | 0.82 | 0.85 |
| 0.3 | 0.91 | 0.72 |
| 0.2 | 0.95 | 0.61 |

**医疗早筛选 0.3 或更低**。理由：

- 漏诊一个肺炎患者（没识别出来，放回家）→ 可能延误治疗
- 误报一个健康人（提示可能有肺炎）→ 医生再看一眼，做个确诊检查

代价严重不对称。**这就是"宁可错报，不可漏报"的工程实现。**

但要说明的是：**这个阈值不是随意定的，应该和临床医生一起确定**（比如"我们能接受的最大漏诊率是多少"），然后反推阈值。

## 练习 4-2-E

```python
majority = np.bincount(all_labels).argmax()
baseline_pred = np.full_like(all_labels, majority)
baseline_acc = (baseline_pred == all_labels).mean()
print(f"多数类基线准确率: {baseline_acc:.4f}")
```

**典型结果**：肺炎数据集正负比约 3:1，所以基线约 0.74。

你的模型 0.88，比基线高 14 个百分点。**这个提升是有意义的。**

**但如果只提升 2%**：这取决于情境：

- 如果基线是 74%，提升到 76% —— **基本没有临床价值**，可能只是噪声
- 如果基线是 95%，提升到 97% —— **可能非常有价值**，因为越往上越难，而且临床收益可能是非线性的

**关键是报告基线。** 一篇医学 AI 论文不报基线，审稿人会直接问"你比瞎猜好多少"。

## 练习 4-2-F

报告模板见 4-2 讲义第六节。**这份报告要满足三个标准：**

1. **可复现**：别人按你写的配置能跑出同样结果（写清随机种子、超参数、环境）
2. **可解释**：不只是数字，要说清"为什么这么做"和"结果意味着什么"
3. **诚实**：局限要写清楚。没做外部验证就说没做，样本少就说样本少

**医学 AI 报告和普通 ML 报告最大的区别在"局限"这一节。** 临床合作者最关心的恰恰是"这个模型在什么情况下不能用"。

## 自测题答案

1. 明确问题 → 找数据 → 数据探索 EDA → 预处理 → 划分 → 建模训练 → 评估与报告
2. 用来调超参数和选模型，避免污染测试集。没有验证集，你就无法知道"什么时候该停止训练"。
3. AUC、灵敏度（召回率）、特异度、PPV、F1，还要看混淆矩阵和每个类别的表现。
4. 因为整体指标会掩盖系统性错误。错误分析能发现"模型在某类病人上总是错"这种致命问题，也能指导下一步改进。
5. 因为报告局限意味着你知道模型的适用边界。医学应用里，"什么时候不能用"比"平均表现如何"更重要。
