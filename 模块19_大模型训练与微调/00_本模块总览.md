## 〇、先说实话

**这一块是三个模块里最难拿的，我建议你把它排在最后。**

**理由不是「不重要」，是「性价比」。**

### 你面对的现实

| 项 | 你的情况 |
|---|---|
| 显存 | **8 GB**（RTX 5060 Laptop） |
| 全量微调 7B 需要 | 60 GB+ |
| LoRA 微调 7B 需要 | 约 16 GB（用 QLoRA 能压到 8 GB，但 Windows 上 bitsandbytes 装不上） |
| **你能做的** | **LoRA 微调 1.5B-3B 模型** |

**这不是你的问题，是硬件限制。实验室的服务器、租的云卡都能解决，但你得先有那个条件。**

### JD3 的加分项你很难满足

```
❌ 顶会论文（ACL / EMNLP / NeurIPS ...）
❌ 心理学 / 医学交叉背景（你有医学，但那份 JD 是心理多模态）
❌ 完整 RLHF 实验经历
✅ 你有的：医学影像背景 + Agent 工程能力
```

**所以策略是：这块「学懂原理 + 做一个能讲清楚的 LoRA 微调」，不追求做完整条流水线。**

## 三、毕业项目：医学问答模型微调

```
基座模型：Qwen3-1.7B（或 Qwen2.5-1.5B）
数据：从指南和题库整理 1000 条「问题-答案」对
方法：LoRA 微调
评估：BLEU / ROUGE / 人工评分 / 对比基座
部署：合并 LoRA + GGUF 量化，用 Ollama 跑起来
```

**为什么选 1.7B：**

| 参数量 | 8 GB 显存能 LoRA 吗 |
|---|---|
| 0.6B | ✅ 轻松 |
| **1.7B** | ✅ **推荐** |
| 3B | ✅ 可以（batch 1） |
| 7B | ❌ fp16 不够，要 QLoRA（Windows 有坑） |

**规模小，但流程完整。** 面试时讲「我用 8 GB 显存完成了 LoRA 微调全流程」，比「我调了个 API」有说服力得多。


**没有模块 16 直接学 19，会很吃力。** 因为 19 里到处都是「你已经在 16 里见过」的东西。

## 五、硬件约束（必须看）

**你的机器：RTX 5060 Laptop，8 GB 显存，32 GB 内存。**

### 能不能做，一张表说清

| 任务 | 8 GB 能做吗 | 说明 |
|---|---|---|
| 加载 1.7B 模型（fp16） | ✅ | 约 3.4 GB |
| LoRA 微调 1.7B | ✅ | 约 5-6 GB |
| 加载 7B 模型（fp16） | ⚠️ 勉强 | 约 14 GB，超出 |
| 加载 7B（int4 量化） | ✅ | 约 4 GB |
| QLoRA 微调 7B | ⚠️ | 要 bitsandbytes，**Windows 支持差** |
| DPO 训练 1.7B | ⚠️ | 要同时装两个模型，显存翻倍 |
| 推理（GGUF 量化） | ✅ | CPU 都能跑 |

### 两个 Windows 特有的坑

**坑一：`bitsandbytes`**

**它是 4bit 量化和 QLoRA 的核心。在 Windows 上：**

- 官方 wheel 长期只发 Linux
- 第三方 Windows 版质量参差
- 装上了也可能在运行时崩

**应对：先用 fp16 的 LoRA（不量化），1.7B 完全够。**

**坑二：`flash-attention`**

**加速注意力的核心库，Windows 上基本装不成功。**

**应对：用 PyTorch 原生的 `scaled_dot_product_attention`，效果接近。**

## 七、学习方式

**这个模块和前四个都不一样：它「贵」。**

**跑一次微调，即使 1.7B，也要 30 分钟到 2 小时。** 不要像 16 那样随便试。

### 三条纪律

**① 先用 100 条数据跑通全流程，再用全量**

```
第一步：100 条 × 1 epoch，20 分钟  → 验证代码对了
第二步：1000 条 × 3 epoch，2 小时  → 正式实验
```

**直接上全量，出了错就是两小时的浪费。**

**② 每次实验必须记录配置**

```yaml
base_model: Qwen/Qwen3-1.7B
method: lora
lora_r: 16
lora_alpha: 32
lr: 2e-4
batch_size: 4
grad_accum: 4
epochs: 3
max_length: 1024
```

**不记配置，跑出来的模型没法复现。**

**③ 先跑 baseline，再跑微调**

**不跑 baseline，你不知道微调到底有没有用。**

**baseline 就是「原始模型 + 同样的提示词」。**
