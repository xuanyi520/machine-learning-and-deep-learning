**先别高兴。真实临床数据几乎不可能零缺失。** 继续往下查。

**四个警报一起响了。**

### 1.3 警报一：有些列被"离散化"了

`HGB`（血红蛋白）只有 **6** 个不同取值，`BMI` 只有 **14** 个，`Age` 只有 **30** 个。

真实的血红蛋白是连续测量的，通常有一位小数，几百个不同值。

**只有 6 个值，说明这份数据已经被分过箱了**（比如把 10-15 分成 6 档）。

**分箱过的数据有两个后果：**

- 丢失了精度，模型学不到细微差别
- 如果你再去做"分箱"这个特征工程，等于对已经分好的箱再分一次

### 1.4 警报二：两个应该相关的指标，完全不相关

临床上 **AST 和 ALT 是同源的**——都是肝细胞里的酶，肝受损时一起升高。正常数据里两者的相关系数通常 **0.6 以上**。

```python
print(df['AST_1'].corr(df['ALT_1']))
```

**真实输出：**

```
0.038
```

**0.038 ≈ 无关。**

而且两列的取值集合**完全相同**（都是 39~128 的 90 个整数）——像是从同一个池子里随机抽出来填进去的。

**这说明数据的生成过程和真实临床没关系。**

### 1.5 警报三：单位不对

```
WBC    2991 ~ 12101      正常应该是 4-10 (×10⁹/L)
RBC    3816422 ~ 5018451  正常应该是 4-5.5 (×10¹²/L)
Plat   93013 ~ 226464     正常应该是 100-300 (×10⁹/L)
```

**数值大了 1000 倍**，说明存的是"每微升多少个"而不是教科书单位。

**这不是错误**，但你必须知道，否则：

- 算 FIB-4 会全错（它要求血小板单位是 ×10⁹/L）
- 和文献对比会对不上
- 写论文时会被审稿人问

### 1.6 警报四：目标变量和其他所有变量都不相关

这是**最致命的一条**。

```python
from scipy.stats import spearmanr

y = df['Baselinehistological_staging']     # 肝纤维化分期 1-4

for c in ['Age', 'BMI', 'WBC', 'HGB', 'Plat', 'AST_1', 'ALT_1']:
    rho, p = spearmanr(df[c], y)
    print(f"{c:8s} rho={rho:+.3f}  p={p:.3f}")
```

**真实输出：**

```
Age      rho=-0.020  p=0.461
BMI      rho=-0.059  p=0.029
WBC      rho=+0.018  p=0.494
HGB      rho=+0.003  p=0.898
Plat     rho=-0.017  p=0.515
AST_1    rho=-0.026  p=0.343
ALT_1    rho=+0.038  p=0.159
```

**全部 |rho| < 0.06，全部不显著。**

而真实临床上，**血小板和纤维化分期是强负相关的**（纤维化越重，脾亢越厉害，血小板越低，rho 通常在 -0.3 到 -0.5）。

**结论：这份数据的标签和特征之间没有真实关系。**

### 1.7 这个发现改变了整个方案

**如果你不知道这件事，会发生什么：**

```
你花 3 天做特征工程 → 训练 → AUC 0.51
你以为是自己做错了 → 反复调参 → 还是 0.51
最后怀疑自己不适合做 AI
```

**而真相是：数据本身没有信号，任何模型都学不出来。**

**所以这一节改用 Hepatitis 做主案例，HCV 作为"如何识别废数据"的反面教材。**

| 用哪个数据 | 做什么 |
|---|---|
| **HCV** | 演示"怎么发现数据有问题" |
| **Hepatitis** | 演示完整的清洗 → 建模流程 |

### 1.8 怎么快速判断一份数据有没有信号

**三步，十分钟内能做完：**

```python
def quick_signal_check(df, target, exclude=()):
    """快速筛查数据里有没有信号。"""
    from scipy.stats import spearmanr

    print(f"目标: {target}")
    print(df[target].value_counts().sort_index().to_string())

    print("\n=== 与目标的秩相关 ===")
    rows = []
    for c in df.select_dtypes('number').columns:
        if c == target or c in exclude:
            continue
        sub = df[[c, target]].dropna()
        if len(sub) < 30:
            continue
        rho, p = spearmanr(sub[c], sub[target])
        rows.append((c, rho, p))

    rows.sort(key=lambda x: -abs(x[1]))
    for c, rho, p in rows[:10]:
        flag = '  <-- 有信号' if abs(rho) > 0.15 and p < 0.05 else ''
        print(f"  {c:24s} rho={rho:+.3f}  p={p:.3f}{flag}")

    strong = [r for r in rows if abs(r[1]) > 0.15 and r[2] < 0.05]
    print(f"\n结论: {len(strong)} 个特征有显著相关")
    if len(strong) == 0:
        print("  警告: 几乎没有信号，先别建模，回去查数据来源")
```

**用法：**

```python
hc = pd.read_csv(r'E:\AI学习\练习代码\data\uci\HCV_Egyptian.csv')
quick_signal_check(hc, 'Baselinehistological staging')
```

**跑 HCV 会看到"0 个特征有显著相关"。跑 Hepatitis 会看到 Age、Albumin、Protime 等好几个。**

## 二、缺失值

### 2.1 换成真正有缺失的数据

```python
h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])

print(h.shape)                 # (155, 20)
print(h.isna().sum().sum())    # 167
```

**`na_values=['?']` 是关键。**

不加这个参数，pandas 会把 `?` 当成普通字符串，`isna()` 全返回 0——你就以为数据是干净的。

### 2.2 真实缺失分布

```python
na_pct = (h.isna().sum() / len(h) * 100).round(1)
print(na_pct[na_pct > 0].sort_values(ascending=False).to_string())
```

**真实输出：**

```
Protime            43.2
Alk Phosphate      18.7
Albumin            10.3
Liver Firm          7.1
Liver Big           6.5
Bilirubin           3.9
Spleen Palpable     3.2
Varices             3.2
Ascites             3.2
Spiders             3.2
Sgot                2.6
Anorexia            0.6
Steroid             0.6
Fatigue             0.6
Malaise             0.6
```

**三个观察：**

**① 缺失率从 0.6% 到 43.2%，跨了两个数量级。**

**② Protime（凝血酶原时间）缺了四成。**

这是最贵的检查之一，不是每个病人都做。

**③ 缺失率和检查成本相关：**

| 类型 | 缺失率 | 为什么 |
|---|---|---|
| 症状（Fatigue、Malaise） | 0.6% | 问一句就有 |
| 体征（Liver Big、Spiders） | 3-7% | 查体可得 |
| 化验（Albumin、Bilirubin） | 4-10% | 要抽血花钱 |
| **特殊化验（Protime）** | **43.2%** | **贵、不是常规** |

**这个规律本身就是信息——它告诉你缺失不是随机的。**

### 2.3 三种缺失机制

| 类型 | 含义 | 例子 | 能插补吗 |
|---|---|---|---|
| **MCAR** | 完全随机缺失 | 试管打碎了 | 能 |
| **MAR** | 缺失与其他**已观测**变量有关 | 检查做得少的病人更少查 Protime | 能（用其他列预测） |
| **MNAR** | 缺失与**这个值本身**有关 | 病情重的病人反而做不了某项检查 | **不能，会引入偏倚** |

### 2.4 用真实数据判断：缺失本身带不带信息

**这一步是本节的精髓。**

```python
# 对每一列，比较"缺失组"和"非缺失组"的死亡率
for c in ['Bilirubin', 'Alk Phosphate', 'Sgot', 'Albumin', 'Protime']:
    g = h.groupby(h[c].isna())['Class'].apply(lambda s: (s == 1).mean())
    miss = g.get(True, np.nan)
    keep = g.get(False, np.nan)
    print(f"{c:14s} 缺失组死亡率 {miss:.2f}   非缺失组 {keep:.2f}")
```

**真实输出：**

```
Bilirubin      缺失组死亡率 0.33   非缺失组 0.20
Alk Phosphate  缺失组死亡率 0.28   非缺失组 0.19
Sgot           缺失组死亡率 0.50   非缺失组 0.20
Albumin        缺失组死亡率 0.31   非缺失组 0.19
Protime        缺失组死亡率 0.21   非缺失组 0.20
```

**看 Sgot 那一行：缺失的人死亡率 50%，没缺失的 20%。差 2.5 倍。**

**这说明"没测 Sgot"本身就是一个强风险信号。**

**所以"补成中位数"会把这个信息永久丢掉。** 标准做法是加一列：

```python
h['Sgot_缺失'] = h['Sgot'].isna().astype(int)
```

**但——先别急着当成万灵药。**

我在这份数据上做了对照实验（见 7.2），结果是：**加了缺失指示列，AUC 反而从 0.831 掉到 0.815。**

原因：只有 155 个样本，一下子多 6 列，噪声压过了信号。

**正确结论：**

> **缺失是否带信息，要单独验证（像上面那样分组看死亡率）。**
> **但"加不加指示列"，必须用交叉验证决定，不能凭原则。**

小样本时，多一列特征可能比它带来的信息更伤。

### 2.5 六种处理方法

| 方法 | 代码 | 什么时候用 | 代价 |
|---|---|---|---|
| **① 删行** | `df.dropna()` | 缺失 < 5% 且 MCAR | 样本变少 |
| **② 均值/中位数** | `df.fillna(df.median())` | 快速基线 | 方差被压缩 |
| **③ 众数** | `df.fillna(df.mode()[0])` | 类别变量 | 丢失缺失信息 |
| **④ 加指示列** | `df['x_缺失'] = df['x'].isna()` | **医学强烈推荐** | 多一列 |
| **⑤ KNN 插补** | `KNNImputer(n_neighbors=5)` | 特征相关强 | 慢，高维失效 |
| **⑥ 多重插补** | `IterativeImputer()` | 严谨研究 | 复杂，要报告插补前后对比 |

**标准写法（④ + ②）：**

```python
def impute_with_flag(df, cols):
    """中位数插补 + 保留缺失指示列。"""
    out = df.copy()
    for c in cols:
        out[f'{c}_缺失'] = out[c].isna().astype(int)
        out[c] = out[c].fillna(out[c].median())
    return out

cols = ['Bilirubin', 'Alk Phosphate', 'Sgot', 'Albumin', 'Protime']
h2 = impute_with_flag(h, cols)
print(h2[['Sgot', 'Sgot_缺失']].head())
```

### 2.6 直接 `dropna()` 会损失多少

```python
print(f"原始:            {len(h)} 行")
print(f"全列 dropna 后:  {len(h.dropna())} 行")
print(f"只留 6 个数值列: {len(h.dropna(subset=['Age','Bilirubin','Alk Phosphate','Sgot','Albumin','Protime']))} 行")
```

**真实输出：**

```
原始:            155 行
全列 dropna 后:  80 行     ← 少了一半
只留 6 个数值列:  80 行
```

**155 掉到 80，样本直接腰斩。**

而且删掉的 75 个人**不是随机删的**——是和"检查做得全不全"有关的，也就是和病情、经济条件、年代有关。**你等于系统性地删掉了一类病人。**

**所以：一上来 `df.dropna()` 是危险的。**

## 三、异常值

### 3.1 三种检测方法

**① 3σ 法（假设正态）**

```python
mean, std = df['ALT'].mean(), df['ALT'].std()
mask = (df['ALT'] - mean).abs() > 3 * std
```

**问题**：医学数据绝大多数是右偏的（ALT、胆红素、肿瘤标志物都是长尾）。用 3σ 在偏态数据上会误杀大量正常的高值。

**② IQR 法（不假设分布，更常用）**

```python
q1, q3 = df['ALT'].quantile([0.25, 0.75])
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
mask = (df['ALT'] < low) | (df['ALT'] > high)
```

**③ 孤立森林（多维）**

```python
from sklearn.ensemble import IsolationForest
iso = IsolationForest(contamination=0.05, random_state=0)
df['异常'] = iso.fit_predict(num_cols)
```

①② 只看单列，③ 能发现"组合上不正常"（比如 ALT 极高但 AST 正常，临床上少见）。

### 3.2 核心认知：异常 ≠ 错误

**这是医学数据处理最容易犯错的地方。**

| 值 | 判断 | 理由 | 处理 |
|---|---|---|---|
| 身高 250 cm | **错误** | 大概率把 175 打成 275 | 查原始记录，确认则改缺失 |
| 年龄 -5 岁 | **错误** | 不存在 | 同上 |
| 年龄 105 岁 | **真实** | 有百岁老人 | 保留 |
| **ALT 3000 U/L** | **真实** | **急性肝衰竭就是这样** | **绝对不能删** |
| AFP 50000 | **真实** | 晚期肝癌可以这么高 | 保留 |
| 血小板 5 | **真实** | 肝硬化脾亢可以这么低 | 保留 |

**用 IQR 法无脑删"异常值"，你会删掉全部危重病人——模型学到一个"病人都不重"的假世界。**

### 3.3 正确处理流程

```
发现异常值
    │
    ├─ 这个值在医学上可能吗？
    │      │
    │      ├─ 不可能（-5 岁、250cm）→ 查原始记录
    │      │        ├─ 确认是录入错误 → 改正
    │      │        └─ 无法确认 → 标为缺失
    │      │
    │      └─ 可能（ALT 3000）→ 保留！
    │               │
    │               └─ 会干扰模型吗？
    │                      ├─ 树模型 → 不怕，不用管
    │                      └─ 线性/神经网络 → RobustScaler 或 log 变换
```

**关键：处理方式取决于用什么模型。**

| 模型 | 对异常值敏感度 | 对策 |
|---|---|---|
| 决策树 / 随机森林 / XGBoost | **不敏感**（只看排序不看距离） | 不用处理 |
| 逻辑回归 / SVM / KNN | 敏感 | RobustScaler、log 变换 |
| 神经网络 | 敏感 | 同上 |

### 3.4 必写代码：判断"错误 vs 真实极端值"

```python
def judge_outlier(field, value):
    """给一个异常值，返回判断和理由。"""
    plausible = {
        '年龄':   (0, 110),
        'BMI':    (10, 70),
        'ALT':    (0, 20000),      # 急性肝衰竭可以上万
        'AST':    (0, 20000),
        '胆红素':  (0, 800),
        '血小板':  (1, 1000),       # 单位 10^9/L
        '白蛋白':  (5, 60),
    }
    if field not in plausible:
        return '未知字段，需人工判断'
    lo, hi = plausible[field]
    if value < lo or value > hi:
        return f'不可能（超出 {lo}-{hi}）→ 查原始记录'
    return f'可能（在 {lo}-{hi} 内）→ 保留'
```

### 3.5 必做实验：删异常值的代价

```python
# 在 Hepatitis 上做：用 IQR 删掉胆红素的高值，看死亡率怎么变
q1, q3 = h['Bilirubin'].quantile([0.25, 0.75])
iqr = q3 - q1
high = q3 + 1.5 * iqr
out = h['Bilirubin'] > high

print(f"被判为异常: {out.sum()} 人")
print(f"异常组死亡率: {h[out]['Class'].eq(1).mean():.2f}")
print(f"正常组死亡率: {h[~out]['Class'].eq(1).mean():.2f}")
```

**你会看到异常组的死亡率明显更高。**

**结论：这些"异常值"恰恰是最重的病人。删掉他们 = 删掉模型最需要的信号。**

## 四、特征工程

### 4.1 编码：类别变量怎么变数字

**① 无序类别 → one-hot**

```python
pd.get_dummies(df, columns=['血型'])
```

`drop_first` 默认用 `False`。设成 `True` 能少一列、避免共线性（对线性模型有用），但会丢失可解释性。

**② 有序类别 → ordinal（保持顺序）**

```python
# 肝纤维化分期 1-4，顺序有意义
df['分期'] = df['Baselinehistological_staging']    # 1/2/3/4 直接用
```

**这里有个大坑：**

```python
# 错误做法
pd.get_dummies(df, columns=['分期'])
```

**为什么错**：one-hot 之后，"1 期"到"2 期"的距离，等于"1 期"到"4 期"的距离。但临床上 1 期和 2 期相邻，1 期和 4 期是天壤之别。**顺序信息丢了。**

**③ 高基数类别 → target encoding，必须做交叉验证**

这条到模块 9 细讲。先记住结论：**高基数编码是泄露重灾区。**

### 4.2 缩放：什么时候需要

| 方法 | 公式 | 适用 | 不适用 |
|---|---|---|---|
| StandardScaler | (x - 均值) / 标准差 | 近似正态 | 有强离群点 |
| MinMaxScaler | (x - 最小) / (最大 - 最小) | 有明确上下界 | 有离群点（被极值拉扁） |
| **RobustScaler** | (x - 中位数) / IQR | **有离群点（医学常见）** | — |

**关键判断：**

| 模型 | 需不需要缩放 |
|---|---|
| 决策树 / 随机森林 / XGBoost / LightGBM | **不需要** |
| 逻辑回归 / SVM / KNN / 神经网络 | **需要** |
| PCA / K-means | **必须** |

**为什么树模型不需要**：它只比较"这个值是不是大于某个阈值"，不比较距离。把 ALT 从 80 缩放到 0.3，分裂点跟着变，结果完全一样。

### 4.3 分箱：用临床阈值，不用等宽

```python
# 差的做法
pd.cut(df['AST'], bins=5)

# 好的做法
pd.cut(df['AST'], bins=[0, 40, 80, 200, np.inf],
       labels=['正常', '轻度升高', '中度升高', '显著升高'])
```

**阈值来源：**

| 指标 | 临床阈值 | 依据 |
|---|---|---|
| ALT / AST | 40 U/L | 常用参考上限 |
| 胆红素 | 17.1 / 34.2 / 171 μmol/L | 黄疸分级 |
| 白蛋白 | 35 g/L | 低蛋白血症界值 |
| AFP | 7 / 20 / 400 ng/mL | 参考上限 / 可疑 / 肝癌诊断线 |
| 血小板 | 100 × 10⁹/L | 脾亢与出血风险 |

**为什么用临床阈值：**

> 等宽分箱在数学上均匀，但**临床上没意义**。
> 医生说"ALT 轻度升高"指的是 40-80 这一段，不是你算法随机切出来的 39.6-57.2。

### 4.4 交互项：领域公式

```python
# ① BMI
df['BMI'] = df['体重kg'] / (df['身高m'] ** 2)

# ② De Ritis 比值（AST/ALT）
df['DeRitis'] = df['AST'] / df['ALT']
# 临床：<1 提示病毒性肝炎，>2 提示酒精性肝病

# ③ FIB-4 指数（无创肝纤维化评估）
# 公式：(年龄 × AST) / (血小板 × sqrt(ALT))
# 注意：血小板单位必须是 10^9/L
df['FIB4'] = (df['Age'] * df['AST']) / ((df['Plat'] / 1000) * np.sqrt(df['ALT']))
```

**注意 `Plat / 1000`**——HCV 数据里血小板存的是"每微升"，除以 1000 才是 ×10⁹/L。**单位错一步，整个指标全废。**

### 4.5 反例：领域特征也必须验证

**这是本节最值钱的一课。**

我在 HCV 数据上算了 FIB-4，结果：

```python
fib4 = (df['Age'] * df['AST_1']) / ((df['Plat'] / 1000) * np.sqrt(df['ALT_1']))
df.assign(FIB4=fib4).groupby('Baselinehistological_staging')['FIB4'].mean()
```

**真实输出：**

```
分期
1    2.98
2    2.92
3    2.99
4    2.85
```

**完全平坦。分期越重，FIB-4 不升反降。**

**但临床文献里 FIB-4 和纤维化分期是强正相关的。**

**矛盾说明什么：** 不是公式错了，是**这份数据本身没有临床信号**（前面 1.6 已经证明了）。

**所以：**

> **加领域特征之后，必须验证它有没有用。**
> **不能因为"文献说有用"就直接写进论文。**

**验证方法：**

```python
# 加特征前后各跑一次交叉验证，比 AUC
auc_without = cross_val_score(pipe_base, X, y, cv=5, scoring='roc_auc').mean()
auc_with    = cross_val_score(pipe_full, X, y, cv=5, scoring='roc_auc').mean()
print(f"加特征前 {auc_without:.3f} → 加特征后 {auc_with:.3f}")
```

**如果没提升，就删掉。** 说不清为什么的增益，多半是噪声或泄露。

### 4.6 特征不是越多越好

**三个原则：**

**① 每个新特征要能说出临床意义。** 说不出，要么是噪声，要么是泄露。

**② 加完必须验证。** 不能只看"我觉得有用"。

**③ 特征数要控制。** 155 个样本，特征超过 15 个就很危险。**经验法则：每 10-20 个样本支持 1 个特征。**

## 五、数据泄露（本节最重要）

### 5.1 定义

> **测试集的任何信息，以任何形式进入了训练过程。**

**"任何形式"** 不只是标签，还包括均值、方差、分布、特征选择结果。

### 5.2 五个经典现场

#### 现场 1：先标准化，再划分

```python
# 错误
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)           # 用了全部数据的均值方差
X_train, X_test = train_test_split(X_scaled)

# 正确
X_train, X_test = train_test_split(X)
scaler.fit(X_train)                           # 只学训练集
X_train = scaler.transform(X_train)
X_test  = scaler.transform(X_test)            # 用训练集的参数
```

**泄露了什么**：测试集的均值、方差。

#### 现场 2：先选特征，再划分

```python
# 错误
X_sel = SelectKBest(k=20).fit_transform(X, y)   # 用了全部标签选特征
X_train, X_test = train_test_split(X_sel)
```

**泄露了什么**：测试集标签参与了"哪些特征重要"的判断。

#### 现场 3：同一病人出现在训练和测试（医学最常见）

```python
# 错误
train_test_split(X, y, test_size=0.2, random_state=0)

# 正确
from sklearn.model_selection import GroupShuffleSplit
gss = GroupShuffleSplit(n_splits=1, test_size=0.2, random_state=0)
train_idx, test_idx = next(gss.split(X, y, groups=df['病人ID']))
```

**为什么医学必须按病人分：**

一个病人做 3 次 CT，如果第 1 次在训练集、第 3 次在测试集，**模型训练时已经见过这个病人的解剖结构**。测试集不再是"没见过的新病人"。

**这就是"内部 AUC 0.95、外部验证掉到 0.75"的根源。**

#### 现场 4：时间泄露

```python
# 错误：随机划分时间序列
train_test_split(df, random_state=0)

# 正确：按时间切
train = df[df['检查日期'] < '2023-01-01']
test  = df[df['检查日期'] >= '2023-01-01']
```

#### 现场 5：标签泄露（用结局之后的信息做特征）

```python
# 错误：预测"是否死亡"，却用了"是否做抢救"（抢救发生在死亡前后）
# 错误：预测"是否肝癌"，却用了"是否做肝切除"（能手术的本来就是早期）
```

**判断方法：这个特征在"预测时点"能拿到吗？**

### 5.3 标准写法：Pipeline 全包

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score

pipe = Pipeline([
    ('impute', SimpleImputer(strategy='median')),
    ('scale',  StandardScaler()),
    ('clf',    LogisticRegression(max_iter=2000)),
])

scores = cross_val_score(pipe, X, y, cv=5, scoring='roc_auc')
```

**为什么 Pipeline 能防泄露：**

```
外层交叉验证切出 train/val
    ↓
pipe.fit(X_train)      ← impute 和 scale 只在 X_train 上 fit
    ↓
pipe.score(X_val)      ← 用训练集的参数 transform X_val
```

**手动做预处理再传给 cross_val_score，就泄露了。**

### 5.4 自查清单

```
□ 预处理是在划分之后做的吗？
□ scaler / imputer / encoder 只在训练集 fit 吗？
□ 用了 Pipeline 吗？
□ 特征选择是在训练折内部做的吗？
□ 同一病人是否只出现在一个折里？
□ 时间顺序是否正确？
□ 有没有用到"预测时点拿不到"的特征？
```

**七条全过，才能相信你的指标。**

## 六、类别不平衡

### 6.1 先看真实的不平衡

```python
h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
print(h['Class'].value_counts())
```

**真实输出：**

```
2    123    存活
1     32    死亡
```

**死亡率 32/155 = 20.6%。**

**"全猜存活"的基线准确率 = 79.4%。**

> 一个什么都没学的模型，准确率就有 79.4%。

### 6.2 四种手段，按这个顺序试

```
第一步：调阈值          ← 最简单，不动训练
第二步：加权损失        ← class_weight='balanced'
第三步：重采样          ← 过采样 / 欠采样
第四步：SMOTE          ← 最后才用
```

**为什么是这个顺序：**

| 手段 | 侵入性 | 可逆性 |
|---|---|---|
| 调阈值 | 最低（不动训练） | 完全可逆 |
| 加权损失 | 低（只改损失） | 可逆 |
| 重采样 | 中（改训练分布） | 需重训 |
| SMOTE | **最高（编造样本）** | 需重训，引入不真实数据 |

**先试侵入性最低的。**

### 6.3 代码

**① 调阈值**

```python
proba = model.predict_proba(X_test)[:, 1]
pred = (proba >= 0.3).astype(int)      # 不用默认 0.5
```

**② 加权**

```python
model = LogisticRegression(class_weight='balanced', max_iter=2000)
```

**③ 重采样**

```python
from imblearn.over_sampling import RandomOverSampler
ros = RandomOverSampler(random_state=0)
X_train_res, y_train_res = ros.fit_resample(X_train, y_train)   # 只能对训练集
```

**④ SMOTE**

```python
from imblearn.over_sampling import SMOTE
smote = SMOTE(random_state=0)
X_train_res, y_train_res = smote.fit_resample(X_train, y_train)  # 只能对训练集
```

### 6.4 SMOTE 的三个危险

**原理**：对每个少数类样本，在它和最近的 k 个少数类邻居之间随机插值造新样本。

| 危险 | 说明 |
|---|---|
| **① 只能对训练集做** | 在测试集上做，指标虚高到失真 |
| **② 在边界造出"不存在的病人"** | 插值出的化验组合临床上可能根本不可能 |
| **③ 高维下失效** | 维度越高，"最近的邻居"越不近 |

**必做实验：SMOTE 用在测试集上会怎样**

```python
# 错误示范（只为看效果）
smote = SMOTE(random_state=0)
X_all, y_all = smote.fit_resample(X_all, y_all)      # ← 全量！错误
Xtr, Xte, ytr, yte = train_test_split(X_all, y_all, test_size=0.2)
```

**AUC 会接近 1.0——因为同一个样本的插值版本同时出现在训练和测试里。**

### 6.5 医学场景的特殊考虑

**先问：这个不平衡是真的吗？**

| 情况 | 例子 | 怎么办 |
|---|---|---|
| 真实患病率低 | 普通人群肝癌 0.05% | 不处理，但**必须报告 PPV 会很低** |
| 数据收集偏差 | 只收集了住院病人 | **重新采样，不是算法处理** |
| 标签定义问题 | "高危"标准太严 | 重新讨论标签 |

**最重要的一条：**

> **不要在算法层面掩盖数据收集的偏差。**
> 如果你为了平衡把 1 万健康人欠采样到 100 个，你得到的是"患病率 50%"的假世界。
> 拿它去真实人群用，PPV 会崩到个位数。

## 七、实战：走完整条流水线

**目标**：用 Hepatitis 预测住院死亡（32 死 / 123 活），从原始 CSV 到可评估的模型。

### 7.1 完整代码

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import make_scorer, confusion_matrix

# ---------- ① 读入（注意 na_values）----------
h = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
h.columns = h.columns.str.strip().str.replace(' ', '_')

# ---------- ② 目标 ----------
y = (h['Class'] == 1).astype(int)        # 1 = 死亡
print(f"样本 {len(h)}，死亡 {y.sum()}，死亡率 {y.mean():.1%}")

# ---------- ③ 特征 ----------
num_cols = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
X = h[num_cols].copy()

# ---------- ④ 特异度打分器（sklearn 没有内置）----------
def specificity(y_true, y_pred):
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred, labels=[0, 1]).ravel()
    return tn / (tn + fp)

spec_scorer = make_scorer(specificity)

# ---------- ⑤ 建模（Pipeline 防泄露）----------
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)

pipe_lr = Pipeline([
    ('impute', SimpleImputer(strategy='median')),
    ('scale',  StandardScaler()),
    ('clf',    LogisticRegression(max_iter=2000, class_weight='balanced')),
])

pipe_rf = Pipeline([
    ('impute', SimpleImputer(strategy='median')),
    ('clf',    RandomForestClassifier(n_estimators=300, random_state=0,
                                      class_weight='balanced')),
])

for name, p in [('LogisticRegression', pipe_lr), ('RandomForest', pipe_rf)]:
    auc  = cross_val_score(p, X, y, cv=cv, scoring='roc_auc')
    rec  = cross_val_score(p, X, y, cv=cv, scoring='recall')
    spec = cross_val_score(p, X, y, cv=cv, scoring=spec_scorer)
    print(f"{name:18s} AUC={auc.mean():.3f}±{auc.std():.3f}  "
          f"召回={rec.mean():.3f}  特异度={spec.mean():.3f}")
```

**关键点：`scoring='specificity'` 会报错**——sklearn 没有内置这个 scorer，必须用 `make_scorer` 自己包一个。

**真实输出（本机实测）：**

```
LogisticRegression AUC=0.831±0.036  召回=0.810  特异度=0.773
RandomForest       AUC=0.825±0.058  召回=0.595  特异度=0.862
```

**注意随机森林召回只有 0.595**——它保守，宁可说"活着"。而逻辑回归召回 0.810。**在"漏诊代价高于误诊"的医学场景，这两个模型的取舍完全不同。**

### 7.2 对照实验：加特征到底有没有用

**这是本节最重要的一个实验。** 四组特征，同样的交叉验证：

```python
def compare_feature_sets(h, y, cv):
    base = h[num_cols].copy()

    flags = base.copy()
    for c in num_cols:
        flags[f'{c}_缺失'] = flags[c].isna().astype(int)

    ratio = base.copy()
    ratio['AST_ALP'] = h['Sgot'] / h['Alk_Phosphate']

    both = flags.copy()
    both['AST_ALP'] = h['Sgot'] / h['Alk_Phosphate']

    for name, X_ in [('① 6 个原始列', base), ('② +缺失指示列', flags),
                     ('③ +AST/ALP', ratio),       ('④ 全部', both)]:
        a = cross_val_score(pipe_lr, X_, y, cv=cv, scoring='roc_auc')
        print(f"{name:16s} {X_.shape[1]:2d} 列  AUC={a.mean():.3f}±{a.std():.3f}")
```

**真实输出（本机实测）：**

| 特征集 | 列数 | 逻辑回归 AUC | 随机森林 AUC |
|---|---|---|---|
| ① 6 个原始列 | 6 | **0.831 ± 0.036** | 0.825 ± 0.058 |
| ② + 6 个缺失指示列 | 12 | 0.815 ± 0.058 | 0.830 ± 0.052 |
| ③ + AST/ALP 比值 | 7 | 0.837 ± 0.037 | 0.821 ± 0.062 |
| ④ 全部 | 13 | 0.820 ± 0.058 | 0.833 ± 0.049 |

**看这张表能得出什么：**

**① 所有差异都在噪声里。**

最好的 0.837 和最差的 0.815 差 0.022，而标准差是 **0.036~0.058**。

> **差值小于标准差时，不能说 A 比 B 好。**

**② 加缺失指示列并没有提升，反而略降。**

前面 2.4 明明看到"Sgot 缺失组死亡率 50% vs 20%"，为什么加了没用？

因为：**155 个样本，加 6 列，过拟合的代价压过了信息量。**

**③ 加领域特征也没有明显提升。**

这是这份数据的局限，不是方法错。

### 7.3 这个实验真正教你的三件事

**第一，任何"改进"都必须用交叉验证验证。**

"加缺失指示列是医学必备"——这句话作为**原则**是对的，但作为**具体操作**，必须验证它在这份数据上有没有用。

**第二，小样本会吃掉大部分改进。**

155 例，12 列特征，已经接近上限（每 10-20 个样本支持 1 个特征）。

**第三，报告必须带标准差。**

`AUC = 0.831` 和 `AUC = 0.831 ± 0.036` 是两个完全不同的信息。前者让你以为很确定，后者告诉你"真实值可能在 0.80-0.87 之间"。

**面试会问**："你怎么知道你的改进有效？" 答案就是这张表 + 标准差。

### 7.4 验收清单

```
□ 读入时用了 na_values=['?']
□ 列名清洗过
□ 目标选对（Class==1 是死亡）
□ 缺失指示列加上了
□ 预处理放在 Pipeline 里（不泄露）
□ 有对照组（不加指示列）
□ 报告了 mean ± std，不是单个数字
□ 同时报告了 AUC、召回、特异度（不只看准确率）
```

**Q1. `df.isna().sum()` 全是 0，说明数据没缺失吗？**

<details>
<summary>看答案</summary>

**不一定。**

缺失常被编码成特殊值：`-1`、`0`、`5`、`99`、`999`、`"unknown"`、`?`。

Hepatitis 数据如果不加 `na_values=['?']`，`isna()` 就全返回 0——但实际有 167 个缺失。

**检查方法**：

```python
print((df[col] == df[col].min()).mean())    # 最小值占比高就可疑
for c in df.select_dtypes('object'): print(c, df[c].unique()[:10])  # 看有没有 '?' 'unknown'
```

</details>

**Q2. 三种缺失机制是什么？哪种不能插补？**

<details>
<summary>看答案</summary>

| 类型 | 含义 | 能否插补 |
|---|---|---|
| MCAR（完全随机） | 与任何变量无关 | 能 |
| MAR（随机） | 与其他已观测变量有关 | 能 |
| **MNAR（非随机）** | **与该值本身有关** | **不能** |

**MNAR 为什么不能补**：比如"病情重的病人没做某项检查"，补成均值等于把最重的病人伪装成平均病人。

**判断方法**：看"是否缺失"这个指示变量和目标有没有关系。Hepatitis 里 Sgot 缺失组死亡率 50%、非缺失组 20%——说明缺失带强信息。

</details>

**Q3. 一份数据 1385 行、29 列、零缺失，可以直接拿来建模吗？**

<details>
<summary>看答案</summary>

**不能。先做信号筛查。**

HCV 就是反例：零缺失、样本量不小，但：

- AST 和 ALT 相关性只有 0.038（临床应该 >0.6）
- 所有特征与目标的 Spearman |rho| < 0.06
- HGB 只有 6 个不同取值（被离散化了）

**建模出来 AUC 会接近 0.5。**

**先做的一步**：算每个特征与目标的秩相关。如果全部不显著，回去查数据来源，别浪费时间调参。

</details>

**Q4. ALT 3000 U/L 算异常值吗？该删吗？**

<details>
<summary>看答案</summary>

**统计上是异常值，但绝对不能删。**

ALT 3000 是急性肝衰竭/急性肝炎的真实表现。

用 IQR 无脑删，你会把最重的病人全删掉，模型学到一个"病人都不重"的假世界。

**正确处理**：
- 树模型 → 不用管
- 线性模型/神经网络 → RobustScaler 或 log 变换

</details>

**Q5. 为什么肝纤维化分期不能做 one-hot？**

<details>
<summary>看答案</summary>

**one-hot 会丢失顺序信息。**

编码后，1 期到 2 期的距离 = 1 期到 4 期的距离。但临床上 1 期和 2 期相邻，1 期和 4 期是天壤之别。

**正确做法**：ordinal 编码（直接保留 1/2/3/4 数值）。

</details>

**Q6. 说出五个数据泄露场景。**

<details>
<summary>看答案</summary>

1. 先标准化再划分
2. 先选特征再划分
3. 同一病人跨训练/测试
4. 时间泄露
5. 标签泄露（用了结局之后的信息）

</details>

**Q7. 为什么医学必须按病人划分？**

<details>
<summary>看答案</summary>

同一个病人的多次检查高度相似。如果分到训练和测试两边，**测试集就不是"没见过的新病人"**。

后果：内部 AUC 虚高，换医院就崩。

**解法**：`GroupKFold` / `GroupShuffleSplit`，把病人 ID 作为 groups。

</details>

**Q8. 加了领域特征（如 FIB-4）就一定有用吗？**

<details>
<summary>看答案</summary>

**不一定，必须验证。**

我在 HCV 数据上算过 FIB-4，按分期分组：

```
分期 1: 2.98    分期 2: 2.92    分期 3: 2.99    分期 4: 2.85
```

**完全平坦**——但这个数据集本身没有信号，所以不能说明 FIB-4 无效。

**正确的做法**：

1. 加特征前后各跑一次交叉验证
2. 比 AUC 有没有提升
3. 没提升就删掉

**说不清为什么的增益，多半是噪声或泄露。**

</details>

**Q9. SMOTE 为什么不能在测试集上做？**

<details>
<summary>看答案</summary>

SMOTE 会在少数类样本之间插值造新样本。

如果在全量数据上做再划分，**同一个样本的插值版本会同时出现在训练和测试集里**——测试集全是训练集样本的"近亲"。

指标虚高到接近 1.0，完全失去参考价值。

**正确做法**：只在训练折内部做，验证/测试集保持原始分布。

</details>

## 十一、常见错误更正

| 错误 | 现象 | 正确做法 |
|---|---|---|
| 只看 `isna()` | 以为数据干净 | 还要查哨兵值、最小值堆积 |
| 不加 `na_values` | `?` 被当成正常值 | 读入时指定缺失标记 |
| 上来就 `dropna()` | 155 行掉到 80 行 | 先看缺失比例和机制 |
| 无脑删异常值 | 删掉全部危重病人 | 先判断医学可能性 |
| 分期做 one-hot | 顺序信息丢失 | 用 ordinal |
| 先标准化再划分 | 指标虚高 | Pipeline 包起来 |
| 按样本随机划分 | 病人泄露 | `GroupKFold` |
| 在测试集上做 SMOTE | AUC 接近 1.0 的假象 | 只对训练集做 |
| 给树模型做标准化 | 白做 | 树模型不需要缩放 |
| 不查数据有没有信号 | 调参三天 AUC 还是 0.5 | 先算秩相关 |
| 领域特征不验证 | 加了反而拖累 | 加前加后各跑一次比 AUC |
| 单位不核对 | FIB-4 全算错 | 先确认 Plt 是 ×10⁹/L 还是 /μL |
