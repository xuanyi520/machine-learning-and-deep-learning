***

## 一、为什么直线不够

线性回归只能画直线。但现实问题往往不是线性的。

比如：肿瘤大小和风险的关系可能是"太小没事、中等危险、太大又危险"——是个 U 形。

**一个线性模型永远画不出 U 形。**

那怎么办？**多层线性叠加也还是线性的**：

```
y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W'x + b'
```

两层线性层等于一层。**堆多少层都没用。**

所以必须在每层之间插入一个**非线性函数**——这就是激活函数。

***

## 二、激活函数

最常用的是 **ReLU**：

```
ReLU(x) = max(0, x)
```

负数变 0，正数不变。

```python
import torch
import torch.nn as nn

relu = nn.ReLU()
x = torch.tensor([-2., -1., 0., 1., 2.])
print(relu(x))     # tensor([0., 0., 0., 1., 2.])
```

简单到令人发指，但它就是深度学习能work的关键之一。

**加上 ReLU 之后：**

```
h = ReLU(W₁x + b₁)      # 隐藏层
y = W₂h + b₂            # 输出层
```

现在这是非线性的了，能拟合 U 形。

**记忆**：没有激活函数的多层网络 = 一层线性模型。

***

## 三、nn.Module：PyTorch 的代码组织方式

每次手写参数太麻烦。PyTorch 给你一个标准容器：

```python
import torch.nn as nn

class MyNet(nn.Module):
    def __init__(self):
        super().__init__()                    # 这行必须有
        self.fc1 = nn.Linear(10, 32)          # 10 -> 32
        self.fc2 = nn.Linear(32, 16)          # 32 -> 16
        self.fc3 = nn.Linear(16, 1)           # 16 -> 1
        self.relu = nn.ReLU()

    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.fc3(x)
        return x

model = MyNet()
print(model)
```

**两个必须记住的规则：**

1. `__init__` 里定义"有哪些层"
2. `forward` 里定义"数据怎么流过去"

**你永远不要手动调 `forward()`。** 要用 `model(x)`，PyTorch 会在背后处理很多事情。

```python
x = torch.randn(5, 10)      # 5 个样本，每个 10 维
out = model(x)               # 注意是 model(x)，不是 model.forward(x)
print(out.shape)             # (5, 1)
```

## 五、常见层速查

| 层 | 作用 | 常用场景 |
|---|---|---|
| `nn.Linear(in, out)` | 全连接 | 通用 |
| `nn.ReLU()` | 激活 | 几乎每层后面 |
| `nn.Sigmoid()` | 压到 (0,1) | 二分类输出 |
| `nn.Conv2d(...)` | 卷积 | 图像（下节讲） |
| `nn.MaxPool2d(2)` | 池化下采样 | 图像 |
| `nn.Dropout(0.5)` | 随机丢弃，防过拟合 | 大网络 |
| `nn.BatchNorm1d(n)` | 批归一化，加速收敛 | 深层网络 |

## 六、跟着做：搭一个二分类网络

用 W7 那种数据（10 维特征，二分类）：

```python
import torch
import torch.nn as nn
import numpy as np
from sklearn.datasets import make_classification

torch.manual_seed(42)

# 数据
X, y = make_classification(n_samples=2000, n_features=10,
                           n_informative=5, random_state=42)
X = torch.tensor(X, dtype=torch.float32)
y = torch.tensor(y, dtype=torch.float32).unsqueeze(1)     # (N,) -> (N,1)

# 模型
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(10, 32),
            nn.ReLU(),
            nn.Linear(32, 16),
            nn.ReLU(),
            nn.Linear(16, 1),
            nn.Sigmoid(),        # 输出概率
        )

    def forward(self, x):
        return self.net(x)

model = Net()

# 损失和优化器
criterion = nn.BCELoss()                            # 二分类交叉熵
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# 训练
for epoch in range(300):
    y_pred = model(X)
    loss = criterion(y_pred, y)

    optimizer.zero_grad()      # 清梯度（3-1 的坑）
    loss.backward()            # 反向
    optimizer.step()           # 更新参数

    if epoch % 50 == 0:
        acc = ((y_pred > 0.5).float() == y).float().mean()
        print(f"epoch {epoch:3d}  loss={loss.item():.4f}  acc={acc.item():.4f}")
```

**注意 `nn.Sequential`**：当模型是简单的串行结构时，用它比一个个定义更清爽。

## 七、优化器：比手写更新更好的选择

W6 你手写的是最原始的 SGD：

```
w = w - lr * grad
```

PyTorch 提供了更聪明的优化器。**Adam** 是最常用的，它能自动调整每个参数的学习率：

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

标准三步：

```python
optimizer.zero_grad()      # 1. 清空旧梯度
loss.backward()            # 2. 算新梯度
optimizer.step()           # 3. 更新参数
```

**这三行的顺序是固定的，背下来。** 写反了模型就不学。

（`AdamW` 现在更流行，因为正则化处理更规范。但 Adam 先够用。）

## 九、自测题

1. 为什么多层线性层等于一层线性层？
因为 W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)，还是线性形式。堆多少层都一样
2. 激活函数的作用是什么？
引入非线性，让网络能拟合复杂函数
3. `nn.Module` 里 `__init__` 和 `forward` 分别负责什么？
__init__ 定义有哪些层（参数在这里注册）；forward 定义数据怎么流
4. 为什么用 `model(x)` 而不是 `model.forward(x)`？
因为 model(x) 会触发 __call__，里面处理了 hook、模式切换等。直接调 forward 会跳过这些
5. 优化器三步的顺序是什么？写反会怎样？
zero_grad() → backward() → step()。写反会用到旧梯度更新参数，模型学不动
