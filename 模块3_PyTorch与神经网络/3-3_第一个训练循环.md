## 一、MNIST 是什么

6 万张训练 + 1 万张测试的 28×28 灰度手写数字图片，标签 0-9。

深度学习界的"Hello World"。虽然简单，但流程和做大模型完全一样。

```python
from torchvision import datasets, transforms

transform = transforms.ToTensor()      # PIL 图像 -> Tensor，并归一化到 [0,1]

train_set = datasets.MNIST(root='./data', train=True, download=True, transform=transform)
test_set = datasets.MNIST(root='./data', train=False, download=True, transform=transform)

print(len(train_set), len(test_set))

x, y = train_set[0]
print(x.shape, y)        # torch.Size([1, 28, 28]) 和标签
```

**注意形状是 `(1, 28, 28)`**：1 是通道数（灰度图只有 1 个通道），后面是高和宽。

***

## 二、DataLoader：批处理

一次喂 6 万张图片进内存不现实，所以分批。

```python
from torch.utils.data import DataLoader

train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
test_loader = DataLoader(test_set, batch_size=64, shuffle=False)

# 看看一个批次长什么样
xb, yb = next(iter(train_loader))
print(xb.shape)      # (64, 1, 28, 28)
print(yb.shape)      # (64,)
```

**两个参数**：

- `batch_size=64`：每批 64 张
- `shuffle=True`：每轮打乱顺序（训练集必须打乱，否则模型可能学到顺序的规律）

***

## 三、一个形状问题必须先解决

全连接层要的是 `(N, 784)`，但图片是 `(N, 1, 28, 28)`。

所以要**展平**：把每张 28×28 的图拉成一维 784。

```python
x = x.view(x.size(0), -1)     # (64,1,28,28) -> (64, 784)
```

`-1` 表示"这一维让它自己算"。这是 W2 形状推理的实战。

***

## 四、完整的训练脚本

**这是第一阶段的里程碑，认真敲，认真跑。**

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

torch.manual_seed(42)
device = "cuda" if torch.cuda.is_available() else "cpu"
print("使用设备:", device)

# ========== 1. 数据 ==========
transform = transforms.ToTensor()

train_set = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_set = datasets.MNIST('./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_set, batch_size=64, shuffle=True)
test_loader = DataLoader(test_set, batch_size=64, shuffle=False)

# ========== 2. 模型 ==========
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Flatten(),              # (N,1,28,28) -> (N,784)，省得手写 view
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, 10),         # 10 个类别
        )

    def forward(self, x):
        return self.net(x)

model = Net().to(device)
print(model)

# ========== 3. 损失与优化器 ==========
criterion = nn.CrossEntropyLoss()     # 多分类标准损失
optimizer = optim.Adam(model.parameters(), lr=1e-3)

# ========== 4. 训练循环 ==========
def evaluate(model, loader):
    """在给定数据集上算准确率"""
    model.eval()                       # 切换到评估模式
    correct = total = 0
    with torch.no_grad():              # 评估不求导
        for xb, yb in loader:
            xb, yb = xb.to(device), yb.to(device)
            pred = model(xb).argmax(dim=1)     # 取概率最大的类别
            correct += (pred == yb).sum().item()
            total += yb.size(0)
    return correct / total

epochs = 5
for epoch in range(epochs):
    model.train()                      # 切换到训练模式
    running_loss = 0

    for xb, yb in train_loader:
        xb, yb = xb.to(device), yb.to(device)

        # 标准三步
        optimizer.zero_grad()
        out = model(xb)
        loss = criterion(out, yb)
        loss.backward()
        optimizer.step()

        running_loss += loss.item()

    train_acc = evaluate(model, train_loader)
    test_acc = evaluate(model, test_loader)
    print(f"Epoch {epoch+1}  平均loss={running_loss/len(train_loader):.4f}  "
          f"训练准确率={train_acc:.4f}  测试准确率={test_acc:.4f}")

print(f"\n最终测试准确率: {evaluate(model, test_loader):.4f}")
```

**5 轮之后测试准确率应该在 97% 左右。** 达到 95% 就过关了。

***

## 五、训练循环的五个步骤（背下来）

```
1. optimizer.zero_grad()     清空上一步的梯度
2. out = model(xb)           前向：算预测
3. loss = criterion(out, yb) 算损失
4. loss.backward()           反向：算梯度
5. optimizer.step()          更新参数
```

**这就是深度学习的心跳。** 从 MNIST 到 GPT，中间就是这五行，只是模型和数据变了。

写不出来的时候，回来抄这五行。

***

## 六、训练/评估模式的区别

```python
model.train()    # 训练时
model.eval()     # 评估时
```

为什么需要切换？因为有些层在两种模式下行为不同：

- **Dropout**：训练时随机丢弃，评估时不丢
- **BatchNorm**：训练时用批统计量，评估时用全局统计量

**如果忘了 `model.eval()`，评估结果会不稳定且偏低。** 这是常见 bug。

## 七、跟着做：可视化预测结果

看看模型到底学了什么，以及它错在哪。

```python
import matplotlib.pyplot as plt

matplotlib.rcParams['font.sans-serif'] = ['SimHei']
matplotlib.rcParams['axes.unicode_minus'] = False

model.eval()
xb, yb = next(iter(test_loader))
xb, yb = xb.to(device), yb.to(device)

with torch.no_grad():
    probs = torch.softmax(model(xb), dim=1)
    preds = probs.argmax(dim=1)

fig, axes = plt.subplots(2, 8, figsize=(16, 4))
for i, ax in enumerate(axes.flat):
    img = xb[i].cpu().squeeze()
    ax.imshow(img, cmap='gray')
    p = preds[i].item()
    t = yb[i].item()
    confidence = probs[i][p].item()
    ax.set_title(f"预测{p} ({confidence:.2f})\n真实{t}",
                 color='green' if p == t else 'red')
    ax.axis('off')

plt.tight_layout()
plt.show()
```

**绿的是对的，红的是错的。** 看看错误样本——往往连人眼也难分辨，这说明模型错得"有道理"。
