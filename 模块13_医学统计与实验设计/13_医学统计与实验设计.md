## 一、描述与推断：先看清数据，再谈差异
### 1.1 核心问题
**两组病人的某个指标不一样，这是真实差异，还是抽样波动？**

回答这个问题分两步：

1. 描述：这组数据长什么样（集中趋势 + 离散程度）
2. 推断：观察到的差异，能不能用"碰巧抽到这批人"解释

**90% 的统计错误发生在第一步：描述方式选错了，后面的检验也跟着错。**

### 1.2 连续变量：均值 ± 标准差，还是中位数 (IQR)？
先看一个例子。10 个病人的 ALT（U/L）：

```
20, 25, 30, 35, 40, 45, 50, 55, 60, 3000
```

| 指标 | 计算 | 结果 |
|---|---|---|
| 均值 | 3360 / 10 | **336.0** |
| 标准差 | 被 3000 拉大 | **936.9** |
| 中位数 | (40 + 45) / 2 | **42.5** |
| Q1 | 25% 分位 | **31.25** |
| Q3 | 75% 分位 | **53.75** |
| IQR | Q3 - Q1 | **22.5** |

**均值 336 不能代表这 10 个人。** 9 个人在 20-60 之间，只有 1 个人是 3000（急性肝损伤，真实值，不能删）。均值被这一个点拉到了 336。

**正确写法：中位数 42.5（IQR 31.25-53.75）。**

#### 判断规则

| 分布 | 描述 | 配套检验 | 医学例子 |
|---|---|---|---|
| 近似正态、无强离群 | 均值 ± 标准差 | t 检验 | 年龄、身高、血红蛋白 |
| 偏态、有离群 | **中位数 (IQR)** | **Mann-Whitney U** | 住院天数、费用、ALT、胆红素、肿瘤标志物 |

**医学数据大部分是偏态的。** 原因很简单：化验指标有生理下限（不能是负数），但上限可以很高。ALT 正常上限 40，急性肝损伤可以到 3000；住院费用下限接近 0，上限可以几十万。这种"右边长尾"就是右偏。

#### 怎么判断正态
三种方法，按可靠性排序：

| 方法 | 怎么做 | 注意 |
|---|---|---|
| 直方图 / QQ 图 | 看形状 | 最直观，必须看 |
| Shapiro-Wilk 检验 | `stats.shapiro(x)` | 样本 < 5000 时好用；样本很大时，微小偏离也会显著 |
| 偏度 / 峰度 | `stats.skew(x)` | 偏度 > 1 基本可判偏态 |

**不要只用 Shapiro-Wilk 的 p 值。** 样本 5000 以上时，p < 0.05 几乎必然，但分布可能足够接近正态。反过来，样本 20 时 p > 0.05 也不能证明正态，只是没有证据拒绝。

**实用规则：**

```
n < 30    → 看 QQ 图 + 中位数更稳妥
30-500    → Shapiro + 直方图
n > 500   → 看偏度和直方图，别迷信 p 值
```

#### 一个常犯的错：描述和检验不匹配

| 错误写法 | 为什么错 |
|---|---|
| 中位数 (IQR) + t 检验 | 描述的是中位数，检验的是均值 |
| 均值 ± SD + Mann-Whitney | 检验的是秩，描述却用均值和 SD |
| 均值 ± **SE** | SE 是均值的不确定性，不是数据的离散程度；表 1 要用 SD |

**表 1 里的 ± 必须是 SD，不是 SE。** SE = SD / sqrt(n)，样本越大 SE 越小，看起来"数据很集中"，这是假象。

### 1.3 分类变量：卡方、Fisher、McNemar
#### 2x2 表长什么样

|  | 死亡 | 存活 | 合计 |
|---|---|---|---|
| 腹水阳性 | a | b | a+b |
| 腹水阴性 | c | d | c+d |

#### 三个检验，怎么选

| 情况 | 检验 | 判断标准 |
|---|---|---|
| 两组，2x2，所有期望频数 ≥ 5 | 卡方（不作连续性校正） | Pearson chi-square |
| 两组，2x2，任一期望频数 < 5 | **Fisher 精确检验** | 直接算超几何概率 |
| 两组，R x C，任一期望频数 < 5 | Fisher-Freeman-Halton | 或合并类别 |
| **同一批人，两种检测/两个规则** | **McNemar** | 只看不一致的格子 |
| 多组，2x2 | 卡方 | 事后两两比较要校正 |

**Fisher 不是"样本量小于 30 才用"。** 判断标准是**期望频数**，不是总样本量。1000 例的样本，如果某个格子只有 2 人，照样要用 Fisher。

#### 期望频数怎么算

```
格子 (i, j) 的期望频数 = (第 i 行合计 × 第 j 列合计) / 总样本量
```

例：腹水阳性 20 人，其中死亡 14 人；腹水阴性 130 人，其中死亡 17 人。

```
死亡合计 = 31，存活合计 = 119，总 n = 150
腹水阳性且死亡的期望频数 = 20 × 31 / 150 = 4.13 < 5
→ 用 Fisher
```

#### McNemar：配对数据的正确检验
**场景**：同一批病人，用两种方法各测一次，比较两种方法的阳性率有没有差异。

不能把两组当独立样本做卡方。因为同一个人被算了两次，两次结果相关。

**只看不一致的格子：**

|  | 方法 B 阳性 | 方法 B 阴性 |
|---|---|---|
| 方法 A 阳性 | a | **b** |
| 方法 A 阴性 | **c** | d |

- b：A 阳性、B 阴性
- c：A 阴性、B 阳性
- 一致格子 a、d 不提供"两种方法有无差异"的信息

**检验统计量：**

```
chi2 = (|b - c| - 1)^2 / (b + c)     # 连续性校正
```

b + c < 25 时用精确二项检验：`binomtest(b, b+c, 0.5)`。

### 1.4 代码：自动判断该用哪种检验的表 1
下面这段代码会读入 Hepatitis，逐个变量判断类型和前提，自动选检验，输出一张表 1。

```python
import pandas as pd
import numpy as np
from scipy import stats

PATH = r'E:\AI学习\练习代码\data\uci\Hepatitis.csv'
df = pd.read_csv(PATH, na_values=['?'])
df.columns = df.columns.str.strip().str.replace(' ', '_')
df['death'] = (df['Class'] == 1).astype(int)      # 1=死亡, 0=存活

# 把 1/2 编码转成临床可读的 0/1（1=有该特征）
df['male']       = df['Sex'].map({1: 1, 2: 0})
df['ascites']    = df['Ascites'].map({1: 1, 2: 0})   # 本文件 1=有，与 UCI 文档相反
df['spiders']    = df['Spiders'].map({1: 1, 2: 0})
df['varices']    = df['Varices'].map({1: 1, 2: 0})
df['liver_firm'] = df['Liver_Firm'].map({2: 1, 1: 0})
df['steroid']    = df['Steroid'].map({2: 1, 1: 0})

def pick_test(data, var, group):
    """按变量类型和前提自动选检验，返回 (格式, 组1描述, 组0描述, p, 检验名)。"""
    sub = data[[var, group]].dropna()
    g1 = sub.loc[sub[group] == 1, var]
    g0 = sub.loc[sub[group] == 0, var]

    # 连续变量：取值多于 2 个
    if pd.api.types.is_numeric_dtype(sub[var]) and sub[var].nunique() > 2:
        normal = stats.shapiro(g1).pvalue > 0.05 and stats.shapiro(g0).pvalue > 0.05
        if normal:
            p = stats.ttest_ind(g1, g0, equal_var=False).pvalue
            return ('mean ± SD',
                    f'{g1.mean():.2f} ± {g1.std():.2f}',
                    f'{g0.mean():.2f} ± {g0.std():.2f}', p, 'Welch t')
        p = stats.mannwhitneyu(g1, g0, alternative='two-sided').pvalue
        return ('median (IQR)',
                f'{g1.median():.2f} ({g1.quantile(.25):.2f}-{g1.quantile(.75):.2f})',
                f'{g0.median():.2f} ({g0.quantile(.25):.2f}-{g0.quantile(.75):.2f})',
                p, 'Mann-Whitney U')

    # 分类变量
    tab = pd.crosstab(sub[var], sub[group])
    _, p_chi, _, exp = stats.chi2_contingency(tab, correction=False)
    if exp.min() < 5:
        p, test = stats.fisher_exact(tab.values)[1], 'Fisher'
    else:
        p, test = p_chi, 'chi-square'
    a = int(((sub[var] == 1) & (sub[group] == 1)).sum())
    b = int(((sub[var] == 1) & (sub[group] == 0)).sum())
    return ('n (%)', f'{a} ({a/len(g1):.1%})', f'{b} ({b/len(g0):.1%})', p, test)

labels = {'Age': '年龄', 'Bilirubin': '胆红素', 'Alk_Phosphate': '碱性磷酸酶',
          'Sgot': 'AST', 'Albumin': '白蛋白', 'Protime': '凝血酶原时间',
          'male': '男性', 'ascites': '腹水', 'spiders': '蜘蛛痣',
          'varices': '静脉曲张', 'liver_firm': '肝质地硬', 'steroid': '使用激素'}

rows = []
for var in ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime',
            'male', 'ascites', 'spiders', 'varices', 'liver_firm', 'steroid']:
    fmt, d1, d0, p, test = pick_test(df, var, 'death')
    rows.append([labels[var], fmt, d1, d0, p, test])

table1 = pd.DataFrame(rows, columns=['变量', '格式', '死亡组 (n=32)', '存活组 (n=123)', 'p', '检验'])
table1['p'] = table1['p'].map(lambda x: '<0.001' if x < 0.001 else f'{x:.3f}')
print(table1.to_string(index=False))
```

**实测输出：**

```
    年龄      median (IQR)  46.50 (38.75-54.50)  38.00 (30.00-50.00)  0.002  Mann-Whitney U
   胆红素     median (IQR)   1.95 (1.20-3.65)     1.00 (0.70-1.20)   <0.001  Mann-Whitney U
```

**读这张表要注意三件事：**

1. **所有连续变量都用了中位数 (IQR)。** 因为每个变量在至少一组里 Shapiro-Wilk p < 0.05。这不是巧合，是医学数据的常态。
2. **性别、腹水、静脉曲张用了 Fisher。** 因为期望频数 < 5（例如女性死亡人数为 0）。
3. **这张表做了 12 次检验，没有校正。** 表 1 的基线比较通常是描述性的，但如果你要在正文里说"两组基线有显著差异"，就要意识到 12 次检验里至少 1 次假阳性的概率是 46%。

**百分比的分母是该变量的非缺失例数，不是总 32/123。** 例如白蛋白死亡组只有 27 例非缺失。

### 1.5 手算例子
#### 例子 1：均值 vs 中位数
10 个 ALT 值：20, 25, 30, 35, 40, 45, 50, 55, 60, 3000。

```
均值 = 3360 / 10 = 336.0
中位数 = (40 + 45) / 2 = 42.5
Q1 = 31.25, Q3 = 53.75, IQR = 22.5
```

结论：报告"中位数 42.5（IQR 31.25-53.75）"，不报告均值 336。

#### 例子 2：期望频数
腹水阳性 20 人（死亡 14），腹水阴性 130 人（死亡 17）。

```
死亡合计 31，存活合计 119，n = 150
阳性组死亡期望 = 20 × 31 / 150 = 4.13
阴性组死亡期望 = 130 × 31 / 150 = 26.87
最小期望 4.13 < 5 → Fisher
```

Fisher 精确检验 p = 2.69e-07（本数据实测）。

#### 例子 3：McNemar
规则 A（胆红素 > 1.2）和规则 B（白蛋白 < 3.5）在同一批 139 人上：

```
A 阳性、B 阴性：24 人
A 阴性、B 阳性：14 人
不一致合计：38 人

chi2 = (|24 - 14| - 1)^2 / 38 = 81 / 38 = 2.132
p = 0.144
精确二项 p = 0.143
```

结论：两种规则的阳性率差异没有统计学意义（p = 0.14）。但注意，这不代表两个规则"一样好"——它们的灵敏度和特异度 trade-off 不同（A 灵敏度 0.741、特异度 0.768；B 灵敏度 0.667、特异度 0.839）。

### 1.6 常见错误

| 错误 | 表现 | 后果 | 正确做法 |
|---|---|---|---|
| 不判断分布，直接用 t 检验 | 偏态数据报均值 ± SD | 均值被离群值拉偏 | 先看直方图/Shapiro |
| 用 SE 代替 SD | 表 1 写"均值 ± SE" | 数据看起来比实际集中 | 表 1 用 SD |
| 中位数配 t 检验 | 描述与检验不一致 | 审稿人直接指出 | 描述和检验必须匹配 |
| 方差齐性不查 | 两组方差差 5 倍还用 Student t | p 值偏小 | 默认 Welch t |
| 多组两两 t 检验 | 3 组做 3 次 t | 假阳性率从 5% 升到 14% | ANOVA + 事后校正 |
| 期望频数 < 5 还用卡方 | 2x2 里有 0 | p 值不准 | Fisher |
| 配对数据用卡方 | 同一批人两种检测 | 忽略相关性，p 值错 | McNemar |
| 把缺失当 0 | `(df['x'] == 1).astype(int)` | 缺失被算成"无该特征" | 用 `map({1:1, 2:0})` 保留 NaN |
| 照抄 codebook 的编码方向 | 腹水 1=有，文档写 1=无 | 阳性率反了 | 用临床合理性验证 |

**最后一条是本数据的真实坑。** UCI 文档写 Ascites 1=No、2=Yes，但这份文件里 1 才是有腹水（1 组死亡率 70%，2 组 13%）。如果你照抄文档，表 1 会写成"腹水阳性 130 人"，临床上说不通。

**判断方法：** 算一下"编码为 1 的组"的结局发生率，看是否符合临床常识。不符合就翻过来。

### 1.7 审稿人会问什么
**问：为什么用 Mann-Whitney U 而不是 t 检验？**

答：该变量在至少一组 Shapiro-Wilk p < 0.05，且直方图右偏；两组样本量不等且方差不齐。Mann-Whitney 不要求正态，比较的是分布位置，更适合这种数据。同时报告中位数 (IQR)，与检验匹配。

**问：表 1 做了这么多检验，为什么不做多重比较校正？**

答：表 1 的目的是描述基线可比性，不是验证假设；常规做法不校正，但会在讨论中说明。如果某个基线变量被用来定义主要终点或做亚组分析，那个分析会单独校正。

**问：Fisher 精确检验是不是只适合小样本？**

答：不是。判断标准是期望频数，不是总样本量。2x2 表中任一格期望频数 < 5 时用 Fisher；总样本 1000 但某格只有 1 人，仍然用 Fisher。

## 二、p 值与置信区间：审稿人最容易被激怒的地方
### 2.1 核心问题
**p < 0.05 到底证明了什么？为什么 p = 0.052 的结论和 p = 0.048 完全不同？**

先给结论：

> **p 值回答的是"如果两组真的没差异，看到这么大数据差异的概率有多大"。**
> **它不回答"差异有多大"，也不回答"这个结果有多重要"。**

### 2.2 p 值的正确含义
想象一个思想实验：

```
总体：两组病人真的没有差异（原假设 H0 成立）
做法：从总体里随机抽两组，算一次检验，记下 p
重复：抽 10000 次
结果：大约 500 次的 p < 0.05
```

**这就是 p 值的频率学含义。** p = 0.03 的意思是：如果原假设成立，重复同样的研究，约 3% 的研究会得到当前或更极端的差异。

它**不是**：

| 错误理解 | 为什么错 |
|---|---|
| p = 0.03 表示"原假设为真的概率是 3%" | 原假设要么真要么假，没有概率；p 是数据在原假设下的概率 |
| p = 0.03 表示"效应很大" | p 小可能只是样本大；效应可能很小 |
| p = 0.03 表示"结果有 97% 的概率可重复" | p 不直接给重复概率；重复概率还取决于效应量、样本量、偏倚 |
| p > 0.05 表示"两组没有差异" | 只能说不拒绝原假设；可能是样本不够，也可能是真没差异 |
| p = 0.000 | 不可能等于 0；应写 p < 0.001 |

**最后一条是写作规范。** 软件输出 `p = 0.000` 是四舍五入的结果，不是真的 0。论文里写 `p < 0.001`。

### 2.3 p = 0.04 和 p = 0.06 的区别，在医学上没有意义
看本章多因素 logistic 的真实结果（n = 87）：

| 变量 | OR | 95% CI | p |
|---|---|---|---|
| 胆红素（每 1 mg/dL） | 1.771 | 0.995 - 3.153 | 0.052 |
| 白蛋白（每 1 g/dL） | 0.210 | 0.059 - 0.746 | 0.016 |

如果按 p < 0.05 的二分法：

- 胆红素"不显著"
- 白蛋白"显著"

**但看 CI，结论完全不是这样：**

- 胆红素的 CI 是 0.995 到 3.153。它跨过了 1（可能无效），但上界到 3.15（可能使风险增加 3 倍）。**数据既不能排除无效，也不能排除强效应。**
- 白蛋白的 CI 是 0.059 到 0.746，整个区间在 1 以下。**方向明确，效应可能存在。**

**p = 0.052 和 p = 0.048 的差别，只是"有没有跨过人为画的一条线"。** 这条线是 Fisher 在 1925 年为了方便决策定的，不是自然规律。

**审稿人真正关心的：**

1. 效应量有多大（OR / HR / 差值）
2. 估计有多准（CI 宽度）
3. 这个效应在临床上重不重要

**p = 0.04 但 OR = 1.05，和 p = 0.06 但 OR = 3.0，后者更值得讨论。** 但很多期刊只让你报第一个。

### 2.4 效应量：p 值不告诉你的东西

| 效应量 | 适用 | 怎么解释 | 医学例子 |
|---|---|---|---|
| Cohen's d | 两组连续变量均值差 | 0.2 小、0.5 中、0.8 大（粗略） | 两组年龄差 0.55 SD |
| OR | 二分类结局 | 每增加 1 单位，odds 变成原来的几倍 | 胆红素每升 1 mg/dL，OR = 1.77 |
| HR | 生存结局 | 每增加 1 单位，瞬时风险变成原来的几倍 | 胆红素升高组，HR = 2.36 |
| RD | 两组风险差 | 绝对风险降低/增加 | 死亡率从 20% 降到 15%，RD = -5% |
| NNT | 需要治疗多少人 | 1 / |RD| | NNT = 20 |

**这一章的数据里，Cohen's d 的实测值：**

| 变量 | 死亡组 vs 存活组 | Cohen's d |
|---|---|---|
| 年龄 | 46.6 vs 39.8 | +0.553 |
| 胆红素 | 2.54 vs 1.15 | +1.297 |
| 白蛋白 | 3.15 vs 3.98 | -1.462 |
| 凝血酶原时间 | 43.5 vs 66.6 | -1.099 |

**注意：** Cohen's d 假设两组方差相近、近似正态。胆红素和凝血酶原时间是偏态的，这里的 d 只能当"描述性效应量"，不能当精确估计。偏态数据更推荐报告"中位数差"或"优势概率"（Mann-Whitney 的效应量）。

**OR 和 RR 不能混。** 结局常见时（>10%），OR 会夸大 RR。例子：

```
暴露组死亡 20/80，风险 25%
对照组死亡 10/100，风险 10%
RR = 25% / 10% = 2.50
OR = (20/60) / (10/90) = 3.00
```

**同一份数据，OR 比 RR 大了 20%。** 论文里写"风险增加 3 倍"是错的，应该说"odds 增加 3 倍"。

### 2.5 置信区间比 p 值更有信息量
**95% CI 的含义：** 重复抽样 100 次，约 95 次的区间会覆盖真实参数。

它同时告诉你三件事：

1. **方向**：区间在 1 的哪一侧
2. **大小**：点估计是多少
3. **精度**：区间有多宽（样本越小越宽）

**报告规范：**

| 差 | 好 |
|---|---|
| `p < 0.05` | `OR = 1.77 (95% CI 0.995-3.153), p = 0.052` |
| `两组有显著差异` | `死亡组中位胆红素 1.95 vs 1.00 mg/dL, p < 0.001` |
| `AUC = 0.82` | `AUC = 0.82 (95% CI 0.73-0.89)` |

**CI 跨 1 怎么解释：**

- OR/HR 的 CI 跨 1：数据与"无效"和"有效"都相容
- 均值差的 CI 跨 0：数据与"无差异"和"有差异"都相容
- **不能说"证明无效"**，只能说"没有足够证据证明有效"

### 2.6 代码：logistic 回归的 OR 和 95% CI
`sklearn` 只给系数，不给标准误。下面用 Newton-Raphson 自己算 SE 和 CI，结果与 statsmodels 完全一致。

```python
import pandas as pd
import numpy as np
from scipy import stats

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = df.columns.str.strip().str.replace(' ', '_')
df['death'] = (df['Class'] == 1).astype(int)

def fit_logit(X, y, names):
    """Newton-Raphson 拟合 logistic，返回 beta、SE、OR、95% CI、p。"""
    X = np.asarray(X, float)
    y = np.asarray(y, float)
    mask = ~np.isnan(y) & ~np.isnan(X).any(axis=1)
    X, y = X[mask], y[mask]
    X1 = np.column_stack([np.ones(len(X)), X])      # 加截距列
    beta = np.zeros(X1.shape[1])
    for _ in range(50):
        eta = X1 @ beta
        p = 1 / (1 + np.exp(-eta))
        W = p * (1 - p) + 1e-12
        grad = X1.T @ (y - p)
        info = X1.T @ (X1 * W[:, None])
        step = np.linalg.solve(info, grad)
        beta = beta + step
        if np.max(np.abs(step)) < 1e-9:
            break
    p = 1 / (1 + np.exp(-(X1 @ beta)))
    W = p * (1 - p)
    cov = np.linalg.inv(X1.T @ (X1 * W[:, None]))
    se = np.sqrt(np.diag(cov))
    out = []
    for i, name in enumerate(names, start=1):
        z = beta[i] / se[i]
        out.append([name, np.exp(beta[i]),
                    np.exp(beta[i] - 1.96 * se[i]),
                    np.exp(beta[i] + 1.96 * se[i]),
                    2 * stats.norm.sf(abs(z))])
    return pd.DataFrame(out, columns=['变量', 'OR', '95% CI 下限', '95% CI 上限', 'p'])

def show(df, title):
    print(f'\n{title}')
    print(df.to_string(index=False,
          formatters={'OR': '{:.3f}'.format,
                      '95% CI 下限': '{:.3f}'.format,
                      '95% CI 上限': '{:.3f}'.format,
                      'p': '{:.3g}'.format}))

show(fit_logit(df[['Albumin']], df['death'], ['Albumin']), '单因素：白蛋白')
show(fit_logit(df[['Bilirubin']], df['death'], ['Bilirubin']), '单因素：胆红素')

sub = df[['Age', 'Bilirubin', 'Albumin', 'Protime', 'death']].dropna()
show(fit_logit(sub[['Age', 'Bilirubin', 'Albumin', 'Protime']],
               sub['death'], ['Age', 'Bilirubin', 'Albumin', 'Protime']),
     f'多因素：n={len(sub)}')
```

```
Albumin 0.094     0.038     0.229  2.14e-07

Bilirubin 2.508     1.657     3.797  1.37e-05
```

**怎么读：**

1. **白蛋白从单因素 OR 0.094 变到多因素 OR 0.210。** 单因素时，白蛋白每高 1 g/dL，死亡 odds 降低 90.6%；调整年龄、胆红素、凝血酶原时间后，降低 79.0%。**效应被其他变量解释了一部分，这就是混杂。**
2. **胆红素多因素 OR 1.771，CI 0.995-3.153，p = 0.052。** 不能写"胆红素与死亡无关"。正确写法："调整后胆红素与死亡风险呈正相关，但未达到传统显著性水平（OR 1.77, 95% CI 0.99-3.15, p = 0.052），置信区间较宽，需更大样本验证。"
3. **年龄 OR 1.039 是"每增加 1 岁"。** 每增加 10 岁，OR = 1.039^10 = 1.47。报告时要写清楚单位，否则读者会以为是"每 10 岁"。

### 2.7 手算例子：OR 和 95% CI
2x2 表：

|  | 死亡 | 存活 |
|---|---|---|
| 暴露 | 20 | 60 |
| 非暴露 | 10 | 90 |

```
OR = (20 × 90) / (60 × 10) = 1800 / 600 = 3.00
ln(OR) = 1.0986

SE(lnOR) = sqrt(1/20 + 1/60 + 1/10 + 1/90)
         = sqrt(0.0500 + 0.0167 + 0.1000 + 0.0111)
         = sqrt(0.1778) = 0.4216

95% CI = exp(1.0986 ± 1.96 × 0.4216)
       = exp(0.2723) 到 exp(1.9250)
       = 1.313 到 6.855
```

**解读：** OR 点估计 3.0，但 CI 从 1.31 到 6.86，很宽。样本只有 180 人，精度有限。

同一张表的其他指标：

```
暴露组风险 = 20/80 = 25%
对照组风险 = 10/100 = 10%

卡方 = 7.20, p = 0.0073

```

**OR 3.0 vs RR 2.5：** 结局发生率 25% 和 10%，不算罕见，OR 明显夸大。论文里如果写"风险增加 3 倍"，审稿人会抓住。

### 2.8 常见错误

| 错误 | 表现 | 正确做法 |
|---|---|---|
| 把 p 当效应量 | "p < 0.001，说明效果很好" | 报 OR/HR/d + CI |
| 只报 p 不报 CI | `p = 0.03` | 所有主要结果带 95% CI |
| 把"不显著"当"无效" | "两组无差异" | "未发现统计学显著差异，CI 为..." |
| 把 OR 当 RR | "风险增加 3 倍" | "odds 增加 3 倍" |
| 写 p = 0.000 | 软件输出直接抄 | p < 0.001 |
| 事后改主要终点 | 先看哪个显著再定 | 预先注册 SAP |
| 单位不写 | "年龄 OR = 1.04" | "每增加 1 岁，OR = 1.04" |
| 多因素模型硬解释可疑变量 | Protime OR < 1 也解释 | 先查数据质量 |

### 2.9 审稿人会问什么
**问：p = 0.052，你为什么还说"呈正相关"？**

答：点估计 OR = 1.77，95% CI 0.995-3.153，方向一致且上界到 3.15；p = 0.052 只是刚好没跨过 0.05，不能据此断言无效。我们会把它列为"边缘显著"，并在讨论中说明样本量限制。

**问：为什么不用 RR 而用 OR？**

答：本研究是回顾性队列，死亡发生率 20.6%，不是罕见结局。OR 是 logistic 模型的自然输出，但在结局常见时会高估 RR。我们在讨论中同时给出了绝对风险差，避免把 OR 解释成"风险倍数"。

**问：置信区间这么宽，结论可信吗？**

答：CI 宽说明精度有限，这正是我们报告 CI 的原因。点估计方向与既往文献一致，但需要外部数据验证；我们不会基于这个 CI 做临床决策推荐。

## 三、多重检验校正：为什么你测 20 个指标必然有假阳性
### 3.1 核心问题
**你比较了 20 个指标，其中 1 个 p = 0.03。这个结果能信吗？**

先算一笔账。

如果 20 个指标全都无效（原假设全真），每个检验的假阳性率是 5%，且相互独立：

```
P(至少 1 个假阳性) = 1 - 0.95^20 = 1 - 0.3585 = 0.6415
```

**64.2% 的概率至少出现 1 个假阳性。** 期望假阳性个数 = 20 × 0.05 = 1 个。

**所以"20 个指标里 1 个显著"完全不值得兴奋。** 这是抛 20 次硬币，至少出现 1 次正面的概率。

### 3.2 FWER 和 FDR：控制的是两种不同的错误

| 指标 | 全称 | 控制什么 | 适用 |
|---|---|---|---|
| FWER | family-wise error rate | **至少 1 个假阳性的概率** | 确证性研究、主要终点、临床决策 |
| FDR | false discovery rate | **被判为阳性的结果里，假阳性占的比例（期望）** | 探索性研究、组学、多指标筛选 |

**区别用一个例子说清：**

```
你做 1000 个基因的筛选，得到 100 个阳性。
FWER 控制：这 100 个里，一个假阳性都不许有（几乎不可能，会筛掉所有）
FDR 控制：这 100 个里，允许有 5 个假阳性（q < 0.05）
```

**探索性研究用 FDR，确证性研究用 FWER。** 选哪个要在分析前定好，不能看完结果再选。

### 3.3 Bonferroni 和 Benjamini-Hochberg
#### Bonferroni

```
校正后阈值 = alpha / m
```

m = 10，alpha = 0.05，阈值变成 0.005。只有 p < 0.005 才算显著。

**优点：** 简单，严格控制 FWER。
**缺点：** 太保守。指标之间相关时（比如 ALT 和 AST），独立假设不成立，Bonferroni 会过度惩罚，把真信号也扔掉。

#### Benjamini-Hochberg（BH）
步骤：

1. 把 m 个 p 值从小到大排序：p(1) ≤ p(2) ≤ ... ≤ p(m)
2. 对第 k 个，算 q(k) = p(k) × m / k
3. 从最大的 k 开始往回，保证 q 单调不降：q(k) = min(q(k), q(k+1))
4. q < 0.05 的判为显著

**直观理解：** 排名越靠前（p 越小），惩罚越轻；排名靠后，惩罚越重。它允许一部分假阳性，换取更高的功效。

### 3.4 代码：10 个指标的 FDR 校正

```python
import pandas as pd
import numpy as np
from scipy import stats

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = df.columns.str.strip().str.replace(' ', '_')
df['death'] = (df['Class'] == 1).astype(int)

def p_value(var):
    sub = df[[var, 'death']].dropna()
    if sub[var].nunique() > 2:
        a = sub.loc[sub['death'] == 1, var]
        b = sub.loc[sub['death'] == 0, var]
        return stats.mannwhitneyu(a, b, alternative='two-sided').pvalue
    tab = pd.crosstab(sub[var], sub['death']).values
    return stats.fisher_exact(tab)[1]

names = ['Age', 'Spleen_Palpable', 'Alk_Phosphate', 'Sex', 'Steroid',
         'Anorexia', 'Antivirals', 'Sgot', 'Liver_Firm', 'Liver_Big']
raw = np.array([p_value(v) for v in names])
m = len(raw)

# Benjamini-Hochberg：先排序，再取 q = p * m / rank，并从大到小保证单调
order = np.argsort(raw)
q = np.empty(m)
prev = 1.0
for rank in range(m, 0, -1):
    idx = order[rank - 1]
    prev = min(prev, raw[idx] * m / rank)
    q[idx] = prev
bonf = np.minimum(raw * m, 1.0)

out = pd.DataFrame({'指标': names, '原始 p': raw, 'BH q': q, 'Bonferroni p': bonf})
out = out.sort_values('原始 p')
out['原始显著'] = np.where(out['原始 p'] < 0.05, '是', '否')
out['BH 后显著'] = np.where(out['BH q'] < 0.05, '是', '否')
print(out.to_string(index=False, formatters={
    '原始 p': '{:.4g}'.format, 'BH q': '{:.4g}'.format, 'Bonferroni p': '{:.4g}'.format}))
print(f'\n原始 p<0.05: {(raw < 0.05).sum()} 个')
print(f'BH q<0.05:   {(q < 0.05).sum()} 个')
print(f'Bonferroni:  {(bonf < 0.05).sum()} 个')

# 与 scipy 内置实现交叉验证
from scipy.stats import false_discovery_control
print('scipy BH 校验:', np.allclose(q, false_discovery_control(raw)))
```

```
Spleen_Palpable 0.005755 0.02877      0.05755    是      是
  Alk_Phosphate  0.03438    0.11       0.3438    是      否
            Sex  0.04401    0.11       0.4401    是      否
        Steroid   0.1136  0.2272            1    否      否
       Anorexia   0.1398  0.2331            1    否      否
      Antivirals   0.1676  0.2394            1    否      否
```

**注意：** 这 10 个指标是探索性集合。校正后剩下的 2 个也不等于"真实因果"，只是"值得进一步验证"。

### 3.5 手算例子：5 个 p 值的 BH
5 个 p 值：0.001, 0.008, 0.020, 0.040, 0.200。m = 5。

| 排名 k | p(k) | q = p × 5 / k | 单调化后 q |
|---|---|---|---|
| 1 | 0.001 | 0.0050 | 0.0050 |
| 2 | 0.008 | 0.0200 | 0.0200 |
| 3 | 0.020 | 0.0333 | 0.0333 |
| 4 | 0.040 | 0.0500 | 0.0500 |
| 5 | 0.200 | 0.2000 | 0.2000 |

**BH：前 4 个 q ≤ 0.05，显著。**
**Bonferroni：阈值 0.05/5 = 0.01，只有 0.001 和 0.008 显著。**

同一个数据，BH 保留 4 个，Bonferroni 保留 2 个。**没有谁"正确"，取决于你要控制 FWER 还是 FDR。**

### 3.6 什么时候不需要校正

| 情况 | 是否需要 | 理由 |
|---|---|---|
| **预先设定的主要终点** | 不需要 | 只做 1 次检验，alpha 就是 0.05 |
| 次要终点，每个单独预设定 | 通常需要 | 多个次要终点是一个 family |
| 亚组分析 | 需要 | 亚组越多，假阳性越多 |
| 事后探索性分析 | 需要，且要标注"探索性" | 数据驱动，最容易 p-hacking |
| 不同 family 的问题 | 分开校正 | 主要终点和安全性终点是两个 family |
| 相关性很强的指标 | 可用更宽松的方法 | BH 比 Bonferroni 合适 |

**关键：校正方案必须在看数据前写进 SAP。** 看完数据再决定"要不要校正""用哪种校正"，本身就是 p-hacking。

### 3.7 常见错误

| 错误 | 表现 | 正确做法 |
|---|---|---|
| 20 个指标不校正 | 只报 1 个 p = 0.03 | BH 或 Bonferroni，或明确标"探索性" |
| 校正后仍报原始 p 为主 | "校正后不显著，但原始 p = 0.04" | 以校正后为准，原始 p 可附在附表 |
| 把所有检验都塞进一个 family | 主要终点也被 Bonferroni 惩罚 | 按 family 分开 |
| 用 Bonferroni 处理相关指标 | 组学数据全被筛掉 | 用 BH |
| 事后选校正方法 | 哪个显著用哪个 | 预先设定 |
| 把 q 值叫 p 值 | "q = 0.03, p = 0.03" | 区分 raw p 和 adjusted q |

### 3.8 审稿人会问什么
**问：你测了 10 个指标，为什么没做多重比较校正？**

答：这 10 个是预先设定的探索性指标，我们用了 Benjamini-Hochberg 控制 FDR。校正后年龄和脾可触及仍显著（q = 0.024 和 0.029），碱性磷酸酶和性别不再显著（q = 0.11）。我们在结果中同时报告了原始 p 和 q。

**问：为什么用 FDR 不用 Bonferroni？**

答：这是探索性筛选，不是确证性试验。Bonferroni 控制"至少一个假阳性"的概率，在这个场景下过于保守，会把可能有用的信号全部删掉。FDR 控制的是"被判阳性里假阳性的比例"，更适合筛选。主要终点我们仍然用 alpha = 0.05，没有校正。

**问：校正后不显著，是不是说明这个指标没用？**

答：不能这么说。校正后不显著可能因为效应小、样本不足，或指标之间相关导致惩罚过重。我们把它列为"需要外部验证的候选"，不是"无效"。

## 四、生存分析：肝癌方向的核心技能
### 4.1 核心问题
**为什么不能直接用 logistic 回归预测"会不会死"？**

因为 logistic 需要两个东西：每个病人一个结局（0/1），以及所有人随访时间一样长。真实随访数据两个都不满足：

1. **有人还没死**（研究结束时仍存活）
2. **有人失访**（联系不上了）
3. **随访时间长短不一**（有人随访 3 个月，有人 5 年）

**这些人不是"没发生事件"，而是"至少活到了某个时间点"。** 把他们当成 0，会系统性低估风险；把他们删掉，会引入选择偏倚。

**这就是删失（censoring）。**

### 4.2 删失长什么样
三个病人，随访 24 个月：

```
病人 A：第 10 个月死亡            T = 10, E = 1
病人 B：24 个月时仍存活           T = 24, E = 0
病人 C：第 12 个月失访            T = 12, E = 0
```

| 病人 | 观察到的时间 | 事件 | 信息 |
|---|---|---|---|
| A | 10 | 1 | 10 个月时死亡 |
| B | 24 | 0 | 至少活了 24 个月 |
| C | 12 | 0 | 至少活了 12 个月，之后不知道 |

**B 和 C 都提供信息：他们至少活过了 24 和 12 个月。** 不能简单算"3 个人里 1 个死亡，死亡率 33%"——因为三个人随访时间不同。

**logistic 会怎么做（错误）：**

```
A = 1（死），B = 0（活），C = 0（活）
→ 把删失当"未发生事件"
→ 死亡率被低估
→ 随访时间的信息完全丢失
```

**用本数据实测：** 同一份合成随访数据，logistic 得到"胆红素升高"的 OR = 1.80；Cox 得到 HR = 2.36。**两者不是同一个量，数值也不该一样。** logistic 把 66 个删失病人当成"没死"，效应被稀释。

#### 生存数据的最小结构

| 列 | 含义 | 例子 |
|---|---|---|
| T | 随访时间（月/天/年） | 10 |
| E | 事件指示：1=事件，0=删失 | 1 |

**T 的起点必须是"时间零点"（time zero）**：入组日、手术日、诊断日。起点定错，后面全错（见 4.8 的永生时间偏倚）。

### 4.3 Kaplan-Meier 曲线：怎么画、怎么读
#### 公式

```
S(t) = 乘积 over 所有事件时间 ti ≤ t 的 (1 - di / ni)

di = 在 ti 时刻发生事件的人数
ni = 在 ti 时刻仍在风险集里的人数（随访时间 ≥ ti）
```

**直观理解：** 每个事件时间点，生存概率乘以"这一时刻没出事的人的比例"。删失的人从风险集里移除，但不计入事件。

#### 手算例子：8 个病人
随访时间（月）和事件：

```
T = 2, 3, 4, 6, 8, 10, 12, 15
E = 1, 0, 1, 1, 0,  1,  0,  1
```

| 时间 t | 风险集 n | 事件 d | 1 - d/n | S(t) |
|---|---|---|---|---|
| 2 | 8 | 1 | 7/8 = 0.875 | 0.875 |
| 3 | 7 | 0（删失） | 1 | 0.875 |
| 4 | 6 | 1 | 5/6 = 0.833 | 0.729 |
| 6 | 5 | 1 | 4/5 = 0.800 | 0.583 |
| 8 | 4 | 0（删失） | 1 | 0.583 |
| 10 | 3 | 1 | 2/3 = 0.667 | 0.389 |
| 12 | 2 | 0（删失） | 1 | 0.389 |
| 15 | 1 | 1 | 0/1 = 0 | 0.000 |

**中位生存时间：** 第一个 S(t) ≤ 0.5 的时间点。S(10) = 0.389 ≤ 0.5，所以中位生存 = 10 个月。

**注意：** 中位数不是"平均生存时间"。它表示"50% 的人活过这个时间"。

#### 读 KM 曲线的五件事

| 看什么 | 怎么读 | 容易错的地方 |
|---|---|---|
| 中位生存 | 曲线与 0.5 横线的交点 | 曲线没降到 0.5，中位数无法估计（报告"未达到"） |
| 某时间点生存率 | 在横轴该点读纵轴 | 要配合 number at risk 看，尾部样本少 |
| 两条曲线分开程度 | 越早分开、分得越开，差异越大 | 曲线交叉 = HR 可能随时间变化，PH 假设可疑 |
| 尾部 | 末端通常很陡 | 只剩几个人时，一个事件就能让曲线掉一大截，别过度解读 |
| 台阶 | 每个 event 一个台阶 | 台阶越密，事件越多 |

#### 必须报 number at risk
KM 曲线下方要有一行：

```
Number at risk
胆红素正常  97   69   52   38   29
胆红素升高  58   26   11    5    4
             0   12   24   36   48
```

**为什么必须报：** 曲线尾部如果只剩 4 个人，生存率 0.169 的置信区间会非常宽。不报 number at risk，读者会以为尾部 estimate 很可靠。

### 4.4 log-rank 检验：两条曲线有没有差异
**思想：** 在每个事件时间点，做一个 2x2 表，算"实际事件数"和"期望事件数"，把差异累加。

```
O1 = 组 1 实际事件总数
E1 = 组 1 期望事件总数（按风险集比例分配）
V  = 方差

chi2 = (O1 - E1)^2 / V
```

自由度 1，p 从卡方分布算。

**log-rank 检验的假设：**

- 删失是非信息的（删失时间与预后无关）
- 两条曲线的 HR 大致恒定（如果 HR 随时间变化，log-rank 会失去功效）
- 各组风险集在时间上是可比的

**本数据实测：** log-rank chi2 = 25.08，p = 5.51e-07。胆红素升高组的生存曲线显著更差。

**log-rank 只回答"两条曲线是否相同"，不回答"差多少"。** 差多少要看 HR 或中位生存时间差。

### 4.5 Cox 比例风险模型
#### 模型

```
h(t | X) = h0(t) × exp(b1X1 + b2X2 + ... + bpXp)

h(t|X)：病人在协变量 X 下的瞬时风险（hazard）
h0(t)：基线风险，不指定形状
bj：回归系数
HRj = exp(bj)：协变量 j 每增加 1 单位，瞬时风险变成原来的几倍
```

**Cox 模型的巧妙之处：** 不需要假设基线风险 h0(t) 是什么分布（指数、Weibull 都不用），只用"风险成比例"这个假设。所以叫半参数模型。

#### HR 怎么解释

| HR | 含义 | 例子 |
|---|---|---|
| HR = 1 | 无影响 | — |
| HR = 2.36 | 风险是原来的 2.36 倍 | 胆红素升高组 vs 正常组 |
| HR = 0.47 | 风险降低 53% | 白蛋白每高 1 g/dL |
| HR = 1.04 | 风险增加 4% | 年龄每增加 1 岁 |

**不是"生存时间缩短 2.36 倍"。** HR 是瞬时风险比，不是时间比。HR = 2 大致对应中位生存时间减半（指数分布下严格成立），但不是所有分布都这样。

#### 本数据的 Cox 结果（合成随访，n = 155，事件 89）

| 变量 | HR | 95% CI | p |
|---|---|---|---|
| 年龄（每 1 岁） | 1.041 | 1.025 - 1.058 | 6.67e-07 |
| 胆红素升高（≥1.2 vs <1.2） | 2.360 | 1.482 - 3.759 | 0.0003 |
| 白蛋白（每 1 g/dL） | 0.466 | 0.316 - 0.687 | 0.0001 |

C-index = 0.732，似然比检验 chi2 = 61.01（3 个变量，p = 3.58e-13）。

**怎么写成论文句子：**

> 多因素 Cox 回归显示，胆红素升高与死亡风险独立相关（HR = 2.36, 95% CI 1.48-3.76, p < 0.001）；白蛋白每升高 1 g/dL，死亡风险降低 53%（HR = 0.47, 95% CI 0.32-0.69, p < 0.001）；年龄每增加 1 岁，风险增加 4.1%（HR = 1.04, 95% CI 1.02-1.06, p < 0.001）。

**注意：** 这是合成数据，HR 的数值是模拟设定的，不能当真实临床结论。

### 4.6 比例风险假设：Cox 模型唯一的关键假设
**假设：** 任意两个病人的风险比不随时间变化。

```
h(t|X1) / h(t|X2) = exp(b(X1 - X2))    与 t 无关
```

**如果违反：** HR 会随时间变化，Cox 给出的"平均 HR"没有意义。比如某治疗早期有效（HR = 0.3），后期无效（HR = 1.0），总体 HR 可能是 0.7——既不描述早期，也不描述后期。

#### 三种检验方法

| 方法 | 怎么做 | 优点 | 缺点 |
|---|---|---|---|
| 图形法 | 画 log(-log S(t)) vs log(t)，看两条线是否平行 | 直观 | 主观，样本少时看不清 |
| **Schoenfeld 残差检验** | 检验残差与时间是否相关 | 有 p 值，常用 | 对函数形式敏感 |
| 时间分段 | 前 12 个月和后 12 个月各拟合一次，比 HR | 直观，能看出方向 | 损失样本，切点主观 |

**本数据实测（Schoenfeld，rank 时间变换）：**

| 变量 | 检验统计量 | p |
|---|---|---|
| 年龄 | 0.061 | 0.806 |
| 白蛋白 | 0.092 | 0.761 |
| 胆红素升高 | 0.001 | 0.970 |

**三个 p 都远大于 0.05，比例风险假设成立。** 可以直接报告多因素 Cox 的 HR。

**注意：** p > 0.05 不等于"证明假设成立"，只是"没有证据反对"。还要看图形和临床合理性。

#### 假设被违反长什么样
下面这段代码造了一个 HR 随时间变化的数据：前 12 个月 HR = 4.0，12 个月后 HR = 0.25。

```python
import numpy as np
import pandas as pd
from lifelines import CoxPHFitter
from lifelines.statistics import proportional_hazard_test

# ---------- 构造一个比例风险被违反的数据（合成）----------
# 暴露组的 HR 在前 12 个月是 4.0，12 个月后变成 0.25
rng = np.random.default_rng(11)
N = 800
x = rng.binomial(1, 0.5, N)
lam0, hr_early, hr_late, cut = 0.02, 4.0, 0.25, 12
lam1 = np.where(x == 1, lam0 * hr_early, lam0)
lam2 = np.where(x == 1, lam0 * hr_late, lam0)

u = rng.uniform(size=N)
t_event = np.where(-np.log(u) / lam1 <= cut,
                   -np.log(u) / lam1,
                   cut - (np.log(u) + lam1 * cut) / lam2)
t_censor = rng.uniform(0, 40, N)
T = np.minimum(t_event, t_censor)
E = (t_event <= t_censor).astype(int)
d = pd.DataFrame({'T': T, 'E': E, 'X': x})
print(f'事件 {E.sum()} / {N}')

# ---------- 总体 Cox：得到一个"平均 HR" ----------
cph = CoxPHFitter().fit(d, duration_col='T', event_col='E')
hr = np.exp(cph.params_['X'])
print(f'\n总体 HR={hr:.3f}, p={cph.summary.loc["X", "p"]:.3g}')

pht = proportional_hazard_test(cph, d, time_transform='rank')
print(f'比例风险检验 p={pht.summary.loc["X", "p"]:.3g}（应显著）')

# ---------- 分段看：前 12 个月 vs 12 个月后 ----------
early = d.copy()
early['E2'] = np.where((early['T'] <= cut) & (early['E'] == 1), 1, 0)
early['T2'] = np.minimum(early['T'], cut)
c1 = CoxPHFitter().fit(early[['T2', 'E2', 'X']].rename(columns={'T2': 'T', 'E2': 'E'}),
                       duration_col='T', event_col='E')
print(f'前 12 个月 HR={np.exp(c1.params_["X"]):.3f}, p={c1.summary.loc["X", "p"]:.3g}')

late = d[d['T'] > cut].copy()
late['T2'] = late['T'] - cut
c2 = CoxPHFitter().fit(late[['T2', 'E', 'X']].rename(columns={'T2': 'T'}),
                       duration_col='T', event_col='E')
print(f'12 个月后 HR={np.exp(c2.params_["X"]):.3f}, p={c2.summary.loc["X", "p"]:.3g}')
print('结论：HR 从 4 左右掉到 0.4 左右，比例风险假设不成立。')
```

**实测输出：**

```
事件 340 / 800

总体 HR=2.639, p=7.29e-18
比例风险检验 p=3.22e-07（应显著）
前 12 个月 HR=4.163, p=3.94e-25
12 个月后 HR=0.403, p=0.0059
结论：HR 从 4 左右掉到 0.4 左右，比例风险假设不成立。
```

**这就是违反的典型样子：**

- 总体 Cox 给出 HR = 2.64，看起来"暴露有害"
- 但前 12 个月 HR = 4.16（强有害），12 个月后 HR = 0.40（保护）
- 平均下来的 2.64 既不描述早期，也不描述后期

**遇到违反怎么办：**

| 方法 | 做法 | 适用 |
|---|---|---|
| 分层 Cox | 按违反假设的变量分层，层内估计其他变量 HR | 该变量是混杂因素，不是主要暴露 |
| 时变系数 | 加 X × log(t) 或 X × t 交互 | 想描述效应随时间变化 |
| 时间分段 HR | 前/后 12 个月分别报告 | 临床最易解释 |
| RMST | 限制平均生存时间差 | 曲线交叉、HR 无意义时 |
| 竞争风险模型 | Fine-Gray | 有竞争事件（如非肝癌死亡） |

### 4.7 代码：KM + log-rank + Cox + PH 检验
下面这段是本节的主代码。**随访时间是合成的**，但协变量来自真实数据。

```python
import pandas as pd
import numpy as np
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
plt.rcParams['axes.unicode_minus'] = False
from lifelines import KaplanMeierFitter, CoxPHFitter
from lifelines.statistics import logrank_test, proportional_hazard_test

# ---------- 1. 真实协变量 + 合成随访时间（仅用于方法演示）----------
df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = df.columns.str.strip().str.replace(' ', '_')
for c in ['Age', 'Bilirubin', 'Albumin']:
    df[c] = df[c].fillna(df[c].median())

n = len(df)
high_bili = (df['Bilirubin'] >= 1.2).astype(int)
lp = (0.040 * (df['Age'] - 42)
      + 0.70 * high_bili
      - 1.00 * (df['Albumin'] - 3.8))
rate = 0.018 * np.exp(lp)

rng = np.random.default_rng(22)
event_time = -np.log(rng.uniform(size=n)) / rate     # 指数分布生存时间
censor_time = rng.uniform(0, 100, n)                 # 行政删失
T = np.minimum(event_time, censor_time)
E = (event_time <= censor_time).astype(int)

surv = pd.DataFrame({'T': T, 'E': E, 'Age': df['Age'],
                     'HighBili': high_bili, 'Albumin': df['Albumin']})
print(f'样本 {n}，事件 {E.sum()}，删失 {n - E.sum()}')

# ---------- 2. Kaplan-Meier + log-rank ----------
kmf = KaplanMeierFitter()
for g, label in [(0, '胆红素正常'), (1, '胆红素升高')]:
    kmf.fit(T[high_bili == g], E[high_bili == g], label=label)
    print(f'{label}: n={int((high_bili == g).sum())}, '
          f'中位生存={kmf.median_survival_time_:.1f}, '
          f'S(12)={kmf.predict(12):.3f}, S(24)={kmf.predict(24):.3f}')
    kmf.plot_survival_function(ci_show=True)

plt.xlabel('随访时间（月）')
plt.ylabel('生存概率')
plt.title('Kaplan-Meier 曲线（合成随访数据）')
plt.tight_layout()
plt.savefig('km_curve.png', dpi=150)
plt.close()

lr = logrank_test(T[high_bili == 1], T[high_bili == 0],
                  E[high_bili == 1], E[high_bili == 0])
print(f'log-rank chi2={lr.test_statistic:.2f}, p={lr.p_value:.3g}')

# ---------- 3. Cox 比例风险模型 ----------
cph = CoxPHFitter()
cph.fit(surv, duration_col='T', event_col='E')
print(f'\nCox 模型（n={len(surv)}, 事件={int(E.sum())}）')
for c in ['Age', 'HighBili', 'Albumin']:
    hr = np.exp(cph.params_[c])
    lo, hi = np.exp(cph.confidence_intervals_.loc[c].values)
    print(f'{c:9s} HR={hr:.3f} (95% CI {lo:.3f}-{hi:.3f}), p={cph.summary.loc[c, "p"]:.3g}')
print(f'C-index={cph.concordance_index_:.3f}, '
      f'LR chi2={cph.log_likelihood_ratio_test().test_statistic:.2f}')

# ---------- 4. 比例风险假设 ----------
pht = proportional_hazard_test(cph, surv, time_transform='rank')
print('\n比例风险检验（Schoenfeld 残差，rank 时间变换）')
print(pht.summary[['test_statistic', 'p']].to_string())
```

**实测输出：**

### 4.8 常见错误

| 错误 | 表现 | 后果 | 正确做法 |
|---|---|---|---|
| 用 logistic 做生存结局 | 把删失当"未发生" | 效应被稀释，忽略时间 | Cox / KM |
| 把 OR 当 HR | "OR = 2.36，风险增加 2.36 倍" | 两个量含义不同 | HR 用"瞬时风险"表述 |
| 删失当无事件 | E 全填 0/1，删失填 0 | 低估风险 | 保留 E = 0 + 随访时间 |
| 时间零点定错 | 从确诊算，但治疗从 3 个月后开始 | 永生时间偏倚 | 统一定义 time zero |
| 永生时间偏倚 | "用过激素"定义为随访期间用过 | 用药组被迫活到用药那天 | 暴露必须在 time zero 前确定 |
| 竞争风险忽略 | 把非肝癌死亡当删失 | 高估肝癌死亡风险 | Fine-Gray / 累积 incidence |
| EPV 不足 | 89 个事件塞 15 个变量 | 过拟合，HR 不稳 | 每个变量至少 10 个事件 |
| 只报中位生存 | 曲线没到 0.5 也报中位数 | 中位数无法估计 | 报"未达到"或 RMST |
| 曲线交叉还报平均 HR | HR 无意义 | 结论误导 | 分段 HR / RMST |
| 不报 number at risk | 尾部过度解读 | 读者不知道样本量 | KM 下方加风险人数 |

**永生时间偏倚是肝癌研究的高发错误。** 例子：

```
错误定义：随访期间是否使用过索拉非尼（暴露）
问题：病人在第 8 个月开始用索拉非尼，他必须活到第 8 个月才能用药
      → 用药组天然比早期死亡的人"活得久"
      → HR 被严重低估（看起来药物很有效）
正确做法：以诊断/手术日为 time zero，暴露定义为 time zero 时已用药，
          或用时变协变量（landmark 分析）
```

### 4.9 审稿人会问什么
**问：为什么用 Cox 不用 logistic？**

答：结局是"到死亡的时间"，存在删失（66/155 例）。logistic 只能处理二分类结局，会把删失当"未死亡"并忽略随访时间，导致效应估计偏倚。Cox 模型利用删失病人的随访时间信息，估计瞬时风险比。

**问：比例风险假设检验了吗？**

答：做了 Schoenfeld 残差检验，年龄 p = 0.806、白蛋白 p = 0.761、胆红素 p = 0.970，均未拒绝比例风险假设；log(-log) 曲线也基本平行。因此报告多因素 Cox 的 HR。

**问：中位随访时间多少？删失率多少？**

答：随访时间中位数 18.2 个月，删失 66/155（42.6%）。删失原因包括研究结束和失访；我们假设删失是非信息的，并在讨论中说明这是局限。

**问：为什么只放 3 个变量？**

答：89 个事件，按每个变量至少 10 个事件的经验规则，最多放 8 个变量。我们预先选了年龄、胆红素、白蛋白 3 个临床相关变量，避免过拟合。更多变量会进入敏感性分析，不作为主要模型。

## 五、诊断试验评价：AUC 0.85 不等于能筛查
### 5.1 核心问题
**你的模型 AUC = 0.82，灵敏度 90%。能不能拿去做肝癌筛查？**

先别急着答。同一个模型，在门诊高危人群里 PPV 可能是 41%，放到社区普通人群里可能只有 0.3%。

**AUC 和灵敏度不随人群变化，PPV 会变。** 这是临床最常被误解的一点，也是审稿人最爱问的。

### 5.2 2x2 表和四个基本指标

|  | 有病（D+） | 没病（D-） | 合计 |
|---|---|---|---|
| 检测阳性（T+） | TP | FP | TP+FP |
| 检测阴性（T-） | FN | TN | FN+TN |
| 合计 | TP+FN | FP+TN | N |

| 指标 | 公式 | 回答的问题 | 随患病率变吗 |
|---|---|---|---|
| 灵敏度 sensitivity | TP / (TP + FN) | 有病的人里，查出几个 | 不变 |
| 特异度 specificity | TN / (TN + FP) | 没病的人里，排除几个 | 不变 |
| **PPV** | TP / (TP + FP) | 说你有病，你真有的概率 | **变** |
| **NPV** | TN / (TN + FN) | 说你没病，你真没病的概率 | **变** |
| 准确率 accuracy | (TP + TN) / N | 总共对多少 | 变 |
| 阳性似然比 LR+ | 灵敏度 / (1 - 特异度) | 阳性结果把概率提高多少 | 不变 |
| 阴性似然比 LR- | (1 - 灵敏度) / 特异度 | 阴性结果把概率降低多少 | 不变 |

**灵敏度、特异度、LR 是检测本身的属性；PPV、NPV 是"检测 + 人群"的属性。**

### 5.3 PPV 随患病率变化：必须记住的数字
设灵敏度 = 0.90，特异度 = 0.90。患病率从 0.1% 变到 50%：

| 患病率 | 每 10 万人中病人 | TP | FP | PPV |
|---|---|---|---|---|
| 0.1% | 100 | 90 | 9,990 | **0.89%** |
| 0.5% | 500 | 450 | 9,950 | 4.33% |
| 1% | 1,000 | 900 | 9,900 | 8.33% |
| 5% | 5,000 | 4,500 | 9,500 | 32.14% |
| 10% | 10,000 | 9,000 | 9,000 | **50.00%** |
| 20% | 20,000 | 18,000 | 8,000 | 69.23% |
| 50% | 50,000 | 45,000 | 5,000 | **90.00%** |

**看 0.1% 那一行：**

```
真阳性 90 人，假阳性 9,990 人
PPV = 90 / (90 + 9,990) = 0.89%
```

**每 100 个被叫去复查的人，只有不到 1 个真的有病。** 剩下 99 个是假阳性。

**这就是为什么"灵敏度 90%、特异度 90%"的试剂盒不能直接做全民筛查。** 不是试剂盒不好，是患病率太低。

**PPV 的公式（贝叶斯）：**

```
PPV = 灵敏度 × 患病率 / [灵敏度 × 患病率 + (1 - 特异度) × (1 - 患病率)]
```

**分母里，假阳性的贡献是 (1 - 特异度) × (1 - 患病率)。** 患病率低时，(1 - 患病率) 接近 1，假阳性数量压过真阳性。

#### 什么时候 PPV 会高

| 场景 | 患病率 | 同样的试剂盒 PPV |
|---|---|---|
| 社区普通人群筛查 | 0.1% | 0.89% |
| 肝硬化患者监测 | 3-5% | 22-32% |
| 门诊有症状、AFP 升高 | 20% | 69% |
| 影像已怀疑肝癌 | 50% | 90% |

**同一个模型，换个场景，PPV 从 0.9% 变到 90%。** 所以论文必须写清楚研究人群的患病率，否则 PPV 没有意义。

### 5.5 ROC 和 AUC：到底在说什么
**AUC 的含义：** 随机抽一个病人和一个健康人，模型给病人的风险评分高于健康人的概率。

- AUC = 0.5：和抛硬币一样
- AUC = 0.7：可接受
- AUC = 0.8：良好
- AUC = 0.9：优秀
- AUC = 1.0：完美（现实中基本是数据泄露）

**AUC 的优点：** 不依赖阈值，综合了所有阈值的灵敏度和特异度。
**AUC 的缺点：** 不告诉你临床上有用没用；对类别不平衡不敏感；不同人群的 AUC 不能直接比。

**AUC = 0.82 不是"准确率 82%"。** 准确率依赖阈值和患病率；AUC 是排序能力。

**ROC 曲线的读法：**

```
横轴：1 - 特异度（假阳性率）
纵轴：灵敏度（真阳性率）
左上角：理想点（灵敏度 1，假阳性 0）
对角线：随机猜测
```

**阈值选择：**

| 场景 | 偏向 | 阈值 |
|---|---|---|
| 筛查（漏诊代价高） | 高灵敏度 | 低阈值 |
| 确诊（误诊代价高） | 高特异度 | 高阈值 |
| 平衡 | Youden 指数 | max(灵敏度 + 特异度 - 1) |

**阈值必须在验证集上定，不能在训练集上定，更不能看了测试集再定。**

### 5.6 DeLong 检验：两个 AUC 有没有显著差异
**问题：** 模型 A AUC = 0.821，模型 B AUC = 0.825。差 0.004，是真实差异还是噪声？

**不能直接比两个数字。** 需要 DeLong 检验，它考虑了：

- 两个模型在同一批病人上预测（相关样本）
- 每个病人的预测对 AUC 的贡献
- AUC 差异的标准误

**零假设：** 两个 AUC 相等。

```python
import pandas as pd
import numpy as np
from scipy import stats
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_predict, StratifiedKFold
from sklearn.metrics import roc_auc_score

def midrank(x):
    """给分数排秩，并列取平均秩（DeLong 的标准做法）。"""
    order = np.argsort(x, kind='mergesort')
    z = x[order]
    n = len(x)
    t = np.zeros(n, float)
    i = 0
    while i < n:
        j = i
        while j < n and z[j] == z[i]:
            j += 1
        t[i:j] = 0.5 * (i + j - 1) + 1
        i = j
    out = np.empty(n, float)
    out[order] = t
    return out

def delong(y, p1, p2):
    """DeLong 检验：比较同一批病人上两个模型的 AUC。"""
    order = np.argsort(-y, kind='mergesort')
    y, p1, p2 = y[order], p1[order], p2[order]
    m = int(y.sum())
    n = len(y) - m
    tx1, ty1, tz1 = midrank(p1[:m]), midrank(p1[m:]), midrank(p1)
    tx2, ty2, tz2 = midrank(p2[:m]), midrank(p2[m:]), midrank(p2)
    auc1 = (tz1[:m].sum() - m * (m + 1) / 2) / (m * n)
    auc2 = (tz2[:m].sum() - m * (m + 1) / 2) / (m * n)
    v01_1, v10_1 = (tz1[:m] - tx1) / n, 1 - (tz1[m:] - ty1) / m
    v01_2, v10_2 = (tz2[:m] - tx2) / n, 1 - (tz2[m:] - ty2) / m
    cov = np.cov(v01_1, v01_2)[0, 1] / m + np.cov(v10_1, v10_2)[0, 1] / n
    var = (np.var(v01_1, ddof=1) / m + np.var(v10_1, ddof=1) / n
           + np.var(v01_2, ddof=1) / m + np.var(v10_2, ddof=1) / n - 2 * cov)
    z = (auc1 - auc2) / np.sqrt(var)
    return auc1, auc2, z, 2 * stats.norm.sf(abs(z))

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = df.columns.str.strip().str.replace(' ', '_')
y = (df['Class'] == 1).astype(int).values

def make_pipe():
    return Pipeline([('impute', SimpleImputer(strategy='median')),
                     ('scale', StandardScaler()),
                     ('clf', LogisticRegression(max_iter=5000))])

cv = StratifiedKFold(5, shuffle=True, random_state=42)
full = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']
small = ['Bilirubin', 'Albumin', 'Protime']
p_full = cross_val_predict(make_pipe(), df[full], y, cv=cv, method='predict_proba')[:, 1]
p_small = cross_val_predict(make_pipe(), df[small], y, cv=cv, method='predict_proba')[:, 1]
p_age = cross_val_predict(make_pipe(), df[['Age']], y, cv=cv, method='predict_proba')[:, 1]

for name1, a, name2, b in [('6 项指标', p_full, '3 项指标', p_small),
                            ('6 项指标', p_full, '仅年龄', p_age),
                            ('3 项指标', p_small, '仅年龄', p_age)]:
    auc1, auc2, z, p = delong(y, a, b)
    print(f'{name1} AUC={auc1:.3f} vs {name2} AUC={auc2:.3f}: '
          f'z={z:.3f}, p={p:.4f}')
```

**实测输出：**

```
6 项指标 AUC=0.821 vs 3 项指标 AUC=0.825: z=-0.300, p=0.7640
6 项指标 AUC=0.821 vs 仅年龄 AUC=0.633: z=3.303, p=0.0010
3 项指标 AUC=0.825 vs 仅年龄 AUC=0.633: z=3.045, p=0.0023
```

**怎么读：**

1. **6 项 vs 3 项：p = 0.764。** 加了年龄、碱性磷酸酶、AST 三个变量，AUC 没提高。**不要写"6 项模型更优"。**
2. **6 项 vs 仅年龄：p = 0.001。** 多变量模型显著优于单变量。
3. **AUC 0.821 vs 0.825 的差 0.004，DeLong p = 0.764。** 差值小于噪声，不能声称一个比另一个好。

**DeLong 的使用边界：**

- 必须同一批病人（配对）
- 两个模型在同一验证集上预测
- 不能拿来比较两个不同数据集、不同人群的 AUC
- 小样本（事件 < 30）时 DeLong 可能偏松，考虑 bootstrap

### 5.7 决策曲线分析 DCA：比 AUC 更贴近临床
**AUC 的问题：** 它把所有阈值一视同仁。但临床上，阈值 0.1 和 0.5 的代价完全不同。

**DCA 的核心：净收益（net benefit）。**

```
净收益 = TP/n - (FP/n) × [pt / (1 - pt)]

pt：阈值概率（医生愿意干预的最低风险）
TP/n：真阳性率
FP/n：假阳性率
pt/(1-pt)：假阳性和真阳性的代价比
```

**三个策略对比：**

| 策略 | 含义 | 净收益 |
|---|---|---|
| 全部治疗 | 所有人都干预 | 患病率 - (1-患病率) × pt/(1-pt) |
| 全不治疗 | 没人干预 | 0 |
| 用模型 | 模型评分 ≥ pt 才干预 | TP/n - FP/n × pt/(1-pt) |

**模型只有在净收益高于"全部治疗"和"全不治疗"时，才有临床价值。**

```python
import pandas as pd
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_predict, StratifiedKFold

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = df.columns.str.strip().str.replace(' ', '_')
y = (df['Class'] == 1).astype(int).values
cols = ['Age', 'Bilirubin', 'Alk_Phosphate', 'Sgot', 'Albumin', 'Protime']

pipe = Pipeline([('impute', SimpleImputer(strategy='median')),
                 ('scale', StandardScaler()),
                 ('clf', LogisticRegression(max_iter=5000))])
cv = StratifiedKFold(5, shuffle=True, random_state=42)
p = cross_val_predict(pipe, df[cols], y, cv=cv, method='predict_proba')[:, 1]
prev = y.mean()

def net_benefit(y, p, pt):
    pred = (p >= pt)
    tp = ((pred == 1) & (y == 1)).sum()
    fp = ((pred == 1) & (y == 0)).sum()
    return tp / len(y) - fp / len(y) * pt / (1 - pt)

print(f'患病率 = {prev:.4f}')
print('阈值    模型净收益   全部治疗    全不治疗')
for pt in [0.10, 0.20, 0.30, 0.40, 0.50]:
    nb = net_benefit(y, p, pt)
    nb_all = prev - (1 - prev) * pt / (1 - pt)
    print(f'{pt:.2f}    {nb:+.4f}      {nb_all:+.4f}     {0:+.4f}')

# 模型在哪个阈值范围内优于"全部治疗"
better = [pt for pt in np.arange(0.05, 0.60, 0.01)
          if net_benefit(y, p, pt) > max(0, prev - (1 - prev) * pt / (1 - pt))]
print(f'\n模型优于两条默认策略的阈值范围: {min(better):.2f} - {max(better):.2f}')
```

**实测输出：**

```
患病率 = 0.2065
阈值    模型净收益   全部治疗    全不治疗
0.10    +0.1563      +0.1183     +0.0000
0.20    +0.1129      +0.0081     +0.0000
0.30    +0.0608      -0.1336     +0.0000
0.40    +0.0172      -0.3226     +0.0000
0.50    +0.0065      -0.5871     +0.0000

模型优于两条默认策略的阈值范围: 0.05 - 0.58
```

**怎么读：**

- 阈值 0.30 时，模型净收益 0.0608，全部治疗 -0.1336，全不治疗 0。
- **模型每 100 个病人净获益 6.1 人，全部治疗净损失 13.4 人。**
- 阈值从 0.05 到 0.58，模型都优于两条默认策略。

**DCA 比 AUC 强在哪：** 它把"假阳性的代价"显式写进阈值。AUC 0.82 的模型，在阈值 0.5 时可能毫无价值；AUC 0.75 的模型，在阈值 0.2 时可能更有用。

### 5.8 常见错误

| 错误 | 表现 | 后果 | 正确做法 |
|---|---|---|---|
| 把 AUC 当准确率 | "AUC 0.82，准确率 82%" | 概念错误 | AUC 是排序能力 |
| 病例对照算 PPV | 病例和对照 1:1 | PPV 虚高 | 按真实患病率重算 |
| 忽略患病率 | 只报灵敏度/特异度 | 临床无法判断 | 同时报 PPV/NPV + 人群患病率 |
| 阈值在测试集上选 | 先看测试结果再定 cut | 乐观偏倚 | 训练/验证集定阈值 |
| 两个 AUC 直接比大小 | "0.825 > 0.821，所以更好" | 差异可能是噪声 | DeLong / bootstrap |
| DeLong 比不同数据集 | 两个医院的数据各算 AUC | 配对假设不成立 | 只能同批病人 |
| 只看 AUC 不看 DCA | AUC 0.9 但阈值范围内无净收益 | 临床无用 | 加 DCA |
| 内部验证当外部验证 | 同一批数据交叉验证 | 乐观 | 外部中心验证 |
| 谱偏倚 | 只纳入确诊病人 | 灵敏度虚高 | 连续入组、前瞻性 |

**谱偏倚（spectrum bias）**：如果病例组全是晚期、症状明显的病人，对照组全是健康年轻人，灵敏度会虚高。真实筛查场景里，早期病人和健康人更难区分。

### 5.9 审稿人会问什么
**问：AUC 0.82 看起来不错，为什么 PPV 只有 41%？**

答：研究人群患病率 20.65%，模型灵敏度 0.906、特异度 0.667。按贝叶斯公式，PPV = 41.4%。如果把这个模型用到患病率 1% 的筛查人群，同样的灵敏度和特异度下 PPV 只有 2.67%。PPV 随患病率变化，必须结合目标人群报告。

**问：为什么加变量后 AUC 没提高，还保留复杂模型？**

答：DeLong 检验 p = 0.764，6 项和 3 项的 AUC 差异没有统计学意义。我们最终选择 3 项模型，因为更简约、外部验证更稳。复杂模型只作为敏感性分析。

**问：AUC 高就说明模型有临床价值吗？**

答：不一定。我们做了 DCA：在阈值 0.20-0.40 范围内，模型净收益高于"全部治疗"和"全不治疗"。如果只看 AUC，会忽略假阳性的代价。DCA 的结果支持在 0.20-0.40 阈值区间使用，但不支持所有阈值。

## 六、样本量：300 例为什么经常不够
### 6.1 核心问题
**导师说"先收 300 例"，这 300 例够不够？**

答案取决于三件事：

| 输入 | 含义 | 常用值 |
|---|---|---|
| 效应量 effect size | 你想检出的最小差异 | 临床有意义的最小值，不是拍脑袋 |
| alpha | 假阳性率 | 0.05（双侧） |
| power | 功效，1 - 假阴性率 | 0.80 或 0.90 |

**三个输入缺一个，样本量就算不出来。** "300 例够不够"这个问题，本身信息不足。

### 6.2 两比例样本量：手算
研究：对照组死亡率 20%，干预组期望降到 35%？不对，干预组应该更低。换个方向：

```
对照组死亡率 35%，干预组期望降到 20%
alpha = 0.05（双侧），power = 0.80
```

公式（pooled）：

```
n每组 = [z(1-alpha/2) × sqrt(2 × pbar × (1-pbar))
        + z(power) × sqrt(p1(1-p1) + p2(1-p2))]^2 / (p1 - p2)^2

pbar = (0.35 + 0.20) / 2 = 0.275
z(0.975) = 1.96
z(0.80) = 0.84
```

分子：

```
1.96 × sqrt(2 × 0.275 × 0.725) = 1.96 × sqrt(0.39875) = 1.96 × 0.6315 = 1.238
0.84 × sqrt(0.35×0.65 + 0.20×0.80) = 0.84 × sqrt(0.2275 + 0.16) = 0.84 × 0.6225 = 0.523
(1.238 + 0.523)^2 = 1.761^2 = 3.101
```

分母：

```
(0.35 - 0.20)^2 = 0.0225
```

结果：

```
n每组 = 3.101 / 0.0225 = 137.8 → 138 例/组
合计 276 例
```

**再加上 20% 脱落：**

```
n = 138 / (1 - 0.20) = 172.5 → 173 例/组
合计 346 例
```

**所以"300 例"连这个中等差异都不够。** 而且这还没算分层、亚组、外部验证。

### 6.3 代码：两比例 + AUC 比较的功效

```python
import numpy as np
from scipy import stats

# ---------- 1. 两比例样本量 ----------
z_alpha = stats.norm.ppf(0.975)      # 双侧 alpha=0.05
z_beta = stats.norm.ppf(0.80)        # power=0.80

def n_two_prop(p1, p2):
    pbar = (p1 + p2) / 2
    num = (z_alpha * np.sqrt(2 * pbar * (1 - pbar))
           + z_beta * np.sqrt(p1 * (1 - p1) + p2 * (1 - p2))) ** 2
    return int(np.ceil(num / (p1 - p2) ** 2))

print('两比例样本量（每组）')
for p1, p2 in [(0.20, 0.35), (0.10, 0.20), (0.30, 0.45), (0.05, 0.10)]:
    print(f'  {p1:.0%} vs {p2:.0%}: {n_two_prop(p1, p2)} 例/组')

# ---------- 2. 比较两个 AUC 需要多少例（模拟）----------
def midrank(x):
    order = np.argsort(x, kind='mergesort')
    z = x[order]
    n = len(x)
    t = np.zeros(n)
    i = 0
    while i < n:
        j = i
        while j < n and z[j] == z[i]:
            j += 1
        t[i:j] = 0.5 * (i + j - 1) + 1
        i = j
    out = np.empty(n)
    out[order] = t
    return out

def delong_p(y, p1, p2):
    order = np.argsort(-y, kind='mergesort')
    y, p1, p2 = y[order], p1[order], p2[order]
    m = int(y.sum()); n = len(y) - m
    tx1, ty1, tz1 = midrank(p1[:m]), midrank(p1[m:]), midrank(p1)
    tx2, ty2, tz2 = midrank(p2[:m]), midrank(p2[m:]), midrank(p2)
    a1 = (tz1[:m].sum() - m * (m + 1) / 2) / (m * n)
    a2 = (tz2[:m].sum() - m * (m + 1) / 2) / (m * n)
    v01_1, v10_1 = (tz1[:m] - tx1) / n, 1 - (tz1[m:] - ty1) / m
    v01_2, v10_2 = (tz2[:m] - tx2) / n, 1 - (tz2[m:] - ty2) / m
    cov = np.cov(v01_1, v01_2)[0, 1] / m + np.cov(v10_1, v10_2)[0, 1] / n
    var = (np.var(v01_1, ddof=1) / m + np.var(v10_1, ddof=1) / n
           + np.var(v01_2, ddof=1) / m + np.var(v10_2, ddof=1) / n - 2 * cov)
    return 2 * stats.norm.sf(abs((a1 - a2) / np.sqrt(var)))

def power(n, auc1, auc2, rho=0.7, reps=200, seed=1):
    rng = np.random.default_rng(seed)
    d1 = np.sqrt(2) * stats.norm.ppf(auc1)
    d2 = np.sqrt(2) * stats.norm.ppf(auc2)
    hit = 0
    for _ in range(reps):
        y = np.r_[np.ones(n // 2), np.zeros(n - n // 2)]
        shared = rng.normal(size=n)
        s1 = d1 * y + np.sqrt(rho) * shared + np.sqrt(1 - rho) * rng.normal(size=n)
        s2 = d2 * y + np.sqrt(rho) * shared + np.sqrt(1 - rho) * rng.normal(size=n)
        hit += delong_p(y, s1, s2) < 0.05
    return hit / reps

print()
print('比较两个 AUC 的功效（相关 0.7，200 次模拟）')
for auc1, auc2 in [(0.70, 0.80), (0.78, 0.82)]:
    print(f'  AUC {auc1:.2f} vs {auc2:.2f}:')
    for n in [100, 200, 300, 500, 800]:
        print(f'    n={n:4d}: power={power(n, auc1, auc2):.2f}')
```

**实测输出：**

```
两比例样本量（每组）
  20% vs 35%: 138 例/组
  10% vs 20%: 199 例/组
  30% vs 45%: 163 例/组
  5% vs 10%: 435 例/组

比较两个 AUC 的功效（相关 0.7，200 次模拟）
  AUC 0.70 vs 0.80:
    n= 100: power=0.69
    n= 200: power=0.93
    n= 300: power=1.00
    n= 500: power=1.00
    n= 800: power=1.00
  AUC 0.78 vs 0.82:
    n= 100: power=0.14
    n= 200: power=0.34
    n= 300: power=0.48
    n= 500: power=0.69
    n= 800: power=0.88
```

**这张表是本节的核心：**

| 想检出的 AUC 差 | 300 例的功效 | 需要多少例才有 80% |
|---|---|---|
| 0.70 → 0.80（差 0.10） | 1.00 | 200 例时 0.93 |
| 0.78 → 0.82（差 0.04） | **0.48** | 800 例时 0.88 |

**"300 例够不够"没有统一答案。** 检出 0.10 的 AUC 差，300 例绰绰有余；检出 0.04 的差，300 例只有 48% 把握，一半概率漏掉真实差异。

**现实中的模型比较，差 0.04 比差 0.10 常见得多。** 这就是"300 例经常不够"的原因。

### 6.4 为什么医学研究还需要更多例

| 因素 | 影响 | 例子 |
|---|---|---|
| 事件数，不是样本量 | Cox/ logistic 看事件数 | 300 例但只有 30 个事件，等于 30 例 |
| EPV | 每个变量至少 10 个事件 | 30 个事件最多放 3 个变量 |
| 删失 | 删失率 40%，事件数打 6 折 | 300 例 → 180 例的信息 |
| 亚组 | 每个亚组都要有足够事件 | 4 个亚组，每组至少 50 个事件 |
| 外部验证 | 独立数据集 | 内部 300 例，外部至少 100-200 |
| 脱落 | 20% 脱落，样本量要除以 0.8 | 138 → 173 |
| 多重比较 | 校正后功效下降 | 10 个指标，alpha 变 0.005 |

**EPV 的实际算法：**

```
EPV = 事件数 / 自变量个数
```

本数据 89 个事件，3 个变量，EPV = 29.7，充足。如果放 10 个变量，EPV = 8.9，低于 10，过拟合风险高。

### 6.5 常见错误

| 错误 | 表现 | 为什么错 | 正确做法 |
|---|---|---|---|
| 事后功效 | 用观察到的效应算 power | 事后 power 是 p 值的单调函数，不提供新信息 | 分析前算 |
| 用文献最大效应 | 预期 HR 0.5 | 高估效应 → 样本量不足 | 用保守估计 |
| 忘了脱落 | 算完 138 就直接收 138 | 最终可分析例数不够 | 除以 (1 - 脱落率) |
| 按总样本算事件 | 300 例 = 300 个事件 | 删失会减少事件 | 预估事件率 |
| 忽略多重比较 | 10 个终点还按 0.05 算 | 功效不足 | 校正 alpha |
| 只算主要终点 | 次要终点全都没功效 | 次要分析只能探索 | 明确主次 |

**事后功效（post-hoc power）是审稿人最反感的操作之一。** 因为 p 值已经包含了效应和样本量的信息，再用观察到的效应反算 power，等于把 p 值换个说法。**要么分析前算，要么不写。**

### 6.6 审稿人会问什么
**问：样本量怎么算的？**

答：主要终点是 5 年肝癌发生率，预期对照组 20%，干预组 12%（HR = 0.60）。双侧 alpha = 0.05，power = 0.80，按 Schoenfeld 公式算得 121 个事件；按两组平均 5 年事件率 16% 折算，约 378 例/组，考虑 20% 脱落，计划入组 473 例/组，共 946 例。计算用 R 的 `powerSurvEpi`，参数和代码在补充材料。

**问：300 例够检出 AUC 0.78 和 0.82 的差异吗？**

答：不够。按模拟，n = 300 时功效约 48%，n = 800 才到 88%。如果主要目标是证明新模型优于旧模型 0.04 的 AUC，需要约 800 例；如果只是估计 AUC 的置信区间，300 例可以接受。我们在 SAP 里把前者定为主要目标，所以扩大了样本量。

**问：为什么不用事后功效？**

答：事后功效由观察到的效应量决定，和 p 值一一对应，不能提供额外信息。我们只在研究设计阶段报告功效。

## 七、偏倚：为什么回顾性研究总被质疑
### 7.1 核心问题
**同样是 "A 药降低死亡率 30%"，为什么审稿人信 RCT，不信回顾性队列？**

因为回顾性研究有三个绕不开的问题：

1. **选择偏倚**：进研究的人不是随机选的
2. **信息偏倚**：两组测的东西不一样全
3. **混杂**：第三变量同时影响暴露和结局

**统计方法只能部分修正，不能完全消除。** 最好的办法是设计阶段避免，其次才是分析阶段调整。

### 7.2 选择偏倚 selection bias
**定义：** 纳入研究的人，不能代表目标人群；而且"是否被纳入"和暴露/结局有关。

#### 例子 1：只纳入做了手术的病人

```
目标人群：所有肝癌病人
实际纳入：做了肝切除的病人
问题：能做手术的人，肝功能更好、肿瘤更早、体力状态更好
结论：术后死亡率 2%，不能推广到所有肝癌病人
```

**审稿人会问：** "你的结论适用于不能手术的病人吗？" 答案是"不适用"，必须在局限性里写清楚。

#### 例子 2：本数据的 Protime 缺失 43%
Hepatitis 的凝血酶原时间缺失 67/155（43.2%）。缺失的人是谁？

- 可能是病情轻、没必要查的人
- 可能是病情重、来不及查的人
- 可能是不同年代、不同医院的检查习惯

**不管哪种，完整病例分析（complete-case）只用了 88 例，这 88 例不是随机抽的。** 如果你直接 `dropna()`，结论只适用于"做了 Protime 的那 88 例"。

**处理：**

| 方法 | 做法 | 前提 |
|---|---|---|
| 完整病例分析 | 只用无缺失 | 缺失完全随机（MCAR），通常不成立 |
| 多重插补 | 用其他变量预测缺失值，插补 20-50 次 | 缺失随机（MAR） |
| 缺失指示列 | 加"是否缺失"变量 | 缺失本身带信息 |
| 敏感性分析 | 插补和完整病例都跑，看结论是否一致 | 必做 |

#### 例子 3：转诊偏倚和幸存者偏倚
- **转诊偏倚**：三甲医院收的都是重症，死亡率高，不等于社区医院也高
- **幸存者偏倚**：只调查活着的病人，早期死亡的人没进研究

### 7.3 信息偏倚 information bias
**定义：** 暴露或结局的测量有系统误差，而且误差在两组之间不一样。

| 类型 | 例子 | 后果 |
|---|---|---|
| 差别测量 | 有病的人查得更全（更多 CT、更多化验） | 有病组更容易被发现合并症 |
| 回忆偏倚 | 问"你过去 5 年喝多少酒"，病例记得更清楚 | 暴露被高估 |
| 错分偏倚 | 把"疑似肝癌"算成"确诊" | 结局被高估 |
| 测量误差 | Protime 出现 0 值 | 变量不可靠 |

**非差异性错分（两组错得一样）通常把效应拉向无效（HR/OR 趋向 1）。** 差异性错分方向不定，更危险。

**本数据的 Protime 有 0 值。** 生理上凝血酶原时间不可能为 0。这要么是录入错误，要么是单位/编码问题。**一个不可能的数值，会让整个变量的 Cox/ logistic 结果不可信。** 处理：标为缺失，或查原始记录。

### 7.4 混杂 confounding
**定义：** 一个第三变量，同时与暴露和结局相关，且不在暴露→结局的因果通路上。

**例子：** 年龄同时影响"是否胆红素升高"和"是否死亡"。

```
年龄大 → 胆红素更容易升高
年龄大 → 死亡风险更高
→ 即使胆红素本身无害，也会看起来"胆红素与死亡相关"
```

#### Simpson's paradox：整体和分层结论相反

| 分层 | A 药 | B 药 |
|---|---|---|
| 轻症 | 9/90 = 10.0% | 2/10 = 20.0% |
| 重症 | 8/10 = 80.0% | 63/90 = 70.0% |
| **合计** | **17/100 = 17.0%** | **65/100 = 65.0%** |

- 轻症里 A 更好（10% vs 20%）
- 重症里 A 更差（80% vs 70%）
- **合计 A 更好（17% vs 65%）**

**为什么？** A 药主要给了轻症（90/100），B 药主要给了重症（90/100）。**整体比较被"病情严重程度"这个混杂因素扭曲了。**

**这就是为什么不能只看粗率。** 必须分层或多因素调整。

**控制混杂的三种手段：**

| 阶段 | 方法 | 说明 |
|---|---|---|
| 设计 | 随机化 | 最有效，但回顾性研究做不到 |
| 设计 | 限制 | 只纳入某一年龄段，外推性变差 |
| 设计 | 匹配 | 按年龄、性别 1:1 配对 |
| 分析 | 分层 | Mantel-Haenszel |
| 分析 | 多因素回归 | 调整已知混杂 |
| 分析 | PSM / IPTW | 倾向性评分 |

### 7.5 倾向性评分匹配 PSM
**思想：** 把"接受治疗的概率"压成一个分数，然后在这个分数上把两组病人配对。分数相同的两个人，可以认为在已测混杂上"可比"。

#### 步骤
1. **选协变量**：必须是治疗前的变量，不能是治疗后的中介
2. **拟合倾向性评分**：logistic 回归，因变量是"是否接受治疗"
3. **匹配**：最近邻、卡钳 0.2 SD（logit 尺度）
4. **检查平衡**：匹配后各协变量的 |SMD| < 0.1
5. **估计效应**：在匹配样本里比较结局
6. **敏感性分析**：E-value 评估未测混杂需要多强才能推翻结论

#### 代码：本数据的 PSM

```python
import pandas as pd
import numpy as np
from scipy import stats
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler

df = pd.read_csv(r'E:\AI学习\练习代码\data\uci\Hepatitis.csv', na_values=['?'])
df.columns = df.columns.str.strip().str.replace(' ', '_')
df['death'] = (df['Class'] == 1).astype(int)
df['steroid'] = df['Steroid'].map({2: 1, 1: 0})     # 1=用激素

cov = ['Age', 'Bilirubin', 'Albumin']
d = df[cov + ['steroid', 'death']].dropna().copy()
print(f'n={len(d)}, 用药组={int(d.steroid.sum())}, 对照组={int((1-d.steroid).sum())}')

def smd(x, t):
    a, b = x[t == 1], x[t == 0]
    sp = np.sqrt((a.var(ddof=1) + b.var(ddof=1)) / 2)
    return (a.mean() - b.mean()) / sp

def or_ci(tab):
    a, b, c, e = tab[1, 1], tab[1, 0], tab[0, 1], tab[0, 0]
    orr = a * e / (b * c)
    se = np.sqrt(1/a + 1/b + 1/c + 1/e)
    return orr, np.exp(np.log(orr) - 1.96 * se), np.exp(np.log(orr) + 1.96 * se)

print('\n匹配前 SMD:')
for c in cov:
    print(f'  {c:10s} {smd(d[c], d.steroid):+.3f}')
print('粗 OR:', np.round(or_ci(pd.crosstab(d.steroid, d.death).values), 3))

# 倾向性评分
ps_model = Pipeline([('impute', SimpleImputer(strategy='median')),
                     ('scale', StandardScaler()),
                     ('clf', LogisticRegression(max_iter=5000))])
ps_model.fit(d[cov], d.steroid)
d['ps'] = ps_model.predict_proba(d[cov])[:, 1]
d['logit_ps'] = np.log(d['ps'] / (1 - d['ps']))

# 1:1 最近邻匹配，卡钳 0.2 SD
caliper = 0.2 * d['logit_ps'].std()
used, pairs = set(), []
for i, row in d[d.steroid == 1].sort_values('ps', ascending=False).iterrows():
    cand = d[(d.steroid == 0) & (~d.index.isin(used))]
    if len(cand) == 0:
        break
    dist = (cand['logit_ps'] - row['logit_ps']).abs()
    j = dist.idxmin()
    if dist.loc[j] <= caliper:
        used.add(j)
        pairs.append((i, j))

matched = d.loc[[a for a, b in pairs] + [b for a, b in pairs]].copy()
matched['treat'] = [1] * len(pairs) + [0] * len(pairs)
print(f'\n匹配成功 {len(pairs)} 对，卡钳={caliper:.4f}')
print('匹配后 SMD:')
for c in cov:
    print(f'  {c:10s} {smd(matched[c], matched.treat):+.3f}')
print('匹配后 OR:', np.round(or_ci(pd.crosstab(matched.treat, matched.death).values), 3))
```

**实测输出：**

```
n=138, 用药组=73, 对照组=65

匹配前 SMD:
  Age        -0.094
  Bilirubin  -0.110
  Albumin    +0.469
粗 OR: [0.656 0.281 1.528]

匹配成功 49 对，卡钳=0.0961
匹配后 SMD:
  Age        -0.110
  Bilirubin  +0.117
  Albumin    +0.094
匹配后 OR: [1.    0.36 2.78]
```

**怎么读：**

1. **匹配前白蛋白严重不平衡：SMD = 0.469。** 用药组白蛋白更高（病情更轻），这本身就影响死亡。
2. **匹配后白蛋白 SMD 降到 0.094**，年龄和胆红素在 0.11 左右（略高于 0.1 的常用阈值）。
3. **粗 OR 0.656（0.281-1.528）→ 匹配后 OR 1.000（0.360-2.780）。** 原来"激素保护"的表象，主要由白蛋白不平衡造成。
4. **匹配后 CI 很宽（0.36-2.78），仍然不能排除有效或有害。** 样本从 138 降到 98，精度下降。

**PSM 不能证明因果。** 它只能平衡"已测"的混杂。如果存在未测混杂（比如体力状态、经济条件），PSM 无法修正。

#### PSM 的五个局限

| 局限 | 说明 |
|---|---|
| 只平衡已测混杂 | 未测混杂仍然存在 |
| 需要阳性区域（positivity） | 某些评分区间只有一组人，无法匹配 |
| 样本损失 | 本数据 138 → 98，精度下降 |
| 平衡 ≠ 因果 | SMD < 0.1 只说明协变量可比，不说明无混杂 |
| 不能处理测量误差 | 协变量测错，PS 也错 |

### 7.6 其他偏倚

| 偏倚 | 定义 | 例子 | 对策 |
|---|---|---|---|
| 永生时间偏倚 | 暴露组被保证存活到暴露开始 | 随访期间用药 | time zero 前定义暴露 / 时变协变量 |
| 领先时间偏倚 | 筛查把诊断提前，看起来生存更长，其实没延长寿命 | 筛查组 5 年生存率更高 | 报告死亡率，不只看生存率 |
| 长度偏倚 | 筛查更容易发现生长慢的肿瘤 | 筛查发现的肿瘤预后更好 | 随机对照筛查试验 |
| 发表偏倚 | 阳性结果更容易发表 | 文献里效应普遍偏大 | 注册、漏斗图、阴性结果也投 |

### 7.7 常见错误

| 错误 | 表现 | 后果 | 正确做法 |
|---|---|---|---|
| 只纳入手术病人 | "术后死亡率 2%" | 外推性差 | 说明纳排标准，讨论局限 |
| 完整病例分析不比较 | 直接 dropna | 选择偏倚 | 比较缺失组和非缺失组 |
| 把中介当混杂 | 调整治疗后变量 | 过度调整，效应被抵消 | 只调整治疗前变量 |
| PSM 后不做平衡检查 | 直接报 OR | 匹配可能失败 | 报 SMD 表 |
| PSM 当因果 | "PSM 后证明有效" | 过度推断 | 只说"关联"，不说"因果" |
| 忽略永生时间 | 随访期间用药 | 严重低估 HR | landmark / 时变协变量 |
| 不讨论未测混杂 | 只报调整后 OR | 审稿人质疑 | E-value 敏感性分析 |

### 7.8 审稿人会问什么
**问：为什么只纳入做了手术的病人？结论能推广吗？**

答：研究问题是"肝切除术后结局"，所以纳排标准限定手术病人，这是设计需要。结论只适用于手术候选者，不能推广到所有肝癌病人。我们在讨论中明确写了这一点，并与不能手术人群的文献做了对比。

**问：PSM 后 OR 从 0.66 变成 1.00，说明激素无效吗？**

答：不能。匹配后 OR = 1.00，95% CI 0.36-2.78，数据与"无效""有害""有益"都相容。只能说"未发现激素与死亡的相关性"，且样本量不足以排除中等效应。PSM 只平衡了年龄、胆红素、白蛋白三个已测混杂，未测混杂仍可能存在。

**问：怎么处理未测混杂？**

答：粗 OR = 0.656 的 E-value 为 2.42：只要存在一个与暴露和结局的关联强度都约 2.4 的未测混杂，就足以把粗 OR 拉回 1。匹配后 OR = 1.00（95% CI 0.36-2.78），E-value = 1，说明"无关联"这个结果本身无法用 E-value 排除混杂。考虑到体力状态、社会经济因素可能与死亡相关，不能排除未测混杂。因此结论是"关联"，不是"因果"。

## 八、统计分析计划：防止 p-hacking 的唯一办法
### 8.1 核心问题
**为什么必须在看数据前写分析计划？**

因为人是有偏的。看到数据后，你会不自觉地：

- 换一个检验，直到 p < 0.05
- 加一个协变量，直到 HR 显著
- 切一个亚组，找到"有效"的人群
- 把连续变量切成两半，找最佳切点

**这些操作单独看都"合理"，合起来就是 p-hacking。** 统计分析计划（SAP）的作用，是把所有这些选择提前锁死。

### 8.4 p-hacking 的七种表现

| 表现 | 看起来像什么 | 为什么错 |
|---|---|---|
| 改主要终点 | "我们最终关注的是..." | 终点应该是研究设计的一部分 |
| 改阈值 | 试了 10 个 cut，选 p 最小的 | 阈值应在验证集预设 |
| 加删协变量 | 逐步回归直到显著 | 变量选择应由临床知识驱动 |
| 亚组钓鱼 | "在女性亚组有效" | 交互检验不显著就不能这么说 |
| 换检验 | t 不显著换 Mann-Whitney | 检验应在 SAP 里定 |
| 只报显著 | 10 个指标只报 2 个 | 选择性报告 |
| 中途看数据 | 每收 20 例看一次 p | 增加假阳性，需 alpha spending |

**"换个检验就显著"是真实存在的。** 同一份数据，t 检验 p = 0.06，Mann-Whitney p = 0.04，你选哪个？如果 SAP 里写的是 t，就必须报 t，然后解释 p = 0.06。

### 8.5 报告规范

| 研究类型 | 规范 | 核心要求 |
|---|---|---|
| 观察性研究 | STROBE | 纳排、偏倚、样本量、统计方法 |
| 预测模型 | TRIPOD | 变量、缺失、过拟合、校准、外部验证 |
| 随机对照试验 | CONSORT | 随机化、盲法、意向性分析 |
| 系统综述 | PRISMA | 检索、筛选、偏倚评估 |
| 肿瘤标志物 | REMARK | 样本、检测、cutoff、验证 |

**投稿前对照清单逐条打勾。** 审稿人经常直接拿这些清单问你。

### 8.6 常见错误

| 错误 | 表现 | 正确做法 |
|---|---|---|
| 没有 SAP | 边分析边决定 | 看数据前写 |
| SAP 写了不执行 | 实际分析和 SAP 不一致 | 不一致要在论文里说明 |
| 主要终点有 5 个 | "主要终点包括..." | 只能有一个 |
| 缺失处理没预设 | 看结果选插补方法 | 预先定 |
| 亚组没预设 | 事后切 10 个亚组 | 最多 4 个，交互检验 |
| 不注册 | 回顾性研究觉得不用注册 | 尽量注册，至少存档 SAP |

### 8.7 审稿人会问什么
**问：你的分析是预设的还是探索性的？**

答：主要终点和分析方案在研究开始前写入了 SAP，并在机构存档。论文中报告的主要分析完全按 SAP 执行；事后探索性分析在结果中明确标注"探索性"，不做因果解释。

**问：为什么主要终点只有一个？**

答：多个主要终点会稀释 alpha，增加假阳性。我们把 5 年肝癌发生率定为唯一主要终点，其余（诊断准确性、全因死亡、亚组）都是次要或探索性。

**问：实际分析和 SAP 不一致怎么办？**

答：任何偏离都要在论文中说明原因，并同时报告 SAP 分析和实际分析。如果偏离是因为数据质量问题（如某个变量缺失太多），要写清楚。隐匿偏离是学术不端。

## 十、自测题（先自己答，再看答案）
**Q1. 一组 ALT 数据右偏，还有一个 3000 的病人。描述用均值 ± SD 还是中位数 (IQR)？为什么？**

<details>
<summary>看答案</summary>

用**中位数 (IQR)**。

右偏 + 离群值会把均值拉高。本讲义的例子：10 个 ALT 里 9 个在 20-60，1 个 3000，均值 336，中位数 42.5。均值不能代表大多数人。

配套检验用 Mann-Whitney U，不要求正态。不能写"中位数 (IQR) + t 检验"，描述和检验必须匹配。

</details>

**Q2. p = 0.03 是什么意思？p = 0.04 和 p = 0.06 的区别在医学上有意义吗？**

<details>
<summary>看答案</summary>

p = 0.03 的意思是：**如果原假设成立（两组真的没差异），重复同样的研究，约 3% 会得到当前或更极端的差异。**

它不是"原假设为真的概率"，不是"效应很大的概率"，也不是"97% 可重复"。

p = 0.04 和 0.06 的差别只是有没有跨过 0.05 这条人为线。医学上更重要的是效应量和 CI。例如本讲义胆红素多因素 OR = 1.77（95% CI 0.995-3.153），p = 0.052：数据既不能排除无效，也不能排除 3 倍风险。不能简单说"无效"。

</details>

**Q3. 你比较了 20 个指标，至少出现 1 个假阳性的概率是多少？怎么处理？**

<details>
<summary>看答案</summary>

```
1 - 0.95^20 = 1 - 0.3585 = 0.6415
```

**64.2%。** 期望假阳性 1 个。

处理：预先设定主要终点（不校正），其余探索性指标用 BH-FDR 或 Bonferroni。校正方法要写进 SAP，不能看完结果再选。

</details>

**Q4. 2x2 表里有一个格子是 0，还能用卡方吗？**

<details>
<summary>看答案</summary>

不能。只要任一格**期望频数 < 5**，就用 Fisher 精确检验。

判断标准不是总样本量，是期望频数：

```
期望频数 = 行合计 × 列合计 / 总样本量
```

本数据性别分析中，女性死亡人数为 0，最小期望频数 3.3 < 5，所以用 Fisher（p = 0.044）。

</details>

**Q5. 同一批病人用两种方法检测，比较阳性率，用什么检验？为什么不能用卡方？**

<details>
<summary>看答案</summary>

用 **McNemar 检验**。

同一批人被算了两次，两次结果相关，不满足卡方的独立性假设。McNemar 只看不一致的格子 b 和 c：

```
chi2 = (|b - c| - 1)^2 / (b + c)
```

本数据 b = 24、c = 14，chi2 = 2.132，p = 0.144，两种规则阳性率差异不显著。

</details>

**Q6. 为什么生存分析不能直接用 logistic 回归？**

<details>
<summary>看答案</summary>

因为**删失**。

- 研究结束时仍存活的人，只知道"至少活到某时"
- 失访的人，只知道"失访前还活着"
- 随访时间长短不一

logistic 需要二分类结局，会把删失当"未发生事件"，低估风险，并完全忽略时间信息。

本数据实测：同一份合成随访数据，logistic 的 OR = 1.80，Cox 的 HR = 2.36。两者不是同一个量。

</details>

**Q7. HR = 2.36 是什么意思？能不能说"生存时间缩短 2.36 倍"？**

<details>
<summary>看答案</summary>

HR = 2.36 的意思是：**该因素每增加 1 单位（或该组 vs 对照组），瞬时死亡风险是原来的 2.36 倍。**

不能说"生存时间缩短 2.36 倍"。HR 是风险比，不是时间比。只有在指数分布下，HR = 2 才大致对应中位生存时间减半；其他分布不一定。

正确写法："胆红素升高组死亡风险是正常组的 2.36 倍（HR = 2.36, 95% CI 1.48-3.76）。"

</details>

**Q8. 比例风险假设怎么检验？违反了怎么办？**

<details>
<summary>看答案</summary>

三种方法：

1. **Schoenfeld 残差检验**：`proportional_hazard_test`，看残差与时间是否相关
2. **图形法**：log(-log S(t)) vs log(t)，两条线应平行
3. **时间分段**：前 12 个月和后 12 个月各拟合一次，比 HR

违反了：

- 分层 Cox（按违反假设的变量分层）
- 时变系数（X × log(t)）
- 分段报告 HR
- RMST（限制平均生存时间）
- 竞争风险模型（Fine-Gray）

不能假装没看见，继续报平均 HR。

</details>

**Q9. 灵敏度 90%、特异度 90% 的检测，在患病率 0.1% 的人群里 PPV 是多少？**

<details>
<summary>看答案</summary>

```
PPV = 0.9 × 0.001 / [0.9 × 0.001 + 0.1 × 0.999]
    = 0.0009 / (0.0009 + 0.0999)
    = 0.00893
    = 0.893%
```

**不到 1%。** 每 10 万人，真阳性 90，假阳性 9,990。

同一个检测，在患病率 50% 的人群里 PPV = 90%。**PPV 随患病率变化，灵敏度和特异度不变。** 论文必须写研究人群的患病率。

</details>

**Q10. 两个模型 AUC 0.821 和 0.825，怎么比较？**

<details>
<summary>看答案</summary>

用 **DeLong 检验**，不能直接比数字大小。

- 必须同一批病人（配对）
- 零假设：两个 AUC 相等
- 本数据实测：z = -0.300，p = 0.764

p = 0.764，差异没有统计学意义。不能写"0.825 的模型更好"。

如果 DeLong 显著（如 6 项 vs 仅年龄，p = 0.001），才能说多变量模型更优。但还要看 DCA，确认临床净收益。

</details>

## 十二、常见错误总表

| 错误 | 现象 | 后果 | 正确做法 |
|---|---|---|---|
| 不判断分布 | 偏态数据报均值±SD | 均值被离群值拉偏 | 先看直方图/Shapiro |
| 描述与检验不匹配 | 中位数 + t 检验 | 审稿人直接指出 | 描述和检验一致 |
| 用 SE 代替 SD | 表 1 写"均值±SE" | 数据看起来过窄 | 表 1 用 SD |
| 期望频数 <5 用卡方 | 2x2 有 0 | p 值不准 | Fisher |
| 配对数据用卡方 | 同一批人两种检测 | 忽略相关性 | McNemar |
| 把缺失当 0 | 布尔比较生成 0/1 | 缺失变成"无特征" | `map` 保留 NaN |
| 照抄 codebook | 编码方向反了 | 阳性率反了 | 用临床合理性验证 |
| 把 p 当效应量 | "p<0.001 说明效果好" | 效应可能很小 | 报 OR/HR/d + CI |
| 只报 p 不报 CI | `p=0.03` | 精度未知 | 所有主要结果带 CI |
| 把"不显著"当"无效" | "两组无差异" | 过度解读 | "未发现显著差异，CI 为..." |
| 把 OR 当 RR | "风险增加 3 倍" | 夸大效应 | "odds 增加 3 倍" |
| 20 个指标不校正 | 只报 1 个 p=0.03 | 假阳性 | BH / Bonferroni |
| 事后选校正方法 | 哪个显著用哪个 | p-hacking | SAP 预设 |
| 生存分析用 logistic | 删失当无事件 | 效应被稀释 | Cox / KM |
| 把 OR 当 HR | "HR = OR" | 含义不同 | HR 说"瞬时风险" |
| 时间零点定错 | 从确诊算，治疗延后 | 永生时间偏倚 | 统一定义 time zero |
| 随访期间定义暴露 | "用过药"=暴露 | 永生时间偏倚 | time zero 前定义 |
| 曲线交叉报平均 HR | HR 无意义 | 结论误导 | 分段 HR / RMST |
| 忽略竞争风险 | 非肝癌死亡当删失 | 高估风险 | Fine-Gray |
| EPV 不足 | 89 事件放 15 变量 | 过拟合 | 每变量 ≥10 事件 |
| 病例对照算 PPV | 1:1 纳入 | PPV 虚高 | 按真实患病率重算 |
| 直接比两个 AUC | "0.825>0.821" | 差异是噪声 | DeLong |
| 阈值在测试集选 | 看结果定 cut | 乐观偏倚 | 训练/验证集定 |
| 只看 AUC 不看 DCA | AUC 0.9 但无净收益 | 临床无用 | 加 DCA |
| 事后功效 | 用观察效应算 power | 无信息 | 分析前算 |
| 只纳入手术病人 | "术后死亡率 2%" | 外推性差 | 说明纳排，讨论局限 |
| 完整病例不比较 | 直接 dropna | 选择偏倚 | 比较缺失/非缺失 |
| 把中介当混杂 | 调整治疗后变量 | 过度调整 | 只调整治疗前变量 |
| PSM 当因果 | "PSM 证明有效" | 过度推断 | 只说关联 |
| 没有 SAP | 边看边分析 | p-hacking | 看数据前写 |
