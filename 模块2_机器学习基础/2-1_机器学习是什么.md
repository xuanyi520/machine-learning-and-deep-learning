## 一、和传统编程的区别

**传统编程**：人写规则，程序执行。

```python
def 判断肝癌风险(afp, 年龄, 直径):
    if afp > 400 and 直径 > 5:
        return "高风险"
    elif afp > 200:
        return "中风险"
    else:
        return "低风险"
```

问题：这些阈值（400、5、200）哪来的？是专家拍的。换个医院、换个人群就不准了。

**机器学习**：人不写规则，人给**数据**和**答案**，让程序自己找出规则。

```python
# 你给 5000 个历史病例，每个都有检查值和最终诊断
model.fit(X, y)          # 模型自己找规则
model.predict(新患者)     # 用学到的规则预测
```

"学到的规则"就是那堆参数（权重）。

**一句话总结**：传统编程是人写逻辑，机器学习是人给例子。

## 二、三类任务

### 监督学习（Supervised）—— 有答案

给的数据带标签。

**分类**：输出是类别。
- 肿瘤是良性还是恶性
- 这张 CT 有没有病灶
- 患者属于哪一期

**回归**：输出是连续数值。
- 预测肿瘤直径（单位 mm）
- 预测住院天数
- 预测术后生存时间

### 无监督学习（Unsupervised）—— 没答案

给的数据只有输入，没有标签，让算法自己找结构。

- **聚类**：把患者按检查指标自动分成几组（可能对应不同的亚型）
- **降维**：把 1000 个基因表达值压缩成 10 个主成分

### 强化学习（Reinforcement）

智能体与环境交互，通过奖励信号学习策略。

- 手术机器人训练
- 药物剂量动态调整

**你这三个月主要学监督学习。** 医疗 AI 落地最多的也是它。

## 三、数据怎么分：训练 / 验证 / 测试

这是新手最容易犯的错误之一：**用训练数据评估模型。**

模型在训练数据上表现好，可能只是因为它**背下来了**，不代表它学会了。就像考试前你把答案背了，考原题你满分，考变式你就完了。

标准做法，把数据切成三份：

| 集合 | 比例 | 用途 |
|---|---|---|
| 训练集 train | 70% | 用来学习参数 |
| 验证集 val | 15% | 用来调超参数、选模型 |
| 测试集 test | 15% | **最后只用一次**，报告最终性能 |

**规则：测试集碰一次就够了。** 如果你根据测试集的结果反复调参，测试集就被污染了，报出来的数字是虚高的。

医学研究里更严格，常用**交叉验证**（K-fold），因为样本量小。这个概念现在知道有就行。

## 四、损失函数

损失函数（loss）衡量"预测得有多差"。

- 预测 5.0，真实 5.1 → 损失很小
- 预测 5.0，真实 9.0 → 损失很大

训练的目标就是**让损失变小**。

### 两种你会天天见的损失

**均方误差 MSE**（回归任务）：

```
MSE = 平均( (预测值 - 真实值)² )
```

平方是为了让正负误差都变成正数，且放大大误差的惩罚。

**交叉熵 Cross-Entropy**（分类任务）：

衡量两个概率分布的差异。现在只要知道名字和用途，第 9 周你会发现 PyTorch 一行就能调用。

**关键认知**：损失函数是一个关于模型参数的函数。训练就是在这个函数上做梯度下降（你 W3 学的东西）。

## 五、参数量怎么估

一个全连接层，把 n 维输入映射到 m 维输出：

- 权重矩阵 W：`n × m` 个参数
- 偏置 b：`m` 个参数
- 总计：`n × m + m`

例：784 维输入 → 10 维输出。

```
784 × 10 + 10 = 7850 个参数
```

**这个技能很实用**，面试常问，而且以后你估算模型大小、显存占用都要用。

## 六、过拟合（先有个印象）

- **欠拟合**：模型太笨，训练集上都学不好
- **过拟合**：模型把训练集背下来了，训练集上分很高，新数据上很差
- **恰好**：训练集和验证集都不错

判断方法就是**看训练集和验证集的差距**。如果训练集准确率 99%、验证集 80%，那就是严重过拟合。

W7 会讲怎么解决（正则化、Dropout、数据增强）。

## 八、自测题

1. 传统编程和机器学习的根本区别是什么？
2. 为什么不能只用训练集评估模型？
3. 验证集和测试集的区别是什么？
验证集用来调超参数和选模型（可以用很多次）；测试集只在最后用一次，报告最终性能。如果根据测试集结果反复调参，测试集就污染了
4. 损失函数的作用是什么？
衡量预测和真实答案的差距，是训练时要最小化的目标
5. 过拟合怎么判断？
看训练集和验证集的性能差距。差距大 = 过拟合
