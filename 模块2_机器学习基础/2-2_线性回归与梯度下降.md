***

## 一、目标

用一条直线拟合一批数据。

数据：一组 `(x, y)`，希望找到 `y = w*x + b`，让这条线尽量贴近所有点。

例如：一个人的身高 x，体重 y。找一条线描述这个关系。

**两个参数**：w（斜率）、b（截距）。训练就是要找到最好的 w 和 b。

***

## 二、损失函数：MSE

怎么衡量"线贴不贴"？

对每个点，算预测值和真实值的差，平方，再对所有点求平均：

```
loss = (1/N) * Σ (y_pred - y_true)²
```

其中 `y_pred = w*x + b`。

**loss 越小，线越贴。** 所以问题变成了：找 w 和 b，让 loss 最小。

***

## 三、手推梯度（关键步骤）

loss 是 w 和 b 的函数。要梯度下降，需要知道 loss 对 w 和 b 的偏导数。

```
loss = (1/N) Σ (w*xᵢ + b - yᵢ)²
```

记 `eᵢ = w*xᵢ + b - yᵢ`（第 i 个点的误差）。

**对 w 求偏导**：链式法则。外层是平方，导数是 `2eᵢ`；内层 `w*xᵢ + b` 对 w 的导数是 `xᵢ`。

```
∂loss/∂w = (2/N) Σ eᵢ * xᵢ
```

**对 b 求偏导**：内层对 b 的导数是 1。

```
∂loss/∂b = (2/N) Σ eᵢ
```

**别背公式，理解推导过程。** 先自己用 W3 的链式法则推一遍，推不出来再看答案。

***

## 四、跟着做：完整实现

```python
import numpy as np
import matplotlib.pyplot as plt

matplotlib.rcParams['font.sans-serif'] = ['SimHei']
matplotlib.rcParams['axes.unicode_minus'] = False

np.random.seed(42)

# ========== 1. 造数据：真实关系是 y = 2.5x + 1，加点噪声 ==========
N = 200
x = np.random.rand(N) * 10          # 0~10 之间
true_w, true_b = 2.5, 1.0
y = true_w * x + true_b + np.random.randn(N) * 1.5   # 加噪声

# ========== 2. 初始化参数（随便给个数）==========
w = 0.0
b = 0.0
lr = 0.01

losses = []

# ========== 3. 训练循环 ==========
for epoch in range(1000):
    # --- 前向：算预测 ---
    y_pred = w * x + b

    # --- 算损失 ---
    error = y_pred - y
    loss = np.mean(error ** 2)
    losses.append(loss)

    # --- 反向：算梯度（上面推的公式）---
    dw = (2 / N) * np.sum(error * x)
    db = (2 / N) * np.sum(error)

    # --- 更新参数 ---
    w = w - lr * dw
    b = b - lr * db

    if epoch % 100 == 0:
        print(f"epoch {epoch:4d}  loss={loss:9.4f}  w={w:7.4f}  b={b:7.4f}")

print(f"\n学到的:  w={w:.4f}  b={b:.4f}")
print(f"真实的:  w={true_w:.4f}  b={true_b:.4f}")
```

**跑通它。** 你应该看到 w 从 0 爬到接近 2.5，b 从 0 爬到接近 1.0。loss 一路下降。

如果学到的参数离真值还有点距离，那是噪声导致的，正常。

## 七、用矩阵重写（进阶，必做）

上面用的是单个 x。现实中你有一堆特征（年龄、AFP、直径……），所以要写成矩阵形式。

```python
# X 形状 (N, 2)，多加一列全 1 用来吸收偏置 b
X = np.column_stack([x, np.ones(N)])     # 第二列全是 1
w_vec = np.zeros(2)                       # [w, b]

lr = 0.01
for epoch in range(1000):
    y_pred = X @ w_vec                    # 矩阵乘法！
    error = y_pred - y
    loss = np.mean(error ** 2)

    grad = (2 / N) * (X.T @ error)        # 梯度的矩阵形式
    w_vec = w_vec - lr * grad

print("w, b =", w_vec)
```

**注意 `X.T @ error` 这个写法。** 它是 `(2, N) @ (N,) = (2,)`，正好得到 [dw, db] 两个数。

这就是 W2 学的形状规则的实战应用：`X` 是 `(N, 2)`，`X.T` 是 `(2, N)`，乘 `(N,)` 的 error，得到 `(2,)` 的梯度。

**这个形式才是工业界的写法**，因为特征可以有很多个。

## 九、自测题

1. 线性回归的损失函数是什么？
(1/N) Σ (预测 - 真实)²
2. 为什么梯度下降要"减"梯度？
因为梯度指向上升最快的方向，要降低 loss 就得往反方向走
3. `X.T @ error` 的形状是什么？怎么推出的？
X 是 (N, d)，X.T 是 (d, N)，error 是 (N,)，所以 X.T @ error 是 (d,)——正好是 d 个参数的梯度
4. 学习率为 0.6 时可能发生什么？
可能震荡不收敛，甚至发散（loss 变大或变 nan）
5. 为什么要在 X 里加一列全 1？（提示：想想偏置 b 去哪了）
因为 b 相当于对应"特征恒为 1"的权重，拼进权重向量后可以统一写成矩阵乘法，代码更简洁
