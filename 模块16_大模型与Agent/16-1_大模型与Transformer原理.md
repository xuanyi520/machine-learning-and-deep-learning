## 〇、这一节在解决什么

你在模块 3 学过一件事：

```python
out = model(xb)
loss = criterion(out, yb)
```

**模型是一个函数，输入张量，输出概率。**

大模型也一样。**它还是那个函数，只不过：**

| | 你的 MNIST 模型 | 大模型 |
|---|---|---|
| 输入 | 一张 28×28 的图 | 一段文字的编号序列 |
| 输出 | 10 个类别的概率 | 下一个词的概率（词表几万个） |
| 参数 | 42 万 | 几千亿 |
| 训练目标 | 猜对数字 | 猜对下一个词 |

**核心就这一句：大模型是一个「猜下一个词」的模型，别的本事都是从这句话里长出来的。**

这一节要拆的，就是这三件事：

1. 文字怎么变成输入张量（token）
2. 中间那层到底在算什么（注意力）
3. 为什么它能说得像人话，又为什么会胡说八道（采样 + 幻觉）

## 一、token：模型眼中的世界

**模型不认识汉字，也不认识英文单词。它认识的只有整数。**

把文字切成小块、每块编一个号，这个过程叫 **分词（tokenization）**，每个小块叫一个 **token**。

### 切分规则不直观

英文大致按词根切：

```
"tokenization"  →  ["token", "ization"]
"unbelievable"  →  ["un", "believ", "able"]
```

**中文的切法更碎。** 一个汉字经常就是一个 token，但常用词可能合成一个：

```
"医学影像"      →  可能是 ["医学", "影像"]，也可能切成 4 个单字
```

**具体切几个，取决于模型的分词表。不同厂商的表不一样。**

### 一个必须记住的单位换算

```
1 个汉字   ≈ 1 到 1.5 个 token
1 个英文单词 ≈ 1.3 个 token
1000 个汉字 ≈ 1000 到 1500 token
```

**为什么要记这个**：所有计费、所有上下文限制，单位都是 token，不是字数。

### 上下文窗口

你配置里那个 `[1M]` 就是这个意思：

```
1M = 1,048,576 个 token ≈ 70 万到 100 万汉字
```

**这是「一次最多能塞进去多少」，包括你发的和它回的。**

## 二、Transformer 和前馈网络的根本区别

你在模块 3 搭的全连接网络长这样：

```
输入(784) → 线性 → ReLU → 线性 → ReLU → 线性 → 输出(10)
```

**每一层都是：所有输入乘上对应的权重，加起来。**

问题在于：**位置 1 的输入和位置 100 的输入，在进第一层的时候，彼此毫无关系。** 信息要层层传递才能相遇。

**文本不行。** 读「病人主诉发热，但白细胞不高」这句话，「发热」和「白细胞不高」必须**直接**发生关系，才能理解成「可能是病毒感染」。

**Transformer 的解决办法：让每个位置能直接看到所有其他位置。**

这个机制叫 **注意力（Attention）**。

### 一句话对比

| | 全连接 / 卷积 | 注意力 |
|---|---|---|
| 谁能看见谁 | 只看相邻位置或全部但线性叠加 | **每个位置直接看全部位置，按相关度加权** |
| 权重 | 固定的（训练学出来的） | **临时的（每次输入现算）** |

**「权重是现算的」这一条是关键。** 同一个词，在不同的句子里，它关注的词不一样。

## 三、注意力：手算一遍

这是本节的核心，必须自己算一遍。

### 三个角色

每个 token 会被算成三个向量：

| 名字 | 全称 | 打个比方 |
|---|---|---|
| **Q** | Query 查询 | 「我在找什么」 |
| **K** | Key 键 | 「我是什么」 |
| **V** | Value 值 | 「我有什么内容」 |

**流程：**

```
1. 拿我的 Q，和每个 token 的 K 算相似度（点积）
2. 相似度除以 sqrt(维度)，防止数值太大
3. 过 softmax，变成加起来等于 1 的权重
4. 用这些权重，把所有 token 的 V 加权求和
```

**一句话：我用「我在找什么」去比「你是什么」，找到最像的几个，把它们的内容按相似度加权拿走。**

### 手算

下面是真能跑通的代码，三个 token，每个两维：

```python
import numpy as np
np.set_printoptions(precision=3, suppress=True)

Q = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
K = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
V = np.array([[10.0, 0.0], [0.0, 10.0], [5.0, 5.0]])

# 第一步：相似度
scores = Q @ K.T
print("QK^T =")
print(scores)

# 第二步：缩放
d = Q.shape[1]
scaled = scores / np.sqrt(d)

# 第三步：softmax
def softmax(x):
    e = np.exp(x - x.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

w = softmax(scaled)
print("注意力权重 =")
print(w)
print("每行和 =", w.sum(axis=1))

# 第四步：加权求和
out = w @ V
print("输出 =")
print(out)
```

**实际输出（我本机跑出来的）：**

```
QK^T =
[[1. 0. 1.]
 [0. 1. 1.]
 [1. 1. 2.]]

注意力权重 =
[[0.401 0.198 0.401]
 [0.198 0.401 0.401]
 [0.248 0.248 0.503]]
每行和 = [1. 1. 1.]

输出 =
[[6.017 3.983]
 [3.983 6.017]
 [5.    5.   ]]
```

### 怎么读这个结果

**第一行 `[0.401, 0.198, 0.401]`**：第一个 token 的 Q 和第一个 K 最像（点积 1），和第二个最不像（0），所以它从第一个和第三个那里各拿 40%，从第二个只拿 20%。

**第三行 `[0.248, 0.248, 0.503]`**：第三个 token 的 Q 和第三个 K 最像（点积 2），所以最大的权重给了自己。

**输出为什么都是正数**：因为 V 里没有负数，加权平均不可能出负数。

### 为什么要除以 sqrt(d)

**不除的话会怎样**：点积的数值随着维度增大而变大。维度 512 的时候，点积可能到几百，softmax 之后会变成 `[1.0, 0.0, 0.0, ...]`——**完全变成一个位置在说话，其他全被压成 0。梯度也就没了。**

除以 `sqrt(512) ≈ 22.6` 把尺度拉回正常范围。

**这是 Transformer 论文里专门讲的一段，面试会问。**

### 多头注意力

上面算的是一次注意力。实际模型里会同时算 8 个或 16 个，每个用不同的 Q/K/V 权重矩阵。

```
8 个头各看各的 → 有的盯语法关系，有的盯指代，有的盯位置
    ↓
拼起来 → 再过一层线性层
```

**为什么要多头**：一次只能学一种「相似」的定义。多头让模型同时关心多种关系。

### 位置编码

注意力有个致命问题：**它不管顺序。**

「猫追狗」和「狗追猫」，注意力算出来一模一样。

所以要把位置信息加进去——给每个位置的向量加一个固定的模式，让模型能区分「第几个」。

**你知道这回事就行，具体怎么加不用手推。**

## 四、为什么它会胡说八道

这是大模型最需要理解的一件事。

### 训练目标决定的

**它的训练目标只有一个：给定前面的词，猜下一个词最可能是什么。**

**注意：是「最可能」，不是「正确」。**

举个真实的例子：

```
输入：中国的首都是___
```

训练数据里「北京」出现得最多，所以模型学会了输出「北京」。这个是对的。

但是：

```
输入：张三的身份证号是___
```

训练数据里没有「张三」，模型不知道。**但它必须输出点什么**——因为它的任务就是猜下一个词。

于是它会输出一个**格式上像身份证号、但完全是编的**字符串。

### 这就是幻觉（hallucination）

> **模型没有「我不知道」这个选项。它只有「下一个词最可能是什么」这个任务。**

**所以它编，而且编得很自信。**

### 三个常见触发场景

| 场景 | 例子 | 为什么 |
|---|---|---|
| 问事实 | 「2024 年诺贝尔医学奖得主是谁」 | 训练数据可能没有，或者记错了 |
| 问引用 | 「哪篇论文提出了 U-Net」 | 会编出不存在的论文标题和作者 |
| 问精确数字 | 「这个药的半衰期是多少小时」 | 数字最容易被编 |

### 正确的应对方式

1. **不要问它「是不是对的」，问它「这句话的依据是什么」**——编的依据也编
2. **事实类问题，让它查资料（这就是 16-4 RAG 要做的事）**
3. **关键结论必须自己核对原始来源**

**记住这条：它能帮你「想」，不能帮你「查」。**

## 五、第一次调用 API

### 请求长什么样

**所有大模型 API 的形状都一样：**

```
发出去：一串 message（谁说了什么）+ 一些参数
收回来：下一段文字 + token 用量
```

### 本机实测可用的代码

用 `requests` 直接发，不装任何 SDK——这样你能看清原始请求长什么样。

**先做一件事：把你的 API Key 存进环境变量，不要写在代码里。**

Windows 命令行临时设置：

```
set DEEPSEEK_API_KEY=你的key
```

PowerShell：

```
$env:DEEPSEEK_API_KEY="你的key"
```

然后跑这段（我在你本机跑通了，2.19 秒返回）：

```python
import os, json, requests, time

key = os.environ["DEEPSEEK_API_KEY"]

t0 = time.time()
r = requests.post(
    "https://api.deepseek.com/anthropic/v1/messages",
    headers={
        "x-api-key": key,
        "anthropic-version": "2023-06-01",
        "content-type": "application/json",
    },
    json={
        "model": "deepseek-flash",
        "max_tokens": 200,
        "messages": [
            {"role": "user", "content": "用一句话说明什么是注意力机制"}
        ],
    },
    timeout=60,
)

print("状态码:", r.status_code, "耗时: %.2fs" % (time.time() - t0))
d = r.json()
print("返回的键:", list(d.keys()))
for b in d["content"]:
    print(f"[{b['type']}] {b.get('text', '')}")
print("用量:", d.get("usage"))
```

**实际返回：**

```
状态码: 200 耗时: 2.19s
返回的键: ['id', 'type', 'role', 'model', 'content', 'stop_reason', 'stop_sequence', 'usage']
[thinking] 
[text] 注意力机制是一种让模型根据当前任务动态地为输入信息分配不同权重、从而聚焦关键部分的计算方法。
用量: {'input_tokens': 36, 'cache_creation_input_tokens': 0,
      'cache_read_input_tokens': 0, 'output_tokens': 64,
      'service_tier': 'standard'}
```

### 三个必须看懂的字段

**① `content` 是一个列表，不是字符串。**

你可能拿到多个块：

```
[thinking]  ← 模型的思考过程（推理模型才有）
[text]      ← 真正的回答
```

**写代码时必须过滤，只要 `type == "text"` 的。** 这是新手第一个坑。

```python
answer = "".join(b["text"] for b in d["content"] if b["type"] == "text")
```

**② `usage` 里有三行 token 数，决定你花多少钱。**

| 字段 | 含义 | 单价 |
|---|---|---|
| `input_tokens` | 这次新读进去的 | 最贵 |
| `cache_read_input_tokens` | 命中缓存的 | **便宜 50 倍** |
| `output_tokens` | 生成出来的 | 中等 |

**③ `stop_reason`**

| 值 | 意思 |
|---|---|
| `end_turn` | 正常说完了 |
| `max_tokens` | **被 `max_tokens` 截断了**，回答不完整 |

**看到 `max_tokens` 就把 `max_tokens` 调大，别以为是模型不会答。**

## 六、采样参数：为什么同一个问题答案不同

### temperature

```
temperature = 0    → 每次选概率最高的那个词，完全固定
temperature = 0.7  → 按概率抽，有随机性（默认值附近）
temperature = 1.5  → 很随机，可能语无伦次
```

**怎么选：**

| 任务 | temperature |
|---|---|
| 提取信息、分类、写代码 | **0** |
| 写报告、总结 | 0.3 - 0.7 |
| 头脑风暴、起名 | 1.0 以上 |

**你要做的医学相关任务，一律 0。** 原因：你要的是可复现。同一个病人在同一个模型上，今天说明天说不一样，这在医疗场景里是灾难。

### 其他参数（知道有就行）

| 参数 | 作用 |
|---|---|
| `top_p` | 只从累计概率前 p 的词里抽，通常和 temperature 二选一 |
| `max_tokens` | 最多生成多少 token |
| `stop` | 遇到这些字符串就停 |

## 十一、常见错误

| 错误 | 表现 | 原因 | 改法 |
|---|---|---|---|
| 把 `content` 当字符串用 | `TypeError: list indices must be integers` | 它是列表 | `"".join(b["text"] for b in d["content"] if b["type"]=="text")` |

| 回答被截断 | 话说一半 | 撞到 `max_tokens` | 看 `stop_reason`，调大 `max_tokens` |
| 用 `temperature=0.7` 做医疗任务 | 同一输入输出不同，不可复现 | 采样有随机性 | 改 0 |
| key 写死在代码里 | 分享代码就泄露 | 图省事 | 读环境变量 |

## 十二、学完该能回答的问题

面试里关于大模型原理，问得最多的就是这几个：

1. 「你了解 Transformer 吗？」→ 讲注意力，讲 Q/K/V，讲多头
2. 「大模型为什么会产生幻觉？」→ 讲训练目标是猜下一个词，没有「不知道」这个选项
3. 「你怎么保证输出稳定？」→ 讲 temperature=0，讲结构化输出（下一节）
4. 「token 是什么？上下文窗口是什么意思？」→ 讲切分、讲计费、讲 1M 大概多少字

**下一节 16-2 要解决的，就是第 3 个问题：怎么让它稳定按格式说话。**
