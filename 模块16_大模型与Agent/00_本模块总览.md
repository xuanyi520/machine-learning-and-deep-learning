## 〇、先回答一个问题：为什么要学这个

2026 年 11 月，我在上海地区的医疗 AI 和算法实习岗位上抽查了十几份真实 JD，
统计出来的技术要求里，有一件事反复出现：

> **几乎每份都要求 Agent、RAG、LangChain 三样中的至少一样。**

而你现有的模块 1-15，覆盖的是「机器学习 + 医学影像深度学习 + 科研统计」这条线。
这条线是**算法岗的底子**，不能丢。但它**不产出能做 Agent 的能力**。

具体差在哪，见下一节的缺口表。

## 二、一条必须说清楚的原则

> **这个模块和模块 1-15 的学习方式，不一样。**

模块 1-3 你可以从数学地基开始，一章一章往下读，因为那是封闭内容，有标准答案。

**大模型应用不行。** 它的理论加在一起不超过三页纸，剩下全是工程：
装包、调 API、报错、改 prompt、再跑。

**所以这个模块的执行纪律是：**

```
每一节结束，必须有一个「能跑起来的东西」。
不是看懂了，不是笔记写完了，是能在终端里跑出结果。
```

**理论 : 动手 = 3 : 7。** 比模块 1-15 的 4 : 6 还要更偏动手。

**判断自己有没有学会的唯一标准：能给一个没学过的人演示，并且他看懂了。**

## 四、毕业项目：医学影像 AI 助手

**这是整个模块的终点，也是简历上要放的那一行。**

```
输入一张胸部 X 光片
   │
   ├─ 预处理：DICOM 读取 → HU 换算 → 窗宽窗位
   │
   ├─ 影像模型：你模块 4-2 训出来的肺炎分类模型 → 概率
   │
   ├─ 知识检索：RAG 查临床指南，找「肺炎影像表现」相关段落
   │
   └─ 报告生成：LLM 综合影像结论 + 指南依据，输出结构化报告
        │
        └─ 每条结论带引用来源（第几版指南第几节）
```

**为什么选这个题目：**

1. 把你已经学的东西全部串起来，不是另起一摊
2. 同时覆盖 16-3、16-4、16-5、16-9 四节的出口标准
3. 医疗 AI 岗位的对口项目，比通用的「电商问答机器人」有说服力
4. 面试时能拆成四层讲：影像模型、检索、编排、服务

**交付物：**

```
项目_医学影像AI助手/
├── README.md                  ← 别人能照着重跑
├── docker-compose.yml
├── src/
│   ├── image_model/           ← 模块 4-2 的模型
│   ├── rag/                   ← 检索模块
│   ├── agent/                 ← 编排逻辑
│   └── api/                   ← FastAPI 接口
├── knowledge_base/            ← 指南原文 + 切分后的索引
├── results/
│   ├── 演示截图/
│   ├── 评估报告.md            ← 检索命中率、回答准确率
│   └── 失败案例.md
└── report.md
```

## 七、学习方式（和其他模块不同的三条）

### 第 1 条：先跑通，再理解

**模块 1-15 的顺序是：读概念 → 写代码 → 验证。**

**这个模块反过来：先复制一段能跑的代码 → 看到输出 → 再回头问为什么。**

原因：大模型的行为是概率性的，你**读十遍概念也预测不了它这次会输出什么**。只有跑起来看，才能建立直觉。

### 第 2 条：每节必须留下「失败记录」

每节讲义里我会给一些「这样写会失败」的例子。**你要自己再踩几个坑，把报错原文记下来。**

```
【失败记录】
场景：
报错原文：
原因：
改法：
```

**为什么**：面试问「你遇到过什么问题」，你答「没遇到问题」等于说「我没做过」。

### 第 3 条：不追框架

2026 年到 2027 年，Agent 框架会换掉一批。**LangChain 今天叫什么，明年可能就不叫了。**

所以：
- **原理层的东西必须手写一遍**（16-5 会要求你不用任何框架写一个 Agent）
- **框架只是加速器，不是知识**

## 八、成本预估

**这个模块比 ML 模块多一项开销：API 费用。**

| 用途 | 估算 |
|---|---|
| 16-1 到 16-3 的调用练习 | 约 10 元 |
| 16-4 RAG 的 embedding（本地模型可省） | 0-30 元 |
| 16-5 到 16-9 的 Agent 反复调试 | 约 50 元 |
| 毕业项目演示与评估 | 约 30 元 |
| **合计** | **约 100-150 元** |

**大部分练习可以用 DeepSeek 的便宜模型跑通，不需要用贵的。**

**能省的地方：** embedding 用本地模型（`BAAI/bge-small-zh`），不花钱；向量库用 Chroma（本地文件），不花钱。
